01 每回合依老師中文提供的新資料用英文說。前兩回合各一句；第三回合先否定再更正。 （12分）

只看當前回合指定中文資料和單獨名字，不看完整英語句卡或答案。

教師施測

逐回合只用中文說：①故事人物只知道名字Lee，關係沒有提供。請用一句英文只介紹Lee的名字，不加未提供的關係。只出示名字Lee。②新工作卡：Jo是烘焙師。用一句英文說Jo的工作。只出示名字Jo。③新物品卡是一本書。別人誤認是筆，請用英文先否定，再用一句話更正成書。各回合記錄才換資料，不先念英語問句或回答；本題及聽辨題完成前不回饋。 未教、無可靠完整模型、無合適機會、未回應、拒絕、受答案提示或改用不同能力，該分項記未觀察，不補0。具備條件且已實際嘗試才按規準評分。

參考答案

This is Lee.／Jo is a baker.／No, it isn’t. It’s a book.

解答理由

關係依說話角色、工作依給定卡；最後以物品框架否定及更正。

給分方式

  • 4分：①說出Lee且未添加未知關係2分；以可理解完整介紹句再2分。若只說Lee得意思2分；添加未提供關係，意思分0，完整句框架另計。
  • 4分：②正確姓名1分、正確工作詞1分；完整可理解工作描述句2分。目標為Jo及烘焙師baker，正確等義句同分。
  • 4分：③可理解完整物品否定句2分；以可理解完整句更正book2分。每部分只有意思或關鍵詞而非完整句各1分。

02 每次聽一句，選出那句真正提供的訊息或物品意思。每次只選一項。 （12分）

中文選卡分四組，老師到當次才給：①甲朋友、乙祖父、丙只介紹名字未提供關係；②甲駕駛、乙教師、丙烘焙師；③甲否定某物品條件、乙否定自己會某動作、丙肯定自己會某動作；④甲米粽、乙龍舟、丙書。

先完成口語，再依試次中文讀當組選卡，不翻譯英語對應。第1試自然讀「This is my friend, Pat.」，等待並記錄。第2試自然讀「Lee is a baker.」，等待並記錄。第3試自然讀「No, I can’t.」，等待並記錄。第4試自然讀「This is a rice dumpling.」，等待並記錄。每試可原句重讀一次；不能改成中文解答，不回饋直到四試完成。 未教、無可靠完整模型、無合適機會、未回應、拒絕、受答案提示或改用不同能力，該分項記未觀察，不補0。具備條件且已實際嘗試才按規準評分。

三、閱讀與文字應用 （56分）

每題資料各自獨立。依題目選、指、說明或寫下；英文短文為本卷原創。

03 ①兩句都說my，分別指誰？②如果老師拿著甲角色卡代讀，甲句中的my會改指老師自己的家人嗎？說明依據。③只有名字Pat、關係未提供，選恰當介紹。 （12分）

甲Kit角色：This is my grandmother, Jo. 乙Mia角色：This is my friend, Jo. 介紹庫：1 This is Pat.；2 This is my grandfather, Pat.

參考答案

①Kit、Mia；②不會，仍是Kit角色所說的關係；③1。

解答理由

拿卡的成人不是故事的關係參照者。

給分方式

  • 4分：Kit、Mia各2分。
  • 4分：不會2分，my仍指Kit角色2分。
  • 4分：③1得4分。

04 ①依新名冊把三句標成「符合」或「不符合」。②把不符合的那句改寫成完整正確句，可從詞庫選詞。 （12分）

新名冊：Jo—driver；Lee—doctor；Pat—baker。句子：甲 Jo is a teacher. 乙 Lee is a doctor. 丙 Pat is a baker. 詞庫：Jo / is / a / driver. / teacher.

參考答案

解答理由

給分方式

  • 6分：修成Jo is a driver.：保留Jo主語2分，is a框架2分，driver工作2分；同義完整句同分。

05 ①第一句介紹的是哪張卡和哪種動物？②第二段明確改指乙後，對Is it red?選完整回答。③再用一個完整英文句補充乙的正確顏色，可用詞庫。 （12分）

甲：red bird紅鳥；乙：blue fish藍魚。Kit指甲：It’s a bird. 接著Kit改指乙：Is it red? 答句：1 Yes, it is.；2 No, it isn’t. 詞庫：It’s / blue. / red.

參考答案

①甲，鳥；②2；③It’s blue.

解答理由

  • 4分：It’s或It is框架2分，blue2分。

07 ①Dragon Boat Festival是什麼節慶？②比較「食物」：寫一項兩份共同提到的食物，並指出甲乙各自依據。③把「乙說全年有人划龍舟，所以每個新加坡人天天划」改成符合資料的一句話。 （10分）

解答理由
