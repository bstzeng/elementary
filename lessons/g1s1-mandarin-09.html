自我介紹與生活分享

選一件願意分享的事，讓新朋友更認識你。

自我介紹可以從「請叫我＿＿」開始。你可以分享一件喜歡做的事，不必交代所有家庭資料。今天練習說清楚，也練習安心地選擇分享什麼。

建議：2次，每次25分鐘；先一對一，再依意願小組分享。孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 能用喜歡的稱呼和一項興趣作簡短介紹。
  • 能說出生活事件中的時間、事情和感受。
  • 能依聽眾需要補充一個清楚細節。
  • 能保留不想公開的資料，尊重同伴選擇。
陪學大人：準備材料
  • 喜好或生活活動圖卡
  • 三格提示紙：稱呼、喜歡、想分享
  • 鉛筆或可替代的指認工具

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

介紹的目的：讓人知道怎麼稱呼你

先說一個你願意使用的稱呼。

「大家好，請叫我小米。我喜歡畫花。」

小米是這堂課的虛構示範人物。她先說稱呼，再說喜歡的活動，讓同伴有一個話題可以接。

你可以用名字、老師同意的稱呼或練習角色名。不需要說住址、電話、密碼或家人不想公開的事情。

  1. 先選一個本次願意用的稱呼。
  2. 從圖卡選一種活動。
  3. 對成人說一句，或把兩張圖卡依序指出。
  4. 成人說回你的稱呼和活動，看看有沒有聽懂。
給大人的引導與觀察

課堂認識的稱呼和真實個資需求分開。公開頁面不蒐集姓名、電話或影像。不要要求孩子用家庭成員、職業、經濟情況證明自己的身分；能完成語言目標即可。

一起學 02

把喜歡說得更清楚

不只說「那個」，再補一個名字。

較不清楚：「我喜歡那個。」
更清楚：「我喜歡玩積木。」
再加一點：「我喜歡用積木蓋橋。」

聽的人看不到你心裡的畫面。說出活動或物品的名字，他就比較容易知道你指什麼。

先說一個喜歡的活動，再補一個小細節。你不需要比別人的興趣特別，也不用說自己沒有的東西。

  1. 成人問：「你喜歡做什麼？」
  2. 孩子選卡說玩積木。
  3. 成人再問：「你想蓋什麼？」
  4. 孩子補橋，連成完整短句。
給大人的引導與觀察

擴句以真實可回答的細節為主，不連問多個問題逼出長篇。孩子說「不知道喜歡什麼」可改觀察現在桌上的物品，不代替他編造興趣。避免成人把自己的偏好寫成孩子意見。

一起學 03

生活分享有順序

先說什麼時候，再說做了什麼。

「昨天放學後，我在家畫了一朵花。畫好時，我很開心。」

這個分享有三個重點：什麼時候、做了什麼、感覺如何。先說一件事就好，不必把一整天全講完。

感受沒有唯一答案。有人畫完覺得開心，有人覺得累；你可以說自己的感受，也可以說還不確定。

  1. 用太陽或月亮圖記想起一個時間。
  2. 畫或選一張事情圖。
  3. 選一個自己願意說的感受。
  4. 按三格順序，說兩句或指圖。
給大人的引導與觀察

時間詞先採今天、昨天、放學後，不要求精確日期。若孩子將今天與昨天混用，用實際日程支持，別把小一的時間概念誤差當說謊。事件可選平常的小事，不以旅遊、消費或成就比較價值。

一起學 04

聽眾不知道時，補哪一點

回答他真正想知道的地方。

我：「我今天做了一個東西。」
同伴：「你做了什麼？」
我：「我用紙折了一艘船。」

提問可以幫分享更清楚。對方問做了什麼，就先回答紙船，不必突然改說昨天吃什麼。

若不想回答私人問題，可以說：「這一題我想先保留。我可以說紙船的顏色。」

  1. 成人先問一個和活動有關的問題。
  2. 孩子回答所問的重點。
  3. 若不清楚，請成人換一種問法。
  4. 練一次禮貌保留不想公開的訊息。
給大人的引導與觀察

不要把拒絕回答私人問題當作不合作。成人示範有界線的語言，也要真的尊重孩子的選擇。問題應服務表達，不挖掘家庭情況；同伴追問可由成人溫和轉回活動內容。

一起學 05

音量和速度，照聽眾調整

讓旁邊的人聽得清楚就好。

和一位同伴說話時，用舒服的聲音；在小組分享，先確認大家能聽見。不是越大聲越好，也不需要故意很快。

一句說完稍停，看看聽眾是否需要再說。你可以看提示圖，不用全背，也不用一直看著每個人的眼睛。

  1. 先對成人試說一句。
  2. 成人只回報是否聽清楚，不評論孩子的個性。
  3. 如果太快，讓一句分成兩小段自然說。
  4. 如果聲音不方便，可指圖、用溝通工具或請成人轉述。

「我叫小米。／我喜歡畫花。」

給大人的引導與觀察

斜線是本課暫時的停頓提示，不是要寫進正式句子的標點。社交焦慮或語言支持需求者可先低壓的一對一，再選擇小組，不強迫上臺。回饋以可理解度為準，不用外向程度評分。

一起學 06

我的三格介紹卡

先排卡，再試著說給一個人聽。

  1. 第一格：畫代表本次稱呼的圖記，成人可代寫。
  2. 第二格：畫一種願意分享的興趣或活動。
  3. 第三格：選一件生活小事，可加感受。
  4. 看卡試說一遍，想刪哪格都可以先和成人討論。
  5. 向一位同伴分享；聽眾先說回一個重點。
  6. 聽眾再問一個相關、非私密的問題，講者選擇回答或保留。

卡片只用在眼前的練習，不必拍照、上傳或貼到公開牆面。也可以使用虛構角色卡練同樣的句型。

同伴回饋：「我聽懂你喜歡＿＿。」不評比誰的生活最好玩。

給大人的引導與觀察

起步只有稱呼加一項活動；一般組加事件與感受；進展組依聽眾追問補細節。家庭語言可先幫孩子整理想法，再選願意練的國語詞。成人代寫只記孩子同意的內容，不補寫未說的承諾或情緒。

一起學 07

介紹完，留一個好的連結

我聽見你，也讓你認識我。

「我聽到你喜歡畫花，我也想看看你畫的葉子。」
「謝謝你聽我說。」

分享後，聽眾可以回應興趣、問一個相關問題，或簡單說謝謝。講者不用一定答應送禮物、借東西或做更多事情。

今天可以想一想：我說清楚哪一點？哪一點我選擇保留？這兩件事都值得尊重。

  1. 說或指出自己清楚表達的一點。
  2. 聽眾說回那一點。
  3. 選下一次可補充的非私密細節。
  4. 把卡片收好，結束本次練習。
給大人的引導與觀察

自我介紹是互相理解，不是社交交換義務。成人確認孩子的界線得到尊重；若聽眾提出借物等新要求，另教自主決定，不將答應當作本課成功指標。評量以表達結構和可理解度為主。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1哪句適合簡短自我介紹？
給我一點提示

想想別人需要先知道哪兩點。

看答案與原因

參考答案：請叫我小米，我喜歡畫花

稱呼加一項願意分享的興趣，能讓人認識你，也不需透露私密資料。

2「我喜歡那個」不清楚，可以怎麼補？
給我一點提示

把「那個」換成活動名稱。

看答案與原因

參考答案：我喜歡用積木蓋橋

說明活動和具體內容，可讓看不到你想法的聽眾理解。

3示例「昨天放學後，我畫花」的時間是？
給我一點提示

先看這句話最前面。

看答案與原因

參考答案：昨天放學後

時間直接放在句首，是昨天放學後，不能自行更換。

4同伴問你做了什麼，哪句切題？
給我一點提示

先回答他問的事情。

看答案與原因

參考答案：我用紙折了一艘船

對方問做了什麼，回答折紙船就補上了需要的訊息。

5不想回答家庭私人問題，可以？
給我一點提示

你能選擇分享的範圍。

看答案與原因

參考答案：說想保留，改分享活動內容

你可以有禮貌地保留私人資訊，分享不是交代所有事情。

6說生活感受時，哪個觀念合適？
給我一點提示

感受不是只有一種。

看答案與原因

參考答案：可以說真實感受，也可以說還不確定

每個人的感受可能不同，不需要迎合一個標準情緒答案。

7看提示圖說話，可以嗎？
給我一點提示

介紹不是背誦比賽。

看答案與原因

參考答案：可以，提示圖幫助整理順序

提示圖是整理內容的支援，能讓意思清楚就有幫助。

8聽眾怎麼回應較合適？
給我一點提示

讓對方知道你聽懂了。

看答案與原因

參考答案：說回對方的興趣，再問相關問題

接住興趣並問非私密相關問題，有助互相理解，不製造交換義務。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

教學定位與範圍

本課連結2-Ⅰ-1、2-Ⅰ-2、2-Ⅰ-3及Bb-I-1等表達方向。目標是簡單自我介紹和生活敘述，不是蒐集兒童個資或培養舞臺表現。先讓孩子從三張活動卡任選，觀察是否能用詞或指圖表達；不願分享自己時，使用虛構角色同樣可達成句型練習。

兩次25分鐘

  1. 第一次：4分鐘聽成人短介紹，6分鐘稱呼加活動，6分鐘活動補細節，5分鐘兩人輪流，4分鐘回述同伴重點。
  2. 第二次：5分鐘三格事件示範，6分鐘選一件生活小事，5分鐘加時間與感受，6分鐘分享及一個追問，3分鐘自主檢查清楚與保留的部分。

分層支持

起步者可只說稱呼或一個活動詞，由成人示範連句後再自願跟說；一般組完成一至兩句並加一個細節；進展組能依提問補充相關資訊，避免漫談。視覺提示保留到孩子不需要為止，不以是否背熟當學會。口語、焦慮或社交需求者用一對一、小組、指圖或溝通工具替代公開發表。家庭語言可做構思資源，口音與語言背景不作低分理由。

常見困難與回饋

總用「那個」時，成人只追問物品或活動名稱；事件太多時，圈選一件保留；時間詞混淆時，用今天的實際生活順序協助，不立刻斷定內容不真實；句子很小聲或說得快時，先確認聽眾距離和情境壓力，再練一句自然停頓。成人要描述「我聽懂你用紙折船」，不說「你終於不害羞」，避免把個性當缺陷。

不要求完整姓名、住址、電話、密碼、家庭職業或私人關係。孩子不想答的問題可以保留並轉回活動，成人必須尊重而非追問。任何實際公開展示需另依學校與家長規範，本課頁面不蒐集、儲存或上傳作品。

學習證據

記錄能否讓聽眾知道稱呼與一項活動、能否依序說一件事、能否回答相關追問或適當保留。成人代讀網頁題，不用識字量影響口語評量。家庭可在餐後選一件平常小事互說，成人也分享，不要求天天有特別成就或強烈快樂感受。
