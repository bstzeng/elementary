安全、防災與生活議題

先保護自己，再聽指示：教室裡的安全判斷

這是可選用的校訂安全示例，不是所有學校必開的同名課。防災學習要配合學校實際計畫。本課先看紙卡、演紙偶；不製造真實危險，也不測誰最快或最勇敢。真實緊急情況依現場成人、校方及救援人員指示。

建議：3 次，每次 25–30 分鐘；只做成人帶領的低壓模擬孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 分辨日常可停下求助的危險，以及地震當下要先保護自己的情境。
  • 在成人指導的安全模擬中理解趴下、掩護、穩住。
  • 知道地震搖晃時不為拿物品或衝門而冒險。
  • 在停止搖晃後依成人與校方指示行動，不自行選危險路線。
  • 用簡短訊息指出危險位置或自己需要的協助。
陪學大人：準備材料
  • 地震、濕地板、取書包等情境紙卡，不播放驚嚇影像或警報
  • 紙偶、紙上教室圖；可全程以指圖練習
  • 如要練桌下姿勢，先由學校成人確認穩固非玻璃桌、淨空、安全距離與個別支持
  • 成人事前核對本校防災計畫與現行官方指引；不使用真火、煙、傾倒家具或障礙逃生場

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

看見危險，先不要把自己放進去

能看見問題，不代表要自己處理。

原創情境：小安去拿畫紙，發現走道有一小灘水。他停在乾的地方，沒有踩進去，也沒有追著同學跑。他對老師說：「老師，畫紙架前面地板有水，可能會滑。」老師來處理，請大家暫時避開。

這次有用的訊息是「哪裡」和「看見什麼」。小安不必猜是誰弄濕，也不必用手試插座附近的水。

如果看見電線破損、不明液體、碎玻璃或搖晃的櫃子，都不碰、不撿、不推；先離開危險位置，讓附近可信任的成人知道。

  1. 大人放一張「地面有水」卡，清楚說是假的情境。
  2. 紙偶停在圖上的乾地，不做真灑水。
  3. 你說或指：「那裡有水，請幫忙。」
  4. 大人回應並說明下一步，讓求助真的得到回應。

安全不是責怪誰動作慢，也不是看到問題就逞強整理。孩子可以提醒和求助，成人負責判斷、隔離危險與處理。

給陪學大人：訊息和責任分開

日常危險練習使用紙卡，不放碎片、帶電設備或濕滑物。先辨認可保持距離的情境，不把「停下求助」變成任何災難都原地等待的唯一答案；下一段地震當下需立即自我保護。

一起學 02

地震正在搖，先保護頭和脖子

不是先拿書包，也不是先衝出去。

如果在教室裡突然地震搖晃，附近有合適的穩固課桌，官方防震原則是趴下、掩護、穩住。目的是減少跌倒與掉落物造成的傷害，保護頭部、頸部和身體。

  1. 趴下：把身體壓低，避免搖晃時站不穩。
  2. 掩護：就近在合適的穩固桌下保護頭頸與身體，不選玻璃桌。
  3. 穩住：抓穩桌腳，持續保護頭頸，留意桌子移動；不要急著起身。

還在搖時，不衝去門口、不跑去拿書包，也不為了找遠處的桌子穿過危險區域。附近沒有桌子時，依官方指引保持低姿勢、保護頭頸，避開窗戶、吊掛物與可能倒下的高櫃；實際位置先由學校成人教清楚。

你可以先看紙偶，不一定要自己趴下。使用輪椅、行動輔具或有其他需要的孩子，應由校方依個別能力預先訂好並練過可行的保護方法，不能臨時要求轉移到地上或由同學抬抱。

給陪學大人：不要只背口號

請使用來源中的消防與氣象官方資料核對動作，再依本校桌型及學生需求示範。不教「生命三角」或門框最安全等概括口訣。若無適當桌子、空間或專業安排，本課全程只做紙上辨識，不能現場拼湊掩體。

一起學 03

小安的選擇：書包等一等

分清楚正在搖，和搖停之後。

這是紙偶故事，不是真實地震。大人拿出「正在搖」卡。小安看到書包在椅背上，原本想伸手取它，接著想起：「現在先保護自己。」他就近在已確認合適的桌下採取保護動作，抓穩桌腳。

大人換成「搖晃停止」卡。小安沒有自己衝樓梯。他留意老師的指示。老師確認狀況並依校方計畫安排移動，小安跟著指定方式走，不推擠、不折返取物。

到了指定集合位置，小安讓老師確認自己在場，說：「我的腳不舒服，請幫忙。」老師接手照顧；其他孩子不回去找人或物品。

  1. 把「正在搖」與「停止後聽指示」分成兩張卡。
  2. 大人讀「去拿書包」，你指出為什麼搖晃當下不適合。
  3. 大人讀「按校方指示移動」，你選停止後那張卡。
  4. 再演一次求助，練表達身體不舒服，而不假裝受傷。

搖停不表示所有地方都安全，可能仍有掉落物或餘震。若再次搖晃，依當下環境採保護措施並聽現場指示；孩子不自行查看裂縫或回樓內探險。

給陪學大人：時序教學

透過兩張狀態卡區分當下保護與後續疏散，不把趴下後必須立刻跑操場編成固定動作串。集合位置及是否疏散由學校實際計畫和現場判斷決定，本課不指定未知校舍的路線。

一起學 04

紙上練一遍，再決定要不要動作練習

慢慢做對，不比快。

先由大人說：「這是已經說好的練習，沒有真的地震。你可以指圖、看紙偶，或按我們約好的方式參與。」不突然搖桌、不關燈、不放警報，也不讓孩子被困住。

  1. 成人在紙上畫一張桌、一面窗、一個高櫃，標示這只是情境圖。
  2. 紙偶位在桌旁。你指出就近合適桌下的保護位置，不選窗邊或櫃前。
  3. 成人念三個步驟，你用手指依序指卡，也可口頭說明理由。
  4. 換成停止卡，等成人說明下一步；紙偶不自行逃跑。
  5. 最後問：「哪一個地方我還不確定？」留時間處理問題。

只有學校成人已確認桌子穩固、非玻璃、下方淨空，且活動符合個別安全安排時，才可做短暫姿勢練習。每次一人或依成人安排輪流，不擠在同一桌下、不搬移家具。身體不舒服或害怕，可以停止，改用紙偶。

給陪學大人：低壓而可退出

成人全程在場，動作不適時立即停，不以完成姿勢換取喝水、如廁或離開。曾受災或對警報敏感的孩子可只讀卡、觀看，或另選時間；不得公開要求說出受災經驗。這是課內概念練習，不能冒稱完成正式校園防災演練。

一起學 05

把訊息說清楚，讓大人幫得上

哪裡、什麼事、需要什麼，可以一句一句說。

緊張時，短句就有用。日常發現危險時，可以說「老師，書架前有水」。已到安全位置且需要協助時，可以說「我的腳不舒服，請幫忙」。不必先說完很長的句子，成人也應注意指圖、手勢或其他溝通方式。

紙偶指「幫忙」卡。大人問：「你需要我再說一次，還是身體不舒服？」紙偶指身體不舒服圖。大人回應：「我知道了，我來協助。」

如果孩子說不清楚，大人先協助確認安全，不能以完整敘述作為幫忙的條件。

  1. 選「地板濕」、「我不舒服」或「沒聽清楚」一張虛構情境。
  2. 用一句話或一張圖表達。
  3. 大人重述「你是說……嗎？」讓你確認。
  4. 若被誤解，指另一張圖或說「不是這個」。

真正的緊急求救由現場成人及救援系統處理，孩子按已學過的校園求助方式行動。這次不撥真電話、不上傳住址，不以錄音錄影證明自己會求助。

給陪學大人：溝通的可及性

依既有溝通支持提供簡短圖卡、大字或孩子熟悉的表達方式。不能把不說話等同不需要幫助；不要逼迫眼神接觸。若須在個別校園計畫教授緊急通報，另用官方資訊和適切模擬，不打真求救電話測試。

一起學 06

事前的小準備，由大人一起做

把通道留出來，不是自己固定高櫃。

真正防災不只是在災難時做動作。平常可以和大人核對：自己的學用品有沒有擋住走道？班級約好的求助對象和集合方式是什麼？哪一些物品是孩子不能自己搬動或修理的？

在正常上課時，小安把自己的書包放到老師指定的位置，讓走道保持通行。高櫃是否固定、燈具是否牢固、出口是否合規，是學校成人及合適人員的工作，不由小安搬櫃或拉電線檢查。

  1. 只在成人安排的正常時段，看自己的桌旁。
  2. 把自己的紙本或筆袋放回指定位置，不動別人或大型物品。
  3. 在紙上說明「需要幫忙時找誰」，不寫對方私人電話。
  4. 請成人指出本班真正的安排；不知道就問，不套用故事路線。

家裡也可由照顧者安排防災準備，孩子只需知道自己能做的一件小事。不能自行開關瓦斯、檢查電器、固定高處家具或整理不明用品。

給陪學大人：生活議題的責任分工

這裡教辨識責任邊界，不交付危險維修。個別用藥、輔具、緊急用品和聯繫方式由成人納入適合的計畫，不在公開課堂展示私人醫療或聯絡資料。不要要求孩子拍家庭出口或交住家平面圖。

一起學 07

換個情境，先問現在發生什麼

同一句口訣，不能處理所有危險。

老師換三張卡：第一張是平常地板濕，第二張是教室地震正在搖，第三張是搖停後老師指示依計畫集合。我們先辨認情況，再選行動，不把每張卡都回答「立刻跑」。

  1. 平常看見濕地板：避開水，告訴附近成人，不自己處理不明液體。
  2. 教室地震正在搖：就近保護頭頸與身體，依合適情境趴下、掩護、穩住。
  3. 停止搖晃後：依現場成人與校方指示行動，保持秩序、不折返取物。
  4. 不能判斷：說「我需要幫忙」，成人協助；真實危險不留在現場研究答案。

今天學的是教室地震與幾個日常求助情境。遇到火災、洪水或在戶外等其他情況，做法可能不同，不能把「躲桌下」套用全部災害。那些情境需要配合各自的官方指引和學校教學。

給陪學大人：收束與情緒照顧

結束時確認孩子知道練習已結束，恢復普通活動。以「你先指出正在搖，才選保護」回饋具體判斷，不說不怕才勇敢。若活動引起持續不適，停止災害材料，聯繫熟悉孩子的校方支持人員；本課不做心理治療或災難暴露訓練。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

課前核對與適用範圍

本課為校訂安全議題可選示例，聚焦教室地震與日常危險求助，不能代替學校防災計畫、正式演練或其他災害的專門指引。2026-10-05 已核閱中央氣象署所載消防署地震避難資料及臺北市消防局地震動作說明。教學前再依學校現有規定確認現場桌型、動線、集合、成人責任及個別學生支持，不把網頁通則當作對未知建築的現場安全判定。

第 1 次：辨識與保護，25–30 分鐘

0–7 分用紙卡演濕地板，練保持距離、說位置及狀況；7–17 分成人說明地震三步的保護目的，使用紙偶及桌圖，孩子可只指卡；17–25 分讀小安故事，分辨正在搖與停止後；餘下時間接受提問並確認模擬結束。不要同時教太多災種，也不靠恐怖照片增加記憶。

第 2 次：成人帶領的低壓模擬，25–30 分鐘

0–5 分明說沒有真災害、可選參與方式；5–15 分指紙偶位置，檢查能否避開窗和高櫃並說明就近保護；15–22 分只在合適且已確認安全的條件下，依個別安排示範姿勢，否則繼續紙上活動；22–30 分換停止卡，練等待及依指示的後續行動。全程不製造晃動、煙、火、黑暗或驚嚇聲，不競速、不障礙逃生，不用真電話測試。

第 3 次：求助與轉用，25–30 分鐘

0–10 分練一句求助和成人重述確認；10–18 分討論平時自己能整理的學用品與成人處理的櫃體、電器；18–25 分用三張不同狀態卡選行動，追問理由；25–30 分自評一項已會與一項仍需提示。若實際演練規畫不在本課授權或能力範圍，保留紙上練習即可。

差異化與迷思

成人接受指圖、口述、既有輔助溝通與共同操作，不能以快速移動、出聲或趴下的動作整齊度判所有孩子通過。行動、輪椅、聽視覺或其他支持依校方個別安排，由適合人員先確認，不臨時要求轉移或讓同伴抬抱。曾有受災經驗者可不披露、不接觸刺激材料。把地震時拿書包當首要者，重演掉落物風險與先保護；把搖停等同完全安全者，回到成人確認及餘震情境；把所有災難都躲桌下者，重申本課情境限制。

評量、隱私與收束

觀察是否能辨識狀態、指出頭頸保護、放下取物衝動、按指示完成紙偶後續行動、表達協助需求，分別記錄獨立、提示後或共同完成。選擇題不能認證真實應變能力；正式校園演練另由學校評估。不得收兒童住址、住家平面圖、醫療資料、家庭防災照片或他人聯絡資料。對恐懼以停止、說明和熟悉成人陪伴回應，不採嚇阻、羞辱或自行開立任何心理或感覺治療方案。
