聆聽故事並回答問題

先聽懂問題，再回到故事找一句證據。

同一個故事，可以從不同問題找到不同線索。今天聽〈紙橋還差一步〉，看看三個人怎麼把紙橋修好。你不用一次全記住；答案要和故事對得上。

建議：2–3次，每次25分鐘；可重聽或由成人分段讀。孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 能依誰、哪裡、為什麼等問題找相關訊息。
  • 能分清人物的提議、實際行動和最後結果。
  • 能用故事明說的原因回答問題。
  • 故事沒有提供的細節，能表達不確定並請求澄清。
陪學大人：準備材料
  • 成人朗讀本課原創故事
  • 寫著阿樂、小文、老師的角色卡
  • 三張空白事件卡、鉛筆

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

聽前準備：帶著一個問題

先找：紙橋遇到什麼事？

本課的紙橋，是把一張紙架在兩個積木座中間，讓小紙人通過的玩具。成人可以用一張紙和兩個平穩物品做小模型；不必承重，也不站上去。

先知道三個角色

阿樂和小文是做紙橋的同伴，老師在教室陪大家活動。人名只是故事代號，不需要猜性別或長相。

  1. 先聽題目〈紙橋還差一步〉。
  2. 看三張角色卡，指一指每個名字。
  3. 帶著「紙橋遇到什麼事」聽完整故事。
  4. 第一輪先不搶答，聽完再回應。

不知道「橋面、積木座」的意思可以先問。理解詞語與記住事件是不同的事，問清楚不是打斷學習。

一起學 02

原創故事：紙橋還差一步

聽完整段，再找橋面發生的事。

美勞時間，阿樂和小文在教室搭紙橋。
阿樂把紙放在兩個積木座上。小紙人走到中間，橋面就往下彎。
小文說：「我們把兩個積木座移近一點，好嗎？」
老師說：「可以先試試看。」
兩人把積木座移近，再把紙放上去。這一次，小紙人順利過橋。
阿樂拿出藍筆，把成功的方法畫下來。小文把剩下的紙收進盒子。

以上故事為本頁原創。第一輪成人自然讀完；第二輪可在橋面彎下、移近座子、記錄收拾三處停一下，讓孩子說回剛才聽到的事情。

先用一句話說你聽懂的主線：「他們的紙橋往下彎，調整後讓小紙人過橋。」忘記藍筆這個細節，仍可能理解主線；兩種理解要分開看。

一起學 03

先看問什麼，再挑答案

問誰，就找人；問在哪裡，就找地方。

誰提出移近積木座？小文。
在哪裡搭橋？教室。
第一次試走時，橋面怎麼了？往下彎。

成人問「誰提出方法」，如果只答「教室」，雖然教室真的出現在故事中，卻沒有回答到這個問題。先看問題需要哪一類訊息，再找線索。

  1. 成人只問一題，孩子先指出問的是人、地方或事情。
  2. 重聽相關的兩句，不必每次從頭背。
  3. 說答案，再說一句能支持它的故事內容。
  4. 換孩子問一題，成人也要指出依據。
大人看：支援而不搶答

可給人物卡協助選擇，但不要用手先指正確角色。孩子回答「小文，他說移近」已表達依據，不要求照抄故事原句。

一起學 04

說、做、結果：不能混成一件事

先有人提議，接著兩人一起試。

  • 提議：小文說，把積木座移近一點。
  • 同意嘗試：老師說，可以先試試看。
  • 實際行動：阿樂和小文把積木座移近。
  • 結果：這一次，小紙人順利過橋。

提出方法的是小文；動手調整的卻是兩個人。老師說可以試，不代表故事寫的是老師獨自搬積木。聽到一句對話後，還要聽後面的行動。

  1. 把「提議」「動手」「結果」寫在三張卡上。
  2. 成人各讀一個片段，孩子放到相應卡旁。
  3. 回聽「兩人」指誰。
  4. 試說「小文提議，兩人試做，最後成功」。

如果你原先記成老師搬積木，可以回到那句修正；改答案是利用新線索，不是丟臉。

一起學 05

為什麼：找故事已說的原因

不要只答「因為他想」。

問：兩人為什麼要調整紙橋？
答：因為第一次試走時，橋面往下彎。

先指出遇到的問題，再連到他們的做法。這個原因在故事裡找得到，不用猜他們是不是想得獎，因為文中沒有比賽。

再問：「阿樂最後用什麼記錄？」要答藍筆，不必重講紙橋的問題。問題不同，需要的證據也不同。

  1. 把「橋面往下彎」與「兩人調整」兩句排在一起。
  2. 試用「因為……所以……」說一次，也可分兩句說。
  3. 指出哪一句是遇到的問題，哪一句是做法。
  4. 刪掉故事沒提到的得獎情節。
大人看：原因的界線

這是敘事理解，不把一次玩具嘗試推廣為所有橋梁的工程規則。可讓孩子談合理猜測，但須明白標示為猜測。

一起學 06

沒有說的地方：停在不知道

你知道筆的顏色，不一定知道紙的顏色。

故事說阿樂拿藍筆，沒有說紙橋用的是白紙或黃紙。也沒有說做了幾分鐘。問到這些細節，可以回答「故事沒有告訴我們」。

有說：阿樂拿出藍筆。
沒說：紙橋是藍色。
有說：小文把剩紙收進盒子。
沒說：盒子放在哪個櫃子。

  1. 畫兩格，寫「有說」「沒說」。
  2. 成人讀上面的四張訊息卡。
  3. 孩子先分類，再回故事確認一張。
  4. 若只是漏聽，練說「請再讀最後兩句」。

「我沒聽清楚」和「故事根本沒說」不一樣。前者可以重聽；重聽後仍沒有提供，才說不能確定。不必為每題發明一個答案。

一起學 07

把答案說給故事夥伴聽

一句答案，加一個線索。

  1. 同伴從「誰提議」「為什麼調整」「最後做什麼」選一題。
  2. 你先用自己的話回答。
  3. 指角色卡或請成人重讀支持答案的一句。
  4. 同伴說回他聽懂的答案。
  5. 若人物或事情弄錯，一起回到原文修正。

轉移小故事

原創新故事：樂樂找不到紅卡片。他翻開桌上的書，發現卡片夾在書裡。他把卡片拿出來。

問：卡片在哪裡找到？答：書裡。證據是第二句。不能只因上一個故事有盒子，就回答盒子。

本次可留下一張角色與事件卡，不需記錄真名、家庭事情或上傳聲音。下次讀新的故事，仍用同一個方法：聽問題、找線索、說答案。

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1故事中，誰提出把積木座移近？
給我一點提示

留意「我們把……好嗎」是誰說的。

看答案與原因

參考答案：小文

提出移近方法的是小文，老師則回應可以先試試看。

給我一點提示

問題問地方，不是問人名。

看答案與原因

參考答案：教室

故事開頭說美勞時間在教室搭紙橋，地點有明確交代。

3第一次小紙人走到中間，橋面怎麼了？
給我一點提示

重聽第一次試走的那句。

看答案與原因

參考答案：往下彎

原文明說橋面往下彎，這也成為兩人接著調整的原因。

4誰實際把積木座移近？
給我一點提示

找「兩人」指的是誰。

看答案與原因

參考答案：阿樂和小文

文中的兩人承接阿樂和小文；提議者、同意者與動手者不能混在一起。

5為什麼兩人要調整紙橋？
給我一點提示

找故事已說的問題。

看答案與原因

參考答案：第一次試走時橋面往下彎

橋面往下彎是原文提供的原因，故事沒有比賽，也未說紙的顏色。

6問「阿樂拿什麼記錄」，哪個回答對題？
給我一點提示

題目問使用的物品。

看答案與原因

參考答案：藍筆

阿樂最後拿出藍筆畫下方法；教室和小文不是這題要找的物品。

7紙橋是什麼顏色？
給我一點提示

不要把筆的顏色移到紙上。

看答案與原因

參考答案：故事沒有說，不能確定

故事只說筆是藍色，沒有說紙橋顏色，所以不能確定。

8轉移小故事中，樂樂在哪裡找到紅卡片？
給我一點提示

回到樂樂的新故事找線索。

看答案與原因

參考答案：書裡

新故事第二句指出卡片夾在書裡，不能沿用前一篇的物品位置。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

教學定位

對應第一階段聆聽與敘事理解，使用Ad-I-2、Ad-I-3方向。與先前抓人物與順序相比，本課加入問題焦點、說話者與行動者的區別，以及有明文原因的回答。先讓孩子聽兩句短故事回答一個誰的問題；若詞彙不熟，先解釋橋面和積木座，不把詞義問題視為不專心。

分次安排

  1. 第一次25分鐘：5分鐘模型與詞義，5分鐘完整聽，8分鐘誰哪裡發生什麼，4分鐘再聽核對，3分鐘主線回述。
  2. 第二次25分鐘：4分鐘回憶，8分鐘提議與行動分類，6分鐘明文原因，4分鐘有說沒說，3分鐘自評。
  3. 第三次可選20分鐘：輪流提問與新故事遷移。每人至少回答一題並指出相關語句，避免齊聲回答掩蓋個別理解。

回饋方法

把小文和老師混淆時，比較兩人的原話；把提出方法等同動手者時，重讀「兩人」並配角色卡；只記藍色卻不知指筆還是紙，將名詞與顏色成對重述。答了故事中真實資訊卻離題，先讓孩子指出問的是哪一類，再找答案。

差異化與支持

起步組每兩句一段，提供兩角色卡；一般組完整聽後回答並指證據；進階組自己提出一題有答案、一題文中無答案的問題，再說明區別。聽覺需求者使用清楚文字、手語或既有支持，並記錄接收資訊的方式；可以指圖或選卡，不要求眼睛一直看成人。

評量與延伸

分記人物關係、問答對應、明文原因、未知判斷四項。選擇題可由成人朗讀，不能以默讀困難推定聆聽理解低落。離堂給新短故事，只換素材不換任務，確認孩子能找新證據。家庭練習選虛構人物或公開小故事，不要求分享衝突、失落經驗或其他敏感私事；不以錄音上傳作為完成條件。
