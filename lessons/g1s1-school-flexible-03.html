校園與在地文化探索

從一張想像地圖，學會看見、詢問和留下線索

這是可選用的校訂探索示例，不代表你的學校一定有同樣景物。本課的「小樹學校」、紙編角與路線都是虛構，先在教室練方法；真正的地方故事，要和老師觀察、查證後再說。

建議：3 次，每次 30 分鐘；實地部分可全改成教室觀察孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 用地圖符號和圖例辨認三個地點。
  • 分辨親眼觀察、資料提供和仍待確認的問題。
  • 從物品、活動或空間提出一個和生活文化相關的問題。
  • 依已知線索做一張不含個資的小介紹卡。
  • 在成人陪同下尊重場地、物件與不同人的說法。
陪學大人：準備材料
  • 本課清楚標示為虛構的「小樹學校周邊圖」
  • 紙、粗筆、三張標籤：我看見、資料說、我想問
  • 由成人準備不含人物身分的物品圖或學校允許的觀察物
  • 若安排真實校園觀察，先由學校成人確認場地、動線與陪同

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

文化藏在每天的生活裡

除了看建築，也看看人怎麼生活。

文化可以出現在人們用的語言、製作的物品、分享的故事和一起做的活動裡。學校周邊可能有許多值得問的事情，但我們不能只看到一樣東西，就說所有人都有一樣的生活。

虛構的小樹學校準備布置「附近的小故事」。小禾想畫一座很舊的屋子，小米卻指著教室的紙編墊：「這個怎麼做？以前也有人這樣編嗎？」老師說：「都能成為問題。我們先記下看見什麼，再找可靠資料。」

  1. 選身邊一樣學校允許觀察的物品，如書架標牌或手作紙墊。
  2. 只描述兩個看得見的特徵：形狀、材料外觀或使用位置。
  3. 提出「誰在什麼時候使用？」之類的問題。
  4. 暫時不知道答案，就把問題留著。

「這看起來舊」不等於「它一定是古蹟」；「我沒看過」不等於「它很奇怪」。正式的歷史名稱、年代和文化意義，要由成人協助查可靠資料。

給陪學大人：地方未知時不補編真實史

本課不設定使用者城市、族群或校史。以一般觀察方法起步；涉及特定族群、宗教、技藝時，使用經核實的當地資料及適合的社群說明，不能把本課紙編活動稱為某族群傳統。

一起學 02

讀一張虛構的周邊圖

先看圖例，再說兩個地方的位置。

圖例像地圖的小字典：方形代表學校，圓形代表花圃，三角形代表展示角。這些符號是這張圖的約定，別張圖可能不同。

  1. 先在圖例指圓形，再找圖上的花圃。
  2. 說出「花圃畫在學校的右邊」；不熟悉左右時可用手指出。
  3. 用手指依序走過三個地方，不真的離開教室。
  4. 問「圓形是不是說花圃真的是圓的？」看看圖例：它只代表位置，沒有告訴我們真實形狀。

圖上沒有比例尺，也沒有標方向，因此不能算出要走幾分鐘，不能把上面當北方，更不能照這張圖上街找路。

一起學 03

三個小袋子：看到、資料說、想問

把不同種類的線索分開放。

老師提供一張明確標示「虛構教學資料」的卡：小樹學校的紙編角展出三張紙墊，由故事中的手作小組在上週製作。桌旁有一張牌寫「請用眼睛看」。這只在本課故事裡成立。

我看見：圖卡上有三張紙墊，紙條一條壓一條。這是直接觀察。

資料說：故事資料卡寫小組在上週製作。這個時間不是看外觀就知道的。

我想問：為什麼有的紙條在上、有的在下？這是還要找答案的問題。

  1. 畫三個大格，或請大人擺三張標籤。
  2. 把「三張」、「上週製作」、「為什麼交錯」分別放進合適的格。
  3. 大人故意說「這些紙墊一定有一百歲」，你找找有沒有資料支持。
  4. 沒有證據，就把這句改成問題，不放進介紹卡。

一個人的回憶很有價值，但可能和別人的不同。聽到不同說法，可以記「有人這樣說」，再由成人查資料，不急著判誰不誠實。

給陪學大人：證據品質的入門

不要求一年級查完整史料，而是建立話從哪裡來的意識。真實活動選清楚標示來源的校方說明或正式館舍展示，不用社群傳言填補缺漏。學生只需指出「我看到」或「大人讀給我」即可。

一起學 04

做一回安靜的觀察員

少拿一樣東西，多看一個細節。

今天先觀察上面虛構展示圖中的第一張紙編墊。大人把它放在大家看得清楚的位置。觀察不一定要摸；如果展示牌說不可碰，就用眼睛看，或請大人描述。

  1. 第一看：整體。它像一塊長方形，上面有交錯的紙條。
  2. 第二看：細節。沿一條橫紙條，看它經過直紙條時，是在上面還是下面。
  3. 第三記：畫兩條交錯的線，旁邊請大人代寫「一上一下」。
  4. 第四問：我想知道怎樣讓紙條不散開。

觀察另一張書架標牌也可以：看圖案、看文字、看它放在哪裡。你沒有摸到實物，仍能說出清楚的觀察。若有視覺需要，可由成人提供經允許的可觸摸教具，不能拿真正展品讓人試摸。

如果老師安排真實校園短觀察，要在指定範圍內跟著成人，不採植物、不取走物件、不進入禁止區。看到不明物、地面濕滑或離隊情況，先告訴帶隊成人，不自行追看。

給陪學大人：評量觀察，不評量旅行經驗

學生不必去過名勝，也不必帶家中珍貴物件。提供同一張圖讓全班取得相等線索；安排行動可及的位置與口述選項。實地延伸由成人查場地風險、無障礙及天候，未完成安排就維持教室活動。

一起學 05

想問一個人，先問願不願意

好問題很短，也容得下「不知道」。

我們不去找陌生人訪問。先讓熟悉的大人扮演紙編角的介紹者，練習問一個問題。真正邀請校內人員或社區來賓，要由學校成人聯繫與安排。

小禾：「請問現在方便回答一個關於紙墊的問題嗎？」

大人：「可以。」

小禾：「紙條為什麼要一上一下？」

大人：「在這個紙編作品裡，紙條交錯會互相卡住，比全部只疊在上面不容易散。你們可以用安全紙條試看看。」

小禾：「我聽到的是，交錯讓它比較不容易散，對嗎？」

  1. 你選一個與作品有關的問題，不問姓名住址。
  2. 大人答「現在不方便」時，練說「好，謝謝」，停止追問。
  3. 若答「我不知道」，把問題保留，請老師找別的資料。
  4. 若有回答，先重述一次，讓對方有機會更正。

不同家庭、語言與工作都值得尊重。不能讓一個人代表所有同樣背景的人，也不能因對方口音不同而取笑。這次不用錄音、錄影、拍人像或留下聯絡方式。

給陪學大人：避免披露壓力

角色問答足以達成本課。不要指定少數文化背景學生介紹家族史、宗教或移動經驗；可自願分享非敏感內容，也可完全不分享。文化活動以有同意、可拒絕、可更正的對話示範。

一起學 06

做一張小介紹卡

寫出發現，也留下還不知道的地方。

介紹卡不是把想像裝成真的。這是完成的示例：

虛構小樹學校：紙編角

位置：練習圖的右下方三角形。

我看見：圖卡上有三張交錯紙條做成的紙墊。

資料來源：本課虛構教學卡說，是故事中的手作小組上週做的。

我還想問：除了紙條，還能用什麼安全材料練交錯？

參觀提醒：牌子寫請用眼睛看，不取走作品。

  1. 你畫一個地點符號和一個觀察到的細節。
  2. 請大人代寫一小句，或由你口述完整介紹。
  3. 用三格標籤檢查：哪個是看到、哪個是資料說、哪個是問題？
  4. 把沒有來源的年代刪去，改寫「還不知道」。

如果換成真實校園的書架標牌，卡上可以寫「教室書架旁的標牌」，不寫學生姓名、門牌、上下學路線或定位。作品留在課堂，不必發布到網路。

給陪學大人：小成果的品質

至少有一個可核對細節、一個來源交代、一個待問問題，就有探究價值。字漂亮或圖畫精細不是重點。協助孩子在每張虛構卡保留「虛構」標記，避免照片截圖流通後被誤認為真實地方史。

一起學 07

換一個地方，也用同樣的方法

新線索來了，可以修改原來的想法。

第二次，老師把紙編角圖換成一張虛構閱讀亭圖。亭子旁有「星期三共讀」的牌。小米原先猜每天都有共讀，讀到牌子後說：「我要改成牌上寫星期三，其他日子我還不知道。」修正是仔細探索的表現。

  1. 從新的圖或成人核實的校園觀察物，說出一個看得見的特徵。
  2. 大人補一條有來源的訊息，你決定它會不會改變你的猜想。
  3. 用「我原本猜……，現在資料告訴我……」說一次；也可以換圖卡。
  4. 想一個保存或尊重的小行動，如只畫下標牌，不拆走它。

我們不必一堂課就知道整個地方的歷史。能問好一個小問題，分清楚知道與不知道，就在學習認識生活周圍的人與事。

給陪學大人：轉用的邊界

家庭可在安全且成人陪同的現有情境觀察一項物品，不要求額外出遊。若涉及宗教、族群特定知識、私人空間或不開放的文化內容，先確認可公開範圍，沒有合適資料便保留問題。不能要求學生取得他人照片、個資或家庭文物證明。

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

1這張地圖裡，圓形代表什麼？

參考答案：共享花圃

6扮演介紹者的大人說「現在不方便」，應怎麼做？

7看到閱讀亭牌子寫星期三共讀，哪句最準確？
給我一點提示

8介紹卡哪一項值得保留？
給我一點提示

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

課程定位與資料界線

本課提供學校自主選用的校園及在地文化探索方法，並非宣告任何縣市或學校的文化特色。小樹學校地圖、展示卡、紙編故事與閱讀亭全部是明示虛構的教學例子。成人不得把它們改稱真實校史；若替換成當地材料，須另核對名稱、年代、開放規則與來源，特定族群文化應尊重社群適當的說明與公開範圍。

第 1 次：地圖與三類線索，30 分鐘

0–6 分以身邊物品討論文化可以從日常提問；6–15 分讀虛構地圖，先圖例配對，再指兩點位置，明說不具真實比例、方位或導航功能；15–25 分把三張敘述卡分到看到、資料說、想問；25–30 分出口任務為說出一個「還不知道」。成人示範承認不知道，不用編造故事換取流暢介紹。

第 2 次：觀察與問答，30 分鐘

0–10 分在教室看紙編圖或可安全操作的練習物，從整體到細節畫記；10–20 分成人扮演介紹者，示範同意、拒絕與不知道三種回答；20–27 分孩子各選一問並重述答覆；27–30 分討論怎樣保護共用物品。不要求對陌生人實訪，也不把同學當作其文化群體的代表。

第 3 次：介紹卡與新線索，30 分鐘

0–12 分做一張五欄簡介，可由成人代筆；12–20 分同伴只檢查是否有觀察與來源，提出一個問題，不比較誰的家鄉更好；20–27 分換閱讀亭線索修正「每天」的猜想；27–30 分選一項尊重場地的小行動。若有正式校園走讀，課堂時間與路線另依校方安排，安全管理不能交給一年級兒童。

迷思、支持與評量

把符號當真實外形時，換一張圖例說明同一地點可用不同符號；把古老外觀當正式古蹟認定時，問「哪個可靠資料說的？」；把單一人說法推廣全部人時，改說「這位介紹者的經驗」。尚未識字者用三張圖卡分類，動作需要協助者口頭指示成人畫；看不清圖者提供逐點描述及可及實物。不以左右口語詞卡住探究，可接受指示位置。進階孩子比較兩條線索是否相合，提出下一個可查問題，而不是要求背歷史年代。
