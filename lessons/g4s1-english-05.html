喜好與禮貌回應

把喜歡、當下要不要和禮貌回應分開，完成不勉強人的問答

把喜歡、當下要不要和禮貌回應分開，完成不勉強人的問答。完整材料在下方，先理解，再有提示練習，最後用新資料自己試。

建議：2–3次，每次20–30分鐘；口語可拆成短段孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

準備好了嗎？

這一課，我會練習

  • 我會用I like…與I don’t like…讀懂角色偏好。
  • 我能對Do you like…?選Yes, I do.或No, I don’t.，並說出依據。
  • 我能尊重不同喜好，分清喜歡某物不代表現在一定要接受它。
陪學大人：準備材料
  • 本頁完整原創情境、字句卡與鉛筆；無需另購教材
  • 可用指認、繪圖、AAC或成人代寫；不用真實個資或食物
  • 教師課前核對完整口語模型；本頁無音檔且未驗聽播放

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

兩個問題可能問不同的事

喜歡和現在想要，不必相同。

Do you like apples?在問你喜不喜歡蘋果；Would you like an apple?在本課情境是提供一個蘋果、問現在要不要。先看對方在問偏好還是提出提供，不能只抓到like就一律回同一種答案。

談一般偏好，本課用複數apples、bananas、pears，或物質用法milk。說I like apples.不代表每個蘋果都愛，也不表示現在一定餓。I don’t like milk.只表示這個角色不喜歡牛奶，不是在替大家判定某食物好壞。

一起學 02

完整角色資料：偏好與當下選擇

所有資訊都是虛構，不用調查同學飲食。

卡A，Kai：I like apples. I don’t like bananas.；現在不想拿食物。卡B，Mia：I like bananas. I don’t like apples.；現在想拿一根香蕉。卡C，Paz：I like pears.；其他喜好與當下選擇未提供。

先做「角色／喜歡／不喜歡／現在要不要」四格。Kai喜歡apples但現在不拿；Mia喜歡bananas而且現在想拿；Paz不能被填成不喜歡apples，因為沒說到不等於否定。孩子可只用角色代號，不寫真實同學名字或飲食資料。

一起學 03

完整對話一：詢問偏好

先答問句，再補一個清楚的資訊。

Mia：Do you like apples? Kai：Yes, I do. I like apples. Mia：Do you like bananas? Kai：No, I don’t. I like pears, too. Mia：I like bananas. We like different things. 我喜歡香蕉。我們喜歡不同的東西。

這個對話另補充Kai也喜歡梨，too在這裡表示也。請在卡A的喜歡欄新增pears，不要抹掉apples。教師先完整讀，再讓孩子輪流指每個回答所對應的問題；看句卡與聽聲音的支持要分別記錄。

一起學 04

完整對話二：禮貌提供

可以婉拒，不必改變喜好。

Mia：Would you like an apple? 你想要一個蘋果嗎？Kai：No, thank you. 不用，謝謝。Mia：OK. 好。

Kai並沒有改口說不喜歡蘋果；只是在這一次婉拒。接受提供可說Yes, please.。教師把「偏好」與「本次提供」標籤放兩旁，孩子將Do you like…?與Would you like…?放到相應欄。三句對話可以坐著用紙卡做，不需要真食物。

一起學 05

一起練：問題和回答配對

回答裡的do跟著偏好問題走。

成人持Mia卡問Do you like bananas?，孩子依Mia答Yes, I do.；再問Do you like apples?，答No, I don’t.。接著成人提供香蕉，Would you like a banana?，Mia現在想拿，因此答Yes, please.。

先練完整回答，再允許自然短答。若孩子把每題都答Yes，成人請他指角色卡中的肯定或don’t；若把do問題答成Yes, I am，將問答卡並排，對照本課完整模型。不要把孩子一次說錯解讀為故意不禮貌。

一起學 06

修復：不同意不等於不尊重

說自己的喜好，別替別人下命令。

錯誤推論：「我不喜歡香蕉，所以你也不能喜歡。」修正為I don’t like bananas.只報告自己的偏好；對方仍可說I like bananas.。不需要用投票決定誰才正確，也不對拒絕者追問健康或家庭原因。

錯誤記錄：「Paz沒有說apple，所以Paz一定don’t like apples。」應寫「未提供」。若想知道，可以提出一般偏好問題，允許對方不回答。本課只處理虛構卡；真實分享完全自願，不記錄成班級偏好名冊。

一起學 07

自己試：換一個角色再安排回合

不要把前一個人的答案沿用。

新角色Nori：I like bananas. I don’t like pears.；現在不想拿香蕉。請先安排一組詢問香蕉偏好的兩回合，再安排一組提供香蕉的兩回合，說明為什麼答案可以一肯定一否定。

完整轉用模型

Do you like bananas? / Yes, I do.；Would you like a banana? / No, thank you.。前者問一般偏好，後者問本次接受；資料並不矛盾。也可由成人代寫、孩子選卡完成。

再把Nori「現在不想拿」改成「現在想拿」，只更改提供的回答為Yes, please.，偏好問答不用變。

一起學 08

檢查一份尊重人的對話紀錄

說明問的是什麼，比猜對單字重要。

成品例：「Nori喜歡bananas；第一次提供時婉拒；更新卡後接受；不需要詢問私人原因。」請孩子圈出當中根據新卡改變的資訊，再指出保持不變的資訊。

成人評角色指涉、肯否與don’t、問句功能和轉用四項。支持者只做Kai和一個apple問題，進階者比較兩種問題與資料更新。真正口語觀察另看聽者能否理解接受或婉拒，不以大家答案一致、吃下食物或公開表演當成合格。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1Kai原卡顯示哪個偏好？
給我一點提示

先看卡A的兩句。

看答案與原因

參考答案：喜歡apples，不喜歡bananas

Kai明說I like apples.及I don’t like bananas.，需要同時保留肯定與否定。

2Do you like bananas?對Mia的本課回答是？
給我一點提示

用Mia資料而不是Kai。

看答案與原因

參考答案：Yes, I do.

Mia喜歡香蕉，do型偏好問句用Yes, I do.與其意思和結構相符。

3Kai婉拒蘋果能證明不喜歡蘋果嗎？
給我一點提示

比較一般偏好與當次提供。

看答案與原因

參考答案：不能，本次不要不等於不喜歡

Kai卡明說喜歡蘋果但目前不想拿，婉拒只說明這次的選擇。

4哪個回應是在禮貌婉拒提供？
給我一點提示

題目問的是婉拒提供。

看答案與原因

參考答案：No, thank you.

No, thank you.表示禮貌拒絕；Yes, please.是接受，偏好短答不對應此任務。

5Paz沒有提供apples資料，應記？
給我一點提示

空白沒有自動的肯否。

看答案與原因

參考答案：未知

Paz只說喜歡梨，沒有提及蘋果，因此不能把未提供的資料補成喜歡或不喜歡。

6對話新增Kai也喜歡哪項？
給我一點提示

找I like…too的內容。

看答案與原因

參考答案：pears

Kai在完整對話說I like pears, too.，這提供梨的新偏好，不能忽略或換成其他食物。

7Nori喜歡香蕉但現在不拿，兩答合理組合？
給我一點提示

先偏好問題，再本次提供。

看答案與原因

參考答案：Yes, I do.／No, thank you.

第一答肯定一般偏好，第二答婉拒本次提供，符合兩項不同的角色資料。

8Nori改成現在想拿香蕉，應改哪部分？
給我一點提示

只改更新卡真的變動的內容。

看答案與原因

參考答案：提供的回答改Yes, please.

只更新本次接受選擇，不必更改原本就喜歡香蕉或其他角色的資料。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

範圍與課前準備

本課是四年級英語文參考主題，三、四年級同屬第二學習階段，分學期順序為編輯安排。先確認孩子能理解所用詞義，再增加資訊比較與改述，不以四年級標籤推定人人相同起點。Ac-Ⅲ-4的300個聽讀說字詞及其中180個拼寫字詞是國小階段整體目標，不是四年級或單學期配額。角色、資料、全文對話及題目均為原創，來源只支持註明的詞義、語法或教學框架。

口語模型與證據

本頁供應完整成人朗讀文本，但沒有音檔，編寫時也未驗聽任何播放。合格英語教師須課前核對詞句並能自然示範，才做聽辨與發音觀察；語音活動以美式模型為本課參考，其他可理解的正常變體不列錯誤。不用中文諧音、字母名稱串讀或合成聲音代替字音。沒有適合示範者，先完成圖文理解，保留聽說待教，不將紙面選擇題算成聽力或發音通過。

差異化與紀錄

先做一回有中文與句卡支持的示範，再做換資料的獨立轉用，分別記下認讀、意思判斷、看卡說、跟讀及自主表達。可指認、繪圖、使用AAC或請成人代寫；記錄所用支持，不把代寫列為獨立拼寫。給重聽、短段和休息，不以音量、對視、反應速度或公開表演評分。所有人名與情境均虛構，不蒐集孩子的真實健康、家庭、地址、照片或錄音。遇到實際需求，任何有效語言與表達都可求助，不以英文正確為獲得協助的條件。

本課專項觀察

四年級重點是偏好與當次提供的語用區分、資料更新和未提供，不增加強迫真實飲食問卷。支持者保留兩種問題標籤，進階者處理Nori更新。新增Kai喜歡pears由正文對話明確供應；不從空白推否定。檢查Do you like搭配do短答、Would you like提供搭配please/thank you，兩種自然答法不互作無情境錯項。評選擇題只評文字語意，現場口語與可理解性另記。
