認識家人的需要與分工

先聽需要，再一起安排安全的小工作

玩偶小米要準備一起看書的角落，有人想休息，有人正在工作。不是每個人此刻都能做一樣多；我們先聽需要，再把事情分成做得到的小步。

建議：3 次，每次約 30 分鐘；可依需要拆成短段孩子可由大人陪讀

準備好了嗎？

這一課，我會練習

  • 辨認日常共同生活中不同的需要。
  • 看見動手與記得安排都屬於工作。
  • 依安全、能力和時間協商分工，不依性別固定工作。
  • 完成一個小工作後核對，遇變化能求助或重新安排。
陪學大人：準備材料
  • 兩組虛構家庭角色卡，可不標明親屬關係或性別
  • 大紙卡：收三本書、擺紙餐墊、煮熱湯、檢查日期、休息
  • 紙、粗筆、待做／完成／需要幫忙三格；無真實家庭資料

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

家可以有不同的樣子

不用和別人住得一樣，才能互相關心。

故事裡，小米與一位照顧者同住；阿禾常由不同的照顧者輪流陪伴。還有些家庭和祖父母、親友一起生活。照顧安排可以不同，本課不評誰的家完整或最好，也不需要說出你住在哪裡。今天一起研究的是：同住或照顧彼此的人有什麼需要，怎麼互相尊重。

  1. 成人出示兩組虛構角色，不要求學生對照自家。
  2. 孩子選一組，替故事安排共同看書的地方。
  3. 說或指角色可能需要座位、光線、安靜等哪一項。
  4. 提醒「可能」還是猜測，等角色說出自己的選擇。
給陪學大人：帶領與觀察

不點名詢問同住人口、婚姻、經濟或照顧困難。兒童可自願使用最熟悉的稱呼，但不被要求介紹家庭。避免只有父親工作、母親家務的固定故事；安全照顧責任仍由成人承擔。

一起學 02

看見線索，還要聽本人

先問需要，別忙著替人決定。

照顧者把書放下，揉了揉眼睛。小米猜對方可能累了，但也可能眼睛不舒服或只是想停一下。她問：「你想安靜休息，還是想我把書放旁邊？」對方說想休息，小米才調低自己的說話聲。關心不是猜中考試，而是讓需要被聽見。

  1. 成人用紙偶演「放下書」的動作，不診斷身體原因。
  2. 孩子說兩種可能，或指「還不知道」。
  3. 練一個有選擇的問句，等待回答。
  4. 依「想休息」的回答選安全可做的支持，不追問私人理由。
給陪學大人：帶領與觀察

允許不回答感受原因，尊重非口語選擇。家人的需要包括兒童自己的飲水、遊戲、休息及被支持，不能要求孩子以犧牲基本需要來照顧所有人。生病或危急狀況交由成人處理。

一起學 03

工作不只最後動手那一下

想到、準備、完成、核對都算。

把三本共用書放回角落前，要先知道放哪裡、讓位置空出來，再搬適量的書，最後看看路是否通。小米負責按圖放書，成人確認書架穩固和較重的物品。提醒時間與準備材料也花心力；不能只看誰拿著東西，就說另一個人什麼都沒做。

  1. 把「找位置、放三本書、看通道」三張工作卡按順序排。
  2. 指出哪張是動手前的準備，哪張是完成後核對。
  3. 成人讀出角色已做的準備，孩子把它也放入完成格。
  4. 試把「整理全部」改成一個範圍清楚的小工作。
給陪學大人：帶領與觀察

避免把「記得提醒全家」變成孩子的固定責任。可讓孩子選一項可掌握步驟，成人負責危險判斷、時間和整體安排。核對的是功能，例如好取用、路暢通，不以完美整齊要求服從。

一起學 04

先過安全關，再談誰來做

重、熱、尖、電，先留給大人。

四張工作卡是：擺大紙餐墊、放三本輕書、端熱湯、處理插座。前兩項在成人確認環境後，可以共同練；後兩項不能為了證明長大就交給孩子。連看起來簡單的工作，也要看桌高、重量和動作是否合適，做不到可以改成指位置或核對。

  1. 成人逐張讀四張卡，孩子分到「可協助確認」或「成人處理」。
  2. 選一件低風險工作，先清空路面並確認拿得到。
  3. 成人示範少量取放，孩子可動手或指揮代做。
  4. 一旦卡住、疼痛、搖晃或不安全就停，告訴成人。
給陪學大人：帶領與觀察

不使用真熱水、刀具、清潔劑、電器、重物或高處物品來測試兒童。不是只要有成人在場就能做所有危險事；成人須把危險步驟排除。無法動手者照樣可參與安排和核對。

一起學 05

公平不一定每人做同樣多

一起看時間、能力和需要。

故事中，甲照顧者正在忙必要工作，乙照顧者有空檢查書架，小米想練放三本書。三人的事情不同，仍能合作。公平要考慮此刻誰能做、誰需休息、工作有多難；不能只數卡片，也不能說某種性別天生該做某件家事。

  1. 在角色旁擺「正在忙、可協助、想練習」狀態卡。
  2. 提出一份分工：成人確認書架，小米按圖放書。
  3. 問每個角色能否接受，沒有回答不當作答應。
  4. 若一個人負擔過多，拆小工作或換時間，不強迫同意。
給陪學大人：帶領與觀察

此為協商示例，不評量真實家庭誰做得少。不給孩子管理家人或要求成人改變的責任。明確保留拒絕不安全工作與提出疲累的權利；不以孝順、乖或性別壓過安全界線。

一起學 06

有變化，分工可以改

先告知，再一起找替代。

小米放完一本書，發現其餘兩本太重。她說：「這兩本我拿不穩，請你幫忙。」原來的分工可以改為成人搬書、小米指格子。改方法不是偷懶；偷偷硬撐反而可能受傷。做完也要讓同伴知道，避免兩人重做或都以為別人完成了。

  1. 用紙卡模擬「太重」的變化，不真的給重物。
  2. 孩子選「停下、說卡點、換方法」三步。
  3. 成人回應並改工作卡，孩子做自己可行的部分。
  4. 把已完成卡移到完成格，未完成的留待做或需要幫忙格。
給陪學大人：帶領與觀察

不要用突然增加重量、催促或批評製造壓力。練的是可靠告知和彈性調整。孩子忘記回報時先用圖卡提示；不把一次漏報推成沒責任感，也不將成人情緒交給孩子安撫。

一起學 07

做完看看：有沒有幫上需要

能好好用，比看起來漂亮更重要。

書都放入角落，卻擋住走路的位置，還不算完成原來的需要。小米與成人一起把書移到安全位置，再確認拿得到、通道空。她記下「下次先看通道」。分工的目的是讓生活更方便並照顧人，不是誰做最多誰才值得被喜歡。

  1. 回到共同需要：能安心坐下讀書，路要通。
  2. 對照這項需要核對成果，指出一個已做到和一個可改處。
  3. 選一次短小家庭或教室工作轉用相同方法，先取得同意。
  4. 以「我完成哪一步、還需要哪個幫忙」結束，不必公開家庭安排。
給陪學大人：帶領與觀察

家庭延伸可直接用教室紙偶替代，不簽家事成績表、不拍攝家中。成人保持對基本照顧的責任，肯定安全求助與核對。若孩子提到負擔過重，先私下支持而非當眾要求更多分工。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

定位與課前準備

本課依生活課程第一學習階段的關係理解、合作安排和生活責任設計，為跨版本原創參考，不是全國固定的學期單元。用虛構家庭和安全紙卡，不向孩子蒐集家庭結構或收入。成人事先確認輕書與桌椅安全；熱、重、尖、電、清潔劑等工作只以卡片辨認，完全不安排兒童操作。

第 1 次：30分鐘陪學

0–8分看不同照顧安排；8–18分由線索提出可能，再讓角色回答需要；18–25分拆出準備、執行、核對；25–30分指出一個常被忽略的準備工作。

第 2 次：30分鐘陪學

0–10分分安全工作卡；10–20分看能力、時間和需要安排工作；20–27分演詢問同意；27–30分由孩子說明一個分工理由，不能以性別作理由。

第 3 次：30分鐘陪學

0–10分演太重時停下告知；10–20分共同完成放書或指位置；20–27分核對通道及取用；27–30分選可在另一場景重用的確認步驟。

差異化與參與方式

需要降低負荷時只用兩名角色、兩項工作；狀態用圖形加口述，不只靠顏色。動作受限者可安排順序、指格子或報告完成，熟練者思考一人臨時需要休息時如何改約定。成人先讀短句，孩子可指卡、口述、用熟悉語言或既有輔助溝通回答；需要動作協助時由孩子決定、大人代做。一次呈現一個問題，不用閱讀速度或動作整齊程度代替理解評量。

常見迷思與修正

需求不能由表情直接定論；公平不是卡片數一樣，也不由性別分配。得到協助仍可負責一小步，安全停下是可靠的行動，不是失敗。

實作評量與回饋

觀察能否先確認需要、辨認成人責任、提出合宜分工、發現困難後告知、最後核對共同目的。對「你說拿不穩，我們能安全換方法」給具體回饋。記錄「獨立完成、提示後完成、共同完成」及一個具體行動。選擇題只能補充判斷，不取代實作；答錯時回到情境找線索，再提供重試，不排名。

延伸與隱私

讓孩子自選一次低風險小工作，也能只在紙偶桌面演。回顧是否符合需要，不記家事排名，不把照顧成人健康或情緒當作兒童作業。不要求購物、家庭照片、姓名住址或上傳作品。可只用虛構角色完成；孩子能選擇展示多少，也能只私下與陪學成人回顧。
