出發前

準備好了嗎？

這一課，我會練習

  • 能把本路線1至3已教數詞配到數卡及點數。
  • 能在亂序情況下接收數詞並選數量。
  • 能在模型支持下表達一個數詞讓伙伴核對。
  • 能分開語言理解與一一對應操作的困難。
  • 知道數詞入門不等於已會所有量詞短語。
陪學大人：準備材料
  • 1、2、3數字點數卡
  • 三個大紙圓片和空盤
  • 兩個紙偶
  • 本路線可用完整官方模型與語言教師支持

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

選一路線，先認1、2、3

同樣三張數卡，在自己的語言裡學習。

這是語言選習課，以1至3的小數量作語言材料，不是要求同時學六種數數法。只展開實際選習的臺灣台語、四縣腔客語、馬祖閩東語、秀姑巒阿美語、臺灣手語或越南語路線。其他腔調、族語與新住民語使用對應模型。

準備三張阿拉伯數字卡1、2、3，每張下方畫相應點數。再放三個大紙圓片，尺寸大到不易誤入口，活動不使用珠子、食物或錢。孩子可以只指點卡、移紙片或口頭回答；手指表示數量只是日常輔助，不自動當成臺灣手語數詞。

本課學的是已核實的數詞與數卡／數量連結，不教未核實量詞。「二」的讀數名稱、表示兩件物的用法，可能隨語言和語境不同；不要一律把數詞接在華語物品名或量詞前面。

先備模型

各音訊需成人和具該語能力者確認可用；手語影片本次完整播放與形式未驗，須教師先確認完整模型才模仿、評量。馬祖及越南的指定資料為跨冊入門例，不宣稱本頁等於教材原學期順序。

一起學 02

原創任務：紙圓片小站

收到多少，就放多少；一片只數一次。

紙偶小豆要做一張有圓點的卡。他先選一張數量卡，伙伴只收到今天語言的數詞訊息，拿出相應大紙圓片。兩人不比速度，放完才把原數卡翻開核對。

  1. 成人先示範1，把一片放到空盤；再示範2、3，每片只移動一次。
  2. 語言學習先從一個數詞和相應卡開始，確定後加入其他數詞。
  3. 成人不按123順序發訊息，孩子拿出數量；再改成孩子發訊息、伙伴取物。
  4. 核對時逐片移到另一邊，防止重數。需要時可看點數卡支持。
  5. 把同樣數量排近或排遠，再接收同一數詞，看看數量是否改變。

如果孩子會清點卻還聽不懂數詞，先教詞和數卡；如果聽懂但常拿錯片數，先支持一一對應。不要把數學操作和語言理解混成同一個分數。

自己核對

三片排得很遠仍是三片；兩片較大的紙不會因此變三片。語言訊息和實際數量要各檢查一次。

一起學 03

路線A：臺灣台語，數量一、兩、三

先聽詞，再把相同數量放出來。

教育部詞目核實：一 tsi̍t、兩 nn̄g、三 sann。本課限定小量清點，以「兩」表示數量2；不把不同語境的文讀音混成唯一數數規則。

  1. 成人各播完整詞，孩子把詞音配到1、2、3點數卡。
  2. 先選1與3作兩選一，穩定後加入2；不要求一次背整列。
  3. 成人播放「兩」模型，孩子拿兩片，再指2卡確認。
  4. 孩子抽1–3卡，跟模型後試說數詞；伙伴拿出相應片數。
  5. 換紙片顏色與排列，語詞意思仍對同一數量。

本課不提供「一個……／兩支……」等新組合，因此沒有未核實連讀音或量詞教學。若孩子已在家用熟悉說法數數，可先聽完整示例、辨明語境，不因和單詞音不同就指責。成人標音只供查核，不要求初學者拼出鼻音符號或聲調名稱。

一個接收、一個表達

隨機聽一詞拿對片數；再看另一張卡用詞表達。能完成兩個方向，比只從頭順數更能看出理解。

一起學 04

路線B：四縣腔客語，數卡名稱

數詞和點數配對，不自行接量詞。

教育部校園篇四縣腔第2課延伸學習，印刷頁6列數字一、二、三，標音idˋ、ngi、samˊ。搭配官方四縣腔音檔及本班教師選定的完整數詞示範。今天辨識的是數字名稱和1–3點數，不教物品前的量詞組合。

  1. 先將數字卡1、2、3分別連到相同點數。
  2. 成人示範完整數詞一，孩子拿1卡；二找2卡，三找3卡。
  3. 把數卡順序改成3、1、2，只聽找卡，不照桌面順序背。
  4. 孩子抽卡試表達數詞，伙伴指卡後取相應紙片，兩人核對。
  5. 同一數卡換成另一種點數排列，重做一次。

數字讀名和描述物品的完整數量短語不能直接等同；需要說「兩個」等形式時，請教師另外提供四縣腔核實模型，不能把華語量詞加上去當正確客語。本課不評這個未教目標。

如果孩子總是把第一張卡叫一，先讓1卡留在新位置重聽，再比較數字和位置。熟練者可反向配對，成人指出點數，孩子選數詞卡；不用跨到其他客語腔調作記憶比賽。

一起學 05

路線C：馬祖閩東語，課內的1至3

跟指定課文數字行，先認出小數量。

使用國教署第1冊第7課「汝厝有幾隻儂」的數字行。互動電子書為第一級第一冊下冊印刷頁19，本頁跨冊取1–3作起步，不宣稱它是上冊或全國小一上共同進度。

已核對該課文字與數字對應，但本次沒有聽驗音訊。課內連讀標示不能直接當每個數字的獨立讀音；因此本頁不再列推測的單詞拼音。熟悉馬祖語教師課前依官方播放確認1、2、3的清楚完整模型，才做下面語言任務。

  1. 先聽課內完整數字行，指著官方數字對照，定位1–3。
  2. 教師示範已確認的單項數詞，孩子從1–3卡選一張，不剪碎音檔湊音。
  3. 孩子把卡下點數一一配到紙片，再核對意思。
  4. 交換角色，在模型支持下發出數詞訊息，伙伴取卡。
  5. 把卡片與紙片擺法改變，再試。

這裡的數量只用紙片，不實際詢問家庭有幾個人。課文主題有家人，不等於每位孩子都要交代住家成員。官方聲音尚不可用時，先完成點數準備，語言接收／表達留待有完整模型，不算教完。

一起學 06

路線D：秀姑巒阿美語，cecay、tosa^、tolo^

先聽方言模型，不照英語規則念。

族語E樂園d=2千詞表精確詞目：cecay（一）、tosa^（二）、tolo^（三）。保留來源的符號；成人按官方音訊及教師說明，不把^讀成一個字，也不以英語字母名稱代讀。

  1. 播放每一完整詞，孩子用1、2、3點數卡配對。
  2. 先做一與二辨別，再加入三；第二輪以3、1、2順序出現。
  3. 成人示範一詞，孩子給出相同片數；伙伴用點數卡核對。
  4. 孩子抽一張數卡，先看／聽模型再試表達；熟悉後撤去模型試一次。
  5. 把紙圓片改成大紙方片，數量未變，詞仍用同一套。

同一個數量在不同族語或方言不必有相同形式。看到其他教材拼寫不同，先核對d=2和具體版本，不能混成一套數詞。這課不教人數、年月或帶量詞的長句，不從字母相似自行推語法。

我學的是什麼？

你學會把三個秀姑巒阿美語數詞和1–3連結。不能因為完成這三詞就說會所有阿美語、所有族語或所有數量表達。

一起學 07

路線E：臺灣手語，數詞1、2、3

看可靠數詞模型，不能用猜的手勢代替。

臺北啟聰「16時間」頁的數詞模型：1、2、3，由官方詞目精確連結。這些頁標籤和網址已核；本次未完整驗證影像播放，不能據此描述手形、方向或動作。

  1. 教師先確認三支完整可用模型，孩子一次看完一支後再選數卡。
  2. 第二輪完整看，再試表達；教師提示手部與非手部觀察重點，不用自行繪圖。
  3. 接收者先指1–3卡，再取紙片，讓語言與數量各可核對。
  4. 教師若要評獨立理解，示範時不先給中文數字答案；字幕提示練習另標記。
  5. 變換點數圖排列，孩子表達相同數量，伙伴核對。

平常伸幾根手指可以作點數輔助，但不是已核實臺灣手語詞的替代品。用片數和點數卡檢查意思，不用中文題自動評手語形式；形式由具臺灣手語能力者看完整實作。有動作需求者按專業支持調整，不能因手形不同就否定其數量理解。

一起學 08

路線F：越南語，một、hai、ba

先把三個數詞配好，再玩取紙片。

國教署越南語第4冊的印刷頁6（PDF第8頁）直接列hai（二）；印刷頁26（PDF第28頁）直接列một（一）、ba（三）。這是本課詞義證據；印刷頁37只是含三詞的連線練習，不是答案表。這是跨冊取用的入門詞例，不要求小一已學完前四冊。

成人在官方第4冊數位教材定位相應詞彙，或由越南語教師提供完整模型。來源PDF確認文字和意思，不能把它當成已聽驗的音訊。本課不教把數詞接到任意名詞前的短語。

  1. 聽một配1，聽hai配2，聽ba配3，每次完整再選。
  2. 成人從中隨機取一詞，孩子先指數卡再放紙片。
  3. 伙伴核對實際數量，讓孩子知道是聽詞混淆還是移片失誤。
  4. 孩子抽數卡，跟模型後試說，交換出題者。
  5. 重新排點數，確認不論靠近或分散都能選同一數詞。

保留một的字母與聲調符號供成人核對，不用「很像某國語音」的口訣。收課時每人選一個已會和一個再練的數詞，分別記聽懂、跟說、獨立表達；同伴不必有越南家庭背景才可以學。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

目標與模型

核心是三個數詞和1–3點數連結，並在傳訊取物中運用。每班只選一語別。本課不教授量詞、年月、電話號碼或人數問句，尤其不能把數字讀名直接接華語量詞當目標語短句。台語採小量清點的一tsi̍t、兩nn̄g、三sann；四縣採官方數字表idˋ、ngi、samˊ的讀名；其餘各按指定官方模型。馬祖第一級第一冊下冊p19與越南第4冊p6、26均為跨冊取詞，不能冒稱上冊原進度。

課前確認孩子是否能用熟悉方式辨認1–3，再安排語言學習。教師備數詞—數卡—點數三欄，確認完整音訊／視訊；手語完整影像本次未核驗，馬祖課內標音不作單詞音自動推導。條件未滿足就暫緩相應語言教學及評量。

兩節流程

第一節5分鐘語別和點數準備，8分鐘一一對應示範，12分鐘一詞一義配卡，10分鐘亂序聽／看取卡，5分鐘孩子用已教數詞回應一次。第二節5分鐘換順序複習，12分鐘紙片站雙人互換，8分鐘同數量改排列、外觀，10分鐘個別接收與表達，5分鐘自評。紙片用大尺寸，不使用吞嚥風險小物，手語兒童不邊操作紙片邊看片。

錯誤診斷

  • 說123很順但隨機找不到2：這可能是序列記憶，先做兩選一、再三選一。
  • 聽懂2卻拿了3片：分開檢查一一對應和目標語，不把拿片失誤全判語言錯。
  • 排遠就說比較多：移片核對每片一次，再回同一數詞。
  • 用日常手指動作冒充手語：圖卡只幫意思，形式依完整模型。
  • 拿課內連讀拼音猜單詞：請熟悉該語教師辨明實際模型，不自行剪音或合成。

支持與評量

初學者從差異大的1與3開始，再加入2；大圖、高對比和短回合可降低記憶負擔。已會者改換物品、點數排列和出題伙伴，仍在1–3範圍增加獨立使用，不急著擴展到十或六語。必要時接受指卡、輔助溝通及成人代移物，但記錄支持方式。

每個數詞亂序出現兩次，記接收是否配對；再抽兩數卡，記表達為獨立、跟示範或需重教。數量操作另欄記是否重數、漏數。口語/手語形式由具該語能力者確認。題庫只測數量概念與學習策略，不能代替真人語言觀察。家庭只需安全紙片三分鐘，無需金錢、住家人數或任何上傳。
