注音符號的認讀與書寫

一次認識一小組，聽得出、找得到，再慢慢寫。

你在書上的國字旁邊，看過小小的符號嗎？它們叫注音符號，能幫我們讀字。今天先選一小組，和大人一起聽、找、讀、寫。整頁可以分很多次學，不必一天全部完成。

建議：主題分次進行：建議10–12次，每次20–30分鐘；依孩子起點調整。首次只學3–4個符號。孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 看到本次學過的符號，能在打亂的卡片中找出相同符號。
  • 聽成人或官方示範後，能指出對應符號並嘗試跟讀。
  • 能觀察起筆、轉折、收筆，依示範書寫本次練習的2–3個符號。
  • 能說出自己容易混淆的一對符號，並用看、聽、再試一次來修正。
  • 完成多次練習後，逐步認識37個常用注音符號。
陪學大人：準備材料
  • 空白卡片與粗筆
  • 大格紙、鉛筆與橡皮擦
  • 可移動的符號卡，每次只放3–4張
  • 一本有注音的繪本
  • 由成人開啟的教育部讀音、筆順頁面；不用註冊或錄音

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

出發：找找書上的小符號

打開一本書。指一個國字，再指旁邊的小符號。

看看：米　ㄇㄧˇ

「米」是國字；「ㄇ、ㄧ」是注音符號；「ˇ」是聲調記號。今天先學認符號。

  1. 大人讀「米」，你看一看。
  2. 用手指找出「ㄇ」。
  3. 在另一處找找看，有沒有同樣的「ㄇ」？
給大人的引導：先讓符號有用途

用孩子熟悉的繪本或姓名例子引起動機，不把「會背ㄅㄆㄇ」當作已能認讀。先給兩張不同符號卡，說「找和書上一樣的」，再試聲音配卡。若孩子只認國字，可由成人指出國字、注音與調號三者的不同功能。

此處「米」只用來認識版面，不要求初學者立即拼讀。聲調、二拼、三拼另有後續主題，本課不以是否會拼詞評量。

給大人的分組與教學次序

總覽完整包含常用37符號。前六組為21個聲符；ㄚ到ㄦ為13個韻符，ㄧㄨㄩ為3個介符；官方手冊把介符列在韻符說明表中。分組是本頁便於查找的編排，不是規定學校必須如此教。

第一天可選ㄅㄇㄧ，也可照學校本週課本選3–4個。一次加入太多形近、音近符號容易混淆；先穩定一個，再作一對比較。ㄢㄣㄤㄥㄦ等組可拆成兩次。每次都用「舊2個＋新2–3個」回顧，最後穿插跨組辨認，不只依固定順序背誦。

符號表上的順序不代表拼音時可任意相接；不要把所有聲符與韻符機械組合成無效音節。

一起學 03

耳朵小偵探：聽、指、再讀

桌上放3張卡。先聽完，再指卡。

  1. 大人先示範一個符號。你可以先聽，不急著讀。
  2. 把三張卡打亂。聽到哪一個，就指哪一張。
  3. 大人再讀一次；你看著卡，跟讀一次。
  4. 把卡蓋住。大人翻一張，請你試著讀。

今天的小任務

用ㄅ、ㄇ、ㄧ玩3回合。每次換位置。選錯了就聽一次、看一次、再找一次。

給大人的正音與回饋

讀音以教育部手冊的音檔或受過訓練的教師示範為準。手冊入口說明：黃色格可聽讀音，藍色格可看筆順。本頁沒有自行合成注音音檔，也不以一般瀏覽器朗讀判定發音。

符號的單讀示範與拼合後的音節需區分。「波」是ㄅㄛ，不能說它就是孤立的ㄅ；也不拿英文字母B的名稱代替ㄅ。先讓孩子聽完整示範，再模仿，不用中文諧音硬記。

錯誤回饋說「你指到ㄇ；我們再聽今天要找的這張」，不要只說錯，也不要讓全班反覆模仿錯音。若口語輸出有困難，允許指卡或配對，將聽辨、視認、發音分開記錄；持續困難時與教師討論支持方式，不用這個遊戲自行診斷。

一起學 04

眼睛小偵探：相像也不一樣

卡片轉正。找兩張相同的，再找不同的。

ㄅ　ㄅ　ㄆ

前兩張相同；第三張不同。請指給大人看。

ㄇ　ㄈ

看看線條在哪裡相接、哪裡留空。

  1. 先讓兩張卡朝同一方向。
  2. 沿著線條慢慢看，不必寫。
  3. 把一張蓋住，再從兩張卡中找回它。
給大人的辨形補救

不要用旋轉符號卡考倒初學者。每次只比較一個特徵：線條位置、開口、轉折或筆畫數，再回到整體字形。ㄅ／ㄆ、ㄇ／ㄈ、ㄉ／ㄌ等可依實際錯誤選一對；沒有混淆就不必全教。

錯把ㄇ認成ㄈ時，先並排教育部範字，請孩子指線條相接的位置，再用粗筆在空中各寫一次。隨後加入一個不相近的符號降低負荷，最後再回測原來的一對。以能認出為目標，不要求背誦成人使用的筆畫術語。

一起學 05

寫字前：手放輕、紙放穩

坐舒服。讓紙穩住。用手指先走一遍。

  1. 找一張高度合適的桌子，身體坐穩。
  2. 慣用手拿筆，另一隻手輕扶紙。
  3. 眼睛看清楚範例；紙張可以微微轉到舒服的角度。
  4. 先用手指在桌上寫，再拿筆寫。
  5. 手累了，放下筆、張開手，休息一下。
給大人的動作支持

左手、右手都可以；不要強迫改慣用手。鉛筆選適合握持的粗細，提供大格和少量練習。若紙張滑動可加止滑墊，若雙手操作困難可由成人協助固定紙。以舒適、可控制、看得到筆尖為原則，不以單一握筆外觀評定成功。

本次只寫2–3種符號，每種2–3個有意識的嘗試。反覆整頁抄寫會讓疲累的手練習錯誤，應看清一筆、寫一個、立即對照。認讀與書寫進度可以不同。

一起學 06

慢慢寫：看示範、跟著寫、自己寫

今天先寫ㄧ，再選ㄅ或ㄇ。一次只看一個。

打開教育部筆順示範，點選今天的符號

第1站：ㄧ

看完整動畫。用手指跟一次，再用筆寫一個。它是一畫；寫完就停。

第2站：ㄅ

先看起點和轉彎。跟著動畫把一畫走完，不在轉彎處自己分成好幾筆。

第3站：ㄇ

看第一筆，再看第二筆。寫完兩筆，看看末筆有沒有多出小鉤。

  1. 看完整示範，不動筆。
  2. 再看一次，手指跟著走。
  3. 照範例寫一個。
  4. 蓋住範例，再寫一個。
  5. 打開範例比一比，選一處調整。
給大人的逐筆示範操作

本頁的格子是原創練習版型，不是重新描繪的官方筆順。實際筆畫方向、轉折與交接以官方動畫為模型。第一次由成人開啟網站，點ㄧ，完整播放；第二輪跟著每一畫的起點移動手指。再用相同步驟示範ㄅ、ㄇ。若頁面無法播放，改用手冊的逐筆圖由成人逐格指出，不用憑印象補畫。

已核對手冊：ㄧ為一畫，ㄅ為一畫，ㄇ為二畫且末筆不鉤。教ㄅ時，觀察孩子是否把一筆中的轉折拆成數筆；教ㄇ時，分清落筆兩次與補描多次。只修正一項，重新示範後留一次修正機會。

接著各次沿用同一流程教新組。下列筆畫數是成人核對表，不要求一年級學生背誦：

  • 1畫：ㄅ ㄋ ㄑ ㄟ ㄣ ㄥ ㄧ
  • 2畫：ㄆ ㄇ ㄈ ㄉ ㄌ ㄍ ㄎ ㄏ ㄐ ㄒ ㄗ ㄘ ㄙ ㄛ ㄜ ㄡ ㄢ ㄦ ㄨ ㄩ
  • 3畫：ㄊ ㄔ ㄕ ㄚ ㄝ ㄞ ㄠ ㄤ
  • 4畫，官方手冊另列可省作3畫的寫法：ㄓ ㄖ

ㄓ、ㄖ的官方手冊列出容許的省筆寫法；請先與學校教法一致，不把官方容許的另一寫法一律判錯。手機字型可能與手寫範字細節不同，以官方手寫模型為準。

一起學 07

符號小郵差：把卡送回家

看一張、找一張，再送給同伴。

  1. 各選3個已學過的符號，當作3間「家」。
  2. 準備同樣符號的信卡，混在一起。
  3. 翻一張，讀或指給同伴看。
  4. 送到相同符號的家；同伴再核對一次。
  5. 交換角色。最後選一個符號寫在空白信卡上。

我翻到ㄇ。我把它送到ㄇ的家，不送到ㄈ的家。

如果我還不會讀，可以指卡，請大人示範後再試。

給大人的分層活動

起步：只放兩間家，先形配形；穩定：三間家，加上聽音送信；熟練：加入兩個已學過但非本組的符號，改由孩子當示範者。不要一次把37個符號鋪滿桌。

觀察一回合的三項：是否認出卡、是否找到相同卡、能否讀或以其他方式回應。書寫另外觀察，不用「讀寫都全對」才能參與。遊戲沒有淘汰制，重試是學習的一部分。

一起學 08

把注音帶回生活

今天只帶一位符號朋友回家。

  1. 選一個你今天學過的符號。
  2. 和家人翻一頁有注音的書，找找它出現在哪裡。
  3. 指給家人看，再聽一次讀音。
  4. 在小卡上寫一個，或從符號卡中選出它。
  5. 說：「今天我學的是＿＿；我還想練＿＿。」

一天找3分鐘就好。找不到時，請家人準備一張卡，明天再找。

給大人的轉移與收尾

請家人只核對當天教過的符號，不提前要求讀整本書。回家任務可以是口頭、指認或紙卡，不需要手機錄音、拍臉或上傳作品。家庭不熟悉國語讀音時，使用本頁官方模型；不要讓家人因不會示範而承擔教學壓力。

隔天先呈現昨天兩個符號，若仍需提示，就先複習再加新符號。各校教材組序和教學節奏不同，這份主題是可調整的練習路線，不是全國統一學期進度。

參考答案：米

米是國字，旁邊的ㄇ和ㄧ是幫忙標音的符號。小小的ˇ是聲調記號。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

教學定位與前測

對應國語文第一學習階段標音符號的正確發音與寫法（Aa-I-1）。37符號是這個主題的累積範圍，不是一節課的認知負荷。先用4張不同符號卡做「看卡找卡、聽音找卡、看卡試讀、仿寫一個」四項前測；能順背但打亂後找不到的孩子，仍需認讀練習。

每次25分鐘的完整流程

  1. 3分鐘，舊知喚回：拿兩個舊符號，打亂位置指認；說出一項已做到的事。
  2. 6分鐘，新符號示範：只教2–3個。每個先聽官方讀音，再看符號、指卡、跟讀。由成人示範完整聲音，避免錯誤類比。
  3. 5分鐘，辨認：兩選一進到三選一，交換卡位；至少給每個孩子個別回應機會，不能只看全班齊讀。
  4. 7分鐘，書寫：每次2–3個符號；完整觀察、逐筆跟隨、臨寫、獨寫、對照。手累可改手指書空。
  5. 4分鐘，遊戲與離堂：完成小郵差一回合，口頭說今天最熟的一個與想再練的一個。

10–12次的彈性安排

每次選總覽中的一小組，也可依學校版本調整。前一次未穩定時保留原組，將5個符號的一組拆開；每3次安排一次舊符號混合辨認。最後兩次可從全部已學符號抽卡，避免只依表格位置辨認。學得快的孩子可在繪本中找符號位置，不能直接要求超前拼長詞。

錯誤對應教法

  • 背得順、抽卡不會：改變卡的位置和出現順序，縮到兩張，再逐漸增加。
  • 形相近就混淆：並排官方範字，只比較一個線條特徵，成功後再加入第三張。
  • 聽到音卻選錯：降低背景聲，先兩選一；用相同的正確模型重播，避免不停換諧音口訣。
  • 認得但寫不出：提供大格、粗筆、描寫起點或手指書空；將認讀與手部控制分開評量。
  • 越寫越重或手痛：立即休息，減量並調整工具；不以抄寫懲罰錯誤。

可觀察的評量與下一步

每次用本次3個符號各測兩次：看符號找相同、聽音選卡、試讀、依示範寫。記「能獨立、提示後能、還需示範」，另記具體混淆對。例：能獨立指出ㄇ，聽音時偶選ㄅ，書寫末端加鉤。下一次先處理這兩點。連續兩次大多能獨立才增加符號；本頁選擇題只檢查概念與視認，不能代替真實聽辨、發音或筆順觀察。

差異化與支持

低視能者可用放大、高對比單卡與可觸摸線條；動作需求者可口述、指認或用選卡完成；聽覺需求者依其既有溝通方式與專業支持調整，不把聽不到判成不努力。孩子有不同語言背景時先連結其熟悉口語，不貶低家庭語言。家長陪練每次3–5分鐘即可。
