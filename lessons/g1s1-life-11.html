歌唱、節奏與簡單樂器

一格一拍，輕輕唱出自己的小樂句

四個空格像四個小座位，每個座位一樣久。聲音可以坐進去，安靜也有座位。一起先指拍點，再試唱一首原創小歌。

建議：3 次，每次 30 分鐘；可依需要分段孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 跟隨平均拍點完成四拍，知道休止仍占時間。
  • 讀懂「拍、拍、停、拍」的圖譜並用動作表現。
  • 學唱一段原創兩音小歌，區分拍點和歌詞節奏。
  • 用安全輕敲為小歌伴奏，輪流開始與停止。
陪學大人：準備材料
  • 雙手、完整紙盒或合宜的現有小鼓；不用豆子瓶、玻璃或小零件
  • 四格拍點卡、圓點和空格卡、紙筆
  • 成人可用自己的舒適聲音示範；若有鍵盤可輕聲給起音，不需音訊檔

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

先找到平均的四個拍點

一、二、三、四，慢慢走一輪。

成人用均勻速度指四格，同時輕念一、二、三、四。每格約一秒只是入門示例，可以更慢；重要的是每格差不多長，不要第一格很久、最後三格擠成一團。拍點像穩穩走路的腳步，可以用指頭點卡，不一定要拍手或站著走。

  1. 畫四個等大的格子，成人均勻指一次。
  2. 孩子跟著指一次，每格只點一下。
  3. 連做兩輪，第四格後回第一格，不突然加快。
  4. 覺得累或跟不上時，先停，成人放慢再開始。
給陪學大人：帶領與觀察

不把每秒一拍當必達標準，不用節拍器強迫速度。聽覺支持者依可見指格；動作支持者用眼神選擇或口述，由成人點格。不以拍手音量判斷節拍穩定，保持舒適低聲。

一起學 02

拍、拍、停、拍

安靜那格，也要等一拍。

四格圖譜是「● ● ○ ●」。這一課約定黑圓點表示輕拍一下，空心圓表示安靜一拍。成人邊指邊做：拍、拍、手停著、拍。第三格不是拿掉，也不是把第四拍提早；我們把時間留給安靜，整輪仍有四拍。

  1. 成人先慢慢口述四格的意思。
  2. 孩子先只指格，不出聲。
  3. 再加入輕拍或輕點桌面，第三格保持手停著。
  4. 成人在第三格也持續指示，讓孩子看見休止的時間。
給陪學大人：帶領與觀察

本課圓點是自訂圖譜，不是要背標準音符名稱。常見錯誤是跳過休止，成人用連續指格修正，不用提高口令聲。孩子可用空中小動作代替接觸拍打，避免皮膚或聲音不適。

一起學 03

一拍裡也能放兩個輕聲

拍點不變，小聲可以分開。

現在第二格改成兩個小點，表示這一拍內平均輕點兩下。四格讀作「拍｜輕輕｜停｜拍」。第二格不是拖成兩拍，而是在原本一拍的時間中放兩個小聲。先慢慢做，不必今天就很熟；只做前一節四格也算完成入門。

  1. 成人一手均勻指四拍，另一手示範第二拍兩下。
  2. 孩子先念「一｜二和｜三｜四」，三仍安靜用指格表示。
  3. 再用兩個手指在自己腿上輕點，保持舒服。
  4. 比較兩種圖譜，指出只有第二格的聲音數量改變。
給陪學大人：帶領與觀察

此為可選進階，不把口令中的「三」真的大聲念出破壞休止；可由成人內數並指格。若雙重任務太難，先聽／看一遍後只做第二格，不要求同時唱歌和伴奏。

一起學 04

原創小歌：小花點頭

只有兩個音，也能有高低。

這首歌的每個字唱一拍，四拍一小句。唱名 3 是 mi、5 是 sol，5 比 3 高。原創歌詞與旋律：小 花 點 頭（3 3 5 5）；微 風 輕 吹（5 5 3 3）；我 們 一 起（3 5 3 5）；慢 慢 向 前（5 3 3 3）。成人先選舒服音域，若用鍵盤可用 E4 為 3、G4 為 5，再依孩子舒適度整體移高或移低。

  1. 先照平均拍點念歌詞，不急著唱。
  2. 成人哼第一句兩個音，孩子用指格或舒適聲音回應。
  3. 一次學一句，再接兩句，中間自然換氣。
  4. 不想唱者用手指出高低，或負責四格拍點。
給陪學大人：帶領與觀察

旋律、歌詞與圖譜均為原創，沒有附錄音或合成音，不宣稱網頁能播放。成人須先能分清兩個起音再示範；可選現有鍵盤低音量確認，不需另購樂器。不追求音準排名，不要求超出自然音域或憋氣。

一起學 05

給小歌加一條輕伴奏

先分工，再一起開始。

歌唱者唱第一句「小花點頭」，伴奏者每句使用「拍、拍、停、拍」。第三拍歌聲仍唱「點」，只是伴奏休息；不同工作可以在同一拍做不同的事。開始前成人用手指預備四拍，大家依同一拍點進來，結束時一起停，不比誰蓋過誰。

  1. 先讓成人唱，孩子只指伴奏四格。
  2. 再選雙手輕點或用手指輕敲完整紙盒。
  3. 第三拍伴奏不敲，但仍看成人唱到哪一字。
  4. 一小句結束就停下確認，再交換角色或保持原角色。
給陪學大人：帶領與觀察

只用手或合宜現有樂器，禁用玻璃瓶、尖棒、未封牢填充物或裝豆子的自製沙鈴。聲音敏感者可做無聲指揮。成人先示範輕敲與停止，任何人不適立即停，不靠加大聲量整齊隊伍。

一起學 06

改一格，聽出不同

先留下原來的，再比較新版本。

小晴把伴奏第三格改成輕拍，得到「拍、拍、拍、拍」；阿圓把第四格改成停，得到「拍、拍、停、停」。兩種都仍是四拍，只是有聲和安靜的位置不同。創作不是亂加快，可以先保留拍點，只變一格，讓自己說得出變了什麼。

  1. 把原圖譜排出來，成人讀回確認。
  2. 孩子選只換一格，黑點換空心或相反。
  3. 先指新版本一輪，再輕聲演一輪。
  4. 說「第幾格從什麼變成什麼」，不一定要用數字可直接指。
給陪學大人：帶領與觀察

成人不要擅自改掉孩子的構想；先確認是否仍能在四格內演出。若加入兩小點，重新約定一格仍一拍。不以複雜度評價創作，也不使用他人現成歌曲作為本站原創。

一起學 07

小小演出，先問願不願意

展示一小句，也可以只指譜。

今天的成果可以是唱一句、輕拍一輪、用手指一張譜，或告訴大人安靜格怎麼做。觀眾先聽或看完，再說具體觀察：「第三格你停了一拍。」不是只說誰最好聽。演出只在願意的對象面前進行，不必錄影或傳上網。

  1. 選唱、拍、指譜其中一種。
  2. 和成人約定開始提示及結束提示。
  3. 完成一輪，聽一個具體回饋。
  4. 選下一次要練的部分，例如不跳過停拍，再試一次。
給陪學大人：帶領與觀察

可完全不公開演出，成人一對一觀察即可。形成性記錄拍點是否平均、休止是否保留、能否辨兩音走向和尊重聲量，不以音色、嗓音高低或膽量評分。家庭練一小句即可，嗓子不適即停止。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

課前確認與課程定位

本課以生活課程第一學習階段的節奏、歌唱與創作表達為方向。主題與活動是跨版本原創示例，不是全國統一學期進度。先確認紙盒完整、場地安靜，準備四格大圖和停止手勢。成人預先練習原創兩音旋律，可用現有鍵盤 E4／G4 對照，再整體移調到舒適音域。沒有音高示範能力時先做節奏課，不假裝已播放示範音檔。

第 1 次：觀察與示範（30 分鐘）

0–10 分均勻指四拍；10–20 分練黑點與空心圓，特別保留第三拍；20–27 分比較有無休止的差別；27–30 分出口任務是指讀四格，尚未穩定者只做兩格交替。

第 2 次：操作與修正（30 分鐘）

0–8 分選做一拍兩小點，非必要門檻；8–20 分每次一小句學兩音原創歌；20–27 分兩句串連，自然換氣；27–30 分孩子用唱、指高低或拍點回應，尊重不唱的選擇。

第 3 次：轉用與回顧（30 分鐘）

0–12 分一人唱一人指伴奏，再加入輕敲；12–20 分改一格並比較；20–27 分自選微型展示與具體回饋；27–30 分自評下一小步。整段可以分日完成，勿長時間反覆唱同句。

差異化支持

尚未識字者由成人讀題，孩子可指物、選圖或操作；不以讀字速度評量生活理解。需要記憶支持時，一次只出示一張步驟卡，完成後再提供下一張。視覺、聽覺、動作或口語表達需要調整時，使用孩子既有的放大圖、觸覺標記、手勢或輔助溝通；孩子可做決定，由大人協助執行。已能獨立完成者改變一項條件，請他說明理由，不增加競速或代管其他孩子安全的責任。

迷思與回饋

休止常被跳過，要持續指格而非重喊；一拍兩聲常拖成兩拍，要先維持成人拍點；音高不等於大聲，旋律只作兩個舒適相對音；第三拍伴奏休止不代表歌者也必須停，先分角色演示。

形成性評量與下一步

觀察四拍等距、休止保留、兩音方向、角色配合和安全停止；旋律表現以可參與與辨差異為主，不作專業音準診斷。每項記錄「獨立完成、提示後完成、共同完成」並保留一個具體行為例子；選擇題僅協助查概念，不能取代操作。孩子答錯時，先問他依據什麼，再回到道具重試，不公布排行榜。

家庭延伸與隱私

家庭選一張四格譜指讀兩輪即可，不需買樂器、錄聲或把孩子的演唱公開。家庭可用最熟悉的語言陪學，沒有材料時使用圖畫或口述即可。不要求購物、拍攝家庭空間、上傳照片、填寫住址或公開身體及家庭經驗。
