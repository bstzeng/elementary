朗讀與語句停頓

先讀懂，再把一組意思讀在一起；停頓讓人聽清楚。

朗讀是讓別人聽懂文字。不是每個字都停，也不是一口氣讀完。今天讀小安的種子卡，先找意思，再試讓聲音跟著意思走。

建議：2–3次，每次20–25分鐘；每次朗讀1–3句，不比速度。孩子可由大人陪讀

出發前

準備好了嗎？

這一課，我會練習

  • 能先理解短句，再依詞語與意思連讀。
  • 能在逗號、句號等適當位置自然停頓。
  • 能用自然聲音讀出陳述、詢問與驚嘆的不同語氣。
  • 能在錯讀後修正，再回讀完整短語或句子。
陪學大人：準備材料
  • 本課原創短文大字卡
  • 可移動的短語卡和暫時停頓標記
  • 成人清楚自然朗讀示範

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

先讀懂這三句

先聽成人讀，再說大概發生什麼。

小安拿起種子卡。
卡上畫著豆子，旁邊寫著名字。
小安看了看，把卡放回盒裡。

這段是原創閱讀練習。種子卡是畫有種子的卡片，並不是要求你拿真種子吃或種。

先問：誰拿卡？卡上有什麼？最後卡到哪裡？理解這些，朗讀時才知道哪些字要連在一起。

  1. 成人完整讀一遍。
  2. 孩子指出人物小安。
  3. 找卡上豆子圖與名字。
  4. 用一句話說小安看卡後放回盒裡。
給大人的引導與觀察

先理解再流暢，不把朗讀等同猜字速度。由成人讀未知國字，允許孩子只讀熟悉短語。種子卡的情境和安全範圍明確，避免引入真種子相關操作。

一起學 02

詞語是一小組，不隨便拆開

把小安、種子卡讀在一起。

小安／拿起／種子卡。
卡上／畫著豆子，／旁邊／寫著名字。

斜線是練習時幫你看一小組意思的記號，不是正式標點，也不是每處都要停很久。先把一小組說順，再連成自然句子。

不要把「種子卡」每個字都停一下，也不要把小安的名字拆成沒有關係的兩段。

  1. 成人指一組讀一組。
  2. 孩子跟讀熟的一組。
  3. 移除斜線，成人自然連讀。
  4. 孩子試讀整句，聽眾確認聽懂物品是種子卡。
給大人的引導與觀察

短語切分有多種合理讀法，示例只作支持，不當唯一答案。不能把每個斜線變成等長喘氣；短句熟練後淡化支架。若孩子不懂拿起，先用卡片動作示範，再讀詞。

一起學 03

逗號稍歇，句號收好

停頓配意思，不用數固定秒數。

卡上畫著豆子，旁邊寫著名字。
小安看了看，把卡放回盒裡。

逗號讓句子中間的意思分得清楚。句號告訴我們一個完整句子結束。通常句末停頓會比句中更明顯，但不是每次都要停同樣幾秒。

讀到標點，不用讀出「逗號」「句號」這些名字。練習朗讀與討論標點是兩件事。

  1. 成人先讀一次沒有停頓的版本，再讀自然版本。
  2. 孩子說哪次較容易理解。
  3. 指出逗號和句號的位置。
  4. 試讀一個句子，依意思自然停。
給大人的引導與觀察

比較時不要用過度誇張的錯讀反覆灌輸。停頓也受語意、句長與呼吸需要影響，不教「有標點才准停」或固定拍數。標點功能以教育部手冊為依據。

一起學 04

同一句開頭，不同語氣

說一件事、問問題、表示驚喜。

「這是豆子。」
「這是豆子嗎？」
「豆子發芽了！」

第一句是在告訴對方一件事；第二句是在詢問；第三句表示驚喜或較強烈的感受。先理解意思，再用自然聲音表達。

問句不需要每個字都升高，驚嘆也不等於一定大喊。讓聽眾聽得清楚，喉嚨舒服就好。

  1. 成人依情境各示範一次。
  2. 孩子指出哪句在問。
  3. 再指出哪句在告訴一件事。
  4. 選一句試讀，聽眾說他聽到的意思。
給大人的引導與觀察

國語字調與句子語調不同，不能為問句把所有字改成二聲。朗讀的情感表現允許差異，不指定只有某種腔調算有感情，也不以戲劇性表演衡量閱讀理解。

一起學 05

讀錯可以修，再回到意思

停一下，改好，不用整篇重來。

你讀到盒裡，覺得盒這個字還不熟，先停一下看清國字與注音。請成人示範，修正盒這個字，再讀「放回盒裡」。

只重複一個字可能還沒接回意思；讀完短語後，再把整句自然讀一次。盒和河都讀ㄏㄜˊ，但字形和意思不同；只聽聲音不能知道原文是哪個，還要看字和句意。

  1. 指出不確定的字。
  2. 請成人或官方字音模型示範。
  3. 讀對一個字。
  4. 回讀它所在的短語。
  5. 最後讀完整句子，確認意思通順。

盒裡 → 放回盒裡 → 小安看了看，把卡放回盒裡。

給大人的引導與觀察

孩子對盒字不熟時，成人先示範正確字音，練習由字回到短語與句子。另以同音的盒、河說明：字形與語意仍須核對，不能聲稱可只靠聽音分出這兩字，也不把同音字誤認當成發音錯誤。

一起學 06

回聲讀、接力讀，再自己讀

成人一句，你跟一句。

  1. 成人讀第一句，孩子看著文字聽。
  2. 孩子跟讀整句或一個短語。
  3. 第二輪成人讀前半，孩子接後半。
  4. 第三輪孩子選一整句自己讀。
  5. 聽眾說回意思，再指出一處清楚停頓。
  6. 只改一項，再讀一次作比較。

接力位置選在完整詞語之間，不故意把詞拆開。小組不比誰最快，不突然點名尚未準備的孩子長篇朗讀。

你可以先和成人一對一，或只指停頓位置；讀得慢也能讓意思很清楚。

給大人的引導與觀察

示範、共同讀、獨立讀逐步退支持。觀察是否只背聲音而不看字，可換一句出現位置或請指正在讀的詞。口語需求者可用指認分組和聽讀理解參與，朗讀輸出另按個別需求調整。

一起學 07

朗讀小回顧

問聽眾：你聽懂什麼？

  1. 選本課一句最熟的。
  2. 先默看或聽成人讀，確認詞義。
  3. 用舒服速度朗讀。
  4. 聽眾說回人物和動作。
  5. 你選一項自評：字詞、連讀、停頓或音量。
  6. 下一次只練這一項，不一次改全部。

如果聽眾能說出小安把卡放回盒裡，表示意思有傳到。還沒聽清楚，就請他指出哪一小段，再一起調整。

可由成人查教育部標點符號手冊與國語小字典，不以一般機器朗讀當唯一評判。

給大人的引導與觀察

朗讀評量重理解、正確與可理解度，速度不是唯一指標。現場聽和回饋即可，不要求錄音、上傳或同儕排名。自然朗讀方式多樣，成人應指出具體例子而非籠統說沒有感情。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1原創短文裡，卡上畫著什麼？
給我一點提示

先理解內容再朗讀。

看答案與原因

參考答案：豆子

第二句直接說卡上畫著豆子，旁邊寫著名字。

2哪個詞比較適合連在一起讀？
給我一點提示

想想卡片是什麼卡。

看答案與原因

參考答案：種子卡

種子卡是一個有關聯的物品名稱，連讀較能保持意思。

3練習中的斜線是什麼？
給我一點提示

它是練習支援。

看答案與原因

參考答案：暫時的分組提示

斜線幫初學者看語意分組，熟悉後可移除，不是固定停時。

4讀到句號時，一般怎麼做？
給我一點提示

這句意思說完了。

看答案與原因

參考答案：自然停頓，表示一句結束

句號標示完整句子結束，朗讀時以自然停頓表現。

5哪一句是在詢問？
給我一點提示

看問號，也聽意思。

看答案與原因

參考答案：這是豆子嗎？

句末嗎和問號表明這句在詢問對方是否為豆子。

6讀驚嘆句一定要大吼嗎？
給我一點提示

讓意思清楚也要讓喉嚨舒服。

看答案與原因

參考答案：不用，理解語氣並用舒服的聲音

驚嘆表現較強感受，不等於傷嗓子地大喊或改變每字聲調。

7更正一個不熟字後，下一步較好的是？
給我一點提示

從小部分回到整句。

看答案與原因

參考答案：回讀短語，再讀整句

回到短語與整句可把修正的字接回原來意思。

8盒與河讀音相同，能只靠聲音確定原文是哪個嗎？
給我一點提示

同音不表示同字同義。

看答案與原因

參考答案：不能，還要看文字與句意

同音字不能單靠聲音區分，需用字形和放回盒裡的情境核對。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

教學定位

對應5-Ⅰ-1、Ac-I-1、Ac-I-3等方向。從理解短文、辨識短語、自然停頓到自我修正。成人先讀原創三句，確認種子卡是畫卡，豆子、名字、盒裡等詞義已懂；沒有理解就先處理詞義，不用反覆催快。

兩至三次教學

  1. 第一次25分鐘：5分鐘聽讀理解，7分鐘短語卡分組，6分鐘回聲讀，4分鐘去斜線自然讀，3分鐘人物動作回答。
  2. 第二次25分鐘：5分鐘複習，7分鐘逗號句號，6分鐘三種語氣，4分鐘一項自我修正，3分鐘聽眾回述。
  3. 第三次可選20分鐘：接力讀到自選獨立一句，對照第一次，只追蹤一項進步。

精準教學要點

斜線是可撤掉的教學提示，不是正式標點或固定秒數命令。詞組切分可以有合理變化，重點不拆破語詞與意思。句末通常較明顯停頓但仍依語意，問句不把字字改二聲，驚嘆句不用大吼。成人勿用單一朗誦腔作唯一標準。盒與河同音，相關段落只作字形與語意查核，不能把同音字當聽音辨字題。

差異化與回饋

起步者跟讀一詞或指語意分組，一般組朗讀一句並回答內容，進展組跨兩句自然停頓、察覺不合理字義並查證。視覺需求用大字與遮行卡，聽覺支持依現有輔具與文字，口語輸出困難者以內容理解和停頓辨識表現學習，另評其可行的發聲方式。尊重不同國語口音，不把語言背景差異等同閱讀差。

卡住時提示看字或注音，成人給正確示範；更正後回短語再回句，不必從全文第一字重來。成人回饋「你把種子卡連在一起，所以我聽懂物品」比要求更有感情清楚。一次只修字音、分組或停頓其中一項。

觀察證據

每次記一個理解回答、一句朗讀中的詞組連讀及一處自然停頓，標示是否依賴成人模型。選擇題只是概念檢查，不能代替朗讀觀察。家庭讀一至三句即可，聽眾回述意思，不以速度、分貝或錄音排名，孩子嗓音不適就停止發聲練習。
