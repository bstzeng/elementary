常見國字與生活語詞

認得樣子，讀出聲音，還要知道在生活裡怎麼用。

字像生活的小標記。看到水，你會想到喝水；看到手，你會想到揮手。今天選幾個常見字，從生活找意思，再回來看清字形。

建議：分3次，每次20–25分鐘；每次選3–4個字，不以本課字數作硬性進度。孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 能認讀山水日月等本次選定的常用字。
  • 能把字形、字音和一個熟悉字義連起來。
  • 能將大、小等字放入生活語詞。
  • 能在字卡換位置後辨認，不只靠圖片與顏色。
陪學大人：準備材料
  • 山、水、日、月、手、口、大、小字卡
  • 相對應簡圖、物品或動作
  • 兩張空白詞卡、官方小字典

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

字有樣子、聲音和意思

看水，聽水，再指水的圖。

水　ㄕㄨㄟˇ　可以說：喝水。
山　ㄕㄢ　可以說：高山。

成人先讀字音，孩子指字卡，再找相對應圖。認字不只是記住黑色的線，也要把線條和口語意思接起來。

今天先選山、水兩個。把字卡移位置，再讀、再找，確認不是只記住右邊那張。

  1. 看字形。
  2. 聽正確字音。
  3. 指對應圖或物品。
  4. 說一個有這個字的語詞。
給大人的引導與觀察

把字形、字音、字義分開觀察後再整合。若孩子會說喝水卻不認水，需字形配對；若會讀水卻不懂詞，在真實生活情境補意義。使用安全熟悉物，不以觸摸熱水或走近水域作任務。

一起學 02

日和月：放進熟悉詞

看日期的日，月亮的月。

日　ㄖˋ：日子、生日。
月　ㄩㄝˋ：月亮、月分。

同一個字在不同語詞裡，意思會有關聯，也可能不完全一樣。生日的日和日子的日都與時間有關；月亮與月分要放回詞裡理解。

成人畫太陽、月亮和一張日曆，讓孩子指圖。只認本課常用意思，不必背所有字典解釋。

  1. 先找月字，成人讀月亮。
  2. 再找日字，成人讀生日。
  3. 把日、月卡打亂，再選一次。
  4. 從生活中的日曆找相同字形，成人可代讀其他字。
給大人的引導與觀察

避免把日永遠等同太陽、月永遠只等同天上月亮。日曆是認字情境，不要求本課孩子理解所有時間單位。多義只用一兩個熟詞自然呈現，不背抽象語義分類。

一起學 03

手和口：用動作幫忙記

揮揮手，指指自己的嘴巴。

手　ㄕㄡˇ：揮手、洗手。
口　ㄎㄡˇ：開口、門口。

手可表示我們拿東西、揮動的手。口可指嘴巴，也會出現在門口這類語詞裡。知道一個意思後，再看其他詞怎麼用。

比動作時只碰自己的身體；不拉同伴的手，也不要求別人張嘴讓你看。

  1. 成人說揮手，孩子做動作或選圖。
  2. 選出手字卡。
  3. 成人說門口，指教室門的位置。
  4. 找口字，和單說嘴巴的意思比較。
給大人的引導與觀察

動作是記憶支援，不是每個字義的字源證明。本頁不編造「古人照著這個姿勢造字」的故事。口在門口為開口處等引申用法，由語詞理解即可，不必要求抽象解釋。

一起學 04

大和小：比較要有對象

同一張圖，兩個大小比一比。

大　ㄉㄚˋ　　小　ㄒㄧㄠˇ
大球／小球　　大手／小手

成人畫一大一小兩個圓，說這是兩顆球。孩子先指大球，再選大字；小球同樣配小字。

大與小需要比較情境。一顆球和更大的球放一起，可能成為其中較小的一顆；字的用法要看我們在比什麼。

  1. 只比較同類的兩顆球。
  2. 分別放大、小字卡。
  3. 交換球圖位置，再放字卡。
  4. 用「這是大球」或「這是小球」說明。
給大人的引導與觀察

不拿孩子身材、家庭大小或物品價格排名。本活動只是建立比較詞語，不混入面積計算。成人先控制只改大小、不改顏色，避免孩子依顏色猜字。

一起學 05

換個地方，還認得嗎

把圖片蓋住，留下字卡。

  1. 桌上放山、水、手、口四張卡，也可只放兩張。
  2. 成人依次讀兩個字，孩子指卡。
  3. 將所有卡換位置，再讀同樣字。
  4. 拿掉圖，只留文字，再試認一個。
  5. 在兩種清楚字體的印刷品中找相同字，成人先確認字形正確。
  6. 配回語詞，如喝水、揮手。

有時同一個字在書上印得粗一些、細一些，仍是同一個字。先看主要線條，不只靠字的大小。

遇到草寫、裝飾字或看不清的招牌，可以先跳過，用清楚模型核對。

給大人的引導與觀察

不要把辨認不同字體變成美術字猜謎。先用標準清楚字體，熟練後才做有限變化。每次測同字不同位置與同位置不同字，才能看出是否真的認字；不一次鋪滿全部生字。

一起學 06

生活語詞配對店

把字放進能說得通的詞。

喝＋水 → 喝水
揮＋手 → 揮手
小＋山 → 小山

  1. 成人提供完整語詞，讀一遍。
  2. 孩子從山、水、手卡中補回缺字。
  3. 讀整個詞或指出意思。
  4. 把詞放進短句：「我喝水。」
  5. 成人遮住其中一個字，孩子從兩張卡找回。

今天只學部分國字，喝、揮、我可以由成人讀寫。你不必先會寫每個字，才能理解整個詞。

不是兩字任意相接都成為常用詞，遇到不確定用法，請成人查小字典或換熟詞。

給大人的引導與觀察

示例是原創生活搭配。補字題可先給圖，再退圖；若語詞不熟，先澄清口語，不能以錯配推論字形不會。成人代寫未教字，避免順便增加大量書寫負擔。

一起學 07

我的三字生活卡

選三個字，讓它們各有一個用途。

  1. 選今天最熟的三個字；起步者選一個即可。
  2. 每字配一個圖、動作或生活詞。
  3. 成人先讀，孩子再指。
  4. 把卡帶到另一張桌子，換位置再辨認。
  5. 明天先找回這些舊字，再加一個新字。

例如：水配喝水，手配揮手，月配月亮。選你真的懂的詞，比把字表全背完更有用。

由成人使用教育部國語小字典核對字音字義，需要寫字時再開官方筆順學習網。

給大人的引導與觀察

認讀和書寫可不同步。本課不要求八字一次默寫，課綱的第一階段累積字詞量也不是一學期或單課配額。家庭每天從熟悉標籤找一字即可，不需把家中所有物品拍照上傳。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1「喝水」裡，哪個是水？
給我一點提示

看本課第一站的水字卡。

看答案與原因

參考答案：水

水是喝水的水，字形和山、手不同，要看清楚再選。

2「揮手」和哪個動作相配？
給我一點提示

找身體的手。

看答案與原因

參考答案：把手揮一揮

揮手是手的動作，可以用動作連結語詞與字義。

3哪組能組成本課的熟悉語詞？
給我一點提示

想想平常喝的是什麼。

看答案與原因

參考答案：喝＋水

喝水是本課的生活語詞，不能只把任意字接起來。

4月只可以表示天上的月亮嗎？
給我一點提示

看看第二站的兩個詞。

看答案與原因

參考答案：不是，月分也會用到月

月在月亮與月分中有相關但不同的用法，要回到詞裡理解。

5想確認是真的認得字，可以怎麼做？
給我一點提示

讓字換個地方。

看答案與原因

參考答案：換位置、蓋住圖再認

換位置並去掉圖片，能檢查是否認字形，而非背位置或猜圖。

6兩顆同類球，一顆較大一顆較小，應如何配？
給我一點提示

比較球的大小，不看位置。

看答案與原因

參考答案：大字配較大球，小字配較小球

大、小在這個明確比較情境中分別對應球的相對大小。

7會認字但還寫不好，應怎麼記錄？
給我一點提示

把不同能力分開觀察。

看答案與原因

參考答案：認讀與書寫分開看

認字與手部書寫是不同面向，可保留認讀進步並另練書寫。

8看到不清楚的裝飾字，怎麼辦？
給我一點提示

先讓字看得清楚。

看答案與原因

參考答案：找清楚的官方或印刷模型核對

清楚模型能確認字形，不能把裝飾筆畫誤認為標準寫法。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

教學定位與選字

對應Ab-I-1、Ab-I-5、Ab-I-6的字音字形字義及語詞使用方向。第一階段跨一二年級，課綱累積字數不是本課或小一上的一次要求。八字是可選材料，每次依學校和孩子起點選三至四個；本課不保證取代任何版本的完整生字表。

每次25分鐘

  1. 4分鐘先看生活物與圖，確認口語詞義；6分鐘成人示範字形與字音；5分鐘字圖配對；5分鐘換位置和拿掉圖；3分鐘放進熟詞短句；2分鐘離堂認一字並說一個用途。
  2. 第二次可選日月或手口，第三次選大小與混合舊字；每回至少保留兩個舊字，錯誤多就減新字。

錯誤的分流處理

能按圖猜但遮圖就不會，先做兩張純字形配對；會讀卻配錯物，補詞義；字形相近時一次只比一個特徵，不整組轟炸；只記左右位置時換位再測；知道水的意思但寫不出時，將認讀記為已會、書寫另列，不要求抄十遍證明理解。

字義與情境

日、月、口等有不同常用意思，採生日、月亮、月分、門口等熟詞示範，不說某字永遠只有一個解釋。動作與圖像只是助記，不當字源學說。大、小比較要給明確對象，不用孩子身材或家庭資源排名。成人查官方小字典核對讀音，未教字可代讀代寫。

差異化與形成性評量

起步組一至二字，保留圖、聽音選卡；一般組三至四字，移位去圖後辨認，再組一個熟詞；延伸組在新排版讀同字，指出同字不同詞的用法。視覺需求者使用大字、高對比；動作需求者指卡或由成人移卡；口語需求者配圖也能顯示理解。家庭語言可用來澄清字義，避免把詞彙背景差異當低能力。

紀錄每字三項：看到能認、聽音能找、知道一個用法。至少換一次卡位並移除圖，確認不是記憶版面。網頁題可成人代讀，不要求識所有題幹國字。結束由孩子挑最有把握的一張和一張要再練的，下次以此開課；不比認字速度或總數。
