讀懂提醒，一起把約定練成做得到的事

出發前

準備好了嗎？

這一課，我會練習

  • 用先、再、最後排出一小段活動順序。
  • 分辨提醒訊號與下一步行動。
  • 說明一項班級約定為誰提供幫助。
  • 遇到例外或需要調整時，能告知成人並參與修正。
陪學大人：準備材料
  • 四張活動圖卡：閱讀、休息、整理、放學
  • 紙偶、共用蠟筆或圖卡、紙和筆
  • 成人事先核對的本班作息及求助方式

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

一天有先後，不是一直做同一件事

看圖，知道接下來要做什麼。

小晴的模擬上午有三個活動：先閱讀，再休息，最後整理。順序讓我們知道什麼時候準備、什麼時候收尾。這不是每所學校共同的課表；你班上的時間可能不同。今天先學會看一小段提示，不急著看懂整張鐘面或背完一天。

  1. 成人擺出閱讀、休息、整理三圖，依序念一次。
  2. 孩子用手指或紙偶從第一格走到最後一格。
  3. 拿走中間圖，問「閱讀後接哪一張？」再補回。
  4. 換成本班已確認的一小段順序，重新排一次。
給陪學大人：帶領與觀察

本課不教授鐘面讀時，也不假定鈴聲用途一致。以圖卡和成人口述降低識字負荷，順序只維持二至三步。孩子排錯時對照實際活動做一次，避免只背字詞而沒有理解先後。

一起學 02

提醒不是催你跑

先停一下，看清楚再移動。

模擬班級用一張「收一收」圖提醒活動快結束。看到它，小晴先停手，看自己還有什麼要收，再走到集合處。提醒可以是聲音、燈號、圖卡或成人告知；有人需要看見圖卡才知道，不代表他故意不聽。每班要先說清楚哪個提醒代表哪一步。

  1. 約定今天把手掌圖舉起，表示「先停、看下一張圖」。
  2. 成人舉圖，孩子先停手，再看整理圖。
  3. 把一樣道具放好，用走的移到安全座位。
  4. 交換成無聲提示再演一次，看看大家能不能收到訊息。
給陪學大人：帶領與觀察

不用大聲鈴響、突然關燈或嚇人的訊號。先預告再演，確認視線和可見範圍。行動不便者以紙偶移動；聽覺支持應兼有視覺提示。重點是懂得確認下一步，不是所有人反應一樣快。

一起學 03

約定是在幫誰？

把「要乖」換成看得見的行動。

「大家要乖」太難猜。改成「借共用筆先問，用完放回盒」，我們就知道要做什麼。這項約定讓正在用的人不被搶，也讓下一個人找得到筆。好約定不只是命令，還有想保護的事：安全、彼此的選擇，或一起使用的機會。

  1. 成人演兩幕：直接搶筆；先問再等。
  2. 孩子指出哪一幕讓使用中的人有選擇。
  3. 把「愛惜用品」改說成一個動作，例如輕放。
  4. 選一項約定，補上「這樣可以幫助……」。
給陪學大人：帶領與觀察

避免以「守約定才是好孩子」評價人格。成人也要遵守約定，例如借孩子的筆先問。需要協助才能做到的動作，應加入支持方式，不把障礙或未識字列為違規。

一起學 04

一起訂一項能做的約定

說清楚誰、什麼時候、怎麼做。

兩個紙偶都想用一枝紫色蠟筆。阿圓建議「誰大聲誰先」，小晴建議「先問，畫完一個圖形再換」。第二個方法比較容易知道何時輪替，也不用比力氣。兩人還要同意才開始；如果畫一個圖形太久，可以一起改成更短的小任務。

  1. 選共用蠟筆或圖卡，不用私人珍愛用品。
  2. 討論「輪到誰、做多少、怎麼交接」。
  3. 用紙偶演兩次輪流，交接時說「換你」。
  4. 問兩個角色是否都能參與，有困難就改一項。
給陪學大人：帶領與觀察

不使用無限等待作為輪流練習。成人掌握短時段，必要時提供另一色或替代活動。進階者比較兩個方案的利弊；入門者從兩張方案圖選擇。協商不能取消任何人的身體界線或基本需求。

一起學 05

約定遇到急事，可以求助

身體需要不必一直等。

班級約定輪流發言，小晴卻突然很不舒服。她可以直接告訴老師「我不舒服，需要幫忙」，不必先把整段話說好，也不必忍到輪到自己。平常的提醒要幫助生活，不能讓人錯過緊急協助。不了解是不是急事，也可以先告知成人。

  1. 紙偶演「我有一個分享」和「我的身體很不舒服」。
  2. 前一種練等輪流；後一種練直接告知成人。
  3. 成人回答「我聽到了」，示範接住求助。
  4. 討論原約定可加上「急需幫忙時直接告知」。
給陪學大人：帶領與觀察

具體如廁和緊急聯繫依本班安排。避免讓孩子判斷他人病情真假，也不要求說明個人病史。以虛構角色演練，不引導揭露家庭或創傷經驗。成人須清楚允許急迫需求直接求助。

一起學 06

忘了，不是只能被罵

停一下，修正，再練一次。

阿圓用完共用筆忘了放回，下一個人找不到。他可以說「我忘了，現在放回」，再看筆盒上的小圖提醒。修正是做一件讓事情變好的行動，不是只說對不起，也不是把責任推給別人。若同一件事常忘，還可以把提示放在更看得見的位置。

  1. 成人先說明這是演練，故意把道具留在桌上。
  2. 孩子指出發生什麼，不用給角色貼「壞」標籤。
  3. 選一個修正動作並做出來。
  4. 加入一張小提醒，重演用完歸位的過程。
給陪學大人：帶領與觀察

對反覆困難先檢查要求是否清楚、材料是否可及、活動時間是否足夠。勿用剝奪如廁、飲水或羞辱處理忘記。形成性回饋指出「你發現別人找不到，願意放回並改提示」，而非只稱讚服從。

一起學 07

開一次小小約定會議

留下有幫助的，調整卡住的。

試過的約定可以再討論。兩個角色發現「全部畫完才換筆」等待太久，改成「畫一個小圖形就換」。改約定前先說哪裡卡住，讓每個人有表達機會，再共同試行。改變不是偷偷不照做，而是把新的方法說清楚，讓大家知道。

  1. 回顧今天的一項約定：有幫助的地方是什麼？
  2. 用角色指出一個困難，可說「我等不到」。
  3. 選一個小改法，成人寫字或畫圖。
  4. 再試一輪，決定保留或下次繼續調整。
給陪學大人：帶領與觀察

孩子可不公開發言，用指圖或成人代述也算參與。不能以多數決要求少數人接受不安全行為。班級實際制度需教師確認；家庭陪學只模擬兩個角色，不宣稱已更改校規。

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

參考答案：先停手，再看下一張提示

提醒讓我們知道要確認下一步，不是要求突然衝跑或亂丟物品。

哪一句可以直接演出來？

看答案與原因

參考答案：用完共用筆放回盒

看得見的具體動作比「要乖」清楚，大家才能理解並練習。

需要讓兩個人都有機會。

參考答案：先同意畫一個圖形再換

說清楚輪流的範圍並取得同意，能讓雙方知道何時有機會使用。

5正在輪流分享，我突然很不舒服。可以怎麼辦？
給我一點提示

急需幫忙時，成人需要知道。

看答案與原因

參考答案：直接告訴老師需要幫忙

緊急身體需求可以直接告知成人，不能為了輪流而一直忍耐。

6忘了把共用筆放回，最有用的修正是？
給我一點提示

做什麼能讓別人找到筆？

看答案與原因

參考答案：放回筆，再用提示重練

修正需要實際行動；歸位並增加提示，可以讓下一位使用，也幫自己記住。

7一項輪流方法試過後讓人等太久，可以怎麼做？
給我一點提示

先讓大家知道哪裡卡住。

看答案與原因

參考答案：說出困難，商量改法再試

約定可以檢查是否有幫助；共同說明並試改，比暗中不遵守更清楚。

8同學需要看圖才知道活動換了，怎麼做合適？
給我一點提示

提醒是要讓每個人都收得到。

看答案與原因

參考答案：讓提醒也有清楚的圖示

不同的人接收訊息方式不同；可見圖示能幫助理解，不應因此嘲笑。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

課前確認與課程定位

本課以生活課程第一學習階段的生活規範、表達與合作為方向。主題與活動是跨版本原創示例，不是全國統一學期進度。先核對本班訊號及緊急需求通報；不直接沿用示例。準備可見圖卡和安全移動範圍，避免突發噪音。

第 1 次：觀察與示範（30 分鐘）

0–8 分排三張活動圖；8–18 分分兩次示範無聲提醒與下一步行動；18–25 分孩子操作紙偶並說先後；25–30 分用一組新順序確認能否轉用，成人只給必要提示。

第 2 次：操作與修正（30 分鐘）

0–8 分演搶筆與先問；8–20 分協商一條可操作的輪流約定並試行；20–27 分討論每個角色是否有機會；27–30 分出口任務為說明約定幫助誰及怎麼幫。

第 3 次：轉用與回顧（30 分鐘）

0–10 分比較日常輪流與急需協助；10–18 分演忘記後修正；18–26 分進行一次小會議，修改不合用的約定；26–30 分挑兩道新情境題並選下次要練的動作。

差異化支持

尚未識字者由成人讀題，孩子可指物、選圖或操作；不以讀字速度評量生活理解。需要記憶支持時，一次只出示一張步驟卡，完成後再提供下一張。視覺、聽覺、動作或口語表達需要調整時，使用孩子既有的放大圖、觸覺標記、手勢或輔助溝通；孩子可做決定，由大人協助執行。已能獨立完成者改變一項條件，請他說明理由，不增加競速或代管其他孩子安全的責任。

迷思與回饋

孩子把約定當不能改的命令時，回到筆輪替的等待問題；把變通當隨意破壞時，示範先說困難、共同調整、再試行。若孩子認為安靜就不能求助，成人當場示範接住不舒服的通報。

形成性評量與下一步

證據包括排出先後、收到提示後查看、說出約定目的、在例外情境求助及提出一個修正。每項記錄「獨立完成、提示後完成、共同完成」並保留一個具體行為例子；選擇題僅協助查概念，不能取代操作。孩子答錯時，先問他依據什麼，再回到道具重試，不公布排行榜。

家庭延伸與隱私

在家選一項共用物品約定，試一次後聽孩子是否容易做到，不要求全家簽約或拍攝遵守紀錄。家庭可用最熟悉的語言陪學，沒有材料時使用圖畫或口述即可。不要求購物、拍攝家庭空間、上傳照片、填寫住址或公開身體及家庭經驗。
