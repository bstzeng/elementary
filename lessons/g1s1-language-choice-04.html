學校生活與學用品

聽／看詞找用品，換位置再試；用本路線已核實詞彙完成一個學校小任務。

先選自己的語言路線。影音須成人和語言教師確認完整可用；臺灣手語影片本次未完成全段播放及形式核驗，實作須合格支持。每條只學列出的已核實詞，未備模型的項目不算完成。

建議：選一條路線，建議2節各35–40分鐘。孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 能在本路線辨認兩至三個已教生活詞。
  • 能把詞義連到用品、場所或學校情境。
  • 能在換外觀與位置後仍理解目標詞。
  • 能依正確模型試表達，讓伙伴核對。
  • 知道語言找物練習不取代借用同意與離校規則。
陪學大人：準備材料
  • 本路線兩至三張用品或學校情境卡
  • 一本書、一支安全放置的鉛筆
  • 剪刀僅用圖卡
  • 指定完整官方模型與語言教師支持

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

今天的學校小任務

選本路線兩至三個詞，把語言和看得到的事連起來。

本課只學實際選習路線，並依官方已核實模型取兩至三個生活詞。台語學冊與鉛筆；四縣客語學課本與鉛筆；馬祖閩東語學書、筆、學堂；秀姑巒阿美語學書與學校；臺灣手語學書、上課、放學；越南語學鉛筆盒與剪刀。詞彙範圍不同，各用自己的任務，不要求每人加修其他語言。

先拿安全用品或大圖卡。筆尖朝桌面，剪刀只用圖片，活動不練剪切；書可用一本不用寫字的空白本。學校、上課、放學使用成人畫的情境圖，不需拍校門或透露就讀學校。

模型依賴課程：授課成人先確認詞義、語別與完整示範可用，再讓孩子模仿。手語影片本次未完成全段播放驗證，需合格臺灣手語支持；文字與連結不是動作示範。口語路線也不用自動合成音訊、國語諧音或英文讀字母替代。

今天的完成標準

接收到已教詞能選對物／情境；看到新位置的圖能試著表達；伙伴能核對。這是語詞入門，不宣稱已會借物句或所有學校用語。

一起學 02

原創故事：用品找錯了位置

聽／看清楚再拿，不靠固定順序猜。

小樹準備上學，桌上擺著空白書、鉛筆、鉛筆盒，以及學校圖卡。他想找書，卻因用品換了位置拿到鉛筆。老師先把目標詞和正確物品配一次，再把物品重新排開，讓小樹用訊息來找。

  1. 依自己的路線，只留下今天的兩至三張目標卡；其他卡先收起。
  2. 成人完整示範一個詞，孩子先看／聽完，再選物或圖。
  3. 核對後把物品換位置，再來一輪，不讓一詞永遠在左邊。
  4. 孩子當物品管理員，用已教詞表達；伙伴指到相應物，再詢問是否可拿。
  5. 用品主人同意後才借用，結束放回約定位置。

指認學校的圖，不代表要走出教室；收到放學詞，也只是辨識情境，不是此刻可以自行離校。生活詞和真實行動的安全規則要分清。

需要幫忙時

如果兩詞混淆，先把圖減到兩張，跟模型逐一配對，再隨機選。請重示並不算失敗；對錯應用來決定下一步，不用來比誰聰明。

一起學 03

路線A：臺灣台語，冊和鉛筆

一個用來讀，一個可以寫，先各學一詞。

教育部臺灣台語辭典：冊 tsheh指書；鉛筆 iân-pit是書寫用品。每個詞都開原詞目聽音，不把「冊」照華語念成cè，也不用「鉛筆」的國語讀音。

  1. 成人出示書，播放冊模型，孩子拿書圖配在旁邊。
  2. 出示鉛筆，播放完整鉛筆詞，孩子配鉛筆圖。
  3. 把實物收到透明盒外側，只聽詞選圖；再把圖換位做一次。
  4. 成人抽圖，孩子跟模型後說詞，伙伴從兩件用品指認。
  5. 換成另一封面的書、另一顏色的鉛筆，重做兩次。

換外觀後仍能辨認，表示詞連到一類物品，而不只是那本紅書。先教詞的意思與自然詞音，詞尾和連讀細節由教師帶，不要求小一背規則或一口氣朗讀拼音。

核對任務

聽冊選書、聽鉛筆選筆。若知道意思但表達還不穩，先重聽一個完整詞再試。借用完整句尚未列為本課已教目標，不能任意接未核實句音。

一起學 04

路線B：四縣腔客語，課本和鉛筆

先聽同一腔調，再當用品管理員。

依教育部校園篇四縣腔，第2、3課有課本，第4課印刷頁11有鉛筆。模型對照：課本 ko bunˋ；鉛筆 ienˇ bidˋ。詞義依序為課本與鉛筆。官方配套音檔只選四縣腔相應課次，成人先定位完整詞所在的語段，不把其他腔的相似音混入。

  1. 用一本課本或課本圖與一支鉛筆建立兩詞配對。
  2. 聽第3課原模型時，成人先告訴孩子只要留意課本，不需記全段課堂指令。
  3. 聽鉛筆完整模型，再指鉛筆；一次只要求一個新意思。
  4. 伙伴用已學詞發出找物訊息，管理員先指認，雙方核對後才移動用品。
  5. 交換角色，讓每人有接收及表達各兩回。

課本不是所有紙張都一樣，先用清楚的課本圖；詞彙熟悉後才比較課本與普通畫紙。頁面拼音供成人校對，孩子不必抄寫。家庭若使用其他腔調，另選該腔完整教材，不用四縣標音強迫改家人說法。此處是找物詞，完整指令句到第06類目標另學。

一起學 05

路線C：馬祖閩東語，書包裡和學堂裡

聽到物品找物品，聽到地點找地點圖。

使用國教署第1冊第3課「我的書包」已核對的書、筆、學堂。電子書為第一級第一冊上冊對應課文；此處按主題取詞，不宣稱國定週次。頁面在該課文標書tsy、筆peihˊ、學堂houh toungˋ；這是課內文字對照，實際獨立詞音和連讀由官方示範與熟悉馬祖語教師核對。

  1. 把書圖與筆圖放在「物品」框，學堂圖放在「地方」框，先建立語義差別。
  2. 成人播放課內完整語段，再選今天的詞，孩子只找對應圖。
  3. 把分類框暫時移走，三圖打亂再聽辨，避免只靠框位置。
  4. 孩子指一張圖，教師完整示範後試說；伙伴把它放進正確物／地方框。
  5. 換成另一張學校示意圖再識別，不要求說出本人學校名字。

學堂在本課是學校意思，不能因華語「堂」就猜成餐桌或教室物品。未取得可用聲音時，只能記已理解中文分類，不能記已聽懂馬祖語。大人不得照平台拼音字母的英語讀法代讀，也不把課內標音自行拼成新句。

一起學 06

路線D：秀姑巒阿美語，書與學校

一個是物品，一個是地方，聽清楚再選。

本頁方言固定秀姑巒阿美語，官方千詞表d=2核實：codad（書）、picodadan（學校）。只教這兩詞，不因其他阿美語教材有相似拼字就自行更換。

  1. 成人先用一本書與學校簡圖說明物品／地方，孩子辨別後再導入族語。
  2. 完整聽codad，指書；完整聽picodadan，指學校。
  3. 把書圖和學校圖換位，成人隨機播放四次，孩子選卡。
  4. 孩子先看一張圖再跟模型試說，伙伴核對。
  5. 換成書的另一種封面、學校另一種外觀，確認詞義可轉移。

兩詞形式有相似部分，但本課不讓孩子猜詞根或自行加字母造新詞，也不說所有族語都這樣構詞。若個別教材讀法不同，先找教師確認方言及書寫來源。

最小完成任務

在沒有中文答案提示時，聽兩個已教完整詞能各選一次；看到其中一張圖能在模型支持下試表達。教材音訊失效時先安排可靠教師示範，不拿英語或合成聲替代。

一起學 07

路線E：臺灣手語，書、上課與放學

先分物品和時段情境，再看完整詞模型。

臺北啟聰「17課堂用語（上課／放學）」連結三個國教署模型：書、上課、放學。詞目和連結已核，完整影片播放與手語形式本次未驗；需教師課前確認清楚完整模型才開始實作。

  1. 書用實物圖；上課用大家正在學習的情境；放學用學習結束、按安排準備離校的圖。
  2. 一次看一支完整影片，看完再指圖；不邊翻卡邊猜動作。
  3. 再完整看同一支，具臺灣手語能力的教師提示一個觀察面向，孩子跟做後伙伴選圖。
  4. 改變圖卡位置，由教師不先提供中文答案示範，檢查獨立理解。
  5. 孩子選一張新情境圖，嘗試已學詞，教師核對功能及形式。

「書」是物品，「上課／放學」是不同生活情境，不能依字幕字數猜。看見放學詞不是當下離校命令；學校真實安全安排由老師和照顧者決定。不造動作圖、不將三詞按華語順序拼成未核實句子，也不由不懂手語者自動判定手形對錯。

一起學 08

路線F：越南語，鉛筆盒與剪刀圖

只用圖片也可以練找物，不需要拿剪刀。

使用臺北市政府教育局越南語補充教材第一輯第二冊第2課「鉛筆盒裡有什麼」印刷頁8核實兩詞：hộp bút（鉛筆盒）、cái kéo（剪刀）。成人到國教署越南語第二冊第2課的數位詞彙模型定位，或由具越南語能力教師完整示範。補充教材是文字證據，不冒稱PDF本身會發聲。

  1. 放鉛筆盒與剪刀的清楚大圖，先確認圖意，剪刀不用實物。
  2. 聽兩個完整詞，各配一次，再打亂順序。
  3. 成人給一個找物詞，孩子把對應卡放到桌上框中；伙伴核對而非搶答。
  4. 交換出題者，跟模型後試說。保留越南語聲調符號供成人對照，不用國語諧音。
  5. 換圖：長鉛筆盒、短鉛筆盒；打開與合上的剪刀圖，選同類用品。

本課不拆掉cái kéo中模型的一部分教成隨意短句，也不擴充未核實的借用語法。回顧時只做自己路線：一個接收找物，一個表達讓伙伴找。選對中文題不代表已聽懂越南語，真實語言表現仍需模型與教師支持。

原課本印刷頁17（PDF第19頁）亦可直接核對鉛筆盒與剪刀詞義；只取詞彙，練習情境為本站原創。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

準備與定位

以實物／情境詞為語言入門，每條只取已核實2–3詞。成人事先建立路線目標表，記每詞意思、完整來源、可用播放位置及所用腔調。國語說明只幫助理解任務，不代替目標語音。馬祖語使用第1冊第3課中的書、筆、學堂；秀姑巒阿美語只取d=2詞表的codad與picodadan，不自行換成其他拼字。越南語文字由臺北市教育局補充教材印刷8核對，聲音另需國教署數位模型或合格教師。臺灣手語完整播放尚待課前確認。

第一節

5分鐘選路線及器材安全；8分鐘用品找錯故事，移動卡片示範不能只記位置；12分鐘一詞一義完整示範與配對；10分鐘收起實物聽／看選圖，再換外觀；5分鐘個別兩次配對。一次只保留當前路線卡，避免六語同時出現造成錯誤連結。剪刀一律用圖片，筆不朝人，學校圖不含真實校名或地點。

第二節

5分鐘亂序複習；10分鐘用品管理員遊戲，每人表達、接收各兩回；10分鐘換外觀或情境再辨認；10分鐘個別理解與表達記錄；5分鐘自評。手語用語屬於情境識別，不是要求聾生按口語指令速度反應；正式獨立理解示範不可先露出中文答案。

常見誤解及修正

  • 看物品位置猜：換位、換外觀、換情境，觀察詞義是否保持。
  • 把學堂或picodadan當用品：先做物品與地方的語義對比，再接語言模型。
  • 把放學詞當離校許可：明確說明是圖片情境，真人離校依原安排。
  • 把會說名詞當會借物句：借用仍要等待同意，完整句需另核實，不拼接單音。
  • 不熟悉語言的成人只憑像不像判對：用具該語能力教師核對，陪學成人提供材料與重播支持。

差異化與評量

起步者用兩張高對比圖和短回合，聽／看完整後再給選擇時間，允許指認、移卡或既有溝通工具。熟練者在新外觀、新位置與新伙伴間完成同樣詞義任務，不自動增加第三種語言。動作、視覺及聽覺需要依既有專業支持調整。

理解以本路線詞各兩次亂序示範配對，記獨立、重示後或需重教；表達以隨機一詞和新圖試說／試做，明記有無模型及提示；互動記伙伴是否收到及是否等借用同意。詞義正確與形式正確分開，中文題不代替實作。結束讓孩子選一個尚需練的詞，再在校內用相同活動練三分鐘，無需拍書包、上傳用品或個人資料。
