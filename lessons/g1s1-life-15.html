分享、合作與愛惜物品

一起做完小任務，也保留每個人的選擇

兩個紙偶想一起做一張遊戲角標示。不是搶著把全部做完，也不是一定把最喜歡的東西送人。來練先商量、一起用、用後收好。

建議：3 次，每次 30 分鐘；可依需要分段孩子可由大人陪讀

出發前

準備好了嗎？

這一課，我會練習

  • 借用前詢問、等到同意，並依約歸還。
  • 為共同任務分工，說清楚誰做哪一小步。
  • 合作時聽見不同方法，遇困難能協商或求助。
  • 以具體行動照顧物品，發現損壞誠實告知成人。
陪學大人：準備材料
  • 四張原創圖卡或紙片、共用色筆、完整收納盒
  • 兩個紙偶、任務卡：排圖、上色、檢查
  • 成人確認可共用的材料；不拿私人珍愛物品做分享測試

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

分享有好幾種方式

可以分享時間、方法或共用品。

小晴帶來自己珍愛的小熊，不想借人抱；但願意說小熊故事。阿圓願意一起用教室共用色筆。兩種都可以。分享不一定是交出私人東西，別人也有權說現在不方便。共同活動要使用已同意的材料，不把「你不借就是不友善」當作要求。

  1. 成人先說明哪些是共用品，哪些是角色私人物品。
  2. 孩子替紙偶選分享故事、一起用共用品或暫不分享。
  3. 練說「這個我想自己留著，我可以介紹給你聽」。
  4. 另一角色回應尊重，另找可用材料。
給陪學大人：帶領與觀察

不要求出借貼身、醫療、輔助或珍愛物品。共用品也有班級規範，需先核對。重點是理解選擇與互惠，不以分享次數評價人格，不讓孩子透過給東西換友誼。

一起學 02

借之前說清楚，歸還才算一圈

借什麼、用多久、放回哪裡。

阿圓想借小晴的綠筆，問「我想畫兩片葉子，可以借一下嗎？」小晴同意後，他才拿；畫完兩片就說「我用好了，還給你」。如果還需要更多時間，先再問，不能以已經借到為由一直拿著。對方說不方便時，改問成人有沒有替代材料。

  1. 用道具演借一枝筆，先停手再問。
  2. 等待對方清楚同意或拒絕。
  3. 同意後完成約定小任務，歸還並確認對方收到。
  4. 換成拒絕版本，演找另一種可行辦法。
給陪學大人：帶領與觀察

不用設定過長等待或以私人財物測試服從。孩子可用指圖詢問，成人協助理解非口語回覆。若借物已破損或使用中出問題，先告知，不偷偷把問題留給下一位。

一起學 03

共同目標要小到看得見

今天只做一張標示。

兩個紙偶的任務是「做一張放在共用筆盒旁的歸位圖」，不是把整間教室變漂亮。標示需要一個筆盒圖、幾枝筆的圖，還要讓別人看懂用完放回。可以加一條指向盒子的箭頭，請成人試著說圖的意思，再決定是否清楚。目標說得清楚，大家才知道什麼時候完成，也能避免一個人不停加工作。

  1. 成人先展示一張原創簡單示例，不要求照抄。
  2. 孩子說或指共同目標與需要材料。
  3. 把任務分成排圖、上色、檢查三小步。
  4. 選今天只做其中兩步或全部，依時間和支持調整。
給陪學大人：帶領與觀察

不要把合作等同一次完成大型佈置。小任務讓分工和回顧有證據，成人可用圖表明確結束點。讀寫尚未熟練者用圖示，不以標語工整度評量合作。

一起學 04

分工不是固定誰最厲害

選做法，也能交換角色。

小晴想排圖，阿圓想上色，兩人同意後開始。檢查時一起看看下一個人能不能知道筆的家。若阿圓手累了，可以提出換角色或請成人代上色，由自己選顏色。分工是讓每個人有實際參與，不是永遠某個人做決定、另一個人只旁觀。

  1. 把三種任務卡放桌上，各選一件願意做的。
  2. 說明交接時的訊號，如「我排好了，換你看」。
  3. 做一小段後停下確認是否需要支持或換工。
  4. 共同檢查目標，不替對方所有選擇下決定。
給陪學大人：帶領與觀察

不按性別或快慢永久分配工作；設計師、指示者與檢查者也是實際角色。成人需觀察權力是否失衡，尤其一人包辦全部或常被排除時應介入調整，不要求弱勢者單獨爭取。

一起學 05

意見不同，拿目標來幫忙

先聽兩個方法，再試小小一段。

小晴想畫三枝筆，阿圓想畫十枝。兩人先看目標：讓人知道筆要回盒，不是比誰畫得多。可以先各畫一小張簡圖，請成人看哪張容易理解，再由兩人決定。不合意時也可請成人協助，不用搶筆或把對方的圖擦掉。

  1. 成人念兩個不同方案，孩子分別復述或指出。
  2. 說共同目標，再找能用來比較的一件事。
  3. 用小草稿試兩方案，不破壞對方作品。
  4. 選雙方接受的方案；仍無法決定時先停並求助。
給陪學大人：帶領與觀察

不以多數或聲量壓過界線。若只有一位孩子陪學，成人用紙偶提出真可比較的不同方案。不能讓孩子扮演受欺負者反覆忍耐；持續威脅或破壞需成人處理。

一起學 06

愛惜是使用方法，不是永遠不能用

輕拿、照用途、發現問題就說。

共用筆是給大家畫圖的，不必因怕弄壞就永遠鎖起來。使用前確認筆蓋好開，使用時不咬筆、不拿筆戳人，用後依需要蓋好歸位。如果筆斷了，先停，告訴成人「這枝不能正常用了」，不要自己摸尖端或把碎片混進盒裡。

  1. 成人示範拿取、使用、歸位一圈。
  2. 孩子用安全道具完成一次，說明其中一個照顧方法。
  3. 出示破損圖卡，練停止與告知。
  4. 成人回應「謝謝你告訴我，我來處理」，讓下一位不遇危險。
給陪學大人：帶領與觀察

真實破損與尖碎物由成人隔離，兒童不用修筆、拆玩具或清理危險材料。若是失誤造成，先處理安全與修復，再討論改善，不以威嚇使孩子隱瞞。正常磨耗與故意破壞要分開理解。

一起學 07

回顧合作，看見每個人的一小步

說誰做了什麼，還能怎麼改。

完成標示後，兩個紙偶一起檢查。小晴說「你上色前先問我要留哪裡，很有幫助」；阿圓說「下次我想先看完整目標」。分享成果不是一個人把功勞全拿走，也不用公開誰做得最慢。能說一個具體貢獻和一個改法，下次就更容易開始。

  1. 把圖交給成人看，檢查能否理解歸位意思。
  2. 每個角色說或指出自己完成的一小步。
  3. 各選一個有幫助的合作動作。
  4. 收回共用品，約定下次只改一項方法，不新增大任務。
給陪學大人：帶領與觀察

不以表面完成度掩蓋合作過程中被忽略的孩子。成人可記是否詢問、等待、交接、共同修正及歸位。成果可以留在陪學桌面，沒有經使用者同意不能擅自貼到真實共用空間。

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

參考答案：等對方清楚同意後

借用需要對方有選擇，問過但未得到同意還不能拿取。

參考答案：先再詢問能否延長

原同意有範圍，超過約定用途或時間要再問，不能把借到當永久使用。

看答案與原因

參考答案：做一張讓人看懂筆要歸位的圖

清楚而小的目標讓分工和完成判準明確，本課不需要擴大為大型工程。

角色與支持可調整，做設計選擇或檢查同樣是有效參與。

6兩人意見不同，較合適的做法是？
給我一點提示

聽見雙方想法並用目標比較，有助找到可接受方法，不需搶奪破壞。

參考答案：停用並告知成人處理

破損可能有尖端風險，先停用告知，避免自己或下一位受傷。

8哪句合作回饋最具體？
給我一點提示

哪句指向真正發生的合作行動？

參考答案：你上色前先問我，很有幫助

說出實際有幫助的行動，讓各角色貢獻被看見，避免只看快慢或服從。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

課前確認與課程定位

本課以生活課程第一學習階段的分享界線、溝通分工與愛惜物品為方向。主題與活動是跨版本原創示例，不是全國統一學期進度。先確認材料可以共用，排除孩子私人物品和醫療輔具。目標為一張原創歸位圖，成人設定可完成的範圍及可選角色，讓每人有決策機會。

第 1 次：觀察與示範（30 分鐘）

0–10 分比較分享方法與拒絕權；10–20 分借用同意、短任務及歸還；20–27 分練被拒絕後找替代；27–30 分出口任務為指出借物何時可以拿、何時需要再問。

第 2 次：操作與修正（30 分鐘）

0–8 分確認共同目標；8–18 分選分工並做一小段；18–25 分模擬兩種設計比較；25–30 分共同決定方案或求助。成人不以包辦提高完成速度，保留孩子協商的時間。

第 3 次：轉用與回顧（30 分鐘）

0–10 分完成作品並測試是否看得懂；10–18 分使用物品及破損告知情境；18–27 分具體貢獻回顧和題目；27–30 分歸還、收納與選下一步。未完成也可保留已做部分，下次再接續。

差異化支持

尚未識字者由成人讀題，孩子可指物、選圖或操作；不以讀字速度評量生活理解。需要記憶支持時，一次只出示一張步驟卡，完成後再提供下一張。視覺、聽覺、動作或口語表達需要調整時，使用孩子既有的放大圖、觸覺標記、手勢或輔助溝通；孩子可做決定，由大人協助執行。已能獨立完成者改變一項條件，請他說明理由，不增加競速或代管其他孩子安全的責任。

迷思與回饋

把分享誤認為必須借出私人珍愛物時，提供分享故事或時間的替代；以為分工固定照能力排名時，示範角色輪換與動作協助；怕弄壞而不敢說時，先安全回應，再一起想修復，不責備求助本身。

形成性評量與下一步

記錄是否詢問同意、依約歸還、說明共同目標、完成或指揮一小步、聽另一方案與誠實告知問題。每項記錄「獨立完成、提示後完成、共同完成」並保留一個具體行為例子；選擇題僅協助查概念，不能取代操作。孩子答錯時，先問他依據什麼，再回到道具重試，不公布排行榜。

家庭延伸與隱私

在家共同整理一盒可共用材料，分兩個短角色即可，不要求孩子送出物品、提供家庭財物照片或做大型家事。家庭可用最熟悉的語言陪學，沒有材料時使用圖畫或口述即可。不要求購物、拍攝家庭空間、上傳照片、填寫住址或公開身體及家庭經驗。
