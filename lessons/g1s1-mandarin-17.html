圖文理解與故事順序

圖裡找線索，文裡找事情，排好先後再說故事。

三張圖被打亂了。小晴的紙風車先出了什麼事，後來怎麼了？你可以先看圖，再聽文字，把線索拼成有順序的小故事。

建議：2–3次，每次25分鐘；先兩步，再練三步。孩子可由大人陪讀

出發前

準備好了嗎？

這一課，我會練習

  • 能從圖中找出支持事件的細節。
  • 能配對圖與文字，排出三步順序。
  • 能區分已發生的內容與自己續編的情節。
  • 能用自己的話重述主要故事，遇到矛盾會回圖文核對。
陪學大人：準備材料
  • 本頁三張原創紙風車事件圖
  • 三張句子卡與先、接著、最後提示卡
  • 紙與筆，可由成人代寫

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

先看亂序三圖

不要照字母猜，看看風車的變化。

這裡故意把圖打亂，A不一定最先。先找葉片鬆開、正在固定、已經修好三個不同狀態。

成人可讀每圖的圖像說明，孩子指出哪一張還需要幫忙。圖是原創情境，不是要你操作工具。

給大人的引導與觀察

圖A的文字說明提供舉起修好的事件，簡圖主要呈現完整葉片；圖C文字說明補足成人協助。圖片與可及說明共同構成教材，不要求孩子從未畫出的手推論人物身份。此課閱讀，不實作紙風車或處理尖銳工具。

一起學 02

再聽原創故事

把故事和每一張圖對上。

小晴發現紙風車有一片葉鬆開了。
她請大人幫忙，一起用膠帶固定葉片。
紙風車修好了，小晴把它舉起來。

成人完整讀一次，再逐句讀。你指這句最適合哪張圖。

第一句的線索是鬆開的葉片；第二句有膠帶和固定動作；第三句說修好、舉起。文字幫我們把圖中狀態連成事件。

  1. 聽第一句，指圖B。
  2. 聽第二句，指圖C。
  3. 聽第三句，指圖A。
  4. 再打亂圖卡，重新配一次。
給大人的引導與觀察

閱讀素材皆原創，沒有引用課本情節。若孩子僅背BCA，換桌面位置並保留圖名，請他說每張的關鍵事件；不能將排序字母當唯一成功證據。

一起學 03

先、接著、最後排出來

先發現問題，才修理，最後修好。

先：圖B，發現葉片鬆開。
接著：圖C，請大人協助固定。
最後：圖A，舉起修好的紙風車。

  1. 把先放在葉片鬆開的圖旁。
  2. 把接著放在固定葉片的圖旁。
  3. 把最後放在完整風車的圖旁。
  4. 沿著三張圖說一句或指一張。
  5. 從頭再看，有沒有把修好放到發現問題之前。

這個故事的順序有線索，不是你喜歡哪一張就放第一。圖上的字母只是名稱，不是時間。

如果只想先練兩步，可以比較鬆開與修好，再加入中間的幫忙。

給大人的引導與觀察

事件順序由原文與狀態改變共同確定，不靠視覺大小或排列位置。先後詞可以替換成後來等自然說法，重點是邏輯一致，不死背三個固定詞。

一起學 04

原因和後來，不完全一樣

問為什麼，要找到事情之間的關係。

「為什麼要固定葉片？」因為有一片葉鬆開。
「固定後發生什麼？」紙風車修好了。

前一題問原因，後一題問之後的結果。故事裡有線索可以回答，不只是把下一句背出來。

故事沒有說葉片為什麼鬆開。不能因為想像風很大，就說一定是大風吹壞。

  1. 成人問為什麼需要幫忙，孩子指鬆開圖。
  2. 成人問幫忙之後怎麼了，孩子指修好圖。
  3. 再問最早怎麼鬆開，孩子說原文沒有說。
  4. 把已知原因與未知細節分開。
給大人的引導與觀察

一年級用具體問題體會關係，不教抽象因果術語。時間先後不自動等於因果；本例只主張鬆開是需要固定的原因，不補充未載來源。接受孩子用簡短的壞了等詞，但可回示範葉片鬆開更精確。

一起學 05

圖文不合時，回頭查

別急著改成自己喜歡的答案。

句子卡：「小晴自己拿剪刀剪開風車。」
能配這個故事嗎？不能，原文沒有這件事。

圖C有膠帶，文字說請大人幫忙固定。沒有剪開風車的情節。遇到一張不合的句子卡，先回到原文與圖找證據。

如果想另外編剪紙故事，可以明說「我另外編的」，不把新故事塞回原文答案。

  1. 成人放一張與原文不合的句卡。
  2. 孩子指出哪一點不合。
  3. 找回真正的那一句。
  4. 讀正確句子與相應圖，停止重複錯誤版本。
給大人的引導與觀察

錯誤句只出現一次作比較，立即回正確模型。剪刀只是文字反例，不安排實際剪切；安全也不是本題唯一理由，主要是圖文證據不支持。避免教成不喜歡的情節就算錯。

一起學 06

講故事的人，留下主線

不用逐字背，主要事情要在。

「小晴的風車葉片鬆了。她找大人幫忙固定，最後舉起修好的風車。」

  1. 先看三圖，用自己的短句說。
  2. 成人聽有沒有發現問題、找人固定、修好三件事。
  3. 若漏中間，成人指圖C，不立即替孩子全部說完。
  4. 孩子補上缺少的事件，再從頭說一遍。
  5. 不想口說時，可按順序指圖，由成人轉述確認。

可以換詞，不能把小晴找大人改成大人故意弄壞。重述要保留人物角色和事件關係。

句子短也能完整，不用加很多原文沒有的形容詞。

給大人的引導與觀察

重述評量看主線與關係，不逐字打勾。成人提供最小提示，記錄孩子是否能自己補回；若需要完整代述，這仍可作示範階段，不虛報獨立重述。

一起學 07

接一個新結尾，記得貼上想像

現在換你編，和原文分清楚。

原文到舉起風車就結束。你可以另接一句：「我想像小晴把修理方法畫下來。」這是你的新結尾，不是原文已說。

先把原來三步排對，再添一張不同底色或標上想像的卡。即使不用顏色，也要寫或說出是想像。

  1. 說出原文最後一件事。
  2. 想一個合理的新事件。
  3. 前面加我想像或我編的結尾是。
  4. 請聽眾指出哪一張是新增。
  5. 再回到三張原圖，重述真正的原故事。
給大人的引導與觀察

創作與理解都值得鼓勵，但評量分開。結尾可多樣，只要不混淆原文；不能因兒童創作有趣而將其算作文本證據。家庭延伸可用日常三步照片但不必上傳，注意他人肖像與隱私。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1哪張圖最先發生？
給我一點提示

先有問題，才有修理。

看答案與原因

參考答案：圖B葉片鬆開

故事先發現葉片鬆開，對應圖B，不依字母先後排序。

2故事完整順序是？
給我一點提示

依葉片狀態找變化。

看答案與原因

參考答案：B→C→A

先鬆開，再請大人固定，最後舉起修好的風車。

3誰幫小晴固定葉片？
給我一點提示

第二句有幫忙的人。

看答案與原因

參考答案：大人

原文明說她請大人幫忙，一起用膠帶固定葉片。

4為什麼需要固定葉片？
給我一點提示

回到第一句找原因。

看答案與原因

參考答案：因為有一片葉鬆開

原文的問題是葉片鬆開，固定是針對這個問題。

5葉片最早為什麼鬆開？
給我一點提示

已知它鬆開，不等於知道怎麼鬆開。

看答案與原因

參考答案：故事沒說，不能確定

文本沒有交代最初鬆開的原因，不可把想像當事實。

6「小晴拿剪刀剪開風車」能當原故事內容嗎？
給我一點提示

找真正寫出的工具與動作。

看答案與原因

參考答案：不能，圖文沒有這件事

故事說用膠帶固定，沒有剪開情節，要回到原文核對。

7重述故事需要逐字一樣嗎？
給我一點提示

留住意思，不只背句子。

看答案與原因

參考答案：不用，但人物和主要事件關係要保留

自己的話可簡短不同，仍要保留發現、協助固定、修好的主線。

8自己續編的結尾，應怎麼標示？
給我一點提示

讓聽眾知道來源。

看答案與原因

參考答案：加上我想像或我編的結尾

標明創作可把新增情節和原故事分清楚，同時保留想像空間。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

教學定位

對應Ba-I-1、Ad-I-2及圖文理解方向。三張原創圖以B鬆開、C協助固定、A修好形成順敘，網站順序刻意打亂，防止只按版面猜。圖像說明是可及教材的一部分，成人可朗讀，讓視覺需求者也能取得等量事件資訊。

三次安排

  1. 第一次25分鐘：6分鐘看亂序圖找狀態，5分鐘成人讀故事，6分鐘逐句配圖，5分鐘兩步到三步排序，3分鐘指出依據。
  2. 第二次25分鐘：5分鐘換位置回顧，6分鐘原因與結果提問，6分鐘圖文不合檢查，5分鐘自己的話重述，3分鐘自評。
  3. 第三次可選20分鐘：原文三步重述、創作新結尾、標示想像與再次回原文。

證據與關係

圖名A、B、C不是時間順序，正確排序須依葉片狀態和文字。只接受以字母背答案時還需要問每圖發生什麼。需要固定的原因是葉片鬆開，至於最初為何鬆開沒有交代，不能補造成大風吹壞。時間先後與原因結果不同，本課用兩種問句作具體區分，不要求背術語。

差異化與錯誤回饋

起步者只比鬆開、修好兩圖，成人短句讀圖；一般組三圖排序並說先後；進展組用自己的話概括，指出一項文本未說的內容，另創作有標籤結尾。口語需求者指圖或用輔具，動作需求者由成人移卡。成人只在漏的一步給圖提示，不立即講完，留下自己修正機會。

圖C少量圖形以膠帶和固定葉片為視覺線索，人物合作資訊由文字明說，不能要求孩子從未畫手部判斷誰動作。若混淆原文與創作，將新增卡標上我想像，先放旁邊再重述原三步。學習不是實際製作風車，不提供尖銳工具或拆修活動。

評量紀錄

保留一次圖句配對、一組排序、一句原因答案及一個未知判斷。過程看是否使用證據、是否能修正；不是只評排序字母。網頁題由成人代讀，避免文字量影響聽圖理解。家庭可用刷牙等熟悉事件口頭排三步，不需拍照上傳；下次換情境時同樣問發生什麼與先後證據。
