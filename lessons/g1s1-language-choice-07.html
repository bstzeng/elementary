童謠、故事與生活文化（依語別）

選一個具名作品或視覺故事，辨認本路線關鍵訊息，分清原作、想像和自己的續畫。

本課是教師輔助的作品入門：先備妥完整模型，才做目標語模仿與評量。外部音訊／手語影片本次未全部完成播放核驗。手語路線以原創圖像故事加三個已識別數詞為限，不宣稱整篇自然手語故事已核實。

建議：選一條路線，建議2節各35–40分鐘；一次只取適齡小段。孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

準備好了嗎？

這一課，我會練習

  • 能在指定小段中辨認本路線已教核心詞／短語或手語數詞。
  • 能用圖像或既有溝通方式指出一個角色、事物或事件關係。
  • 能依模型支持嘗試核心目標語訊息。
  • 能分清原作品內容和自己新編的安全續畫。
  • 尊重作品版本、不同家庭及身體文化界線。
陪學大人：準備材料
  • 本路線指定作品及完整可用模型
  • 角色、物品或情境圖卡
  • 三張空白紙與筆
  • 紙偶與語言教師支持

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

一條路線、一個小作品

先知道在看／聽什麼，再找一個懂得的關鍵訊息。

童謠、故事能用不同語言分享生活、想像和情感。今天只選你的語言路線，不把六種作品都變成考試。口語路線從一首具名官方童謠的指定段落找關鍵詞或事件；臺灣手語路線用完整數詞模型參與原創視覺故事，沒有唱歌、跟聲音節拍的要求。

本頁提供原創觀察與練習，不重製整首歌詞、旋律、書籍插圖或手語影片。成人從指定來源播放，先確認能完整接收，再設定小段目標。每次只問一件事，聽／看完才拿圖卡，不一邊翻頁一邊漏掉訊息。

模型與完成邊界

本次核對文字、語別、課名或精確官方影片連結，沒有重新完成所有音訊與手語全段播放核驗。語音、手語形式的模仿與評量，須具該語能力教師課前確認完整可用模型。不能播放的作品先留待教，不用中文唱法、合成聲或猜手勢替代。

不同家人可能唱不同版本；先記清楚今天的版本，不把自己熟悉的版本說成唯一正確。分享家中故事完全自願，沒有家庭資源者用本頁指定來源即可。

一起學 02

三張圖，幫我們抓住意思

用作品裡真的有的線索，排出小段意思。

準備三張空白紙。成人先播放選定的小段，請孩子用畫圖、指認或簡短說明指出一個角色、一樣物品或一個動作。再播放一次，在能從原模型確認的訊息下畫出第二張、第三張。不憑想像把新的情節當原作品內容。

  1. 先問「看見／聽見的是什麼？」而不是立刻問抽象道理。
  2. 一次抓一個關鍵詞，回到相同模型找到它的位置。
  3. 若有事件先後，把三張圖排列；若只有並列事物，就並排，不硬編先後。
  4. 從作品找一處和生活可連結的事，再分清想像與真實。
  5. 換伙伴，讓他根據你選的圖說出小段意思，回模型核對。

本課新增的小故事要標成「我們新編的」，不冒稱是某族群傳統。可以畫紙偶幫忙、動物出發等安全情境，不模仿追捕野生動物、落水、衝撞、飲酒或文化限制的儀式。

原作與新編怎麼分？

原作圖卡只放模型支持的角色與事件。你新添一把傘或一個朋友，可以放在另外的「我的續畫」區，不能說原歌也一定有這個角色。

一起學 03

路線A：臺灣台語，火金姑的想像遊戲

先認識火金姑，再聽它在歌裡遇到什麼。

指定模型：國立教育廣播電臺《愛聽臺灣聲》第5集「兒歌：火金姑、火金星」，本課只取其中第一首火金姑。官方節目介紹確認它以螢火蟲為角色，串起茶與水果等想像內容；今天的核心詞「火金姑」連到螢火蟲圖，語音跟節目及台語教師。

  1. 成人先定位第一首歌的開始與結束，不把後面另一首混成同一版本。
  2. 孩子先聽一次，只在螢火蟲與鳥的圖中選主角。
  3. 第二次聽，成人在歌中先定位茶與香蕉出現的短段，孩子按接收線索放兩張物品圖；不要求背整首。
  4. 跟可靠模型試說核心詞火金姑，再回到原小段辨識。
  5. 畫一張自己的安全續畫，例如紙偶遠遠觀察螢火蟲，標示為新編。

歌裡請螢火蟲吃東西是想像，不能推成真的飼養方式。本課不去抓螢火蟲、不用光照牠，也不要求實地夜遊。生活連結是人們可以用身邊動物創作有趣語言，不表示所有台語家庭都唱這一版。

小段理解檢查

指出主角、找一張在該段出現的物品圖；若說的是續畫物品，回到原節目重新聽，分清來源和創作。

一起學 04

路線B：四縣腔客語，月光下的圖像

聽四縣蕭玉這一版，別把同名歌曲混在一起。

指定模型為新北市客家文化典藏資料庫「童謠－月光光 秀才郎－四縣蕭玉」，附件名清楚標四縣蕭玉.mp3。網頁有此版本文字，開頭把月光、人物騎馬與池塘連起來。本課只取開頭小段，核心辨識「月光光」，不抄整首或自行配新旋律。

  1. 成人先核對四縣版本，完整聽過後圈定開頭的安全片段。
  2. 準備月亮、白馬、池塘三圖，先教中文圖意，再聽模型找聽到的場景。
  3. 跟模型嘗試核心詞，再回小段聽它位於哪裡；不從字形猜客語聲調。
  4. 以紙偶和三圖表現人物經過場景，不真的騎乘、靠近池塘或拿物模仿武器。
  5. 同伴把圖打亂，依原小段線索重排或核對關係。

「秀才」是歌裡的歷史稱謂，老師用一句話解釋為過去的讀書人稱呼即可，不把孩子分成比較有文化或比較沒文化。後段有成人婚嫁、飲酒等生活詞，本課不取作兒童模仿活動，也不把歌詞內容說成今日每個家庭習慣。

遇到另一首同名「月光光」，先核對作者、腔調與錄音，不因題目相同就把音檔配到本頁文字。熟練者可以說明兩個版本有差異，但本次語音評量仍依選定模型。

一起學 05

路線C：馬祖閩東語，跋落浦的童謠世界

故事可以想像，現實裡要遠離落水危險。

指定模型：國教署第1冊第5課「唱小歌－跋落浦」。電子書第一級第一冊上冊目錄指向印刷頁46；網站國語題名為唱小歌－掉池塘。這個題名、正文文字與中文對照已核，聲音需熟悉馬祖語教師配完整官方播放，本頁不列未聽驗的拼音。

課中以兒童掉入池塘後看見動物婚禮的想像展開。本課只辨題名的事件與一個教師選定可核實角色，不要求扮婚禮儀式或照做危險情節。主要目標是聽到所選語段能從原課圖文找到對應意思。

  1. 成人先用原課圖說明題名指掉池塘，明確說這是童謠想像，不是活動指令。
  2. 播放完整小段，孩子從「掉池塘」與「坐著讀書」兩圖選情境。
  3. 再播放，教師只指本段一個已確認角色，讓孩子在原課圖中找出。
  4. 在完整模型支持下嘗試題名短語，回到原段落理解，而不把詞音自行串接。
  5. 用紙上的前後兩圖說明故事發生什麼；另外畫現實安全選擇，如留在岸上找成人。

不靠近真實水域、不推人、不演落水。文化欣賞可以保留幽默與想像，同時清楚說明不模仿危險。若原模型無法播放，先看圖準備，該段馬祖語聽說目標待教，不以華語敘述冒充已完成。

一起學 06

路線D：秀姑巒阿美語，小青蛙詞與情節

聽見小青蛙，找對圖；歌裡追，生活裡不追。

指定模型是族語E樂園秀姑巒阿美語歌謠篇第8首「小青蛙」及08 Takora’ 小青蛙《傳唱篇》。官方d=2歌詞資料核實開頭重複的小青蛙稱呼Takora’，並描述追逐後青蛙離開；本頁只取核心詞和這一小段意思，不轉載整段歌詞。

  1. 先將青蛙和鳥兩圖並列，成人播放核心詞所在原段，孩子找青蛙。
  2. 再聽一次，核心詞每出現一次就移一張紙卡作記號；不是打拍子搶速度，也不要求精確數完整首的次數。
  3. 由教師用完整詞模型帶孩子試說Takora’，不用英語規則拼讀。
  4. 用紙上三格表示注意到青蛙、追逐、青蛙離開，依原小段核對；不補寫未核實族語句。
  5. 另畫新結局：角色停下，保持距離觀看青蛙。說明這是班級新編，不改稱原歌。

歌曲使用者和生活習慣不能以一首歌概括。選秀姑巒阿美語，不與馬蘭同名小青蛙影片或其他方言混播。歌中追逐是敘事，不是活動規則；本課不捕捉、不觸摸真實青蛙，也不模仿受文化限制的祭儀。

我的兩個證據

我能從目標詞找青蛙圖；能分清原小段中青蛙離開和自己新編的安全觀察結局。詞音由該語教師核對。

一起學 07

路線E：臺灣手語，三張圖的紙屋故事

用看得見的訊息參與故事，不把手語配成口語歌。

本路線採本站原創圖像故事「紙屋多了窗」：第一張紙屋有一扇窗，第二張加到兩扇，第三張成為三扇。這是中文／圖像支架的故事，不宣稱為已核實整篇自然臺灣手語故事；目標語言只取三支完整官方數詞模型。

模型為1、2、3，與第05主題相同，但本課用它們核對故事的三個畫面和變化。詞目連結已核，本次完整播放／形式未驗，先由合格臺灣手語教師確認可靠模型，才實作。

  1. 按順序看三張故事圖，再看教師對應已教完整數詞的示範。
  2. 教師給一個數詞，孩子選相應故事畫面，檢查視覺語言理解。
  3. 孩子抽一張圖，表達核實的數詞，伙伴找到同一畫面。
  4. 把三圖排回故事先後，用既有溝通方式說明窗戶的變化；不自造「多一扇窗」手語句。
  5. 另畫下一張自己想像的紙屋，標為續畫；若未學其數詞，不猜新手形。

文化觀察可由成人介紹國立臺灣圖書館「手譯非凡」手語繪本專區，看見視覺語言也能分享故事。該入口是延伸資源，不作本課未核實故事詞句的證據。手語敘事不是把華語歌詞逐字配動作；本課完整語言實作限三個已識別數詞。

一起學 08

路線F：越南語，放學回家的生活歌

聽出回家後的問候，尊重每個家的不同。

指定作品為國教署越南語第一冊印刷頁22（PDF第24頁）「Đi học về／放學回家」，作詞Hoàng Long、作曲Hoàng Lân。文字與中文對應已直接核對；原歌談放學回家、問候父母及親子回應。成人在第一冊數位教材「複習一／我會唱」定位完整音訊，或由越南語教師提供可靠示範。

  1. 先用「在學校／放學回家」兩圖建立題名意思。
  2. 聽指定歌的開頭，從兩圖選回家情境；核心聽辨為題名短語Đi học về。
  3. 再聽回家後問候的段落，孩子把「到家」與「向家人問候」兩圖連起來，核對原文，不要求全歌背唱。
  4. 教師帶核心短語，孩子跟完整模型後再回段落聽辨。
  5. 另畫自己的故事角色回到熟悉照顧者身邊；標為新編，不要求與原歌家庭一樣。

原歌有親子親吻的描寫，欣賞不表示孩子必須親吻、擁抱或接受碰觸。可以用自己舒服的問候方式；不要求分享實際家庭或回家路線。不同家庭都能參與這個語言活動。

最後的小作品

選本路線一個核心詞／短語或核實手語詞，配一張自己畫的意思圖，再告訴伙伴哪部分來自原模型、哪部分是新編。語言形式由教師核對，創作圖不需上傳。

備課：把作品與目標分清

本課依語別取小作品，原創任務不抄歌詞或教材插圖。台語只用教育廣播電臺該集第一首火金姑，客語固定四縣蕭玉月光光版本，馬祖固定第1冊第5課，秀姑巒阿美語固定d=2/s=8及vid4902，越南固定第一冊印刷22的作品。每條只選一個核心詞／短語加一小段意思，不要求兒童掌握整首。臺灣手語以原創圖像故事與已識別數詞1–3完成關鍵訊息任務，明示不是完整自然手語篇章，也不以手譯非凡入口宣稱新故事語言已核實。

成人課前完整閱聽作品，確認模型、語別、版次及播放位置；本站未完成所有音訊／影片播放核驗。記錄要用段落的開始與結束，按孩子能力選短片段，不能只隨機播整集。手語要有合格支持及清楚完整視覺模型，口語要有具該語能力者核對，不使用合成聲或自造動作。

兩節安排

第1節5分鐘選路線及圖意，8分鐘完整看／聽指定小段，10分鐘核心訊息配圖，10分鐘再接收並選角色或場景，7分鐘用模型試表達。第2節5分鐘同一模型複習，12分鐘用圖呈現段落關係，10分鐘新編安全續畫，8分鐘區分原作與新編，5分鐘伙伴分享。若原段為並列，不強制排成故事先後。圖像支架可協助初學，不能把看圖猜對全記為獨立目標語理解。

常見誤解及安全文化界線

  • 會跟旋律但不懂詞：先讓孩子指出核心詞所對的角色，再回原段。
  • 把同名歌混成同一版本：核對語別、腔調、示範者、來源和片段。
  • 把童謠行為當真實規則：台語不餵或抓螢火蟲；客語不近水或模仿飲酒；馬祖不演落水；族語不追捕青蛙；越南不強迫親密碰觸。
  • 以一首歌概括一群人：作品是特定例子，不保證每個家庭都唱、都做一樣的事。
  • 把新編當傳統：在作品上明記班級續畫，尊重來源與文化脈絡。

分化和評量

需要支持者用兩圖選主角／場景，再增加一個事件，成人代畫或接受指認。熟練者說明一個原作線索和一個新編差異，語言擴充仍須另核模型。手語不跟音樂節拍評分，也不以孩子能否唱歌或大聲表演作能力判準。各類動作、視覺及聽覺需求依既有支持調整。

評量三欄：核心目標語訊息辨認、指定小段意思、原作與新編界線。每欄記獨立、模型／圖像支持或需重教；實際語音或手語形式由具該語能力教師另欄核對。共通題只測方法與文化判斷，不測未示範的新語句。回家任務完全可在校內完成；不用蒐集家人國籍、族別、家庭故事或錄音影像。
