自我介紹與名字

選自己的語言，用已核實的詞或短問答，加一張自選稱呼卡，讓伙伴認識你。

你的稱呼值得被好好理解。先選一條路線，使用已核實的詞或短問答。影音依賴路線需成人與具該語能力的教師先確認完整模型可用；臺灣手語影片本次未完成全段播放核驗，不能自行猜動作。詞彙加卡與完整短句分層學習及記錄。

建議：選一條路線，建議2節各35–40分鐘；詞彙層與短句層分別記錄。孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 能確認自己的選習語別，知道今天練的是詞彙層還是短句層。
  • 能理解本路線已教「我／名字」詞或姓名問答的用途。
  • 能依本路線已核實模型，以詞加自選卡或完整短問答介紹。
  • 能接收伙伴介紹並核對稱呼卡。
  • 尊重本人稱呼及不公開私人姓名資料的選擇。
陪學大人：準備材料
  • 兩個紙偶
  • 兩張自選稱呼卡與兩張用品卡
  • 已確認的語別及腔調／方言卡
  • 本路線官方音訊或完整手語影片與語言教師支持

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

先選路線與想用的稱呼

名字可以自己選一個課堂用的稱呼，不必公開全名。

和大人確認今天的語別，以下六條只學選好的那一條：臺灣台語、四縣腔客語、馬祖閩東語、秀姑巒阿美語、臺灣手語、越南語。客語其他腔調、其他族語及新住民語別應使用各自正式教材，不能照搬本頁示例。

準備一張課堂稱呼卡，可以由成人寫你願意使用的稱呼，也可以用虛構紙偶的名字。卡片只留在活動中，不上傳、不公布住址、學校班級、家人姓名或名字來歷。孩子可以先不介紹真人，用紙偶也能完成語言練習。

兩個起步層次

詞彙層：能理解並表達本路線已核實的「我／名字」，搭配自選卡讓伙伴知道正在介紹誰。

短句層：有確切官方問答模型的路線，練習聽問句、用名字句回應。未核實完整句的路線不宣稱已完成短句層，也不把詞直接拼成句。

兩層都要讓伙伴有回應機會。會念一個詞，不等於已會整段自我介紹；能流利背句，也還要檢查是否理解問的是誰。

一起學 02

原創故事：兩張卡放錯了

我介紹自己，你幫我核對卡片。

紙偶小光和小葉加入畫圖小組。桌上有兩張名字卡，但卡片放反了。小光先用今天的語言模型介紹自己，再拿起自己的卡；小葉把卡放回對應紙偶旁。這個活動不用先讀會所有字，成人可用不同外框圖案協助辨認。

  1. 先指出目前誰在表達、誰在接收，不急著講句子。
  2. 成人播放或示範本路線目標一次，孩子依意思選卡。
  3. 第二輪由孩子使用所學詞或已核實短句，伙伴指出他想介紹的紙偶。
  4. 交換角色，調換位置，再核對一次。位置變了，名字仍屬於同一紙偶。
  5. 卡片配錯時，先重示名字，不取笑，不擅自替紙偶換名。

在詞彙層，介紹方式是目標詞加指卡的輔助溝通；成人明確記錄這個支持。在短句層，聽到提問後才選對應回應，不只輪流背同一句。

觀察一下

伙伴能找對卡，說明訊息有傳到。若只因外框顏色猜對，還需換位置、取消額外線索後再練；不要把視覺配對全當成目標語理解。

一起學 03

路線A：臺灣台語，先建立「我」和「名字」

聽懂是介紹自己，再指向你選好的卡。

本路線核心詞：我（白讀guá）、名字（miâ-jī／miâ-lī）。由成人在教育部詞目選同一套音讀，每次播放一詞，孩子不照國語讀字，也不混用「自我介紹」裡的文讀音。

  1. 成人扮紙偶，用「我」的模型，再指出自己所扮紙偶；換人表達，指涉跟著換。
  2. 聽「名字」模型，在名字卡和用品卡之間選名字卡。
  3. 孩子先表達「我」，再展示自己同意使用的稱呼卡。稱呼的實際台語讀法請教師或本人熟悉成人確認，不由系統猜漢字讀音。
  4. 伙伴指回正確人物與卡，交換角色重做。

本課已核實的是兩個詞。這個詞加卡的入門介紹不等於完整台語姓名句；不列未核實的「我叫……」朗讀，不把字典單字音自動串接為句音。具備起點者，由教師用已核實完整句另做擴充並記錄來源。

這輪檢查

說「我」時應指正在表達的人；「名字」應連到稱呼卡。自己的稱呼不一定每字都只有一種讀法，先尊重本人希望的用法。

一起學 04

路線B：臺灣客語，四縣腔名字問答

先聽問句，輪到你時再介紹。

使用教育部《客家語情境對話練習》校園篇四縣腔第2課，印刷頁5及同頁四縣腔音檔。「𠊎安到王小明。」意思是我叫王小明；「你安到麼个名？」是詢問對方名字。本課只取姓名問答，不要求透露教材中延伸的年齡或家庭。

成人對照模型：𠊎安到王小明 ngaiˇ onˊ do vongˇ seuˋ minˇ；問句 nˇ onˊ do maˋ ge miangˇ。標音供成人核對，不是小一默寫要求。選四縣音檔第2課，不從六腔音檔混剪。

  1. 把王小明卡交給紙偶，先聽完整回答，指出介紹的是誰。
  2. 成人播放問句，紙偶再用已核實回答，讓孩子辨別問與答。
  3. 孩子扮教材角色，聽問句後回應；伙伴選對名字卡。
  4. 想改用自己的稱呼時，先請教師確認該稱呼讀法和完整句，不改動其餘語言形式。

這是對熟悉同伴的課堂練習，不要求對陌生人回答姓名。若沒有聽清楚，先用已會的溝通方式請重播，不假裝答應。學海陸、大埔等其他腔調者請使用該腔完整教材，不僅換聲調符號。

一起學 05

路線C：馬祖閩東語，先理解「我」的指涉

輪到誰介紹，「我」就是誰。

本頁已核實國教署部編第1冊第3課「我的書包」中的「我」標示ngui+。成人開啟該詞的官方播放，配合熟悉馬祖語的教師示範。此處只把「我」用作自我指涉的詞彙入門；完整自報姓名句尚未在本頁提供核實模型。

  1. 教師在課文中播放含「我」的原句，讓孩子知道這個詞出現在人物介紹自己的物品時。
  2. 再選該詞示範，成人指自己；孩子換成自己表達時也指出自己。
  3. 一個孩子展示自選稱呼卡，另一人配對到人物。這裡是詞彙加卡的輔助介紹，不冒稱完整姓名句。
  4. 交換座位、卡片順序，再辨認是誰在介紹。

加號是平台標音的一部分，不當成加法，也不照英語或國語拼出聲音。本課不要求兒童讀寫它。單詞音與課文連讀可能不同，均以原模型及語言教師為準，不將課文拼音拆開自行接句。

給大人的進度界線

可記錄「能理解我／能用詞指向自己／能配對稱呼卡」。完整名字問答仍需授課教師另備確切句子、意思與錄音後教學，不能因孩子完成圖卡遊戲就記為會說完整馬祖語自介。

一起學 06

路線D：秀姑巒阿美語，教材角色的名字

先確認方言，再聽問答配卡。

本頁只選秀姑巒阿美語，使用族語E樂園句型篇國中版：第17類問答第1項的原始短對話。雖資源分類為國中版，本課只選一句生活問答作初學模型，不要求整個級別內容。

已核對問句「Cima ko ngangan no miso?」意思為你叫什麼名字；回答「Ci Panay ko ngangan no mako.」意思為我叫Panay。保留同一來源形式，不把其他教材的ako、iso等形式任意混進來；發音跟該方言官方示範。

  1. 成人準備Panay卡和另一張紙偶卡，說明只是教材角色。
  2. 完整聽回答，選Panay卡；再聽問句，指出正在問對方稱呼。
  3. 一人依模型問，一人扮Panay回答，交換問與答的角色。
  4. 把卡移位再聽辨；熟練後才由教師核實自選稱呼的替換。

不替孩子創造族名、不詢問族譜，也不由教材名字推定孩子族別。其他族語或阿美語方言使用各自模型。本頁羅馬字是語言文字，不套用英語讀音；大人核對官方頁參數d=2，避免切到預設的其他語別。

一起學 07

路線E：臺灣手語，用模型和稱呼卡認識自己

看「我」和「名字」模型，不自己發明手語名字。

本路線選臺北啟聰詞彙手冊「15人稱代詞」所連的兩支官方模型：我、名字。成人先確認整支可播放、臉和雙手完整可見，再由具臺灣手語能力者帶學。本頁不寫手形指令或自造手勢圖。

  1. 看完整「我」模型，讓孩子在人物圖中選正在表達者。
  2. 看完整「名字」模型，配到稱呼卡，先理解再試做。
  3. 孩子以已教模型指涉自己，另展示自選稱呼卡；接收者指出對應人物。兩個詞的練習分開核對，不宣稱把中文「我的名字是」逐字比出來就是自然手語句。
  4. 換角色、調整位置，教師觀察指涉與訊息接收。

書面名字卡可以輔助介紹，不等於已獲得一個手語名字。不得用外貌、缺點或笑話替孩子命名；若本人有既有手語名字，按本人意願與熟悉其用法的教師處理。完整自然手語自介需另有句子模型。本頁核實詞目與影片連結，未重新驗收全段影像；播放失敗時不把圖卡配對算作已學會兩詞。

一起學 08

路線F：越南語，自我介紹與詢問名字

聽清楚問的是名字，才用名字回應。

使用移民署「實用場景語言教室：自我介紹」中「自我介紹」與「詢問對方姓名」兩段。文字模型為「Xin tự giới thiệu, tôi tên là _______.」（介紹一下，我叫……）以及「Bạn tên là gì?」（你叫什麼名字？）。本課限定熟悉同伴的角色練習，對長輩的稱呼與禮貌層級另由越南語教師核實。

  1. 先準備兩張自選紙偶名字卡。成人播放完整問句，再問孩子應選名字卡還是物品卡。
  2. 聽完整介紹句，教師在空格接已確認讀法的教材或自選稱呼；不要求公開真實全名。
  3. 孩子先跟句，再扮紙偶；伙伴聽後指出正確卡片。
  4. 交換問答，改變卡片位置。需要重播時可以提出，不能只背固定出場順序。

越南語聲調及字母組合按官方語音與班級教師，不用國語諧音或英文讀字母代替。不因本人家庭背景決定該用哪個稱呼。新住民語文選其他語別者不能使用本頁越南語當同語版本。

本課最後一次介紹

只用你選路線已教的層次：詞與稱呼卡，或有核實模型的短問答。讓伙伴核對人物及稱呼，再說明你下次想練理解、發音／手語表達，還是輪流回應。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

範圍與模型檢核

六條是選習路線，不是共同必修六語。此課刻意標示不同起點：台語有我與名字詞，馬祖語有我詞，臺灣手語有我與名字的影片詞目；這三條只完成詞彙加自選稱呼卡的輔助介紹，不冒稱完整自報姓名句。四縣客語、秀姑巒阿美語、越南語有精確官方問答，按各自模型練習。若學校目標要求完整句，前述詞彙層路線需另備經核實句子再教，不能記整句目標達成。

課前逐項核對：語別/腔調、目標文字及意思、完整音訊或視訊、名稱替換是否合適、兒童願意使用的稱呼。羅馬字供教師對照，不是小一拼寫考試。外部播放器可能失效；無完整可用模型或合適語言支持時，只進行已能核實部分，不自行合成音訊或拼手語。

兩節安排

第1節5分鐘選路線與稱呼卡，8分鐘紙偶卡放錯故事，12分鐘本路線模型配對與跟學，10分鐘兩人輪替，5分鐘記錄理解與表達。第2節5分鐘換位置複習，10分鐘問答或詞卡介紹，10分鐘新伙伴重新配卡，8分鐘個別評量，7分鐘回顧與再練。起步者只用兩角色；需要時由成人代寫卡，不把識字或口語音量當語文成績。

誤解、分化及評量

  • 把我固定當某個人：交換表達者，實際重指涉。
  • 背問句卻不知要回答什麼：先分名字卡與用品卡，再回到完整問句。
  • 讀漢字一律用華語：把成人文字暫時移開，聽正確詞音；姓名依本人及教師核實。
  • 混合族語方言：核對d=2及同一套句型，不將不同原文相似形式自行合併。
  • 把書面名卡當手語名字：分開輔助工具和語言名稱，尊重本人既有稱呼。

初學者先完成辨認我與名字卡；熟練者在有核實模型的路線變換角色和稱呼，其他路線先鞏固詞彙，進階句另列目標。需要動作、聽覺或視覺支持者使用既有溝通方式與專業調整，不強迫眼神接觸、碰觸或上台。

評量分三欄：接收目標詞/問句的意思、按本路線已教層次表達、伙伴能否核對對象。每欄記獨立／跟模型／需要重新配圖，並註明是否有名字卡、中文提示或其他線索。語音和手語形式由具該語能力者核對。共通選擇題只能檢查互動及策略，不代替真實語言表現。家庭練習可在校內替代，不要求上傳姓名、照片、影像或名字背後的私人歷史。
