品德、人際與多元文化

同一張合作畫，可以放下不同的想法

這是學校可採用的校訂人際與多元文化示例，不是要求每個家庭分享背景的課。一起用紙偶做合作畫：練習先問、傾聽、協商和修復。任何人都可以選擇不談私事，不需要擁抱、握手或上臺證明友善。

建議：3 次，每次 30 分鐘；用虛構角色練習，不必分享私事孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 在共用與個人物品情境中先詢問，接受對方拒絕。
  • 遇到意見不同時說清楚需要，聽對方說完，再提出可行辦法。
  • 用具體修復行動處理弄亂、誤取或傷人的情況。
  • 辨認家庭、語言與生活方式可以不同，不以一個人代表整群人。
  • 提供不同參與方式，讓同伴有表達和選擇的機會。
陪學大人：準備材料
  • 兩個紙偶與一張共同畫紙，可改為成人畫圖
  • 成人準備的大張圖形卡，不用食物試吃或文化服裝扮演
  • 「可以、現在不要、請幫忙」三張大字圖卡
  • 三張本課虛構家庭活動卡；沒有學生真實家庭資料

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

一盒彩筆，兩個想法

想一起做，也可以有不同選擇。

小樂和阿禾要畫「我們的休息角」。小樂想畫樹，阿禾想畫看書的椅子。他們同時伸手拿教室共用的綠色筆。小樂說：「我要先用！」阿禾拉住筆，兩個人都不開心。

老師先請兩人把筆放回桌上，讓手安全分開，然後說：「你們都想畫完自己的部分。我們先一人說一句，再找辦法。」小樂說想先畫樹葉，阿禾說想先畫椅墊。原來需要的是同一枝筆，不是誰比較值得畫。

  1. 你選一個紙偶，也可以只幫忙指需要的物品。
  2. 說出小樂需要什麼、阿禾需要什麼。
  3. 大人示範把「你很討厭」換成「我也需要綠色筆」。
  4. 想一個能讓兩個人繼續創作的方法，先不急著決定。

生氣、失望都可以被說出來；拉扯、推打或辱罵不能因為有情緒就放任。若有人持續傷害你，先離開能離開的危險、找可信任大人協助，不必獨自協商到對方滿意。

給陪學大人：分清衝突和安全問題

此例是平等角色爭用道具。若有霸凌、威脅、身體傷害或權力不對等，成人應介入保護，不能要求受影響孩子以分享或道歉換取安全。不要使用學生真實衝突公開點名演出。

一起學 02

先問、等回答，再借用

說了請，也要等對方同意。

教室共用筆依班級約定輪流；同伴自己的物品則要先得到同意。把兩種情況分清楚，就不會把「要分享」變成必須交出私人用品。

小樂：「等你畫完椅墊，可以換我用共用綠筆嗎？」阿禾：「可以，我畫好這一小塊就放回。」

另一張情境卡：阿禾的私人貼紙。小樂：「可以給我一張嗎？」阿禾：「現在不想。」小樂：「好，我可以畫一個圖案。」

  1. 大人說明是共用道具，還是紙偶自己的物品。
  2. 你用「可以……嗎？」提出請求，也可指物加詢問卡。
  3. 等到清楚回答，不把沒出聲當同意。
  4. 如果拒絕，停止拿取，選別的方法或請成人協助協商共用資源。

對身體接觸也一樣。想和同伴擊掌，可以先問；對方不願意，就改成點頭或口頭祝賀。朋友的關係不需要用交出物品或接受碰觸來證明。

給陪學大人：拒絕仍是有效溝通

示範自然接受拒絕，不讓紙偶說不後被嘲笑或失去參與權。對於班級共用物，教師協助維持公平使用的約定；對私人用品不以德育名義強迫贈送。孩子可以用既有手勢、圖卡或口述表達。

一起學 03

輪流聽，再選一個可試的辦法

先說各自需要，不是先找誰贏。

回到綠筆的問題。老師給兩個可行辦法：甲是輪流畫一小塊再換人；乙是先各用其他顏色畫不需綠色的部分，等綠筆空下再用。沒有規定一定選同一個答案，只要安全、能參與且雙方清楚。

小樂：「我想先畫葉子，因為我怕忘記位置。」阿禾：「我還要畫一小塊椅墊。」

老師重述：「一位怕忘記，一位快完成了。」

小樂：「那我先用鉛筆圈出葉子，等你畫好。」阿禾：「好，畫好就放中間給你。」

  1. 每個紙偶說一句需要，另一位先不打斷。
  2. 指出兩個候選辦法各會怎麼做。
  3. 選一個雙方能接受的辦法，成人幫忙說清楚先後。
  4. 演一輪，再問「每個人有沒有接到使用機會？」

輪流不一定用秒數計算。對一年級來說，「畫好這一小塊就換」常比等很長一段不明時間清楚。若約定反覆被破壞，找老師調整，不靠搶回來。

給陪學大人：公平不是每人完全一樣

有些孩子需要較大筆、成人代筆或更長操作時間，這不表示他比較貪心。公平的目的是有合理機會參與。成人可提供平行材料與清楚輪次，不把協商壓在尚不能表達的孩子身上。

一起學 04

做錯一件事，可以修復

不只說一句對不起，還要看下一步。

阿禾轉身時，碰倒小樂剛排好的三張圖卡。小樂很失望。阿禾不是故意的，也仍可以幫忙修復造成的影響。

阿禾：「我碰倒了你的圖卡，對不起。你想要我幫你排回去，還是先讓你自己排？」

小樂：「請你把卡拿到桌上，位置我來指。」阿禾照做，沒有擅自把畫改成自己的樣子。

  1. 大人用安全紙卡演出被碰亂，不真的弄壞孩子作品。
  2. 說明發生什麼，不找理由否認影響。
  3. 提出具體可做的修復，先聽對方願不願意。
  4. 一起完成約好的行動，再決定怎樣避免重來，如留出放手的位置。

接受道歉也有自己的時間。對方可以說「我還需要一下」，不必立刻笑、不必擁抱，也不必說「沒關係」讓大人放心。如果傷害持續，要由成人保護與處理，不只重複要求一句道歉。

給陪學大人：回饋行為，不貼人格標籤

指出「你先承認碰倒，再問要怎麼幫忙」比說「你終於是好孩子」清楚。不能把一時錯誤定義成壞人，也不能把無心當成不需處理影響。孩子可由紙偶或圖卡完成修復對話。

一起學 05

不同的家，有不同的生活方式

聽一個故事，不代表所有人都一樣。

老師拿出三張虛構家庭活動卡，不指向任何同學、族群或國家。甲角色和祖父一起讀圖畫書；乙角色和一位照顧者說熟悉語言的晚安話；丙角色和兩位照顧者輪流分享今天的一件事。卡上沒有說誰的方式比較好，也沒有把某種活動指定給某個文化。

小樂說：「我沒聽過乙的晚安話，聽起來很有意思。」老師說：「你可以好奇，但不能因為聽不懂就叫人家說法奇怪。乙也可以選擇不示範。」

阿禾問：「是不是每個和乙說同樣語言的人都這樣？」老師說：「一張角色卡只告訴我們這個故事，不能代表所有家庭。」

  1. 選兩張卡，說一個相同處：都有與熟悉的人相處。
  2. 說一個不同處：有人讀書，有人說話。
  3. 用中性短句描述，不比高低。
  4. 提出自願可答的問題，如「你願意多說一點這個活動嗎？」

你不用介紹自己的家庭成員、語言、宗教或照顧安排。可以只談角色卡，也可以說「我今天不分享」。不同家庭、沒有同住的家人或不同照顧方式，都不影響孩子被尊重的權利。

給陪學大人：避免文化展覽式教學

不要求特定學生穿服裝、帶食物、翻譯或代表族群。沒有可靠資料和社群脈絡時，不編造特定文化習俗。重點是尊重與避免以偏概全，不是背各國標籤。

一起學 06

同一張合作畫，留出多種參加方法

畫、說、指和排，都能幫到作品。

現在實際做一張「休息角」合作畫。你可以畫一棵樹、指示成人畫一張椅子、排一張圖卡，或先看一輪再選。作品需要不同工作，不必每個人都站起來說話。

  1. 每人先選想做的部分，能拒絕不合適的角色。
  2. 說明共用材料的輪流方法，必要時請成人協助。
  3. 做一小段後停下，問「還有誰的想法沒被聽到？」
  4. 讓用指圖的同伴有時間表達，成人再確認意思。
  5. 需要改動別人的部分時先問；未同意前不塗掉或搬走。

原創示例：小樂畫樹，阿禾排椅子卡，小米指一張「安靜看書」圖。小米沒有口述長句，大家仍把這個想法放入休息角，並問他位置是不是合意。

幫忙不是替人決定。可以問「你希望我拿卡，還是你自己拿？」對方說不用時，尊重他的選擇。需要支持時提供支持，不把輔助工具拿走考驗獨立。

給陪學大人：檢查參與實際發生

觀察誰有提出選擇、誰的意見被採用、誰需要溝通時間，不以全班看起來安靜或服從判合作成功。若有人被取笑，立即制止並保護；不要叫被排除者更努力討好。

一起學 07

帶走一句話，再練一件小事

尊重藏在做法裡，不只在口號裡。

你可以選一句今天學過的話：「可以借我嗎？」、「我現在不想。」、「我還需要一下。」或「你希望我怎麼幫忙？」和大人用紙偶換個情境試一次，例如借故事卡、選合作位置或接受他人拒絕。

  1. 先說清楚新的情況，是物品、意見還是參與方式不同。
  2. 選一句適合的話，或指出對應圖卡。
  3. 聽到回答後做相應行動，不只背完就繼續拿。
  4. 回顧「我做了哪個讓對方保有選擇的動作？」

紙偶說不想擊掌，你把手放下，說「好，我向你點點頭」。這個行動比反覆說「我很尊重你」更能表示尊重。

不要求你回家檢查家人是否有禮貌，也不收家庭訪問或同學祕密。下次在安全的合作活動中練一個小步驟，就能把今天學的帶到生活。

給陪學大人：最後的觀察

詢問、等待、接受拒絕、修復影響及避免以偏概全都可在虛構角色中評量。不使用「誰最有品德」排行榜。不願分享私事不是不合群，也不應失去參與與被照顧的機會。

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

3同伴還沒回答能不能借，應怎麼做？

參考答案：先等清楚回應，必要時再確認

沉默可能代表沒聽懂、還在想或不願意，不能當同意；先確認再行動。

4小樂怕忘記葉子位置，阿禾椅墊快畫完，哪個方案能回應兩人的需要？
給我一點提示

能不能先做不需要綠筆的那一步？

先用鉛筆記位置，接著輪用綠筆，能兼顧兩人需求；拉扯與排除會使問題更大。

5碰倒別人排好的卡，哪個是具體修復？
給我一點提示

下一個行動能否幫事情變好？

承認影響、詢問並完成合適協助，才是修復；無心不代表不需處理後果。

6同伴接受道歉前還需要一些時間，怎麼做？
給我一點提示

對方不必立即恢復心情或接受接觸；可尊重界線，仍負責自己的修復行動。

7虛構乙角色說一種晚安話，可以推論什麼？

單一角色不能代表整個語言或文化群體；可以了解此例，也保留差異和未知。

8同伴用指圖表達休息角的想法，最合適的是？
給我一點提示

看答案與原因

參考答案：給他時間並確認意思，讓想法加入

指圖也是表達，確認後納入共同決策，可讓不同溝通方式的孩子有效參與。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

定位與必要邊界

這是校訂彈性的人際及多元文化原創示例，品德與多元文化亦可融入既有領域，不是另加全國必修課。本課以虛構角色處理共享資源、拒絕、修復及不同生活方式，不蒐集學生家庭、族群、宗教、身心或移居資料。教師事前看過所有角色卡，避免暗指班上個別孩子或用刻板文化符號分類。

第 1 次：需要與同意，30 分鐘

0–7 分讀綠筆故事，先指出雙方需要；7–15 分比較共用筆和私人貼紙，練先問、等待及接受拒絕；15–24 分試兩種輪流辦法，成人確認每位參與者有機會；24–30 分換物品重試。孩子可指卡，不要求大聲說完整禮貌句才能取得基本需求。

第 2 次：修復與差異，30 分鐘

0–12 分以安全圖卡演碰亂情境，示範承認影響、問怎麼幫忙、完成修復；12–23 分讀三張虛構家庭活動卡，練中性描述一同一異；23–30 分處理「一個人是否代表所有同語言者」的問題。全程允許不談自己的家庭，不能要求家庭樹、食物帶來分享或文化表演。

第 3 次：共同創作，30 分鐘

0–5 分每人選畫、指、排或觀察角色；5–18 分合作一張休息角圖，成人觀察材料輪流與修改前詢問；18–25 分暫停檢查有沒有被忽略的意見並調整；25–30 分自選一句話轉用到新情境。成果不以美術完成度計分，重點是共同決策過程。

迷思與安全介入

把分享理解成必須交出私人物品者，對照物品所有與共用約定；把沉默當同意者，成人示範再次確認；認為道歉後別人就必須擁抱或立刻原諒者，說明修復與對方感受需要時間；認為同文化者全都相同者，縮回一張卡所提供的範圍。若有威脅、羞辱、排擠、持續傷害或權力不對等，停止普通協商活動並由成人保護、依學校程序處理，不讓受影響者獨自解決。

差異化與評量
