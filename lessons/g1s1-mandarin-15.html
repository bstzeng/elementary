兒歌、短文與繪本閱讀

兒歌聽節奏，短文找事情，繪本把圖與字一起看。

閱讀不只有一種樣子。兒歌可以有節奏，短文把事情說清楚，繪本的圖也會說話。今天每種讀一小段，先享受，再找線索。

建議：分3次，每次20–25分鐘；可重讀喜歡的一小段。孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 能聽讀原創兒歌，找到重複的詞或句式。
  • 能說出短文人物與主要事件。
  • 能從圖與文各找一個線索，理解微型繪本。
  • 能提出問題、修正預測並說出喜歡的具體地方。
陪學大人：準備材料
  • 本頁原創兒歌、短文與三頁微型繪本
  • 一本家中或班上的適齡繪本，由成人陪讀
  • 空白紙與彩筆

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

讀之前，先看看這是什麼

翻封面，找書名和創作者。

拿一本繪本，成人指出書名，找作者與繪者。作者寫文字，繪者畫圖；有時同一人也同時做兩件事。

看看封面，你可以說「我猜這本書會說＿＿」，再問一個想知道的問題。猜想不是答案，讀完可以改。

  1. 成人讀書名。
  2. 孩子指出封面一個畫面線索。
  3. 選擇說猜想或提出問題。
  4. 翻頁後回來看看猜想有沒有改變。

本課下面的文字與小圖都是原創教學素材，沒有取自課本或商業繪本。

給大人的引導與觀察

書名與創作者有時在封面、書名頁或版權頁，依實書位置找，不宣稱每本一定同樣排版。幼兒與小一可成人代讀，找作者不是識字測驗。選書不要求特定消費，班書、家書或圖書館書皆可。

一起學 02

原創兒歌：風來了

聽一行，跟一行，找重複的地方。

風來了，葉子搖。
風來了，小花搖。
我把小手輕輕搖，
和你說聲早上好。

成人以舒服節奏讀，不必唱固定旋律。找找哪一句開頭出現兩次：風來了。再找搖出現在哪幾行。

葉子和花的搖，是想像風吹過的畫面；小手搖可以表示招呼。你可以輕揮手，也可以只聽。

  1. 第一輪只聽。
  2. 第二輪跟讀風來了。
  3. 第三輪選一行喜歡的讀。
  4. 用一句說自己想到的畫面。
給大人的引導與觀察

原創兒歌不附合成音樂。閱讀目標是語感、重複和意象，不教成所有兒歌都必須押同樣韻或每行字數相等。動作只是參與方式之一，不要求所有孩子站起揮手。

一起學 03

原創短文：找葉子

這一次，看看事情怎麼發生。

下課後，小禾在地上看見一片落葉。
她先看葉子的顏色，再看葉邊。
小禾把看到的樣子畫在紙上。
她想，下次還要找找不同的葉子。

成人讀完，問：誰在看葉子？她先看什麼、再看什麼？這段短文把一件觀察小事依順序說出來。

文中沒有說小禾摘樹上的葉子，也沒有說每片葉子都同色。回答要跟著文字線索。

  1. 找人物小禾。
  2. 指出她觀察的兩個地方。
  3. 用一句說大意：小禾觀察落葉並畫下來。
給大人的引導與觀察

不用考每句字數或要求逐字背誦。觀察與畫圖是故事內容，若延伸現場觀察由成人確認安全，勿隨意採摘、舔食或接觸不明植物。本課主要是閱讀，不把戶外活動設為必要。

一起學 04

原創微型繪本：盒裡的小花園

一頁一頁看，圖和字都找線索。

書名：〈盒裡的小花園〉。文字與圖：本頁原創。這三頁是縮小的教學繪本，成人可逐頁讀圖像說明。

讀完問：空盒後來有什麼？紙上的畫從哪裡來？圖中的兩片葉子能幫你對照最後一頁的文字。

給大人的引導與觀察

圖文互補：文字告訴小禾與大人合作，圖提供盒中小苗、兩葉與畫紙的視覺證據。不要從簡圖推論實際紙盒長期栽種方法；這是閱讀情境，非園藝教學或植物生長速度紀錄。

一起學 05

讀第二次，找剛才沒看見的

重讀可以帶一個小問題。

第一次知道故事大概，第二次可以找更小的線索。〈盒裡的小花園〉第1頁的盒子是空的，第2頁多了土和小苗，第3頁多了觀察畫。

如果封面猜想與故事不同，可以說：「我原本猜＿＿，讀了以後發現＿＿。」修改猜想表示你正在用新線索理解。

  1. 先選兒歌、短文或微型繪本。
  2. 成人和孩子各提出一個小問題。
  3. 帶問題重讀相關的一行或一頁。
  4. 指出線索，再回答。
  5. 保留還不知道的問題，下次再查。
給大人的引導與觀察

重讀不等於把每次都變考試，可由孩子選感興趣的問題。對推論接受有依據的不同答案，但對文中明確事件回到證據。不要以成人預設寓意取代孩子對字面內容的理解。

一起學 06

說出喜歡，帶上一個理由

不是只說好看，再指一個地方。

「我喜歡『我把小手輕輕搖』，因為想到和朋友打招呼。」
「我喜歡最後一頁，因為能看見小苗和畫。」

喜歡的地方可以不同，也可以說目前沒有特別喜歡。若願意分享，指出一行、一幅圖或一件事，讓聽的人知道你的理由。

你可以畫出喜歡的畫面，成人代寫你的話；也可用指圖和表情選擇，不必寫心得整頁。

  1. 選一個具體地方。
  2. 說喜歡或想問的原因。
  3. 同伴先聽完，再說他理解的一點。
  4. 不用比較誰的答案最好。
給大人的引導與觀察

感受與評價沒有唯一正解，但可要求理由與作品相關。成人不能替孩子指定「必須感動」或「一定喜歡」。書寫能力不應妨礙閱讀回應，讓口語、圖示和代寫並存。

一起學 07

做一張自己的閱讀小卡

記書名，留一個線索和一個問題。

  1. 選本課一篇，成人幫你寫題目。
  2. 畫或說一個確定的內容。
  3. 留下一個想再問的問題。
  4. 說明這是故事有說，還是自己想到。
  5. 明天重新看一次，看答案有沒有更清楚。

讀課外繪本也能用同樣方法：先看封面，成人陪讀，圖文找線索，再分享一點感受。

這張小卡只留在自己或班級需要的範圍，不必拍照上網。找共讀方法可由成人看教育部親子共讀手冊。

給大人的引導與觀察

閱讀量可從一頁開始，品質不以完成整本或寫滿學習單判斷。成人示範帶著好奇重讀，同時尊重孩子想單純聽故事的時間。無字繪本也能看圖說線索，不因沒有注音而排除。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1兒歌哪個開頭重複兩次？
給我一點提示

回看兒歌第一、第二行。

看答案與原因

參考答案：風來了

前兩行都從風來了開始，這是本例的重複句式。

2〈找葉子〉的小禾在哪裡看到葉子？
給我一點提示

找第一句的位置。

看答案與原因

參考答案：地上

短文直接說在地上看見一片落葉，沒有說她摘葉。

3小禾先看顏色，再看什麼？
給我一點提示

注意先與再之間的內容。

看答案與原因

參考答案：葉邊

短文第二句說先看葉子的顏色，再看葉邊。

4微型繪本第1頁的盒子有什麼？
給我一點提示

比較前兩頁的變化。

看答案與原因

參考答案：還是空盒

第1頁圖文都顯示空盒，後一頁才加入土與小苗。

5第3頁紙上的兩片綠葉從哪裡來？
給我一點提示

把最後一頁圖和字合起來看。

看答案與原因

參考答案：小禾觀察小苗後畫下來

文字說小禾看見小苗後畫下綠葉，圖可核對小苗與畫紙。

6讀後發現猜想和故事不同，怎麼辦？
給我一點提示

猜想本來就還不是答案。

看答案與原因

參考答案：用新線索修正猜想

預測可以隨閱讀更新，修改想法是理解的一部分。

7哪個回應說得較具體？
給我一點提示

讓人知道你喜歡哪裡。

看答案與原因

參考答案：我喜歡最後一頁，因為能看見小苗和畫

指出頁面並給與圖文相關的理由，能讓聽眾理解你的感受。

8還不會自己讀所有字，可以參加共讀嗎？
給我一點提示

閱讀可以有支持。

看答案與原因

參考答案：可以聽成人讀並指圖回答

共讀可由成人代讀，孩子透過聽與圖像理解並表達。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

教學定位

對應Ad-I-2、Ad-I-3及第一階段閱讀興趣與理解方向。兒歌、短文、微型繪本皆為原創，不對應任何出版教材篇名。成人先完整帶讀，讓兒童理解與享受，再提出少量問題；尚未能獨立識字者可以聽、看、指圖參與，不必等所有注音都熟了才能閱讀。

三次25分鐘

  1. 第一次：4分鐘實書封面，6分鐘原創兒歌聽讀，5分鐘找重複，6分鐘短文成人朗讀，4分鐘人物事件提問。
  2. 第二次：4分鐘題目預測，9分鐘逐頁共讀微型繪本，5分鐘圖文線索，4分鐘重讀確認，3分鐘修正猜想。
  3. 第三次：5分鐘重訪喜愛片段，6分鐘線索提問，6分鐘分享理由，5分鐘閱讀小卡，3分鐘說想再讀什麼。

文體特徵與界線

兒歌本例有重複與節奏，不代表所有兒歌都同韻同長。短文以一件事形成順序，微型繪本文字與圖提供不同資訊。作者與繪者資訊由實書查找，不強定版面。教「我猜」與「讀了發現」容許預測更新，避免把預測是否猜中當分數。故事中的紙盒種苗只是閱讀情境，不當園藝操作指引。

差異化與評量

起步者聽成人讀並找一張圖；一般組說人物、主要事件或一個重複詞；延伸組比較圖文提供的線索、為推論指出依據。低視能者由成人讀圖像說明或以觸摸材料支持；聽覺需求者提供文字和既有溝通方式；口語需求者指圖、畫圖或溝通工具作答。非國語家庭可先理解故事後再練關鍵詞，不把口音當理解錯誤。

錯誤回饋回到作品：把小禾說成摘葉時，重讀地上的落葉；把第3頁當苗突然長大時，比較圖文只說畫下兩片葉子；把喜歡的理由套成任何故事都能用時，請他指一處具體畫面。不要求道德寓意、勵志心得或標準情緒。

家庭共讀

可從現有一本書一頁開始，成人代讀，孩子選問題；不增加購書壓力。把閱讀理解與國字書寫分開，不以寫滿學習單判完成。原創小卡只記題目、一個內容和一個問題，足以留下學習證據；不需公開兒童聲音、姓名或家庭影像。
