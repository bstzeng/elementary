標點符號與簡單句子

把一句話說清楚，再用合適的小記號幫人讀懂。

文字說事情，標點幫我們看清楚語氣和停頓。今天從「小貓睡覺。」開始，把一句話完成，再試試問朋友一句話。

建議：分3次，每次20–25分鐘；先句號與問號，再加入逗號、驚嘆號。孩子可由大人陪讀

出發前

準備好了嗎？

這一課，我會練習

  • 能把詞卡排成表達完整訊息的簡單句子。
  • 能在一般陳述、詢問與驚嘆句末選合適標點。
  • 能用逗號分開句內需要停頓的部分，而不隨意切開詞語。
  • 能重讀自己的句子，檢查內容與標點是否相配。
陪學大人：準備材料
  • 本課句子卡與。？，！四張標點卡
  • 誰、做什麼、在哪裡詞卡
  • 大格紙與鉛筆，成人可代寫

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

先讓一句話有意思

誰在做什麼，先說清楚。

小貓／睡覺 → 小貓睡覺。
桌上／有一本書 → 桌上有一本書。

第一句告訴小貓在做什麼；第二句告訴桌上有什麼。完整句不一定都長一樣，也不一定每句都要出現人。

本課練獨立句子，讀的人不用另外猜後半件事。只寫小貓，通常還沒有在這個練習裡說清楚牠做什麼。

  1. 成人先讀詞卡。
  2. 孩子選能連成有意思的一組。
  3. 口頭說完整句。
  4. 成人代寫或孩子寫已會的字。
給大人的引導與觀察

避免把主語動詞賓語硬套所有句型，或宣稱名詞短答永遠不是句子。此處限定獨立陳述練習；日常對話可有省略，視情境判斷。先看內容是否完整，再教標點，不因字多就算完整句。

一起學 02

句號：這件事說完了

用。收好一般陳述。

小貓睡覺。
我在看書。
桌上有一本書。

這些句子是在告訴別人一件事。語意完整、不是疑問或感嘆時，句末可用句號。

句號是一個小圓圈。正式書寫時給它合適位置，不擠進國字裡；在本課大格練習，可用一格留給標點。

  1. 成人讀一句。
  2. 孩子判斷這是在說一件事。
  3. 選句號卡放句末。
  4. 重讀，不必念出句號的名稱。
給大人的引導與觀察

教育部手冊句號占一字位置、居中，原則上不獨占行首。本課先教功能與辨認，精細排版由成人支持，不為初學者標點稍偏就否定句意。句號不是所有句末的唯一選擇。

一起學 03

問號：我想知道答案

真正在發問，就看問號。

你在看書嗎？
小貓在哪裡？
誰把書放在桌上？

問號讓讀者知道這句在詢問。問題不一定有嗎；誰、哪裡也能形成問句。

不要只看到問字就亂放問號。例如「我問老師。」是在告訴別人一件事，不是直接詢問讀者。

  1. 成人讀你在看書嗎。
  2. 孩子選？。
  3. 再讀我問老師，孩子選。
  4. 說明兩句是在問人還是說一件事。
給大人的引導與觀察

用實際語氣與句意判斷，不教「有嗎才是問句」或「出現問字就問號」。此處只用簡單直接問句；反問、引述內問句等複雜情況不在本次範圍。

一起學 04

驚嘆號：較強的感受

驚喜可以寫出來，也能用舒服聲音讀。

哇，好大的彩虹！
太好了！

驚嘆號常用在感嘆或較強的語氣後。看到很大彩虹而驚喜，可以用它表現感受。

不是所有開心句子都一定只能用驚嘆號，也不是寫越多個就越清楚。本課練習句末一個！即可。

  1. 成人先說平常告訴別人的語氣，再說驚喜語氣。
  2. 孩子說哪一種符合哇好大的彩虹。
  3. 選驚嘆號放末尾。
  4. 自然讀一次，不大喊。
給大人的引導與觀察

標點選擇有語境彈性，題目要明確提供強烈驚喜情境，不能將可用句號的陳述硬判只能驚嘆。官方亦列命令、加重語氣等用途，但本課只用安全簡單驚喜例。

一起學 05

逗號：一句裡稍停一下

把相關意思連著說，但分清楚。

我收好書包，走到門口。
放學後，我和家人回家。

逗號可分開句內的小部分，幫人看清語意或停頓。第一句先收好書包，再走到門口，句尾仍用句號。

不要為了喘氣把一個詞切斷，像「書，包」就把書包拆開。讀到哪裡換氣不一定都要寫逗號。

  1. 先讀完整句。
  2. 找收好書包與走到門口兩段意思。
  3. 在兩段之間放逗號。
  4. 比較錯拆詞和完整詞，指出書包應連著。
給大人的引導與觀察

逗號不是只按字數每五字一個，也不是所有朗讀停頓都要有標點。用手冊句內停頓功能作基礎，接受符合語意的合理選擇；課堂選擇題設明確內容，避免多解而硬給唯一答案。

一起學 06

句子工坊：排、說、標、讀

先有意思，再選記號。

  1. 成人提供小狗、跑步、你、在畫畫嗎等適當詞卡。
  2. 孩子選一組，例如小狗＋跑步。
  3. 先口頭說「小狗跑步」。
  4. 判斷是一般陳述，選句號。
  5. 再換「你＋在畫畫嗎」，選問號。
  6. 重讀兩句，聽聽語氣和標點是否配合。

你也能用自己的內容，但不需要寫私人地址或其他敏感資料。不會寫的字可以用注音、圖或請成人代寫，再一起核對。

第一次只用句號和問號，熟了再加入驚嘆號與逗號。

給大人的引導與觀察

句子創作不要求機械套同一主語，允許存在句或簡單描述句。成人代寫忠於孩子意思，不擅加情緒、評價或承諾。每次只修一個問題：內容未完整先補內容，句意完整再處理標點。

一起學 07

小編輯最後檢查

讀一遍，看看讀者會不會懂。

我的句子說清楚什麼？
我是在告訴、詢問，還是感嘆？
標點放在合適位置嗎？
有沒有把一個詞拆開？

  1. 選自己寫或成人代寫的一句。
  2. 先說這句的意思。
  3. 指出句末標點。
  4. 若有逗號，看看是否切開書包等詞。
  5. 請同伴讀，回報是否理解。
  6. 只改需要的一處，再讀一次。

可由成人開教育部標點符號手冊核對。今天完成兩句清楚的話，就是完整練習，不用堆很多標點。

給大人的引導與觀察

修訂是寫作的一部分，不把第一次有錯當失敗。評量看語意、語氣匹配與位置，不只計標點數。大格或紙卡支援可保留，寫字速度不當句子能力指標；作品不需上傳或公開。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1一般告訴別人「小貓睡覺」這件事，句末用？
給我一點提示

它沒有在詢問讀者。

看答案與原因

參考答案：。

這是語意完整的一般陳述，句末適合使用句號。

2「小貓在哪裡」是在詢問，句末用？
給我一點提示

哪裡是在問位置。

看答案與原因

參考答案：？

這句直接詢問位置，即使沒有嗎，也應用問號。

3驚喜地說「哇，好大的彩虹」，句末最適合？
給我一點提示

注意哇和驚喜的情境。

看答案與原因

參考答案：！

題目已指定強烈驚喜語氣，驚嘆號能表現這種感受。

4「我問老師。」需要因為有問字就改問號嗎？
給我一點提示

看整句意思，不只看一個字。

看答案與原因

參考答案：不用，這句是在陳述一件事

我問老師是告訴別人我的動作，不是直接提出問題。

5哪個逗號位置沒有拆開詞語？
給我一點提示

書包要連在一起。

看答案與原因

參考答案：我收好書包，走到門口。

逗號放在兩段相關動作之間，保留書包這個詞的完整。

6「桌上有一本書。」可以是完整句嗎？
給我一點提示

句子是否完整要看意思。

看答案與原因

參考答案：可以，它說清楚桌上有什麼

存在句也能傳達完整訊息，不是只有人物做動作才算完整。

7想寫句子但有國字不會，怎麼做？
給我一點提示

你的想法可以先說出來。

看答案與原因

參考答案：先口述、用注音或請成人代寫再核對

先表達意思再用適當支持記錄，可以把組句和識字書寫分開練。

8檢查句子時，最重要的做法是？
給我一點提示

讓讀者讀懂才是目標。

看答案與原因

參考答案：重讀意思與語氣，確認標點相配

標點服務語意與語氣，重讀能檢查是否完整、切題和停頓合理。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

定位與先備

對應Ac-I-1、Ac-I-2、Ac-I-3及6-Ⅰ-1、6-Ⅰ-2方向。先由口語完整表意，再轉文字與標點；不要求一年級孩子先寫出全部國字才能創句。一般陳述、存在句、直接問句和明確驚喜情境為本次範圍，避免一次教十五種標點。

三次25分鐘安排

  1. 第一次：5分鐘口頭完整句，7分鐘兩種基本句型，6分鐘句號與位置，4分鐘兩句排卡，3分鐘重讀。
  2. 第二次：5分鐘一般陳述回顧，7分鐘有嗎與沒有嗎的問句，5分鐘我問老師反例，5分鐘強烈驚喜和驚嘆號，3分鐘句意配符號。
  3. 第三次：6分鐘逗號與完整詞，8分鐘排說標讀工坊，6分鐘同伴回讀，5分鐘只修一處並自評。

規範與彈性

依教育部手冊：句號用在語意完整且非疑問感嘆的句末，問號處理疑問，驚嘆號處理感嘆或加重語氣，逗號標示句內分隔或語氣停頓。功能先於形狀，問句不一定有嗎，出現問字也不一定是問句。語境可能允許不同標點，評量時提供足夠情境，不宣稱所有開心句只有一種寫法。

差異化與錯誤對應

起步者成人代讀詞卡，先排一個陳述句；一般組說兩句並選句號問號；進展組加一個句內逗號或用語境解釋驚嘆號。國字不熟可口述、注音或畫圖，由成人忠實代寫，將書寫與組句分評。視覺和動作支持可用大卡、高對比、成人移卡，不以細小標點書寫精準度定義理解。

只寫小貓而內容不明時，先問本句要告訴什麼；任何句末都放句號時，回到是否在問問題；看到問就加問號時，用我問老師作完整陳述對照；逗號插在書包內，先圈整個詞再放句內分隔。成人每次只改一件事，不把初稿全部塗改。

評量與遷移

保留一個陳述、一個問句和一個逗號位置判斷，請孩子以口語解釋意思與選擇。選擇題不能替代真實創句，最後由孩子自己的內容完成一句並重讀。家庭可寫簡單非敏感小便條，成人查官方手冊，無需上傳或公開；不以句子越長、標點越多算進步。
