熟悉字詞的認讀與抄寫

從看懂到抄清楚，讓字母、空格和句號一起傳訊息

從看懂到抄清楚，讓字母、空格和句號一起傳訊息。依本頁完整教材先理解，再在合格成人示範下練習，最後換一組資訊自己試。

建議：2–3次，每次20–30分鐘；語音與動作練習可拆為短段孩子可由大人陪讀

準備好了嗎？

這一課，我會練習

  • 我能把熟悉詞組和物品意思連起來。
  • 我會對照模型抄寫並檢查字母順序、空格與句號。
  • 我知道抄寫與默寫不同，可以誠實記錄使用的支持。
陪學大人：準備材料
  • 本頁原創圖文與大紙字卡、鉛筆
  • 紙上虛構角色卡；可用指認、繪圖或AAC回應
  • 英語教師課前核對完整詞句；本頁未提供或驗聽音訊

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

抄寫不是只畫相似線條

先知道寫什麼，再保留原本訊息。

今天的red pen是紅筆，a red pen是一枝紅筆，It is a red pen.是「它是一枝紅筆」。先認讀並用中文說意思，再把文字抄清楚；看不懂意思時只描字形，還需要補上理解。

本課供應的是印刷文字抄寫參照，不是每個字母的手寫筆順動畫。教師先依學校合法書體示範需要的字形，接納a、g、I、l等正常造型差異。手累可停下，改成指字母或請成人依指示代寫。

一起學 02

三層完整模型

單字、詞組、句子各有工作。

第一列兩個單字red和pen分別說顏色和用品；第二列把它們放成詞組；第三列是完整句。句首It的I大寫，詞之間留空格，最後有句號。這課的大小寫與標點是供閱讀用的具體模型，不是要背抽象文法名稱。

成人可再畫一枝紅色筆並標「紅pen」幫意思配對，或使用這張完整文字情境，不需要實物尖筆傳接。印刷字體只作辨認，手寫仍依已確認模型。

一起學 03

示範：看一小段，寫一小段，再核對

一次一詞，最後讀全句。

成人示範抄It is a red pen.：先看It，說這是開頭，抄完核對I/t；留空再寫is；依序加a、red、pen；最後句號。完成後從左到右對原模型，檢查沒有漏字、換字或把兩詞黏成一個。

範例錯稿Itis a red pen.少了It和is之間的空格。修正時把這一處重寫成It is，不必把整頁全部擦掉。再看It is a red pn.，這回不是空格，是pen漏e；先找問題類型，修復才準。

一起學 04

一起做：三張檢查卡

字母、空格和意思分別看。

檢查甲：把red與der並排，指出字母順序不同，本課模型要red。檢查乙：把a red pen與ared pen並排，找a後的空格。檢查丙：把It is a red pen.與It is a blue pen.並排，兩句形式可讀，但顏色資訊不同，不能拿blue代替要抄的red。

孩子依序拿「字母順序」「詞間空格」「內容一致」三卡配錯稿，成人等孩子指出後才修。不是看到任何差異都說手寫不好，而是給能操作的具體提示。

一起學 05

修復：不要把支持當失敗

看模型抄寫就是這次任務。

有人遮住範本要求「不看才算會」，這已把抄寫改成默寫。先把模型放回，完成本課看懂、看著抄與核對；若日後想練默寫，要另給明確任務，不假裝兩者相同。

字距不必每個空格精確一根手指，但要讓詞能分開。左手或其他握筆方式先重視舒適和清楚，不能從字寫得慢推斷態度。成人代寫時由孩子指正確順序和空格位置，可證明規畫能力，但不是獨立手寫。

一起學 06

自己試：新顏色、新用品

抄完整新模型，不沿用舊句。

新模型：It is a blue book.，意思是「它是一本藍書」。先指出blue和book分別取代原句哪兩個詞，再看模型抄一遍。完成後只用三張檢查卡自己核對，成人不立即指出錯處。

核對重點

It is a blue book.

開頭It保留大寫I；五個詞之間分開；blue與book不可沿用red與pen；句末保留句號。對照抄寫完成，不等於已能離開範本默寫。

若不便書寫，可把大紙詞卡It／is／a／blue／book.排成句，記為詞序操作。

一起學 07

帶著證據回看進步

挑一處修正，比重抄十遍有用。

原創紀錄：「第一次少It後空格；檢查卡提醒後重寫該處；新句blue/book有依模型更新。」下次目標是先指每個詞間位置，再抄新句。不需要寫真實姓名作評量標題。

認讀、抄寫、自己校對與默寫分別看。發音和朗讀若要評量，仍須教師實際聽見；一張字形清楚的紙不能證明口語已熟練，也不能單靠成品推定筆順。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1本課red pen表示什麼？
給我一點提示

把顏色和物品合起來。

看答案與原因

參考答案：紅筆

red是紅色、pen是筆，詞組組合出紅筆而非其他物品或年齡。

2Itis a red pen.主要少了什麼？
給我一點提示

逐詞對照原模型。

看答案與原因

參考答案：It和is之間的空格

原句It與is是兩個詞，少空格會黏在一起，應針對這一處修正。

3It is a red pn.哪個詞要修？
給我一點提示

看用品詞的字母是否完整。

看答案與原因

參考答案：pn應補e成pen

模型用品是pen，錯稿漏中間e；不是顏色或句首的問題。

4把red抄成blue，問題是？
給我一點提示

形式可讀也要內容一致。

看答案與原因

參考答案：改變原本顏色資訊

blue是有效色詞，但不同於範本red，抄寫必須保留原有訊息。

5看著模型完成屬什麼任務？
給我一點提示

任務允許查看原文。

看答案與原因

參考答案：抄寫

抄寫本來可看模型；默寫不看原文、聽寫則依實際聲音，證據不同。

6新模型It is a blue book.更新哪兩詞？
給我一點提示

比較新舊句的內容詞。

看答案與原因

參考答案：red→blue，pen→book

新句改顏色和用品，前面的It is a保持相同而不需任意替換。

7不便手寫時如何呈現詞序理解？
給我一點提示

把理解與動作要求分開。

看答案與原因

參考答案：排大紙詞卡並記操作支持

詞卡排列可呈現順序與空格理解，需如實記支持而非宣稱手寫完成。

8只看成品可以確定什麼？
給我一點提示

過程和聲音需要另觀察。

看答案與原因

參考答案：可見字形與空格狀況

成品能檢查外觀內容，但筆順過程與口語聲音不能由靜態紙張推知。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

定位與媒材

這是三年級英語文參考主題，第二學習階段涵蓋三、四年級；單課順序不是全國統一課表。先看學生實際經驗，不假定人人已有低年級英語。國小畢業的300字詞與180拼寫目標不作本學期配額。故事、角色、卡片與題目均為原創，所列來源只支持註明的語言或教學事項。

口語實施前提

本頁沒有音檔，編寫時未驗聽播放。教師須先用可靠官方或字典模型核對本課完整詞句，並有能力以自然清楚的速度示範，才進行聽辨或發音觀察；本系列語音課採美式模型，但其他可理解的正常英語變體不列錯誤。不用中文諧音、合成聲音或拼字聲代替字音。無合適示範者時先做圖文理解，另安排口語課，不聲稱已完成聽說。

紀錄與可近用

書面選擇題只檢查文字可判斷的資訊；把認讀、理解、獨立口語和示範後跟讀分欄記錄。孩子可指卡、繪圖、使用AAC或請成人代寫；這能證明相應理解，不能冒充獨立發音或筆順表現。等待、重聽、短段休息均可，不以速度、音量、對視或公開表演膽量給分。不使用真實姓名、年齡、家庭、健康資料，不錄音錄影或上傳。

本課專項

先語意配對，再示範分詞抄寫，錯稿分為字母遺漏、詞間空格和內容更動。轉用新句要求有模型抄寫及自查，不偷換成默寫。支持者放大字、減為詞組或用詞卡；進階者自己指出修改證據，不增加抄寫量。教師把認讀、手寫控制與校對分欄，接受合法書體差異。靜態模型不證明筆順，實際動作仍以已確認書寫模型現場觀察，無強迫改慣用手或忍痛書寫。
