校園花草的觀察記錄

讓下一次的你，看得懂今天的發現

「花變多了！」是哪一株、哪兩天、看哪一段？把這幾件事留在記錄裡，下一次就不必靠記憶猜。我們先讀一份模擬圖，再試做自己的小記錄。

建議：3 次，每次約 30 分鐘；可依需要拆成短段孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

準備好了嗎？

這一課，我會練習

  • 用日期、對象代號和觀察範圍留下可再比較的記錄。
  • 以圖、數量或簡短文字記實際看見的特徵。
  • 比較同一對象的兩次資料，保留不確定及缺漏。
  • 分開變化與原因，提出下一次可核對的小問題。
陪學大人：準備材料
  • 本課P株兩日模擬圖；也可用成人勘查後的同株安全觀察點
  • 大格紙、筆、日期卡、植物代號卡；成人可代寫
  • 成人提供的固定觀察範圍提示，無學生定位或家庭照片

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

觀察卡先有三個小標記

哪一天、哪一株、看哪裡？

如果一張紙只寫「好多花」，別人不知道它是在今天還是上週，也不知道哪一株。小芃在卡上標「4月8日、P株、朝步道這一段枝條」。日期幫忙排先後，代號幫忙找對象，範圍幫忙知道數的是哪部分。這些比畫得像照片更能幫助比較。

  1. 成人念三個標記，孩子用日期、字母、框線卡依序配對。
  2. 把本課模擬記錄的P株當對象，不要求找到真實P株。
  3. 若實地觀察，用成人確認的非個資代號，不寫孩子位置軌跡。
  4. 成人代寫後讀回，孩子核對有沒有記錯對象或日期。
給陪學大人：帶領與觀察

日期可由成人提供，尚不識日期者用第一日、第二日搭配完整日期。不可把模擬日期當實際觀測日。固定範圍不需綁植物、採花或使用GPS，成人用圖上圈選或安全地標說明即可。

一起學 02

一個符號只表示一件事

先說圖例，再開始記。

小芃決定用一個圈表示一朵已張開的花，花苞畫小三角，葉子另畫葉形。圈是記號，不是說花真的圓圓的。若沒說圖例，別人可能以為一圈代表一整株。今天先只記張開的花，避免一口氣把葉、花、蟲和顏色全混在一起。

  1. 成人畫「圈＝一朵張開的花」的圖例並讀給孩子。
  2. 用兩個大花卡示範看到一朵就記一圈。
  3. 拿出花苞卡，說它不計入這次張開花的欄位。
  4. 孩子可指花由成人記圈，再一起一對一核對。
給陪學大人：帶領與觀察

符號需高對比，可用觸覺或口述代替。避免依顏色單獨區分，也不強制畫寫；孩子負責判斷，成人可記錄。計數超過能力時縮小範圍，而不是編一個看似精確的總數。

一起學 03

讀兩日圖，把證據指出來

同一個P株枝段，先找兩次數量。

這份原創模擬資料畫同一範圍：4月8日兩朵張開的花，4月11日三朵。小芃畫兩圈和三圈，兩兩配對後，第二日多出一圈，所以記「第二次可見的張開花多一朵」。圖沒寫天氣，也沒有拍到兩日之間所有過程，不能直接說一定因為下雨而增加。

  1. 指出兩張圖的相同代號與不同日期。
  2. 依圖各記一排圈，成人可協助逐花對點。
  3. 用手指配對兩排，找到第二排多出的一圈。
  4. 說出有證據的變化，再把「為什麼」放到待查格。
給陪學大人：帶領與觀察

本圖不是某種植物的保證生長時程，不說三天一定增加一朵。只比較提供範圍的可見張開花，不推斷全株總花數、總花苞數或生理原因。數學需要支持時可用大花卡配對代替算式。

一起學 04

角度不一樣，可能不是植物變了

先檢查怎麼看的。

第一次看正面只見兩片葉，第二次換到背面看見三片，不能立刻說植物新長一片。可能只是原本被擋住的葉看到了。想比較同一件事，要盡量保留同一對象、範圍和安全角度；若角度變了，就把它寫下，不為了看一致而走入危險地方。

  1. 成人用紙葉在另一張紙後遮住一片，再換視角露出。
  2. 孩子描述兩次可見數不同，指出遮擋的影響。
  3. 選下次可重用的安全站位或圖片範圍。
  4. 條件不同時加註「角度不同」，不硬下增加或減少結論。
給陪學大人：帶領與觀察

用桌面紙卡展示遮擋，不拉扯真葉。自然光、風、遮蔽等都可能影響可見範圍；一年級只挑一項重要條件練習。不是要求完全相同才能記錄，而是知道不同條件會限制比較。

一起學 05

沒看到、不清楚、沒去看，各有意思

記錄不必每格都填一個數。

小芃那天請假，不能把花數填0；0表示有依範圍觀察而沒見到要記的花，「未觀察」才表示沒有看。若枝葉遮住一部分，可記「看見兩朵，後方不清楚」。誠實留空或寫原因，比為了漂亮表格猜數字更有用。

  1. 成人提供三個故事：已看未見花、沒去看、部分被遮住。
  2. 孩子把它們配到「未見、未觀察、不清楚」卡。
  3. 把一份故意寫錯0的模擬表改成未觀察。
  4. 回讀記錄，確認下一個人不會誤以為全部都數過。
給陪學大人：帶領與觀察

不以零值代表所有缺測，這是基本資料誠實而非高年級統計。成人接納忘記或未能完成，不追究成品整齊。天氣、照顧安排或安全限制導致未觀察時，改用課內資料即可。

一起學 06

實作一張，小到下一次能重看

先選一個特徵，記完再核對。

小芃只記一段枝上的張開花。她先看完整範圍，再慢慢畫記號，最後回到圖一一核對，發現多畫一圈就劃掉並註記修正。記錄能改，不需要偷偷重畫成一次就全對；留下改的原因，有助記得哪裡容易漏看或重複。

  1. 成人選安全觀察點或本課圖，確認不摘、不碰、不餵食。
  2. 孩子選一項可見特徵，成人協助填三個標記與圖例。
  3. 畫、指或口述記一次，然後對照原對象核對。
  4. 若有修正，清楚改記；整理紙筆，不向網站上傳記錄。
給陪學大人：帶領與觀察

實地全程成人帶領，天氣不宜立即替代。可用葉輪廓或花是否張開等特徵，不一定計數。觀察的重點是有根據記錄與核對，不要求連續多日打卡或家庭幫忙完成整套作業。

一起學 07

用記錄提出一個下一步

說出知道，也說出還不知道。

小芃能說：「模擬圖的P枝段第二次多見一朵張開花；原因這兩張圖沒告訴我。」下一步可再看同一範圍，或問成人查找可靠植物資料。圖畫讓問題更清楚，但不能替沒有做過的觀察作保證。分享時只選自己的記錄，不公開同學或家庭資料。

  1. 孩子用「哪兩次、哪個範圍、哪項變化」說一句結論。
  2. 再補「目前還不知道……」，不急著填原因。
  3. 選下一次安全可做的觀察問題，例如同一枝段花數。
  4. 把方法轉用到另一張原創植物圖，核對標記與圖例是否足夠。
給陪學大人：帶領與觀察

延伸不必追求更多數量或長期追蹤；成人可於原定課程自然重看。評量能否有範圍地說結論，而不是記錄頁數。保留不確定是成功的探究行為，不能因缺乏答案而扣掉求知動機。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

定位與課前準備

本課依生活課程第一學習階段的觀察記錄、證據比較與簡單探究設計，為跨版本原創參考，不是全國固定的學期單元。先選本課模擬資料或安全可及觀察點，明示兩者差異。不要要求拍照定位、綁記號到植物或採摘標本。準備大圈、花苞三角與日期代號卡，成人負責不適天氣和場域安全。

第 1 次：30分鐘陪學

0–8分看只有「好多花」的不足；8–18分加入日期、對象、範圍；18–25分建立圈的圖例並一對一記數；25–30分讀回一張記錄。

第 2 次：30分鐘陪學

0–12分讀P株兩日原創圖並配對花數；12–20分分開變化與原因；20–27分桌面遮擋示範角度影響；27–30分給條件不同的記錄加註。

第 3 次：30分鐘陪學

0–10分辨未見、未觀察、不清楚；10–22分完成一張小記錄並核對修正；22–27分提出一個下一步；27–30分用帶範圍的結論回顧。

差異化與參與方式

識字或日期能力尚未穩定時由成人填標記，孩子決定觀察結果；需要時只比兩朵花。視覺辨識困難者用放大圖、凸點或成人逐項描述。熟練者指出比較條件，而非要求更長文字。成人先讀短句，孩子可指卡、口述、用熟悉語言或既有輔助溝通回答；需要動作協助時由孩子決定、大人代做。一次呈現一個問題，不用閱讀速度或動作整齊程度代替理解評量。

常見迷思與修正

可見數不同可能是角度或遮擋，不一定生長；未觀察不能填0；知道花數改變不等於知道原因。示範「我有證據說什麼，還不能說什麼」以修正過度推論。

實作評量與回饋

看孩子能否指出記錄對象、使用一致圖例、依證據比較、標註缺漏、核對後改正。保留一個實際操作例作回饋，不將未能戶外觀察當成學習不足。記錄「獨立完成、提示後完成、共同完成」及一個具體行動。選擇題只能補充判斷，不取代實作；答錯時回到情境找線索，再提供重試，不排名。

延伸與隱私

用同一張圖片稍後再核對一次即可；若自然再訪要由成人安排與陪同。記錄可只留在紙上，成人不要求公開姓名、學校位置、家庭所在地或連續攝影。不要求購物、家庭照片、姓名住址或上傳作品。可只用虛構角色完成；孩子能選擇展示多少，也能只私下與陪學成人回顧。
