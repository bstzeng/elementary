簡單手語訊息的理解與表達

教師輔助課：用四個官方短片學感謝與回應、道歉與回應；完整模型可用後才進行語言實作。

本次尚未完整核驗外部影片播放與手語形式；實際詞句教學需合格臺灣手語支持及課前確認可用完整模型。頁面選擇題只檢查情境與學習方法。先看懂人物想表達什麼，再跟可靠模型慢慢試。

準備好了嗎？

這一課，我會練習

  • 能在完整視覺模型支持下分辨感謝、回應感謝、道歉、接受道歉四項功能。
  • 能看已教臺灣手語短訊息並配對情境。
  • 能在安全生活情境中嘗試使用合適的臺灣手語短訊息。
  • 能在伙伴準備好後表達，並等待和核對回應。
  • 知道沒關係是一種可選回應，不能強迫原諒。
陪學大人：準備材料
  • 四支指定國教署完整手語短片
  • 具臺灣手語能力的教師或合適教學支持
  • 紙片、紙屋或積木模型、兩個紙偶
  • 四張功能情境圖與一張休息提示卡

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

今天學臺灣手語：兩種小對話

先看完整模型，再用在真正合適的情境。

本課只屬臺灣手語選習路線。今天理解並嘗試四個完整短訊息：得到幫助時的感謝、收到感謝時的回應、不小心造成困擾時的道歉、對道歉的一種回應。你不必讀會四個中文字，先看圖理解情境，再看影片中的語言。

四個模型來自教育部國民及學前教育署《學齡前2至6歲教保服務人員手語手冊》。每一詞目都有獨立短片；本課把完整短片當短訊息模型，沒有自行拼接成未核實的長句。

上課前，大人先確認

頁面與官方影片身分已核對；本次播放器停在黑畫面，尚未完成全段播放及手語形式核驗。成人須先從頭播放到結尾，確認畫面清楚，看得到臉部和雙手，再上課。若黑畫面、遮住手或不能播放，使用學校已備妥的合法完整模型與合格教師示範；未備妥時，本課語言理解及表達部分尚不能驗收。

不要只看中文字猜動作，也不用中文諧音、逐字配手勢或合成聲音代替臺灣手語。指圖可以表示你理解意思；表達手語本身仍需要實際視覺模型及回饋。

一起學 02

故事一：紙片有人幫忙撿

先看「幫忙」和「感謝」是誰做的。

原創情境：小米整理作品，兩張乾淨紙片落到桌邊。阿禾問過後幫忙拿回，小米收到紙片，想表達感謝。阿禾收到感謝，也想友善回應。用兩個紙偶演一次，再把「得到幫助」圖放小米面前，把「回應感謝」圖放阿禾面前。

先開官方短片：第三單元詞彙19「謝謝」，從開頭看到結尾。第一次孩子只看，不同時拿紙片或翻卡。第二次再看，選小米所在的情境卡。成人確認孩子知道訊息的用途，才邀請跟模型做一次。

接著開官方短片：第三單元詞彙20「不客氣」，完整觀看，同樣先配圖再模仿。現在收到感謝的是阿禾，請把回應放到正確角色。

  1. 成人播放一支短片，孩子選兩張角色情境卡中的一張。
  2. 兩支輪流，不照固定次序，重做三回。
  3. 孩子選一個角色，影片看完後再表達；另一人指圖核對意思。
這輪重點

幫忙者和受幫忙者的訊息不同。不能只看誰先站起來就猜答案，要看剛才發生了什麼。

一起學 03

故事二：不小心碰倒了作品

道歉可以表達，對方也可以說出自己的感受。

原創情境：阿禾移動空紙盒時，不小心碰倒小米已擺好的紙屋。沒有受傷，阿禾先停下，想表達道歉，再幫忙整理。小米確認紙屋沒壞，願意表示沒關係。這只是其中一種結果；受到困擾的人不必立刻說沒關係。

開官方短片：第二單元詞彙08「對不起」，完整看一次。把它配到「我不小心造成困擾」圖，再看一次後試做。開官方短片：第二單元詞彙09「沒關係」，配到「我願意接受這次道歉」圖，再模仿。

  1. 用紙偶演碰倒紙屋，不推撞真人、不故意破壞作品。
  2. 造成困擾的角色選道歉訊息；另一人看完再回應。
  3. 若收到道歉的人需要時間，可指休息卡或用已有溝通方式表達，不被迫使用今天的第四個訊息。
  4. 雙方同意後合作把紙屋擺回來，確認語言之外也有修補行動。

成人問：「如果有人受傷呢？」先停下並找可信任成人處理。說出道歉不會自動消除傷害，也不能當成繼續危險行為的許可。

一起學 04

看完整表達：臉和手都在訊息裡

一次觀察一件事，不急著和影片搶速度。

重新選一支剛學過的短片。第一次看整個人上半身和完整動作；第二次由教師提示注意一個面向，例如手在身體附近的哪個位置、動作方向，或臉部等非手部訊號。這些是觀察方向，不是本頁給你的手形指令；具體形式一律以影片和合格教師為準。

不要只擷取一張靜止圖片就說那是完整詞。某些差異需要從動作開始到結束才能看到。成人可以重播完整短片，必要時依教師指導短暫停格，但每次分看後都回到完整模型。不要鏡像翻轉影片、自行改方向或把字幕順序當手語語序。

  1. 看完後放下雙手、休息一下，再嘗試。
  2. 教師只指出一個優先調整的地方，再完整示範。
  3. 孩子看過後再試，接收者選相應情境。
  4. 比對是否更容易理解，不以誰動得大、快或整齊取代準確性。

有動作或視覺需求的孩子，由合格教師和相關支持人員調整接收與表達方式。不能因為做不到相同手形就認定沒有理解，也不能把任意動作記為已學會標準模型。

一起學 05

理解小挑戰：不看提示字選情境

看一則手語訊息，找它適合的事情。

桌上放四張不含答案字的情境圖：收到拾回紙片、回應別人感謝、碰倒紙屋後道歉、願意接受道歉。成人先逐張說明或以孩子可接收的方式確認圖意，不讓閱讀能力決定答案。

  1. 成人隨機播放一支已教完整短片，播放時先不指向答案卡。
  2. 看完後，孩子選圖；需要重播可以提出。
  3. 成人翻開圖卡背面的中文功能做核對，再回放完整模型。
  4. 下一輪換卡片位置，防止只記左上右下。
  5. 每個孩子接收四則訊息，記下獨立選對或重播後選對。

若影片字幕直接給出答案，理解評量由具備臺灣手語能力的教師，以相同核實模型現場示範且不先給中文答案；不可用遮住臉、裁掉畫面或亂改影片的方法除字幕。教師不在時，這輪只算帶提示練習，不宣稱獨立手語理解測驗。

怎麼處理選錯？

先看是否混淆角色：受助者和回應者、道歉者和接受者。重新演情境，配一次完整模型，再抽新卡；不要求把四個動作盲目重做十遍。

一起學 06

表達小劇場：讓伙伴真的收到

先確認伙伴準備好，再傳一則訊息。

把兩個故事布置成桌面小站。第一站是紙片，第二站是紙屋。每人先選想演的角色，不一定上台。合作前約定怎麼取得注意，保留舒服距離，讓彼此看得到臉和雙手；不強迫眼神接觸或觸碰。

  1. 成人只給情境，不立即播放答案。
  2. 表達者嘗試使用合適的已教訊息。需要幫助時先看完整模型再試，記為有支持的表達。
  3. 接收者用相應回應、情境圖或既有溝通方式表示理解。若要評今天的回應詞，就須實際使用已核實的手語模型。
  4. 換角色，兩人都有表達和接收機會。
  5. 換道具為橡皮擦、紙片房屋以外的積木模型，確認不是只記住故事台詞。

請具備臺灣手語能力的教師核對語言形式與情境是否適合；不懂手語的陪學成人不能只因「看起來像」就判正確。伙伴猜不出時，先檢查是否準備好、是否看清楚，再回到模型修補。

一起學 07

我會了哪一種？把理解與表達分開看

我能看懂，也能慢慢試著表達。

在自己的紙上畫四個小格：感謝、回應感謝、道歉、願意接受道歉。每格可貼或畫情境，不要求書寫。完成一個就用自己的記號記錄「看懂了」「跟模型做過」「能在新情境使用」。三種狀態可以不同，不需一律打滿。

例子：你看到模型能選對感謝圖，但自己表達時仍要重看，表示理解已有進展、表達還在練習。再選這一格作下一次目標。另一例：動作跟得很像，卻在收到幫助時選了道歉，就回到情境功能，不能只練外形。

  1. 成人抽一張尚未演過的安全情境圖，例如有人把借用的紙交給你。
  2. 孩子先選意思，再使用已學訊息。
  3. 伙伴回應，教師給一項具體回饋。
  4. 孩子選「下一次再看哪支模型」，作為自訂練習。

回家可以和熟悉且願意陪伴的人練一個自然小情境。沒有適合語言支持時，校內完成同等任務。不要求錄影上傳，也不讓孩子獨自搜尋陌生手語示範者。題目選對只能檢查情境與學習策略，不能取代本課的實際視覺理解和表達。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

模型與使用界線

限定臺灣手語路線，核心是兩組功能互動、四個獨立短訊息。已核對官方詞目頁與國教署頻道的影片標題及連結：第三單元詞彙19謝謝、20不客氣，第二單元詞彙08對不起、09沒關係。網站核驗時播放器未完成播放，因此不宣稱手形、動作或畫面完整性已由本站重新驗收。課前須由成人及合格臺灣手語教師在實際裝置確認完整模型；無法取得時，停止該項語言教授和驗收，不以中文情境討論填補已完成紀錄。

第1節：功能配對與模型學習

5分鐘確認路線和視線；8分鐘演受助故事，先辨別兩角色；8分鐘學感謝及回應完整模型；8分鐘演紙屋故事並學道歉及回應模型；6分鐘打亂情境配對；5分鐘分開記理解與表達。每段影片先完整看，再模仿，不要求孩子同時聽中文長講解、看手語和翻圖。四詞對起步者過多時，兩節各處理一組功能。

第2節：理解、表達及修補

5分鐘隨機複習；10分鐘無中文答案提示的教師示範選圖，或有字幕的支持性練習並正確標記；12分鐘紙片與紙屋兩站互換角色；8分鐘改道具的新情境轉移；5分鐘完成自評。正式獨立理解評量不可讓字幕先揭露答案；也不可遮住臉部等訊號來藏字幕。

常見誤解與差異化

  • 只記四個動作順序：變換情境、角色與卡片位置，要求看意思。
  • 只看手、不看臉：完整模型可能含非手部訊號，請教師示範語言功能，不能笑鬧模仿。
  • 把字串拼成句：本課使用官方獨立短訊息，不增添未核實語序。
  • 以為道歉就一定要被接受：保留另一方感受、時間和修補需要。
  • 比較動作整齊：按個別動作與接收需要提供支持，不強迫同姿勢或上台。

初學者先學謝謝與不客氣，以兩圖辨別角色；需要支持時並列圖意、短回合和更多完整重示。熟練者在不同道具與伙伴下獨立選用同一組功能，先鞏固而非增加未核實長句。有視覺或動作障礙者與專業人員合作調整，記錄所用支持。

可操作的評量

理解：四項完整示範各配一次圖，記獨立／重示後／需重教。表達：給兩個隨機情境及角色，核對功能選擇與語言形式，後者由具備臺灣手語能力者判讀。互動：確認伙伴接收、等回應、選擇合宜修補。理解選圖正確不代表表達已熟練；看過影片也不等於學會。家長不具該語能力時只協助播放、配圖和觀察參與，不自行做語言正確性裁判。家庭練習無需公開影像或真人故事。
