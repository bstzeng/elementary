社團、技藝與特色活動

小小紙編社：學一招、練一回、做出自己的圖紋

這是可選用的校訂社團與技藝示例，不表示每所學校都有紙編社。我們用大人備好的寬紙條練交錯，做一小塊紙編圖。這是一般紙材練習，不冒稱某族群傳統技藝；真實文化工藝需另有合適來源與教學。

建議：3 次，每次 30 分鐘；完成一排也可以先收好孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 在成人提供的安全材料中理解紙編的一上一下交錯。
  • 依圖示完成或指示完成一排，再讓下一排方向相反。
  • 檢查一個交叉處，發現漏穿時退回修正。
  • 自己選圖紋、角色或用途，和同伴輪流分享做法。
  • 知道特色活動可以依學校安排與個人需要調整，不需競速或購買材料。
陪學大人：準備材料
  • 成人預先準備六條寬紙條，約手指數倍寬，邊緣平整，不需兒童剪裁
  • 三條直紙編號1、2、3；三條橫紙編號甲、乙、丙，顏色可不同但不是必要
  • 成人分好的少量紙膠帶或可移除固定材料、底板、粗筆
  • 若不便手作，可用本頁交叉圖指示成人操作；不使用刀、針、熱熔膠、燙熨或電動工具

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

先試一回，找到你想學的事

社團可以練技巧，也可以發現興趣。

原創故事：小晴第一次參加教室的紙編活動，看到兩個作品，一個是大塊拼貼，一個是紙條交錯。她說：「我想知道紙條怎麼穿過去。」老師請她先試一排，感受自己是否想繼續，不必一開始就承諾做很大一件。

  1. 看一眼成品圖，指出你想了解的地方。
  2. 選今天的小目標：認出一上一下，或完成一排。
  3. 選參與方式：自己拿紙、指示成人拿、或先觀察。
  4. 把材料放在平坦桌上，確認邊緣沒有破損或會刮到的附件。

學一項技藝，會經過看示範、慢慢試、發現問題、再調整。有人喜歡排圖紋，有人喜歡說明步驟，都能為活動出力。沒有立即喜歡紙編，也可以把學到的檢查方法帶到別的活動。

給陪學大人：社團身分與安全

本課是教室可用的樣例，不收報名費、不要求套裝材料，也不代表正式社團招生。所有紙條事前由成人準備，兒童不拿剪刀、刀片或打洞器完成本課。紙條與膠帶不入口、不纏繞手指、脖子或身體；不舒服就停下。

一起學 02

兩張紙的上面和下面

先只看一個交叉點。

把一條直紙平放在桌上，再把一條橫紙跨過它。從上方看，交叉處能完整看到橫紙，就是橫紙在直紙上面。把直紙輕輕抬起，橫紙穿到下面，交叉處看到直紙，就是橫紙在下面。

成人問：「現在橫紙在上還在下？」孩子先用手指指出哪一條覆蓋另一條。答案說的是交叉處的相對位置，不是紙在桌子的左邊或右邊。

  1. 只放兩條寬紙。讓成人先演橫在上。
  2. 你指出交叉處，說或指「上」。
  3. 大人換成橫在下，你再辨認。
  4. 輪到你決定上下，請成人依指示擺一次，再核對。

用兩種顏色會容易看，但也可在直紙畫一條線、橫紙畫圓點辨認。不需要只靠顏色；看不清楚時，用經成人確認可觸摸的寬紙條慢慢感受重疊，或聽完整描述。

給陪學大人：避免空間詞混淆

固定直紙與橫紙角色，提問始終是「橫紙相對直紙」的位置。不要一下問直紙在上、一下又問橫紙在上造成誤會。孩子先能區分單一交叉，再增加到三個；手部操作可由成人執行，理解和動作分開觀察。

一起學 03

第一排：上、下、上

一次過一條，不用一次穿完。

把三條直紙並排成1、2、3，頂端由成人用少量可移除膠帶固定在底板，條與條之間留空隙，下面仍能輕抬。橫紙甲從左往右走三次：

  1. 到直紙1：放在它上面。
  2. 到直紙2：輕輕抬起2，把甲穿到下面，再放下2。
  3. 到直紙3：讓甲回到上面。
  4. 看三個交叉處，依序說「上、下、上」，讓甲平放而不硬拉。

小晴穿到2時卡住了。她沒有拉破紙，而是退回一點，請成人幫忙抬高2，再把甲慢慢滑過去。紙平順就可以，不必壓得完全沒有縫。

給陪學大人：保留孩子的選擇

成人可固定底紙，孩子選下一步。若只剩記憶負擔，先露出1、2兩條，穩定後加入3。不要握住孩子的手強迫穿紙；先問他希望怎麼協助，也不使用尖工具替孩子撬開。

一起學 04

第二排換相反，第三排再回來

隔壁的交叉，要互相穿插。

只把每張橫紙疊在同樣位置，紙條會比較像一層層蓋上去。紙編的練習是讓相鄰兩排交叉方式相反，形成互相穿插的結構。

橫紙甲：上、下、上。

橫紙乙：下、上、下。第一個交叉就和甲不同。

橫紙丙：上、下、上，和甲相同。

  1. 乙從直紙1下面開始，先輕抬1，再穿過。
  2. 經過2時放上面，經過3時穿下面。
  3. 讓乙與甲靠近但保留可以調整的空間，不用用力塞緊。
  4. 丙照甲的方法做。做完每排都用指圖或口述檢查。

如果今天只完成甲和乙，也已經可以看到交錯。把作品連同底板平放收好，下次再加丙。沒有完成三排，不等於沒有學到技巧。

給陪學大人：理解規則而非追求整齊

觀察孩子能否說出或指出乙的起點與甲相反。若每排都排甲的樣子，先只比較第一個交叉，讓他發現兩排相同，再決定從哪裡改。不要一次拆掉全部作品使孩子無從辨別修正位置。

一起學 05

發現一格不一樣，退回再試

檢查是做作品的一部分。

小晴檢查乙排時，依序看到「下、上、上」。最後一格應該在下，她卻忘了穿過直紙3。她把乙的末端退回到3之前，輕抬3，再把乙放到下面。前兩格原本正確，不用全部拆掉。

  1. 先指要檢查的那一排，說出原本約定的順序。
  2. 一格一格比對，不把整張紙稱為失敗。
  3. 找到第一個不相合的交叉，停止硬拉。
  4. 把橫紙退到能重新穿的位置，再慢慢修正。
  5. 最後重查該排三格，確認調整是否真的生效。

紙邊破了、膠帶卡手或身體不舒服，就停下請成人處理，可以換紙或改口頭指示。修正需要時間，做快不一定做得比較清楚。

給陪學大人：給可操作的回饋

說「乙在3這一格還在上面，我們對照圖」比「你都做錯了」具體。只示範退回與重穿，不替孩子整件重做。若記不住三項順序，依正在做的那排提供三格提示卡（乙排為下、上、下），完成一格就指下一格，不以撤掉提示作為唯一進步標準。

一起學 06

選一個圖紋，讓作品有自己的樣子

共同學一招，可以做出不同作品。

交錯方式練穩後，你可以決定紙條的圖案。有人在直紙畫線、橫紙畫點；有人只用原有紙色。圖案是自己的選擇，不必照同伴的配色才算漂亮。

小晴想做「雨點和小路」：直紙畫長線，橫紙畫圓點。阿禾想留白，讓交錯的形狀自己說話。兩個人都用一上一下的技巧，作品卻不同。

  1. 先選一個想法，說或畫出準備放的圖案。
  2. 在成人提供的安全材料上加少量記號，不塗到別人作品。
  3. 由成人協助適度固定鬆動末端，紙編圖放平展示。
  4. 決定用途：當一張圖紋作品或放在練習本旁觀察，不當承重用品。

這是紙做的練習品，不是隔熱墊、防水墊或能承重的籃子。不要放熱杯、食物、電器或用它吊重物。若想認識真正的傳統編織，應由熟悉來源的教師或工藝者另行帶領，不能把這張練習當成任何族群代表。

給陪學大人：不把裝飾變成新負擔

可以完全不加圖紋，選擇留白也是決定。材料固定由成人依情況處理，無需增加熱熔膠、釘書機、亮粉或小飾品。評量仍回到交錯理解和檢查，不以外觀華麗或家庭購買能力比較。

一起學 07

當一回小教練，說出一個訣竅

別人做的時候，先問要不要幫忙。

兩個人輪流介紹一個做法。你不必上臺，也不必公開作品；可只向陪學大人指一個交叉處。

小晴：「乙的第一格要在下面。我卡住時，先退回再請大人抬紙。」

阿禾：「我想自己再試一次。」小晴回答：「好，我先等。」她沒有把作品搶過來重做。

  1. 選一個你學到的技巧，用指、說或圖卡表達。
  2. 請對方按這句話試一個交叉，看看說明清不清楚。
  3. 有需要就改說法，例如指出是橫紙還是直紙。
  4. 收好可用材料；膠帶與碎紙由成人協助依班級方式整理。

下次可以自選只練第二排、改一格錯位，或再畫一個圖紋。完成作品很開心，發現自己喜歡什麼、能怎麼練，也都是特色活動的收穫。

給陪學大人：轉移的適切深度

可把規則帶到大張條紋排列或圖卡交錯，不要求升級針線、竹條、金屬或電動工具。孩子不想繼續紙編時，仍可回顧看示範、拆小步、檢查修正的方法；不把興趣選擇判成意志力不足。

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

課程定位與材料把關

本課是校訂社團或技藝課可採的安全紙材示例，不是全國每校必開，也不是特定文化工藝的授權傳承教材。成人事先備好寬、平整、無尖銳附件的六條紙及底板，活動中兒童不需剪裁、打洞、穿針、加熱或使用電動工具。只用少量已分好的固定材料；紙與膠帶不入口、不纏身體，無合適材料就用圖卡指示完成。

第 1 次：單一交叉到一排，30 分鐘

0–6 分看成品選小目標與參與方式；6–15 分用兩條紙比較橫在上與橫在下，固定提問對象；15–25 分成人固定三條直紙，帶做甲排上、下、上，逐格停；25–30 分孩子指一格解釋。先確認空間概念再增加動作，不要求第一堂做完。

第 2 次：相反排與修正，30 分鐘

0–7 分重查甲排；7–18 分做乙排下、上、下，僅在孩子準備好時加丙；18–25 分成人以另一張教具示範乙末格在上的錯位，讓孩子找一格、退回再穿；25–30 分回到自己的作品檢查。錯誤由成人教具呈現，不破壞學生作品來測反應。

第 3 次：選圖紋與說技巧，30 分鐘

0–12 分孩子選是否加線或點，也可完成尚未完成的一排；12–20 分兩人輪流說一招並尊重對方想自己試；20–27 分用新兩條紙或圖卡轉用上下關係；27–30 分收材料與自評。完成物只作紙上圖紋，不用來承重、隔熱或接觸食物。

差異化與常見誤解

把上下當成左右者，停在單一交叉，用遮住哪條來辨認。每排都同起點者，比較甲乙第一格。紙卡住者先退回或請成人抬紙，不要求用力。視覺需要支持者用寬紙、清楚邊界、圖像描述或經確認可用的觸覺教具；色覺不同者用編號、線點作區別。手部動作需要支持者由孩子指定順序、成人操作，不握住手強迫穿編。需要記憶支持者保留三格提示，熟練者說明相鄰排為何要相反，不以縮小材料或加速作加深。

形成性評量與延伸

分開觀察辨上下、指出相鄰排差異、完成或指示一排、找出一格錯位、說出求助與修正方法，記錄獨立、提示後或共同完成。作品整齊和速度不是同一能力；選擇題只能檢查規則，須搭配至少一次操作或指示。對興趣尚不確定者肯定嘗試，允許停在一排。家庭延伸使用原材料做一個交叉即可，無需購買、拍照上傳、參賽或比較他人技藝。
