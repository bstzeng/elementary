夏天的生活與節水

照顧身體需要，也減少水白白流走

天氣熱時，身體需要水，也需要休息。節水不是忍著不喝，而是看看哪裡的水沒有幫上忙就流掉了。我們用乾桌模擬，練把水留給真正需要的地方。

建議：3 次，每次約 30 分鐘；可依需要拆成短段孩子可由大人陪讀

出發前

準備好了嗎？

這一課，我會練習

  • 依當日天氣與身體感受選擇補水、休息和遮陽。
  • 知道節水不等於少喝需要的水或省略必要清潔。
  • 辨認水未被使用仍流走的情境，選合宜關水方法。
  • 以具體小行動記錄改善，遇漏水或設備問題交成人處理。
陪學大人：準備材料
  • 大紙卡：補水、休息、遮陽、關水、通報漏水；不需真實耗水演示
  • 紙畫水龍頭與原創情境記錄；可在乾桌上全程模擬
  • 若結合必要洗手，成人確認安全可達水龍頭與清潔方法，不新增無需的洗手次數

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

夏天的安排，要看今天的情況

季節是提醒，天氣還要確認。

同樣說夏天，有的地方很熱，有時下雨或天氣較涼。出門前由成人看當地天氣和活動地點，再安排衣著、遮陽、可休息處與飲水。不能只因日曆寫夏天就認定每一天適合玩水，也不能因有雲就保證不會熱或沒有日曬。

  1. 成人描述兩個原創情境：炎熱操場與下雨走廊，不要求戶外曝曬。
  2. 孩子各選一個需要調整的安排，例如改室內或找合適涼處。
  3. 指出今天的資訊要由成人確認，不依昨天經驗硬套。
  4. 在紙上規劃一段活動與一段休息，不要求固定時長。
給陪學大人：帶領與觀察

避免將季節圖示當天氣預報；實際安排依學校規定和氣象資訊。成人負責高溫風險，不測試耐熱、流汗量或曬多久。無法外出者可用室內情境學習，課程不需要戲水。

一起學 02

身體需要水，節水也不能省掉

渴了要說，不舒服就停。

小安玩紙卡時覺得熱，告訴成人需要休息與飲水。平日由照顧者提供合宜的飲水機會，少量分次，不等到一直忍耐才喝；每個人的需要不同，不在班上比誰喝最多或最少。若頭暈、想吐或很不舒服，要停止活動立即告知成人，由成人照顧和判斷求醫。

  1. 成人用紙偶說「我很熱，想休息」，孩子選合宜回應。
  2. 找出可取得飲水與呼叫成人的方式，不操作不熟悉的熱水設備。
  3. 演先停止活動、告知不適、跟成人到合適涼處。
  4. 口述飲水與休息是必要照顧，不拿它們換節水獎勵。
給陪學大人：帶領與觀察

不提供全班統一毫升數，不強迫灌水，也不以此課處理疾病。無法自行吞嚥、意識不清等緊急狀況由成人求援，不能讓兒童餵水。照顧者依個別醫療需要安排飲水，不公開孩子健康資料。

一起學 03

先分必要用水與空流

有在幫忙的水，不隨便省。

洗掉手上髒污、沖掉肥皂和喝需要的水都有用途。水龍頭開著，但人已走開、容器也沒在接，水就在空流。節水先找這種可避免的浪費，不是把洗手改成不洗。是否可再利用也要看水的乾淨程度與用途，孩子不能自己拿不明水來喝或洗食物。

  1. 成人讀三張卡：沖手上肥皂、人離開水仍流、喝需要的白開水。
  2. 孩子指出哪張是這次最應先改善的空流。
  3. 用「這股水在幫什麼忙？」說明理由。
  4. 遇用途不清楚的水，先問成人，不自行關掉別人的必要用水。
給陪學大人：帶領與觀察

不以用水越少就越好作唯一價值，清潔、健康與安全有必要需求。避免讓兒童監督或指責同伴如廁、飲水。示範全用紙卡，不故意開水空流來做反例，也不回收污水實驗。

一起學 04

洗手時，把空檔關起來

搓揉關水，沖洗再開。

這裡的重點是水龍頭何時需要開：先用適量流動水沾濕，關水塗肥皂並仔細搓揉，再開適量水沖淨，最後關好並擦乾。節水不縮短需要的清潔，也不只沾一下就算洗過。每種龍頭不同，有的自動感應，要依成人示範正確使用，不硬扭。

  1. 先在乾桌排沾濕、關水搓揉、開水沖淨、關好擦乾四張圖。
  2. 成人用紙龍頭模擬開關，孩子指哪個時段可關。
  3. 若剛好需要洗手，才在成人陪同下用實際設備練一次。
  4. 做完確認不再空流，若不能正常關閉就告知成人。
給陪學大人：帶領與觀察

完整洗手方法依衛教與校內流程，這段只抓減少空流，不以節水取消肥皂、搓揉或沖洗。不要讓孩子攀爬濕滑凳子或操作熱水；動作需要支持時由成人協助開關。

一起學 05

漏水不是靠孩子用力修

看見問題，告訴負責的大人。

小安看到無人使用的龍頭一直滴水。他先問成人是否已關好；如果正常關閉後仍漏，就把地點和現象說清楚：「洗手區左邊龍頭一直滴。」不需要拿工具拆開或站到濕地查看。地板濕時先避開，請成人處理，不能把節水變成修水管任務。

  1. 成人用紙畫滴水情境，孩子描述看到的現象。
  2. 指出可告知的已確認成人，例如老師或管理人員。
  3. 練說位置與問題，不猜誰弄壞或責罵使用者。
  4. 地面滑、設備鬆動或有電器時保持距離，由成人接手。
給陪學大人：帶領與觀察

不要求查看馬桶水箱、管線、高處儲水或家中帳單；這些由成人處理。無需上傳設備照片和地址。可記紙偶的通報卡，不蒐集真實校園維修資料，安全先於立即止漏。

一起學 06

用一次小記錄，看方法有沒有變

記行動，不編省下幾桶水。

原創模擬紀錄寫：第一次搓肥皂時水仍流；第二次看提示卡，搓揉前先關水。這能說明第二次減少了那段空流，但沒有量水，也不知道總用水量，所以不能寫「一定省了十桶」。我們先記是否使用了方法，也記用了提示，不用為了測量額外放水。

  1. 成人畫兩格，分別放空流與先關水的圖卡。
  2. 孩子指出第二次具體改變的是哪個動作。
  3. 選一項自己在必要用水時可做的行動，由成人安排合宜機會。
  4. 回顧一次，記獨立、提示或共同完成，不記飲水量排名。
給陪學大人：帶領與觀察

模擬資料不能當家庭真實省水成效；不把單一行動推成總量保證。低年級先看可靠行為證據，較熟練者可說還缺什麼資料才能算水量，不實際做浪費水的測量試驗。

一起學 07

把方法帶到別處，先問用途

照顧需要，再減少浪費。

準備畫畫時，成人正在接清洗畫具的水，小安不能只因水在流就立刻關。先知道正在做什麼，再找是否能在不用時關好。公共設備和家庭設備也可能不同，能控制的範圍不同；孩子做一小步、告知問題就有參與，不必替全家承擔水費或缺水壓力。

  1. 成人演「正在接需要的水」和「人已離開仍空流」兩種情境。
  2. 孩子先判斷用途，再選等待、正常關好或求助。
  3. 用一句話總結：我會照顧需要，也減少哪個空流。
  4. 收好紙卡，讓下次在自然生活時才用，不增加反覆清洗活動。
給陪學大人：帶領與觀察

不要布置查家中經濟、每人用水量或監督洗澡的作業。低資源家庭可用任何安全既有設備，不能因無省水產品被評為不環保。整課不操作電器、不取不明水、不做戶外水域延伸。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

定位與課前準備

本課依生活課程第一學習階段的季節生活、健康照顧與資源珍惜設計，為跨版本原創參考，不是全國固定的學期單元。以乾桌模擬為主，不為示範浪費而開水。若結合必要洗手，先確認可達設備、地面防滑與熱水隔離。飲水與清潔是必要需求，不能設少喝水或不洗手獎勵；成人負責天氣與個別健康安排。

第 1 次：30分鐘陪學

0–10分讀不同夏日天氣情境；10–20分選補水、休息與遮陽；20–27分紙偶不適求助；27–30分說明為何節水不減必要飲水。

第 2 次：30分鐘陪學

0–10分分必要用水與空流；10–20分排四步關水時機；20–27分乾桌模擬或結合一次必要洗手；27–30分遇設備關不緊時練告知成人。

第 3 次：30分鐘陪學

0–10分描述漏水地點與現象；10–20分讀兩次模擬行動記錄；20–27分轉到畫具接水情境先問用途；27–30分選一個安全可做的小目標。

差異化與參與方式

用大圖與口述減少讀字；無法控制龍頭者可辨認時機，成人執行。熟練者說明行動改善和水量數字不同，不增加量水、查帳單或家庭監督工作。成人先讀短句，孩子可指卡、口述、用熟悉語言或既有輔助溝通回答；需要動作協助時由孩子決定、大人代做。一次呈現一個問題，不用閱讀速度或動作整齊程度代替理解評量。

常見迷思與修正

夏天不是每天同樣天氣；節水不等於不喝水、不沖淨肥皂；看見水流要先辨用途；一次改行動不能憑空推算節省公升數。遇不適先照顧人，不能為課程繼續忍耐。

實作評量與回饋

觀察能否依情境選照顧、辨空流、在搓揉時選關水、通報設備問題、用具體證據回顧。評量的是判斷與可做行動，不比較家庭設備、費用或孩子飲水量。記錄「獨立完成、提示後完成、共同完成」及一個具體行動。選擇題只能補充判斷，不取代實作；答錯時回到情境找線索，再提供重試，不排名。

延伸與隱私

在原有生活中提醒一次不用水時正常關好就足夠；沒有可控制設備就用紙卡。家中漏水交成人，不要求孩子修繕、上傳照片或節省必要生活用水。不要求購物、家庭照片、姓名住址或上傳作品。可只用虛構角色完成；孩子能選擇展示多少，也能只私下與陪學成人回顧。
