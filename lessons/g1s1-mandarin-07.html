專心聆聽與輪流發言

讓對方說完，接住一個重點，再輪到我。

你說故事時，希望有人聽。朋友說話時，也需要一段自己的時間。今天輪流當說的人與聽的人，用一句話接住對方的意思。

建議：2次，每次25分鐘；日常再練1–2分鐘。孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 能用適合自己的姿勢聽完一段短話。
  • 能重述或指出對方說的一個重點。
  • 能等到約定訊號再發言，必要時禮貌請求重說。
  • 能區分一般輪流與需要立即求助的安全情況。
陪學大人：準備材料
  • 一張說話卡和一張聽話卡，可用文字或圖示
  • 喜歡的活動圖卡、空白紙
  • 安靜且能舒適坐或站的空間

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

聽的目標是懂意思

先聽這一句，再選圖。

小安說：「我今天帶了藍色水壺。」

成人讀一次。桌上放藍水壺、紅帽子、綠書包三張簡圖，你選出小安說的物品。

眼睛不一定要一直看著對方，身體也不必完全不動。你可以看水壺圖、輕輕點頭，或用自己的方式把注意力放在話語上。

  1. 聽到物品是什麼。
  2. 再聽它的顏色。
  3. 選圖或回答「藍色水壺」。
  4. 如果漏聽，請成人再說一次。
給大人的引導與觀察

專心的證據是理解和回應，不是強制眼神接觸、雙手背後或一動不動。調整背景聲、說話距離與圖卡支援；尊重孩子的感官和溝通需求。若答錯，先檢查是否聽清楚，不直接責怪分心。

一起學 02

讓一句話說完

等對方說完，再把卡交給你。

甲：「我喜歡畫畫，因為可以畫小狗。」
乙：「你喜歡畫小狗。輪到我，我喜歡看書。」

拿說話卡的人先說，另一人先聽。說完把卡放到中間，表示可以換人。卡片只是練習幫手，平常也可以用停頓或「換你」當訊號。

  1. 成人當甲，孩子當乙。
  2. 先聽完整一句，不搶著接自己的故事。
  3. 指出一個聽到的重點。
  4. 看到換人訊號，再說自己的話。
  5. 交換角色再做一次。
給大人的引導與觀察

一開始每人10–20秒即可，不以計時器施壓。若成人自己頻繁打斷，孩子很難學會等待，應先示範真正聽完。輪流規則不是誰拿卡就能一直占用，也不是不准孩子拒絕分享。

一起學 03

很想說，可以先留住想法

畫一個小記號，等輪到你。

朋友的話讓你想到自己的小狗，你很想立刻說。先把想法留在心裡，或在紙上畫一個小狗圖記。等他說完，再接著說。

如果你怕忘記，可以輕輕舉手或出示「我想說」卡，不必越喊越大聲。

  1. 先做一次成人未說完時，孩子留圖記。
  2. 成人說完，明確給換人訊號。
  3. 孩子看圖記，說一句自己的想法。
  4. 如果已忘了，也可以說「我等一下再說」。

「我也有一個想法。你說完後可以換我嗎？」

給大人的引導與觀察

等待能力需要支持和練習，不是品格測驗。提供視覺順序、短回合和預告；頻繁插話時縮短成人發言，不加長等待當懲罰。圖記可由成人代畫，不要求先會寫字才有發言權。

一起學 04

接住內容，不只說「嗯」

用一句話，說回你聽到的事。

朋友：「下雨了，我把球收進屋裡。」
我：「你把球收好了。」

不用逐字背出朋友的句子。只要意思對，用自己的話也可以。你可以說「因為下雨，你收球」，也可以指出「收球」圖。

如果朋友說的與你不同，先聽懂，再說自己的看法。聽見不等於一定要同意。

  1. 成人說原句，孩子找重要動作。
  2. 孩子用短句或指圖重述。
  3. 成人確認或補一個漏掉的重點。
  4. 孩子再問一個和內容有關的問題。
給大人的引導與觀察

重述看語意是否保留，不要求句型完全一樣。若孩子只仿說最後三個字，改問「誰做什麼」並給圖選。延伸可讓孩子說「我聽到……；我想……」，區分他人的話與自己的意見。

一起學 05

沒聽清楚，也能好好問

請人重說，比亂猜更有用。

「我沒聽清楚顏色，請再說一次。」
「你是說把書放桌上嗎？」

不知道時可以求助，不用假裝都懂。說出哪裡沒聽懂，對方比較知道要補充什麼。

先聽「把紅色卡放盒裡」，如果只記得放盒裡，就問「要放哪個顏色的卡？」

  1. 成人先讀完整指令。
  2. 孩子重述自己確定的部分。
  3. 孩子提問缺少的一點。
  4. 成人重說後，孩子完成排卡。
給大人的引導與觀察

不能故意含糊或突然加難考倒孩子。可先示範成人自己問清楚，讓求助變正常。孩子使用手語、溝通卡或輔具提出重說需求，同樣算有效溝通；不因語法不完整拒絕回答。

一起學 06

兩人練習：我說你接

每人選一件喜歡做的事。

  1. 先選畫畫、看書、玩積木中的一張圖。
  2. 甲用一句說喜歡的活動，可以加原因。
  3. 乙聽完用短句或圖卡說回重點。
  4. 甲確認：「對，我說的是……」或補充一點。
  5. 交換說話卡，乙說自己的活動。
  6. 最後各指出同伴做到的一件事，如等我說完或問清楚。

不想談喜好也能改用「桌上有一本書」等中性內容。不想在全班說，可以先和成人一對一練。

回饋說具體行為：「你先聽完，再問積木的顏色。」比只說你很乖更清楚。

給大人的引導與觀察

起步：一句五至十字、兩圖選；一般：一句加原因、短句重述；延伸：兩句連續訊息、相關提問。成人確保兩人都有回合，不把流利者當永久示範、較慢者當永久聽眾。作品不需拍攝或公開。

一起學 07

什麼時候要立即求助

安全的事，可以立刻告訴大人。

一般分享時，等輪到你。可是看到有人受傷、聞到煙味或自己需要緊急幫忙，應立即叫可信任的大人，不必等說話卡。

你可以說：「老師，有人跌倒需要幫忙。」說清楚發生什麼和在哪裡，讓成人處理，不自己靠近危險。

  1. 成人說「我想介紹新鉛筆」，孩子指等待卡。
  2. 成人說「走廊有人受傷」，孩子指求助卡。
  3. 練一句清楚的求助。
  4. 再回到普通分享，練輪流一次。

今天收尾：我聽到了＿＿；我等對方說完後＿＿。兩個空格可以口答或指圖。

給大人的引導與觀察

輪流是合作方法，不能凌駕安全或剝奪求助。只用口頭情境，不模擬煙火、跌倒或製造危險。將一般發言與必要中斷並教，避免孩子因守規則而延誤向成人求助。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1小安說帶了藍色水壺，哪張圖符合？
給我一點提示

先想物品，再想顏色。

看答案與原因

參考答案：藍水壺

話裡的物品是水壺，顏色是藍色，兩個線索都要對上。

2朋友還沒說完，你想到自己的事，可以？
給我一點提示

把想法暫時放在紙上。

看答案與原因

參考答案：先留圖記，等換人訊號

留住想法並等待訊號，可讓朋友完整說完，也保留自己的回合。

3朋友說下雨所以收球，哪句接住了內容？
給我一點提示

找與球有關的回答。

看答案與原因

參考答案：你把球收好了

收球是原句的重點，用自己的短句重述也可以。

4沒聽清楚要拿哪個顏色的卡，怎麼問？
給我一點提示

把不清楚的地方說出來。

看答案與原因

參考答案：請問要拿什麼顏色的卡？請再說一次。

指出漏聽的顏色並請求重說，能幫助對方補充必要訊息。

5哪個能顯示有理解對方？
給我一點提示

想一想你聽懂了什麼。

看答案與原因

參考答案：能說回或指出一個重點

能回應內容才是理解的證據，專心不必只有一種身體姿勢。

6哪個情況應立即求助，不必等回合？
給我一點提示

安全問題不能等太久。

看答案與原因

參考答案：走廊有人受傷

有人受傷需要成人協助，安全求助可立即打斷一般分享。

7聽懂朋友的意見後，可以不同意嗎？
給我一點提示

理解和同意是兩回事。

看答案與原因

參考答案：可以，先尊重地聽懂再說自己的看法

聽懂不等於必須同意，可以輪流表達不同想法。

8同伴用指圖回答，可以算回應嗎？
給我一點提示

回答可以有不同方式。

看答案與原因

參考答案：可以，重點是讓意思被理解

指圖或其他溝通方式也能傳達意思，應尊重不同表達需求。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

目標與觀察起點

對應1-Ⅰ-1、2-Ⅰ-3的聆聽與互動方向。先讀藍色水壺一句，看孩子能否選對物品與顏色；用理解反應判定注意，不以眼神、坐姿或完全靜止作唯一標準。成人先調整噪音和句長，確保孩子實際聽得到、詞語也懂。

兩次25分鐘

  1. 第一次：4分鐘聽句選圖，6分鐘成人示範輪流，6分鐘兩人短回合，5分鐘重述重點，4分鐘離堂指出同伴說過的活動。
  2. 第二次：4分鐘回顧換人訊號，6分鐘留圖記等待，6分鐘提問重說，6分鐘雙人練習，3分鐘區分安全求助與一般等待。

具體教學語言

成人回饋應描述行為與影響，例如「你讓他把原因說完，所以知道他為什麼喜歡畫畫」。不要把聽話等同服從，不要求孩子同意每個人的意見。插話出現時先指換人訊號，再提供下一個回合，不當眾貼標籤。若已等待卻一直得不到發言機會，調整成人主持，不能只要求孩子再忍耐。

差異化與補救

起步者以一短句、兩圖選和成人明確交卡支持；一般組說回一個重點，再說自己的想法；延伸組可問相關問題，區分別人的話與自己的意見。口語輸出需求者用指圖、文字、手語或溝通輔具；感官需求者可以不對視、輕微活動或戴既有輔具。不要把學習支持設成要先乖坐才可獲得的獎勵。

忘記話語時，不先加碼長句；重播同一句，再檢查是物品、顏色或動作哪個漏掉。等待困難時縮短每回合，加入圖記和明確次序。若孩子不願分享私事，改中性觀察句，不強迫揭露家庭情況。安全情境只做口頭判斷，提醒即時求助的例外。

形成性評量

一對一記錄三項：是否能指出一句重點、是否在約定訊號後發言、是否能提出一次重說需求。標示獨立、提示後或仍需協助，不用總分判性格。網頁題只檢查情境判斷，還需真實互動觀察。家庭每天一分鐘互說一件小事即可，由成人也示範等待；無須錄音、拍攝或比誰最安靜。
