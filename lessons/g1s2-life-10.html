生活材料自製玩具

做一隻會合攏與展開的紙紙蟲

一張紙，不用剪、不用彈射，也能變成動一動的小玩具。今天做「紙紙蟲」：握著兩端慢慢合攏和展開，看看摺痕怎麼一起動，再讓它有自己的花紋。

建議：3 次，每次約 30 分鐘；可依需要拆成短段孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 看材料安全與特性，選可摺且完整的大紙張。
  • 依對折、再對折、展開和交替折的步驟完成紙玩具。
  • 觀察摺痕如何讓紙形狀合攏或展開，不把它說成紙被拉長。
  • 先測試再改一項，說明玩法並取得他人同意後分享。
陪學大人：準備材料
  • 一張完整長方形紙，如無個資的乾淨再用紙；不用剪刀、訂書針或裁刀
  • 粗筆、平整乾桌；可由成人預折大摺痕
  • 本課四格紙帶示意，不用橡皮筋、小眼珠、電池、繩索或外加發射裝置

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

先挑材料，玩具才好開始

乾淨、完整、好摺，也要夠大。

小禾找到一張沒有個資的單面紙，先請成人確認沒有釘子、尖邊、污漬或裂口。紙太厚不容易折，太薄破損又不耐操作，可用一般完整紙試。再用是把仍安全好用的材料用下去，不是所有撿到的包裝都適合玩，陌生髒物不拿來做。

  1. 成人提供兩張安全紙：一般薄紙與較厚卡紙，孩子只用手輕試彎。
  2. 選一張容易折、手能掌握的大長方紙。
  3. 確認另一面沒有名字、住址或其他不宜公開內容。
  4. 把桌面清空並擦乾，材料只留紙和筆，不需任何刀剪或小零件。
給陪學大人：帶領與觀察

回收包裝可能有食物殘留、釘子和個資，成人應先排除而非讓兒童自行清理。選用有足夠抓握面積的紙，避免入口。視覺或動作需要支持可用較大紙張和預折痕，不硬壓手指。

一起學 02

先想玩法，不急著裝飾

要怎麼動，才知道怎麼做。

紙紙蟲的玩法是把兩端慢慢靠近、再慢慢分開，紙沿摺痕合攏和展開。它不是會自己爬的真蟲，也不會因你大力拉就長得更長。先說清楚玩法，就知道兩端要留抓握位置，花紋不能用鬆掉的小裝飾，不能拿玩具打人或彈向他人。

  1. 成人用手中的預折大紙展示慢慢合攏與展開。
  2. 孩子指出兩端在哪裡，選自己要握或指揮成人握的位置。
  3. 在四格草圖上先想一個大花紋，例如線、點或自己的臉形。
  4. 約定玩具只在乾桌前慢動，別人說停就停。
給陪學大人：帶領與觀察

不要以真昆蟲知識解釋紙偶機構，也不承諾能自行行走。兩端保持大面積完整，不剪出尖觸角或細尾巴。兒童可選抽象紙帶而不畫動物，同樣完成設計目標。

一起學 03

先折出四格，讓摺痕幫忙

邊對齊，手慢慢壓平。

把長方紙橫放，左右短邊對齊，折成一半；保持折好狀態再左右對齊折一次。全部打開後，原紙有三道摺痕、四個相連的格子。第一次折歪可重新對齊，不需要剪掉；如果太難，由成人先折，孩子仍可以指出邊和格子來參與。

  1. 將完整長方紙放在桌上，成人指左右兩條短邊。
  2. 左邊對到右邊，先扶住對齊處，再用指腹壓摺痕。
  3. 折好的紙再同方向對半一次，慢慢壓平。
  4. 全部展開，沿三道痕指四格；不把紙撕開成四張。
給陪學大人：帶領與觀察

流程不需剪刀或刀具。成人可在初始短邊畫不同形狀提示但不依顏色單一線索；低視力者用觸摸摺痕或口述。若紙過厚改合適薄紙，不要求兒童靠全身重量壓折。

一起學 04

一折一反，讓紙帶會合起來

沿舊摺痕，改成像手風琴。

沿第一道摺痕向一邊折，第二道往反方向折，第三道再與第一道同方向。從側面看，四格像W或倒過來的W交替連著。慢慢把兩端靠近，四格靠攏；分開兩端，四格展開。摺的是同一張紙，改的是形狀和兩端距離，不是紙真的變長。

  1. 先在打開的四格畫大花紋，兩端保留可握空間。
  2. 成人示範第一折，孩子沿第二折反向，再沿第三折反向切換。
  3. 若一時折回原本兩層，展開找第二道痕再換方向。
  4. 握兩端輕試，看到摺痕輪流抬起與放下，再慢慢放平。
給陪學大人：帶領與觀察

W只是側面視覺比喻，不要求形狀完全一樣。成人可持一端協助或整段依兒童指令完成。別把彎折當伸長原紙的證據，不使用膠帶連接細小片或橡皮筋使它彈出。

一起學 05

試一次，只修最卡的一步

找到卡點，比重做全部更有用。

小禾發現中間那格不肯折回，紙紙蟲看起來有一段平平的。他先看是不是中間摺痕方向沒交替，再只把那一道重新折好。若同時換紙、加很多裝飾又改玩法，就很難知道哪個改變有幫助。作品不必一開始就跟成人一樣整齊。

  1. 用第一次成品慢慢合攏，再慢慢展開一次。
  2. 孩子指出哪一段順、哪一段卡，可用成人口述代替。
  3. 先選一個修法：重新對齊摺痕或改正交替方向。
  4. 用同樣慢動方式再試，比較是否更容易，不以拉扯力量比賽。
給陪學大人：帶領與觀察

不故意破壞孩子成品做測試。紙破裂就停用，由成人改安全紙，不用釘書機補；不要求一定救回破損作品。較熟練者可比較兩張安全紙的摺曲容易程度，但不要說一次試就代表所有紙。

一起學 06

做一張玩法卡，讓別人安全試

先問願不願意，再交代三件事。

小禾的玩法卡寫：「握兩端、慢合慢開、說停就停。」他先問同伴願不願意試，再展示如何保留手指和桌面空間。分享可以是只示範，不一定把珍愛作品借出去；若借用，先說時間和歸還方式，不能因朋友好就省略詢問。

  1. 把三項玩法畫成大圖，可由成人代寫短句。
  2. 請紙偶或成人按卡操作，看看有沒有不清楚的詞。
  3. 對方若問哪裡是兩端，作者指清楚再試一次。
  4. 孩子選展示、借用一回或不借，接收者尊重這個決定。
給陪學大人：帶領與觀察

不將借出私人物品當合作的必考門檻。分享時不拍攝他人或公開姓名，回饋只談可見的操作。若兩人同玩，不能抓住相反方向拔河，成人維持安全界線與停止權。

一起學 07

換一個主題，保留可用設計

玩具可以改，安全約定也跟著看。

小禾把四格畫成從種子到葉子的想像故事，朋友把它畫成四段彩色路。這些是原創裝飾，不需要模仿書本角色。改花紋時仍保留握的位置和三道摺痕。玩完檢查紙有沒有破損，完整的先保存；不再使用的由成人確認分類，不把作品數量當成努力證明。

  1. 孩子選新的大花紋或四格故事，不需要外貼小裝飾。
  2. 說出哪項改了、哪項為了玩法要保留。
  3. 最後完整示範一次，或用指圖交代成人代做。
  4. 整理紙筆，記「我修了哪一道摺痕」這個方法，下次可再用。
給陪學大人：帶領與觀察

只有更換裝飾不代表完成機構探究，仍要讓孩子指出摺痕作用及一次測試。不要要求大量製作送全班或購買材料；作品可不公開。紙張再用與分類依當地規則，不能混有異物便一概回收。

同一張紙沿摺痕改形，端點距離變大，不表示紙本身被拉長或有生命。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

定位與課前準備

本課依生活課程第一學習階段的材料探索、設計製作與修正設計，為跨版本原創參考，不是全國固定的學期單元。只用完整大紙與筆，無刀剪、熱源、強力膠、訂書機、橡皮筋彈射、小零件或電器。成人先檢查紙的污損、尖邊和個資；預備大尺寸及預折替代材料，確保乾桌和抓握空間。

第 1 次：30分鐘陪學

0–8分比較安全紙材；8–18分看慢合慢開玩法並規劃握持處；18–25分成人示範兩次對折；25–30分展開指出四格與三道摺痕。

第 2 次：30分鐘陪學

0–8分畫大花紋；8–18分沿三道痕交替折；18–25分試一次找卡點；25–30分只改一個摺痕再試。兒童可全程決策而由成人折。

第 3 次：30分鐘陪學

0–10分製作三步玩法卡；10–20分讓成人按卡測試並補說明；20–27分選新花紋保留機構；27–30分檢查完整、收納並回顧修法。

差異化與參與方式

動作不便或精細動作尚在發展者用預折痕、大紙與成人代做；視覺需要者觸摸四格並聽口述，不以摺痕整齊判理解。熟練者一次換一種安全紙比較，不增加危險零件或速度。成人先讀短句，孩子可指卡、口述、用熟悉語言或既有輔助溝通回答；需要動作協助時由孩子決定、大人代做。一次呈現一個問題，不用閱讀速度或動作整齊程度代替理解評量。

常見迷思與修正

紙合攏展開是形狀和端點距離改變，不是原紙變長；不會自己爬不代表失敗；卡住先查交替方向，不以用力拉解決。再用材料仍須安全和無個資。

實作評量與回饋

觀察能否說玩法目標、指出四格三痕、理解交替折、按同樣方法試並只改一處、交代安全玩法及尊重借用同意。保留一次修正前後的具體描述。記錄「獨立完成、提示後完成、共同完成」及一個具體行動。選擇題只能補充判斷，不取代實作；答錯時回到情境找線索，再提供重試，不排名。

延伸與隱私

只要展示已有玩具或把三步玩法口述一次，無需購物或再做一批。家人可幫持兩端，但不要變成拔河或用彈力發射；破損停止並交成人整理。不要求購物、家庭照片、姓名住址或上傳作品。可只用虛構角色完成；孩子能選擇展示多少，也能只私下與陪學成人回顧。
