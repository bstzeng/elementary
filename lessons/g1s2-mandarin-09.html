故事人物、地點與事件

把人物、場所與發生的事連起來，說出故事的主線。

故事裡有誰、在哪裡、做了什麼，像三條線編在一起。只背出名字，還不知道發生了什麼；只記住月亮，也不一定知道誰把它拿回來。今天把三條線接起來。

建議：2次，每次25分鐘；第三次可換新故事檢查遷移。孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 能找出主要人物，區分角色、場所與物品。
  • 能追蹤角色從一個場所到另一個場所的行動。
  • 能用問題、做法、結果整理主要事件。
  • 能保留角色關係，用自己的話簡短重述。
陪學大人：準備材料
  • 小露、阿成、老師角色卡
  • 教室、活動室兩張地點卡
  • 月亮紙卡與書架物品卡

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

三張小標籤：誰、哪裡、什麼事

先分清楚，才容易接在一起。

誰：小露、阿成、老師。
哪裡：教室、活動室。
物品：月亮紙卡、書架。

物品不是今天這個故事裡會說話的角色。教室是角色活動的地方；書架是教室內放東西的物品，兩者的範圍不同。

  1. 先聽成人讀這些詞，確認活動室的意思。
  2. 把名字放到誰，場所放到哪裡。
  3. 留下物品卡，等讀故事後再看它們怎麼影響事情。

有些童話的月亮可以成為會說話的角色，但不能只因別的故事這樣寫，就當今天的月亮紙卡也會自己走路。要看這篇真正提供的內容。

一起學 02

原創故事：月亮還在書架上

先讀完，再找遇到的問題。

小露和阿成要在活動室排練紙偶戲。出發前，小露把月亮紙卡放在教室的書架上。
到了活動室，阿成找不到演夜晚場景要用的月亮。小露想起紙卡還在教室，便和老師回去拿。
老師陪小露走到書架旁，小露拿回月亮紙卡。阿成留在活動室，把布幕整理好。
小露回到活動室，兩人把月亮紙卡貼在布幕上。夜晚的場景準備好了，排練繼續進行。

這是本頁原創故事。月亮是演戲用的紙卡，不是真的月亮。可以讓成人分段讀，你負責指角色與地點卡。

先說一句主線：他們排練時少了月亮紙卡，小露在老師陪同下拿回，排練才繼續。故事沒有說表演日期或觀眾人數，這些不必補猜。

一起學 03

人物的事情，各自接對

陪同的人和拿紙卡的人不一樣。

  • 小露：記起紙卡位置，和老師回教室，親手拿回紙卡。
  • 阿成：發現少了月亮，留在活動室整理布幕。
  • 老師：陪小露回教室。

小露與阿成都參與排練，是這篇的主要人物；老師協助其中一段。不能因為老師出現，就把每個動作都算成老師做。

  1. 成人讀「留在活動室整理布幕」，孩子找阿成卡。
  2. 再讀「拿回紙卡」，孩子找小露卡。
  3. 把同一時間不同人物做的事並排放。
  4. 用「小露去拿紙卡，阿成整理布幕」說一次。

人物可以合作，也可以分頭做不同的事。重述時名字忘了，可以先看角色卡，不必用猜的把人換來換去。

一起學 04

場所路線：人走動，地點跟著換

這是故事流程，不是真實校園地圖。

小露先離開活動室取物，再回活動室；阿成在取物這段留在原地。圖為簡短摘要，要確認誰親手拿紙卡，仍回故事原句。

一起學 05

找主線：問題、做法、結果

挑三件重要的事，不背每個字。

我來整理

問題：排練時找不到月亮紙卡。
做法：小露想起位置，在老師陪同下取回。
結果：月亮貼上布幕，排練繼續。

「書架」是線索，因為它告訴小露去哪裡拿；「紙卡顏色」沒有交代，不需要加進主線。想要簡短，不代表可以把關鍵原因和做法都拿掉。

  1. 將問題、做法、結果三卡排好。
  2. 用一至三句重述，成人可代寫。
  3. 檢查有沒有把小露的行動說成阿成。
  4. 再回原文核對結果不是正式演出結束，而是繼續排練。

「準備好了」和「演完了」不一樣，讀故事要注意事件做到哪一步。

一起學 06

重要與有趣：都能談，但用途不同

摘要留下主線，喜歡的細節可以另外說。

你可能喜歡紙偶戲，也可能覺得把紙卡忘在書架上很有趣。分享喜歡的地方時可以說它；要讓沒讀過的人懂故事，仍需交代缺少紙卡、取回和繼續排練。

只有物品：月亮、書架、布幕。
有事件：小露取回留在書架上的月亮紙卡，兩人繼續排練。

列三個名詞還不是完整的故事主線，因為沒有把人物和事情接起來。可以用動作詞讓物品發生關係。

  1. 同伴先聽你的摘要。
  2. 問他「發生了什麼問題」「後來怎麼了」。
  3. 若回答不出，補一個必要事件。
  4. 最後再各說一個喜歡的細節，不把喜歡當作唯一標準答案。

一起學 07

換一個故事，畫自己的三條線

人物和地方換了，方法還能用。

原創新故事：阿田在美勞桌旁找不到膠水。小荷指出膠水就在材料盒裡。阿田找到後，把紙星星貼上卡片，完成了作品。

  1. 找誰：阿田、小荷。
  2. 找哪裡：美勞桌旁；材料盒是膠水的位置。
  3. 找事情：找不到膠水、得到位置提示、找到並完成作品。
  4. 用一句話說新主線，不再搬用月亮和活動室。

故事元素不是要填滿固定數目的格子。有的故事人物少，有的地方沒說；遇到沒有交代的項目，就留不知道。不要為了讓每一格都有字，把猜想填成事實。

卡片可用圖記或成人代寫，沒有拍照上傳需求。全用虛構故事，也能練習閱讀和重述。

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1故事裡主要一起排練的是誰？
給我一點提示

找參與活動的人，不是物品。

看答案與原因

參考答案：小露和阿成

小露與阿成準備並繼續排練；書架、月亮紙卡和布幕是物品。

2排練紙偶戲的場所是哪裡？
給我一點提示

問的是角色排練的地方。

看答案與原因

參考答案：活動室

故事在活動室排練，書架是紙卡原先放的位置，不是排練場所。

3月亮紙卡原先放在哪裡？
給我一點提示

找出發前小露的動作。

看答案與原因

參考答案：教室的書架上

開頭寫小露把紙卡放在教室書架上，這是後來取物的線索。

4誰親手拿回月亮紙卡？
給我一點提示

注意陪同和拿回是不同動作。

看答案與原因

參考答案：小露

老師陪到書架旁，而原文說小露拿回紙卡，兩種角色功能不同。

5小露回教室時，阿成在做什麼？
給我一點提示

讀兩人分頭行動的那段。

看答案與原因

參考答案：留在活動室整理布幕

阿成留在活動室整理布幕，沒有和小露一起返回教室。

6哪一句最能保留本故事主線？

要有問題、做法和結果。

參考答案：少了月亮紙卡，取回後繼續排練

「少了月亮紙卡，取回後繼續排練」連起主要問題與結果；名詞清單不足以說故事，正式演出也不在原文。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

定位與準備

依Ad-I-2、Ad-I-3及Ba-I-1的敘事方向，從找零散訊息進到連結角色行動、場所變化及主線。先確認紙偶戲、布幕、排練的意思，示範紙卡是道具。前測讓孩子把角色、場所、物品三種卡分開，但不把分類當成唯一課程成果。

兩次流程

  1. 第一次25分鐘：4分鐘詞義與卡片、6分鐘共讀故事、7分鐘誰做什麼、5分鐘追蹤場所、3分鐘兩句回述。
  2. 第二次25分鐘：5分鐘角色回顧、7分鐘問題做法結果、5分鐘摘要和細節、5分鐘新故事遷移、3分鐘自評。

關鍵誤解

把老師當取卡行動者，重讀老師陪、小露拿的兩個動作；以為阿成也回教室，對照留在活動室；把書架視為全篇場景，區分人物活動的場所與物品存放位置；把排練繼續說成演出完畢，核對最後一句。流程圖第三格是共同取物的摘要，親手拿取仍以原文為準。

差異化

起步組先一個人物的路線，成人逐句讀、孩子移卡；一般組比較小露和阿成分頭做的事，再說三步主線；進階組刪去不影響理解的細節並解釋一個取捨。聽覺支持可用全文與角色卡，口語困難可指卡排序或成人代筆。閱讀理解不等同背誦名字的速度。

評量與遷移

分記角色行動配對、場所轉換、問題結果連結及原文依據。摘要不必逐字重現，能保留主線並避免人物互換即可；喜歡某角色或細節的理由可多元，不納入單一正解。新故事改用膠水，檢查孩子是否仍沿用月亮舊答案。課後可共讀其他原創或合法書籍，但不要求透露家庭經歷或上傳兒童錄音。本次流程圖不是現實校園導引，不用它指示孩子離開教室取物。
