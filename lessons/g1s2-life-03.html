表達關心與感謝

把看見的好意，變成適合對方的表達

小菱想幫小禾拿作品，小禾卻說：「我想自己拿。」關心是不是沒有成功？今天練習讓好意真正合用，也說清楚曾經得到什麼幫助。

建議：3 次，每次約 30 分鐘；可依需要拆成短段孩子可由大人陪讀

出發前

準備好了嗎？

這一課，我會練習

  • 以具體事情說出感謝的原因。
  • 關心前先詢問需要，尊重拒絕與身體界線。
  • 用口述、圖畫或合宜行動傳達心意。
  • 發現幫忙不合用時能停止、澄清並修正。
陪學大人：準備材料
  • 虛構紙偶、成人畫的「要／不要／等一下」大圖卡
  • 安全紙筆、折半卡紙；不需買禮物或拍攝他人
  • 關心情境卡：找不到書、想安靜、共用材料不夠

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

關心先停一下，聽對方怎麼說

有好意，也要問一聲。

小菱看到小禾拿著一張大畫，想伸手接過去。她先問「需要我幫你拿，還是替你把門留開？」小禾選留門。關心不一定是替人完成，也可能讓對方保有自己做的機會。只看到拿東西，還不能知道他一定很累或不想拿。

  1. 成人用兩紙偶演拿畫情境，不真的搶孩子作品。
  2. 孩子替小菱選一個詢問句，成人用圖卡回答。
  3. 照對方選擇做一個安全的小行動，或尊重不需要。
  4. 再演一次對方說「等一下」，孩子練先停而非立刻做。
給陪學大人：帶領與觀察

不以猜中需求作評分，也不把同意一種幫忙擴大成任何接觸都可以。留門只是故事例，實做不安排兒童擋防火門或承受重門；桌面紙偶能完成同樣的理解。

一起學 02

感謝說得具體，對方才知道

說出那件事和帶來的幫助。

「謝謝你剛才幫我指圖，我找到該放書的位置」比只說「你好棒」更清楚。可以拆成兩小句：你做了什麼；這件事怎麼幫了我。若不確定對方是不是為自己做的，先說看見的行動，別替對方編理由，也不需把每句話說成長長的作文。

  1. 讀原創示例：「謝謝你等我說完，我能把問題講清楚。」
  2. 孩子指第一句感謝哪個行動、第二句說什麼幫助。
  3. 用紙偶「借我大圖卡」的故事換掉其中一部分。
  4. 成人代寫孩子的意思，讀回讓孩子確認，不擅加感受。
給陪學大人：帶領與觀察

避免要求孩子對任何照顧都必須感恩、欠人情或永遠聽話。對傷害、不舒服或不合理要求，孩子不必說謝謝；成人應先保護安全。謝意可以真實而短小，不要求眼神或特定表情。

一起學 03

同一份心意，可以有不同樣子

說、畫、指或做，都可以。

小禾不想在大家面前講話，他畫一張卡：左邊畫大圖卡，右邊畫找到的書格，請成人代讀「謝謝你借圖卡」。這張卡不需要昂貴材料或漂亮字。也有人用手勢、輔助溝通或私下說一句；收卡的人不必立刻抱抱、回禮或公開展示。

  1. 把紙對摺，外面畫一個自己選的簡單記號。
  2. 裡面畫一件真正發生或紙偶故事裡的幫助。
  3. 加一句原創短話，由孩子決定文字，可由成人代寫。
  4. 先確認對象與是否願意接收，再選私下給、口頭說或保留。
給陪學大人：帶領與觀察

本課成品可完全留給紙偶，不要求實際送人。若送給真人，尊重接收和公開範圍，不含姓名、電話、照片及私人情況。成人不以美工完成度評價關心，低視力者可改觸覺符號與口述。

一起學 04

拒絕幫忙，不等於拒絕這個人

聽到不要，就停下來。

小菱問「我幫你整理書包嗎？」小禾說「不用，我想自己整理」。小菱可以回答「好，需要時再說」，不用追問為什麼不領情。對方說謝謝，也不表示答應下次借所有物品或接受身體接觸。關係裡，給與收都能保留選擇。

  1. 成人示範「謝謝你的好意，我現在不需要」。
  2. 孩子用停手圖卡讓紙偶停止整理。
  3. 替關心者選一句接受拒絕的回應，不冷落或威脅。
  4. 交換角色，再練一次自己說「不需要」或「只幫這一步」。
給陪學大人：帶領與觀察

不要把拒絕說成沒禮貌、孤僻或不知感恩。不設計真的翻動私人物品以測試孩子反應。若孩子難以拒絕，成人提供簡短圖卡並立即尊重，讓界線在實作中有效。

一起學 05

好意不合用，就把方法改一點

先停，問清楚，再試。

小菱把小禾正在排的圖卡收起來，以為桌子清空就是幫忙。小禾說還沒用完。小菱停下，說「我沒先問，讓你找不到順序了」，再問「要我按你指的地方放回，還是你自己放？」修正要回應造成的影響，不是只說自己出發點很好。

  1. 用紙偶和大圖卡演誤收情境，不拿走真正在用的作品。
  2. 孩子先指出受到的影響：原本的順序被移動。
  3. 練「停下、承認這件事、詢問怎麼修正」三步。
  4. 依對方選擇恢復或交還，不要求對方立刻原諒。
給陪學大人：帶領與觀察

修復不能變成逼迫道歉、擁抱或原諒的表演。成人保護物品和界線，對反覆傷害應介入，不只要求受影響者教對方。重點是看行動是否改變，並接受對方需要時間。

一起學 06

聽到感謝，可以怎麼回應

不用回禮，也能接住心意。

紙偶說「謝謝你提醒我等一輪」，小菱可以說「收到」「不客氣」，也能用點頭或圖卡表示。她不必回答「你以後都要讓我先」。感謝不是交易，幫過忙不會取得別人的秘密或身體決定權；收到好意的人也能說謝謝但拒絕附加要求。

  1. 成人讀一段感謝，孩子選舒服的回應方式。
  2. 比較「不客氣」與「以後都要聽我的」造成的不同。
  3. 演「謝謝借我卡，但我不想被抱」的界線句。
  4. 由孩子決定是否練真人對話，或繼續用紙偶完成。
給陪學大人：帶領與觀察

不評價笑容、語調或回應速度是否夠真誠。非口語或需較長處理時間的孩子可預留停頓。將感謝和服從分開，避免把禮貌教育變成接受不舒服接觸的訓練。

一起學 07

選一次小關心，再看有沒有合用

關心要有回應，也能調整。

閱讀角的紙偶找不到一本書。小菱先問，再依同意指一下分類標記；小禾說「這樣我知道去哪裡找」。這個回應告訴她方法有用。若對方仍找不到，可以請成人協助，不必保證自己解決全部。下次可把先詢問的方法用到另一個共同活動。

  1. 選找書、共用紙不足、想安靜三個情境之一。
  2. 先問角色需要，再做一項安全可行的行動。
  3. 讓接收者選「有幫助、還需要、先停止」其中一張。
  4. 回顧一個合用方法和一個要改處；可只私下留下圖記。
給陪學大人：帶領與觀察

不要求一天幫助固定人數或追蹤他人是否回謝。關心不是監看同學，不記錄私事。若情境超過兒童能力，求助可信任成人就是合宜的終點，成人仍負責安全和必要資源。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／9 題。做錯也能再試。

1小菱想替小禾拿作品，先怎麼做？
給我一點提示

好意和同意是兩件事。

看答案與原因

參考答案：問他想要哪種幫助，再等回答

先詢問讓對方保有選擇，不能由外觀直接推論能力或需要。

2哪句感謝最具體？
給我一點提示

哪句說出事情和影響？

看答案與原因

參考答案：謝謝你等我說完，我能把問題講清楚

這句指出等待的行動及它帶來的幫助，較能讓人理解謝意。

3孩子不想公開說感謝，還能怎麼表達？
給我一點提示

表達方式是否只有一種？

看答案與原因

參考答案：用圖卡、私下說或保留給紙偶

心意可用不同方式傳達，公開表現和花費都不是必要條件。

4對方說「不用，我想自己整理」，關心者應怎麼回？
給我一點提示

有沒有真的尊重他的選擇？

看答案與原因

參考答案：好，需要時再說

接受拒絕並停止干預，才讓關心符合對方需要。

5誤收別人還在用的卡片後，第一步怎麼做？
給我一點提示

先避免影響變大。

看答案與原因

參考答案：停下來，確認影響並問怎麼修正

先停並了解影響，才可依對方需要恢復，不用好意替行為辯解。

6有人感謝你提醒輪流，哪個回應合適？
給我一點提示

感謝是不是換取控制的交易？

看答案與原因

參考答案：不客氣，或用自己舒服的方式回應

收到謝意可簡短回應，不因此取得別人的物品、秘密或決定權。

7「謝謝借我卡，但我不想被抱」表示什麼？
給我一點提示

兩個選擇能不能同時成立？

看答案與原因

參考答案：可以感謝一件事，也拒絕身體接觸

對借卡的謝意與身體界線不同，兩者都應被尊重。

8幫忙指分類標記後，對方仍找不到書，怎麼辦？
給我一點提示

關心能不能包括尋求更多支持？

看答案與原因

參考答案：問是否需要成人協助，不必一人解決全部

方法未合用可調整或求助，不把未解決誤當對方不感謝。

9把感謝卡給真人之前，要確認什麼？
給我一點提示

收卡與公開展示是同一份同意嗎？

看答案與原因

參考答案：對方是否願意接收，以及可分享的範圍

接收與分享都要尊重界線，不擴大成公開個資或索取回報。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

定位與課前準備

本課依生活課程第一學習階段的關心表達、具體回饋與尊重界線設計，為跨版本原創參考，不是全國固定的學期單元。準備紙偶和同意選項，先讓孩子知道可以說不要、暫不分享或使用替代表達。所有故事不必對應家庭真人；不要求買禮物、公開致謝或親吻擁抱。

第 1 次：30分鐘陪學

0–10分看拿作品故事，分開可見行動與猜測；10–20分練詢問與等回答；20–27分拆解感謝的事情和影響；27–30分孩子指出一個具體行動。

第 2 次：30分鐘陪學

0–12分製作一張原創圖卡，可由成人代寫；12–20分演接受拒絕；20–27分討論給卡前要確認的接收範圍；27–30分孩子決定保留或只給紙偶。

第 3 次：30分鐘陪學

0–10分演誤收後修正；10–18分練接收謝意且不附加條件；18–27分選新情境完成一次詢問、行動、回看；27–30分指出對方的選擇是否被尊重。

差異化與參與方式

語句負荷高者只用「要幫忙嗎」「不用」「好」三卡；已有能力者試分出「謝謝這一步」與「不同意下一步」。觸覺或高對比圖替代細緻繪畫，不要求照範本。成人先讀短句，孩子可指卡、口述、用熟悉語言或既有輔助溝通回答；需要動作協助時由孩子決定、大人代做。一次呈現一個問題，不用閱讀速度或動作整齊程度代替理解評量。

常見迷思與修正

好意不會自動變成同意；拒絕一次幫忙不代表否定關係。感謝不等於欠回報，修正需要實際改行動，不只強調自己的好意。

實作評量與回饋

觀察能否描述具體事件、提出可選的關心、等待回應、依拒絕停止、發現不合用後修正。回饋以「你照他的選擇停下來」為例，不以受歡迎或感恩程度打分。記錄「獨立完成、提示後完成、共同完成」及一個具體行動。選擇題只能補充判斷，不取代實作；答錯時回到情境找線索，再提供重試，不排名。

延伸與隱私

用一個日常小情境練「先問再做」，可以不製作卡片、不送真人。若孩子提到不舒服的要求，私下支持並處理安全，不要求感謝造成傷害的人。不要求購物、家庭照片、姓名住址或上傳作品。可只用虛構角色完成；孩子能選擇展示多少，也能只私下與陪學成人回顧。
