這一課，我會練習

  • 知道臺灣手語是自然語言，指圖不等於已學會手語。
  • 能找出一個遮擋視覺訊息的環境因素並改善。

  • 能輪流、核對理解並請求重示。

陪學大人：準備材料
  • 圖畫紙與彩色筆
  • 可移動的紙偶、三張空白情境卡
  • 兩張椅子或桌面座位圖

一起學 01

先認識：臺灣手語和聾人文化

用眼睛接收語言，也能一起聊天、學習和說故事。

今天是臺灣手語路線的文化與溝通課。臺灣手語是有自己表達方式的自然語言，不能把它當作一串猜動作遊戲，也不能用華語逐字配手勢來代替。這課練習讓彼此看得到、收得到訊息；本課不教實際手語詞句；詞句學習須另備經核實的完整模型及合適教學支持。

「聾人文化」包含聾人社群在語言、互動和生活中形成的經驗。學習它，可以從尊重臺灣手語、看清楚再回應、讓本人選溝通方式開始。不能看一個人使用助聽設備，就猜他會不會手語；也不能替他決定自己的稱呼或認同。

先分清三件事

  • 臺灣手語：一種語言，要向可靠模型學習。
  • 指圖或畫圖：能幫忙溝通，但一張圖不等於完整手語。
  • 我的選擇：可以告訴別人哪種方式讓自己舒服、容易理解。

成人讀三張卡：「用手語分享故事」「把杯子畫在紙上」「表示想休息」。孩子可以指認它是在談語言、輔助方法，還是個人選擇。三件事都重要，不必互相比高低。

一起學 02

原創故事：被書包擋住的朋友

先找出哪裡看不清，再想一個改法。

小禾和阿青準備一起拼圖。小禾把大書包放在兩人中間，又低頭邊找拼圖片邊分享下一步。阿青沒有接收到訊息，還在等待。小禾說：「你怎麼都不做？」老師沒有責怪任何一人，而是請兩人先看看桌面。

  1. 用兩個紙偶和一個紙盒重現故事。你坐到阿青的位置，看看紙盒擋住了什麼。
  2. 把紙盒移到旁邊，再把紙偶轉向彼此；不用推、拉真人。
  3. 先停下手邊工作，確認伙伴準備好，再展示一張「找角落」圖卡。
  4. 阿青指回圖卡，表示已收到；兩人再各找一片拼圖。

想一想：前一次沒有開始，能不能直接說阿青不合作？不能。先確認訊息有沒有到達。這是一個溝通環境的問題，不是誰比較笨，也不是要阿青猜小禾的心事。

故事檢查

關鍵改動有三個：移開遮擋、暫停找物、等對方接收。只把聲音加大，沒有處理視線被擋的問題。畫圖是本活動的共用提示，沒有把圖卡冒稱為臺灣手語。

一起學 03

引起注意：先約定，再開始

我可以等一下，也可以選不要被碰。

先和同伴約定喜歡的提醒方式。例如，在對方能看見的地方輕輕揮一下手，等對方回應；或用已經約好的桌面提示卡。揮手在本活動中只是取得注意的生活方法，不是新教一個手語詞。

  1. 各自從「視線內小幅揮手」「把提示卡放在約定位置」「請老師協助」選一種。
  2. 接收者看著紙上圖案；發訊者依約定提醒一次，保留舒服距離。
  3. 收到者用雙方已會的方式表示準備好了，再開始傳圖卡。
  4. 若沒有回應，先停下。可能對方忙著、沒看見或想休息，請大人協助，不連續逼近。

有些熟識的人會事先同意輕觸肩膀等提醒，但不能因為學到這個例子，就認為任何時候都可以碰別人。本課不要求觸碰；說不、退開或沒有同意，就不碰。不要抓手、拍頭、拉身體、朝臉揮動物品，也不要自行閃燈或製造巨大聲響。

小任務

用紙偶演兩次：第一次伙伴表示「等一下」，你停下；第二次伙伴準備好了，你才傳訊息。學會等待，也是有禮貌的交流。

一起學 04

看得到的座位與光線

幫三個紙偶找到都看得清的位置。

桌上放三個紙偶。先排成一列，讓最後一個只能看到前人的背面。再排成小半圓，各紙偶朝向分享者。問：「哪個安排比較容易同時看見分享者的臉和手？」用你觀察到的遮擋來回答，不必說半圓永遠最好。

接著把一張大紙當成高高的裝飾，放在分享者前面。你能移開它嗎？再請成人用普通室內光線比較：站在明亮窗戶前的人，臉有時比較難看清。可以改坐向、拉合適窗簾或移位；不要直視太陽、拿手電筒照眼睛或把教室突然弄暗。

  1. 選一位分享者，另外兩位試坐或移動紙偶。
  2. 逐一問接收者看得清不清，不替他回答。
  3. 只改一件事，例如移開書包，檢查是否改善。
  4. 換分享者，重新檢查；原來看得清不代表換位置後仍然看得清。

好的安排也要顧到輪椅、視力、動作和感官需求。需要更靠近或休息時可以提出；不強迫一直盯著眼睛，只確認對方能以合適方式接收完整訊息。

一起學 05

輪流、澄清和溝通修補

沒收到時，我可以請你再來一次。

準備三張很清楚的圖：圓形、房子、樹。發訊者選一張，等接收者準備好才展示兩秒。接收者從自己的圖卡中選相同圖，放到桌上，兩人核對。這是視覺訊息傳遞練習，不是手語詞彙測驗。

第二輪，發訊者故意太早收起卡片。接收者不用假裝懂，可用既有溝通方式、指向「再一次」提示卡或請成人代達。發訊者再完整呈現，給足時間。不要把「再一次」中文字旁自行畫成手形；若要用臺灣手語表達，另用合格教師的核實模型。

  1. 一次一人分享，不同時搶著比或說。
  2. 接收者先確認內容，再換角色。
  3. 猜錯時，先檢查時間、遮擋、距離，再重示。
  4. 兩人各完成兩次成功的修補，就換圖卡。
為什麼要核對？

對方點頭有時只是表示正在看，不一定已了解每個細節。讓對方選圖或以自己的方式回應，能檢查訊息是否一致。沒理解不是丟臉，也不表示對方不專心。

一起學 06

聾人生活：直接和本人互動

先認識這個人，再問他需要什麼。

想像班上要辦圖畫分享。阿青喜歡畫機器人，安安喜歡畫海邊。他們都可能使用臺灣手語，興趣卻不必一樣。共同語言能讓人交流，但不會使每個人的喜好、家庭和生活變成同一個樣子。

臺灣手語課綱把聾人社群的生活、習慣、活動及互動禮節列入學習。這提醒我們：學語言也學習尊重使用者的生活。參與故事、遊戲和創作時，先問對方想怎麼參加，不把對方當成給全班觀察的對象。

兩個情境，請選回應

情境一：旁邊有大人協助翻譯。你想問阿青喜歡哪幅圖。先朝向阿青，把問題給本人，留時間讓他回應；不用越過他只問陪同者。

情境二：有人想拍下阿青使用手語。先停止拍攝，請成人說明同意和隱私；參加活動不代表同意被拍。本課不用錄影就可以完成。

不要求同學解釋聽力、醫療或家庭經驗。不會手語的人也可以學，不把臺灣手語限制為某一種身分才准使用；需要更完整對談時找合適的語言與溝通支持。

一起學 07

把教室改好：我的一項行動

畫出一個讓伙伴更容易收到訊息的方法。

在紙上畫一張活動桌，至少放兩個紙偶和一件用品。選一個可以改善的地方：移走遮擋、換座位、輪流分享、先提醒再展示、讓訊息多停一下。圈出你要改的那一處，再畫改好的版本。

  1. 同伴先看改前圖，指出哪個人可能收不到訊息。
  2. 你用口語、已會的臺灣手語、指圖或輔助溝通介紹改法。
  3. 同伴從自己的位置試看，告訴你是否真的有幫助。
  4. 若仍看不清，合作修改，不以「我已經很努力了」要求同伴接受。

最後完成一句意思：「下次一起看圖時，我先＿＿，再＿＿。」例如先確認伙伴準備好，再展示圖卡。這句中文是回顧提示；不要求照中文順序拼手語，也不計中文字數。

我做到了嗎？

我能指出一個遮擋；能用約定方法取得注意並等待；能在沒收到訊息時要求重示；能讓本人選擇自己的溝通方式。做得到其中一件，就指出具體例子；還不會的選一項下次重試。這項自評不是臺灣手語詞句熟練度的分數。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

定位與課前準備

本課是臺灣手語路線的視覺溝通與文化入門，不是口語課的發音練習，也不以指圖活動代替臺灣手語教學。適用已有或將有正式臺灣手語詞彙課的初學者。其他語別班級可作多元文化補充，但不增加必修語別。先讀臺灣手語課綱第一學習階段的文化、互動禮節方向，以及國家圖書館指引印刷頁79–80。指引談一般服務，本課把其中確認溝通方式、保持視線與重述的原則轉化為原創兒童活動，並加入明確身體同意界線。

第1節：從看不到到收得到

5分鐘辨識語言、指圖與個人選擇；8分鐘紙偶故事，請孩子找出遮擋而非責怪人物；10分鐘各選注意提示，演練等待與停止；10分鐘三人座位及光線檢查；5分鐘每人用自己可用的方式指出一項有效改善。成人的示範先用紙偶，不把任何聾生當現場教材，也不做戴耳塞或禁止說話的模擬聾人活動。

第2節：修補與參與

5分鐘回顧兩項約定；10分鐘三圖傳訊，實際核對收到內容；8分鐘討論插話、只和翻譯者說話及未經同意拍攝的情境；12分鐘完成改前改後座位圖並讓同伴試用；5分鐘離堂評量。孩子需要休息可縮短回合，重點是有效的來回，不是維持固定姿勢多久。

常見誤解與回饋

  • 以為沒聽見就是沒理解：先提供可近用訊息，分開接收障礙和理解表現。
  • 以為看手勢就懂所有手語：說明生活手勢、圖卡與臺灣手語不同，不猜譯，不自創教學手形。
  • 把表情當搞笑：若在正式手語課，臉部等非手部訊號可能具有語言功能，須依完整模型理解。
  • 把拍肩當通行證：先用不接觸方式，本課沒有碰觸要求；任何不同意均停止。
  • 把聾人想成同一種人：回到人物不同興趣、語言與偏好，不由輔具或外表推測能力。

差異化及評量

起步者只用兩張差異大的圖，高對比、較大尺寸及固定位置；可由成人協助移動紙偶，不以精細動作作門檻。視覺、動作或感官需求者，依既有支持和專業建議調整呈現，不強制眼神接觸。熟練者在三人輪替時主動檢查每人接收狀態，並說明兩種改法哪種更適合當下情境。

觀察表分「取得注意前先約定、訊息可見、輪流與修補、尊重本人選擇」四欄。每欄記獨立／提示後／需再練，旁記一個看得到的行為。不得以聽力、發聲、是否使用助聽器或是否敢上台評文化理解。課後只在熟悉伙伴間試一項環境改善，不要求拍攝、蒐集障礙資料或接觸陌生人。
