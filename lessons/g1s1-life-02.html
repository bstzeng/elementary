書包、學用品與整理

讓每樣用品有家，明天找得到

阿圓每次找橡皮擦，都把整個書包倒出來。今天我們不比誰收得快，來替用品安排容易找到的家。

建議：3 次，每次 30 分鐘；可依需要分段孩子可由大人陪讀

出發前

準備好了嗎？

這一課，我會練習

  • 依當天清單選擇需要的用品。
  • 按照使用方式安排位置，能說明一個理由。
  • 練習取出、用完歸位和再次核對。
  • 發現損壞或找不到用品時，能先停下並求助。
陪學大人：準備材料
  • 現有書包或布袋、鉛筆盒、兩本書、水壺
  • 兩張無個資的虛構用品清單、紙卡、筆
  • 三個安全托盤或畫出的三個區域；不需購買收納盒

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

書包不是越滿越好

先看今天需要什麼。

阿圓把三本故事書、玩具車和水壺全部塞進書包，卻忘了今天要用的圖畫本。書包裝得滿，不表示準備好了。今天的練習通知只有「圖畫本、鉛筆盒、水壺」。我們用通知決定帶什麼，不用猜別人帶了什麼。用品找不到時可以一起找，不能拿同學的代替。

  1. 大人念練習通知，孩子先指三種需要的用品。
  2. 一樣一樣移到「今天要帶」區；玩具車先留在原處。
  3. 對照清單重看，說「三樣都有」或「還缺一樣」。
  4. 換成兩樣的新通知，重新選一次。
給陪學大人：帶領與觀察

練習通知不可冒充本校規定，實作前換成學校當日要求。第一次只放四件候選物，熟悉後再增加一件。孩子指對而拿取困難時，允許成人代拿；觀察的是選擇與核對，不是動作快慢。

一起學 02

先分三區，再做決定

要帶、放回、請大人幫忙。

整理前先騰出安全桌面。阿圓拿出昨天的練習紙、鉛筆盒和一枝筆尖裂開的鉛筆。練習紙可能還要交，不能看起來舊就丟掉；筆尖裂開也不用自己折。先分區可以讓我們看清楚問題，不必一次把所有東西處理完。

  1. 畫三區：「今天要帶」「先放回原處」「請大人確認」。
  2. 依清單把鉛筆盒放進第一區。
  3. 不確定是否要交的練習紙放第三區，問「這張還要用嗎？」
  4. 損壞用品只做辨認，交成人檢查；不徒手摸尖端。
給陪學大人：帶領與觀察

使用完整安全道具代表破損用品，不放真尖銳碎片供操作。紙張是否丟棄、物品是否修理由成人確認，不把私人文件當廢紙。需要分類支持時，用圖和實物對照；進階可說明為何同一張紙在不同通知下會換區。

一起學 03

替用品找一個固定的家

常用的，要容易拿。

鉛筆與橡皮擦住在鉛筆盒，書本整齊靠在一起，水壺依書包設計放在合適位置。固定位置像找人的約定：用完回同一處，下次少找一點。沒有側袋也沒關係，可以和大人找穩妥位置；不能讓水壺擠壓漏水，或讓用品掉出袋口。

  1. 把兩本書疊齊或直立放好，試著只拿出其中一本。
  2. 把常用筆與橡皮擦放進鉛筆盒，闔起後再打開。
  3. 成人確認水壺蓋和放置方式；孩子指出水壺的位置。
  4. 用紙畫三個用品位置，當作自己的收納提示。
給陪學大人：帶領與觀察

不用要求所有孩子採相同配置，也不設定固定重量比例。成人檢查書包是否合身、可承受且容易使用；負重不適應減少非必要物並向校方詢問。支持單手操作或觸覺辨識時，可用大拉環、不同觸感標記等既有工具。

一起學 04

用一樣，回一樣

不用的先放回去。

小晴寫完字，把筆留在書頁中，又拿出水壺。書合起來時筆滾到桌下。她換了一個方法：先把筆放回鉛筆盒，再做下一件事。歸位不是讓桌子永遠不能用，而是讓下一次使用有地方開始。現在桌面只留下這一步需要的東西。

  1. 拿出筆和紙，畫一個圓。
  2. 指著筆的家，把筆放回鉛筆盒。
  3. 拿出書翻一頁，再合上放回原位。
  4. 請大人問「現在想畫線，要到哪裡找筆？」孩子指或拿出。
給陪學大人：帶領與觀察

不在真實上課中要求每次換動作都機械收完，應依活動需要調整。孩子找不到時先等待，再問「上次用完放哪裡？」避免直接代收。若桌面空間不足，讓孩子先選一個可用區，不把環境限制當成不整齊。

一起學 05

拉鍊卡住，停下來看

發現不順，就不要硬拉。

阿圓想把凸出的衣角拉進袋子，拉鍊卻卡住了。用力拉可能弄壞物品，也可能夾到手。他先停，再把袋子放穩，請大人一起看。愛惜物品也包括知道什麼可以自己做、什麼需要幫忙；不是弄壞後都不能說。

  1. 用完好的袋子假裝拉鍊卡住，不真的把布塞進去。
  2. 演出「停手、放穩、說問題」三步。
  3. 說：「拉鍊拉不動，請幫我看看。」
  4. 成人排除問題後，孩子慢慢開合一次，手指避開拉鍊路徑。
給陪學大人：帶領與觀察

不安排拆卸、修筆尖、清除尖銳異物或接觸電池。若孩子說「怕被罵所以藏起來」，先接住求助，再處理物品，不以懲罰讓他避報。進階提問可比較「忘記歸位」與「用品已損壞」，兩者需要的解法不同。

一起學 06

換一個活動，位置還有用嗎？

試拿一次，才知道好不好找。

這次通知改成「閱讀活動，帶一本書和鉛筆盒」。阿圓不用把書包裡每樣東西都重新洗一遍或換新；先看新通知，再拿掉不需要的，保留需要的。整理方法可以改：如果常用橡皮擦總被壓住，就換到更容易拿的格子，再試一次。

  1. 大人給新的閱讀清單，孩子重新選用品。
  2. 把用品放好，關袋後再找指定的一樣。
  3. 指出哪個位置好找、哪個位置不好找。
  4. 只改一個位置再試，說明改前與改後的差別。
給陪學大人：帶領與觀察

用「找得到、拿得出、放得回」作為功能性標準，不以成人審美或同款收納用品打分。可讓孩子做口頭設計師，由成人依指示操作。進階者可用相同用品試兩種安排，說明自己選擇，不必比較時間。

一起學 07

我的離桌小檢查

看桌面、看清單、看袋口。

整理結束，阿圓不是立刻跑走。他看一眼桌面，有沒有留下自己的用品；再看清單，有沒有少帶；最後確認袋口能安全關好。這三看能幫我們發現剛剛漏掉的小事。今天只練其中一看也可以，明天再加另一看。

  1. 請大人故意把練習用橡皮擦留在桌上，先說明是演練。
  2. 孩子照三看檢查，找到後放回。
  3. 選一句帶回家用的提醒，例如「筆回盒」。
  4. 下次用完一樣用品後再試，說「我已做到」或「還需要提示」。
給陪學大人：帶領與觀察

不偷偷藏孩子的真物品來測試責任感。形成性紀錄包括是否依清單選擇、能否描述位置、發現遺漏後是否修正。家庭練一個固定時段即可；大人可共同完成，不把獨立收好全部物品當作一年級入門門檻。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1清單只寫圖畫本、鉛筆盒、水壺。玩具車應怎麼辦？
給我一點提示

先和今天的清單比一比。

看答案與原因

參考答案：先留原處，有需要再問

依今天通知選用品，沒有列入的物品先確認，不是書包越滿越好。

2一張練習紙不確定還要不要交，先放哪一區？
給我一點提示

還不清楚的事，可以先問。

看答案與原因

參考答案：請大人確認

不確定用途的紙張先保留並問清楚，不能因為看起來舊就丟掉。

3哪種位置比較有用？
給我一點提示

想一想下次要怎麼找到它。

看答案與原因

參考答案：橡皮擦有固定位置，拿得到

固定且可及的位置讓下次容易尋找，也方便用完後歸位。

4畫完圖後要去閱讀，可以先做什麼？
給我一點提示

筆有自己的家。

看答案與原因

參考答案：把暫時不用的筆放回盒

用完暫時不需要的用品先歸位，可減少滾落與遺失，也騰出閱讀空間。

5拉鍊拉不動，最適合的下一步是？
給我一點提示

不順的時候，要不要更用力？

看答案與原因

參考答案：停手放穩，請大人查看

卡住時硬拉可能損壞或夾手；先停下再求助比較安全。

6阿圓把橡皮擦換到容易拿的格子，下一步是？
給我一點提示

用一次能發現什麼？

看答案與原因

參考答案：試拿與放回，看看是否好用

整理方法需實際使用才能知道是否適合自己，不必讓每個人的配置一樣。

7離桌前看見自己的筆還在桌上，怎麼做？
給我一點提示

這枝筆原本住在哪裡？

看答案與原因

參考答案：核對並放回筆盒

回頭檢查是為了找到遺漏，發現後歸位就是有效的修正。

8手部動作比較慢的孩子能怎麼練整理？
給我一點提示

整理包含想一想和做決定。

參考答案：自己選位置，請大人協助取放

孩子能做選擇、指示位置和核對，成人協助動作也能練到整理方法。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

課前確認與課程定位

本課以生活課程第一學習階段的自我照顧、物品整理與問題解決為方向。主題與活動是跨版本原創示例，不是全國統一學期進度。成人先準備不含姓名的練習清單，核對用品無尖端破損、袋扣安全，並確認本班實際攜帶要求。

第 1 次：觀察與示範（30 分鐘）

0–5 分讀阿圓故事；5–15 分示範清單配物，再讓孩子做兩次不同清單；15–25 分分三區並說明不確定物品的去向；25–30 分出口任務為找到缺少的一項，記錄提示方式。

第 2 次：操作與修正（30 分鐘）

0–8 分孩子決定三樣物品的位置；8–18 分進行取用與歸位循環；18–25 分以安全道具演拉鍊卡住，練停手求助；25–30 分請孩子解釋自己的固定位置，不要求和示範一樣。

第 3 次：轉用與回顧（30 分鐘）

0–10 分換閱讀清單；10–20 分試兩種放置方法，每次只改一個位置；20–27 分做離桌三看與情境題；27–30 分選一個明日提醒。孩子可坐著指示成人取放，仍能呈現完整思考。

差異化支持

尚未識字者由成人讀題，孩子可指物、選圖或操作；不以讀字速度評量生活理解。需要記憶支持時，一次只出示一張步驟卡，完成後再提供下一張。視覺、聽覺、動作或口語表達需要調整時，使用孩子既有的放大圖、觸覺標記、手勢或輔助溝通；孩子可做決定，由大人協助執行。已能獨立完成者改變一項條件，請他說明理由，不增加競速或代管其他孩子安全的責任。

迷思與回饋

若認為「帶越多越安全」，拿清單逐項配對，問多出的用品是否需要；若認為整理就是丟掉東西，把待確認紙張放回第三區；若認為收一次就不會亂，示範使用後歸位是可重複的小動作。回饋具體指出「你發現水壺沒放，再核對一次」。

形成性評量與下一步

觀察四項：能依不同清單選擇；能說明一個收納理由；用完歸位；發現卡住或破損時停下求助。每項記錄「獨立完成、提示後完成、共同完成」並保留一個具體行為例子；選擇題僅協助查概念，不能取代操作。孩子答錯時，先問他依據什麼，再回到道具重試，不公布排行榜。

家庭延伸與隱私

延伸只選筆盒或一個書包口袋，親子共同整理三分鐘，不檢查全家房間。家庭可用最熟悉的語言陪學，沒有材料時使用圖畫或口述即可。不要求購物、拍攝家庭空間、上傳照片、填寫住址或公開身體及家庭經驗。
