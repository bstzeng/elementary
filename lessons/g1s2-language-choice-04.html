  • 理解本路線已核實請求、邀請或問答功能。
  • 用相關回應或圖卡表示意願。
  • 等待、確認並在不清楚時重示。

陪學大人：準備材料
  • 三回應圖卡
  • 紙偶、故事桌及點心圖片
  • 空杯圖與紙上路線

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

提出需要之後，要等真正的回答

問是把選擇交給對方，不是叫對方一定答應。

原創紙偶任務有三站：邀請一起看書、請求暫停、詢問要不要一張點心圖。每次只處理一個需要。問完要等待伙伴表示同意、拒絕或還沒清楚，再確認下一步；不能一邊問一邊把卡塞給對方。

本課只選正在學的語別。有的路線提供完整官方問答，有的只有核實詞或邀請句，欠缺的完整請求須由教師先確認。本頁會說清楚，不能以華語支架活動假稱學會全部目標語對話。

教師協助模型條件：文字與意思或官方索引已核，不代表所有聲音／影片已完整聽看驗收。口語由具該語能力教師確認完整原音與自然示範；臺灣手語須確認完整起迄、臉和雙手及正確形式。沒有可用完整模型，先做情境理解，語言產出欄待補，不用諧音、合成音或單詞剪接替代。

共同回應卡

「願意」「先不要」「請再一次」。這些是活動支架，不是假造各語句子或手語。孩子也可用既有溝通方式回應。拒絕不需交代私人理由，改變心意也可以。

只用紙圖，不試吃、不真的打電話、不離開成人監督範圍。真實的如廁、飲水、休息或求助需求先被接收，不以背對句子作為取得協助的條件。

一起學 02

路線A：臺灣台語，邀請去故事桌

先建立去哪裡，問句才有共同意思。

模型取教育部辭典欲詞目完整用例你欲去無？ Lí beh khì--bô?，中文意思「你要去嗎？」。採該用例讀音beh，不混入別腔欲的形式。這句本身沒有說目的地，所以本課先指明紙上故事桌，再詢問；沒有共同情境就不能要求伙伴猜去哪裡。

  1. 教師展示「故事桌」圖，說明只是移動紙偶。
  2. 完整示範問句，孩子指出這是在詢問意願，不是命令。
  3. 接收者選願意、先不要或請再一次卡，不新增未核實台語答句。
  4. 提問者指回卡確認；願意才把紙偶移到故事桌，先不要就留在原位。
  5. 換成已事先說明的畫圖桌，保留同一原問句，換人提出。

進階在看情境主動提問、等待並尊重回應，不在把句尾說得更大聲。若伙伴沒有回答，先問是否接清楚，不把沉默當同意。完整口語回答由教師另備核實模型；圖卡回應如實記為支持性互動。

一起學 03

路線B：四縣腔客語，提出如廁需要

這是紙偶語言情境，真需要時先得到協助。

教育部校園篇四縣腔印刷11完整例句𠊎做得去便所無？，標音ngaiˇ zo dedˋ hi pien soˋ moˇ，意思我可以去上廁所嗎。印刷13教師回應「做得。」zo dedˋ，意思可以。從兩個指定位置取完整已核模型，不擅加身體症狀細節。

  1. 給紙偶「需要如廁」情境卡，不要求孩子分享自己情況。
  2. 聽完整請求，接收者指出需要的是如廁協助，不是借書。
  3. 教師示範做得回應，再用安全紙上路線安排由成人協助。
  4. 孩子交換角色，一人傳請求，一人給已核回應；不實際離開教室。
  5. 最後說明：若真的急需，可以用任何已會方式立即求助。

配套音檔由成人在四縣腔音檔頁預先定位並確認。課堂不要安排另一孩子扮大人拒絕基本需要，也不以這個語言例句建立強制憋忍規則。會說請求與知道安全求助方式分開觀察。

一起學 04

路線C：馬祖閩東語，詢問後讓對方選

已有水果詞可回應，請求完整句仍需教師提供。

本路線已核實的食物模型來自第1冊第8課：下冊印刷28–29之芭蕉果（香蕉）、黃梨（鳳梨，官方中文對照）。本站此次未核實一組完整需求問答；以下完整提問語句必須先由具馬祖語能力教師提供及核對，不在頁面印猜出的句子。

情境改為用品站發水果圖卡，不是真的發食物。教師課前選定一個適合的完整需求問句並示範，記錄來源或本人核對；孩子可用已核實水果詞加圖卡選擇來回應。想說「先不要」也先由教師核對，沒有模型時用共同拒選卡。

  1. 先認香蕉和鳳梨兩圖及課內完整詞模型。
  2. 教師以確認過的問句詢問，孩子選一圖或先不要。
  3. 選圖者嘗試完整水果詞，接收者指回核對。
  4. 拿錯圖時，孩子再次選擇並完整重示詞；發卡者換回正確圖。
  5. 交換提出需要者，不要求人人都選水果。

只有水果原音可用、而提問尚未核實時，明記「詞義回應已練，完整馬祖語提問待補」。可用孩子已有方式練習等待和確認，但不把這部分記成已完成馬祖語問句教學。

一起學 05

路線D：秀姑巒阿美語，餅乾問答有完整來源

聽懂一問一答，再讓角色自己選。

生活會話第6主題第2季官方資料第21–22句為Mangalay kiso to piyang haw?／Hay, maolah kako.，中文對應「你要吃餅乾嗎？」／「好，我很喜歡。」這是同頁相鄰問答，不是作者把獨立詞拼成句；d=2限定秀姑巒阿美語。

  1. 紙偶伙伴拿餅乾圖片，先建立這是在詢問，尚未把圖交出去。
  2. 教師完整播放／示範問句，孩子指提問者；再示範回答，指回應者。
  3. 孩子可選願意的教材角色，用完整回答；若選不願意，用共同拒選卡，別被迫說喜歡。
  4. 提問者等待並核對回應，再移動紙圖。
  5. 換人演同一問答，圖的位置改變，但語句保持原模型。

本課不教飲食理由或疾病，不真的吃餅乾。不能把piyang換成任意食物就宣布新句驗證完成。對方答先不要時，即使沒用阿美語完整拒絕句，也應尊重；教師可另備合適拒絕模型，再分開增加語言目標。

一起學 06

路線E：臺灣手語，要、不要與要不要

功能不同，臉和動作都要跟完整模型。

官方28 A不A句型頁逐項列出要不要、要、不要。本課採這三個精確模型，未由本站驗收完整影片與形式；教師必須先確認它們在本情境的完整使用，不以標題推斷手形或提問表情。

先把一本空白故事小冊放在雙方能看清的位置，確認現在談的是這個物品。教師示範核實模型提出要不要，接收者在要／不要兩種功能中選一個。若需要完整自然問句超過此模型，由合格教師另示，不自行加「你＋書」詞片。

  1. 先完整看三模型並配詢問、接受、拒絕功能圖。
  2. 確認伙伴準備好，一次傳一個完整訊息。
  3. 等待接收者作選擇；可先用圖卡回應，再跟核實模型練。
  4. 表達者核對後才交書卡，不把拒絕當答錯。

模型觀察包括完整起迄、雙手、臉與教師指出的非手部訊號。不能僅靠字幕就記獨立視覺理解，也不強制眼神接觸或搬動孩子的手。

一起學 07

路線F：越南語，邀請喝水與確認意願

邀請句不是疑問句，還要留下選擇。

國教署越南語第6冊印刷10／PDF12的加一加練習明列完整Mời uống nước.＝請喝水。本課把它作邀請語，不能誤稱這是「你要不要水？」的越南語問句。後者尚未在本頁核實，若要教，先由越南語教師提供完整模型。

用空杯圖，不拿真正飲料。先用孩子能接收的方式詢問角色需要什麼；教師示範已核實的請喝水邀請，角色可用願意／先不要卡回應。邀請與回應構成支持性來回，但不記成已學會未核實越南語問答全句。

  1. 聽完整邀請，指出水杯圖，與無關的書卡比較。
  2. 跟完整模型，確認是請對方喝水，不是命令必須喝。
  3. 接收者選自己的回應，提出者等待後確認。
  4. 換一種杯子圖再次邀請，保持同一原完整句。
  5. 若要新增感謝、拒絕或詢問，教師先逐句核對，不把零散單詞接成長句。

教材屬跨冊少量引用，稱謂和地域發音由教師依原模型說明。本課不要求沖泡、喝水量或健康資料；真正需要飲水或幫助時，先處理需要，不讓語言成為門檻。

一起學 08

獨立任務：需要、回應、確認三步

有拒絕或重示，才看得出是在互動。

兩人各拿一張角色卡：甲想邀伙伴去紙上故事桌；乙這回先不參加。依自己路線選擇合適的已核模型或教師確認完整語句，不能為了湊情境硬套如廁問句。若只練已有餅乾問答，就換成圖卡邀請情境，保留角色可選擇的結構。

  1. 提出者先說清共同主題，用核實模型發起。
  2. 接收者選願意、先不要或請再一次，不預排每次都答應。
  3. 提出者等待、確認，不把沉默當同意。
  4. 若拿錯圖或誤解意願，回到原訊息重示，讓對方再確認。
  5. 交換角色，第二輪由孩子主動選最需要練的步驟。

成人記一個真實課堂觀察例：孩子先等待再移圖，或聽不清時主動請重示。語言形式與互動態度分開看：詞句跟得像卻不讓人拒絕，仍需重教互動；圖卡回應合適但尚無目標語句，就記支持性回應。

收課時各自說明「我知道你要什麼」的證據，不替別人解釋私人原因。以紙偶完成全部，不要求家人錄影、健康調查或實際外出。

練習選用：共同情境與策略題可供大家練習；特定語別詞義題只作可選查閱，僅評自己選習且已教的路線，不要求完成六語，也不以混合題總分代表語言熟練。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

由問候進到自主需求

本課新增發起、拒絕、澄清及確認，不能把問答練成唯一接受台詞。選一語別授課，依該路線證據設定目標。台語有完整意願問句；四縣有如廁請求及可以回應；秀姑巒阿美語有官方相鄰餅乾問答；臺灣手語有三個確切功能模型。馬祖完整需求問句與越南語直接需求問句仍有教師模型依賴，越南已核請喝水是邀請句，不改名為疑問句。

課前模型

台語欲7469完整用例你欲去無；四縣校園篇p11與p13分別核請求和答覆，配套四縣音檔預定位。阿美語生活會話theme6/season2官方API order21問餅乾、order22答好我喜歡，保留其原文。手語三詞需教師先看驗起迄、臉手和語義功能；不從片名重建形式。馬祖兩水果詞來源第8課，但完整請求須由具能力教師先提供核對，未備妥時產出欄待補。所有未聽驗音訊仍須課前確認可用。

兩節安排

第一節40分鐘：5分鐘三回應卡；10分鐘本路線模型及角色意義；10分鐘跟完整示範；10分鐘等待與確認；5分鐘區分邀請、請求、回答。第二節40分鐘：8分鐘角色自主選；12分鐘交換且含一次拒選；10分鐘請重示或選錯修補；5分鐘新紙圖轉移；5分鐘自評。手語一次看完再操作圖，口語先聽完整再自然分段，兩者不套同一發音評量。

差異化

需要支持者只做一問加圖卡回應，照實記支持性互動；熟練者主動發起並確認，不新增未核詞。把沉默當同意時，以紙偶停住不交卡示範重新確認；把拒絕當錯時，重申每回合由接收者決定。聽不清或看不清是合理求助，不扣合作分，也不要求說明健康原因。

安全及評量

全程紙偶和空杯圖，不實際試吃、外出、通話或模擬憋尿。真實基本需求優先處理，不因語言不熟延遲協助；如廁場景不請學生扮權威拒絕。記提出者的功能選擇、接收者的相關回應、等待與確認三欄，再由語言教師評完整模型形式。概念理解不等於已會完整句，尤其依賴教師補足模型的路線要在紀錄與對家長說明中保留邊界。

共同概念題與各語詞義題分開選用，只評選習且已教路線，不要求全部語別；自動題總分不作語言熟練指標，實際理解及產出另記。
