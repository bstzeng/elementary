相似字形與同音字辨別

長得像，讀音可能不同；聲音相同，選字還要看意思。

有的字像雙胞胎，眼睛要看仔細；有的字聲音一樣，耳朵卻不能單獨幫你選字。今天用未、末、園、圓做小偵探，讓字形、讀音和意思互相幫忙。

建議：3次，每次20分鐘；每次先比較一對。孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 能指出未與末兩橫長短的差別，連回不同讀音。
  • 能知道園與圓在本課同讀ㄩㄢˊ，但語詞意義不同。
  • 能讀整個詞與句子，選合適的同音字。
  • 能修正錯別字並說一個具體理由。
陪學大人：準備材料
  • 未、末、園、圓字卡
  • 短橫與長橫觀察提示，不作自畫筆順
  • 本頁詞卡、空白修正紙

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

兩個小任務：先分清楚問題

這次要比形，還是要選意思？

任務一：未　末
任務二：園　圓

第一對未、末長得很像，讀音不同。第二對園、圓，整個字不相同，本課常見用法讀音卻相同。不是所有相似字都同音，也不是所有同音字都長得很像。

  1. 先看第一對，指出你注意到哪一處。
  2. 再聽成人讀第二對的完整語詞：公園、圓形。
  3. 說說只聽聲音，能不能知道要寫哪一個字。

今天每次只處理一對。不要一次列十幾個近似字考記憶；先看清一處有用差異，再回到整字核對。

大人看：不急著貼錯字標籤

孩子可能辨形正確但不熟詞義，或聽懂詞卻還不會寫。先問他選字的依據，再決定需要看字卡、聽示範還是解釋語境。

一起學 02

未與末：上面那一橫有多長

比同一個字裡的兩條橫。

未　ㄨㄟˋ　　末　ㄇㄛˋ

未：上橫較短，下橫較長。
末：上橫較長，下橫較短。

把兩張同大小、同方向的卡並排。比較的是各字兩條橫的相對長短，不是把一張字放大、另一張縮小後比誰整體比較寬。

  1. 先在未中指出較短的上橫。
  2. 再在末中指出較長的上橫。
  3. 成人讀一字，孩子指整張字卡。
  4. 卡片換位，再比較一次。

這是兩字的辨形線索，不是筆順教學。要拿筆寫，請成人開官方模型看完整運筆，不用自行添箭頭猜先後。裝置字型若細節不清，改用放大的官方範字。

一起學 03

放進語詞，意思分開

尚未完成，不等於到了末尾。

尚未：到現在還沒有。
末尾：最後的部分。

原創小情境：小光的畫還沒塗好，他說：「我尚未完成。」小米已讀到故事最後一段，她說：「我讀到末尾了。」兩句不是同一件事，也不能把兩個字交換。

  1. 成人先用孩子熟悉的話說明尚未和末尾。
  2. 孩子找出尚未的未，說一次整詞。
  3. 再找末尾的末，指向一排詞卡的最後一張。
  4. 讀新句：「這頁尚未寫完。」說說是不是已經完成。

看到形狀後還要配意思，不能只背「上短下長」就停。未有其他用法，末也能用在別的詞；這裡先練本頁兩種語詞，不說它們只有這些意義。

一起學 04

園與圓：同音也不能隨便換

公園說地方，圓形說形狀。

園　ㄩㄢˊ　公園、花園
圓　ㄩㄢˊ　圓形、圓桌

兩字都有外圍的框，框裡不一樣。園內是袁，圓內是員；今天只觀察整體差異，不要求一年級把裡面的字另寫十遍。

「公園」是可以散步遊玩的地方；「圓形」說的是形狀。公園可以有圓形花圃，也可以有別的形狀，所以不能因為園有外框，就說所有公園都是正方形。

  1. 成人說完整的公園，孩子選園。
  2. 成人說完整的圓形，孩子選圓。
  3. 只讀ㄩㄢˊ時，孩子可以問「是哪個詞？」
  4. 再把答案放回原來的語詞核對。

一起學 05

原創短文：兩張標示卡

先懂整句，再補空格。

小鹿班要布置閱讀角。
小米在一張卡上寫「公園故事」，另一張寫「圓形貼紙」。
第一張放在故事書旁，第二張放在貼紙盒旁。

這是想像中的班級活動。「公＿＿故事」需要園，因為說的是以公園為內容的故事；「＿＿形貼紙」需要圓，因為說貼紙的形狀。

  1. 先聽完整短文，找兩個物品類別。
  2. 用園、圓兩卡補在相應位置。
  3. 說一個理由：地方或形狀。
  4. 把兩張卡換位置，再讀詞確認。

只聽園、圓的單字音，不能做出唯一選擇。聽寫時遇到同音字，請成人給完整語詞或情境，不把訊息不足的題目當作孩子應該猜中的考驗。

一起學 06

錯字修理：保留想說的意思

換字之前，先問原來要說什麼。

兩張待修小紙條

甲：「我們在公圓散步。」
乙：「請拿園形貼紙。」

甲說散步的地方，公圓改成公園。乙說貼紙的形狀，園形改成圓形。兩句都可能讀起來一樣，朗讀順不表示字選對了。

  1. 成人先問孩子要表達的意思。
  2. 圈出需要核對的那一個字。
  3. 查詞卡或官方辭典，選合適的字。
  4. 只重寫需要修正的詞，讀回整句。

不要把整張紙都擦掉，也不用把兩字罰寫很多遍。回饋可以是「你說的是地方，所以選園；再看看框內不同」，讓孩子知道下一次怎麼查。

一起學 07

字音不夠時，開口問

請給我一個詞，我才能選字。

成人：請找ㄩㄢˊ。
孩子：你是說公園的園，還是圓形的圓？
成人：圓形的圓。
孩子：那我選圓。

這不是不會，而是兩個字確實可以有相同讀音。問清楚語詞，才能做出有根據的決定。

  1. 成人提供一個本課的完整詞。
  2. 孩子選卡，說出意思類別。
  3. 換孩子給詞，成人也要看完整情境。
  4. 最後找一本適合的書，確認一個已學的字出現在什麼詞。

不必拍書頁或上傳學習紀錄。下次只複習自己容易混淆的一對，換卡位、換新句；能用新句說理由，才更接近真的學會。

一起學 08

換個規則：同音放一組

先比聲音，再看整個字形。

  1. 把未、末、園、圓四卡混放，成人逐張讀本課用法。
  2. 先按「本課讀音相同」分組，園和圓可以放一起。
  3. 再找未和末，指出它們雖然形近，讀音卻不同。
  4. 選一張卡說完整語詞，請同伴用句意再核對一次。

分類的規則改變，放在一起的理由也會改變。不能因園、圓同組，就在公園一詞中任意交換；也不能因未、末相像，就說兩字同音。最後讓孩子指出今天最需要的線索：字形、聲音或意思；大人下一次從那一項開始複習。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1未與末，哪個字的上橫較短、下橫較長？
給我一點提示

比較各字內的兩條橫。

看答案與原因

參考答案：未

未的上橫較短，末的上橫較長；這是本對字可用的辨形線索。

2「尚未完成」的未，讀哪個音？
給我一點提示

把未放回尚未這個詞。

看答案與原因

參考答案：ㄨㄟˋ

尚未的未讀ㄨㄟˋ，不能因和末長得像就改讀ㄇㄛˋ。

3小光說「我尚未完成」，表示什麼？
給我一點提示

想想尚未是不是已經。

看答案與原因

參考答案：到現在還沒完成

尚未在這裡表示還沒有完成，不能把未和表示最後部分的末混用。

4「故事的末尾」指什麼？
給我一點提示

末尾和最前面的位置不同。

看答案與原因

參考答案：故事最後的部分

末尾說最後的部分，是一個位置概念，並不是尚未完成的意思。

5「我們去公＿＿散步」，選哪個字？
給我一點提示

這裡要說散步的地方。

看答案與原因

參考答案：園

公園是供人休憩的地方，圓形則在說形狀，應寫園。

6「請拿＿＿形貼紙」，選哪個字？
給我一點提示

這裡要說貼紙的形狀。

看答案與原因

參考答案：圓

圓形描述形狀，園用於公園、花園等詞，本句應選圓。

7成人只說ㄩㄢˊ，面前有園和圓，怎麼辦？
給我一點提示

同音字需要語詞或情境幫忙。

看答案與原因

參考答案：問是公園還是圓形的字

兩字本課都讀ㄩㄢˊ，只有單字音時資訊不足，應請對方補完整語詞。

8「公圓」讀起來順，就不用改嗎？
給我一點提示

聲音相同，字義和用法仍不同。

看答案與原因

參考答案：仍要依地方的意思改成公園

用於散步地方的詞是公園，朗讀順不能替代正確選字。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

教學定位與起點

依Ab-I-1與Ab-I-3的形音義及字形結構方向，以兩對字練習辨形與語境選字。未末為形近不同音，園圓兼有外框相同與本課同音的特徵；不是要求每一對只能歸一類。前測分看卡辨認、聽詞選卡、說詞義三項，避免以單字同音聽寫製造不公平題目。

三次安排

  1. 第一次20分鐘：3分鐘任務比較、7分鐘未末辨形、6分鐘尚未末尾語境、4分鐘換位重測。
  2. 第二次20分鐘：5分鐘園圓比形、6分鐘完整語詞、6分鐘標示短文選字、3分鐘說理由。
  3. 第三次20分鐘：5分鐘混合複習、6分鐘錯字修理、5分鐘澄清對話、4分鐘個別新句。

回饋與誤概念

未末混淆，只比較兩橫的相對長短，字卡大小一致；選園圓只看框，轉看內部和詞義；只因讀音相同就判正確，指出語意雖可聽懂但書寫需選合適字。不要將字形助記說成造字歷史，不把園外框當所有公園形狀的證據。

差異化

起步者每次一對，由成人讀句，孩子選卡；一般組看新句填字並說地方、形狀或尚未的意思；進階組自己給一句足以辨認同音字的語境，再檢查訊息是否足夠。低視能使用高對比大字，語言需求者可先用熟悉語言表達詞義。書寫困難可口述，辨認和字形書寫分別記錄。

評量與收尾

四項觀察是未末形差、讀音連結、園圓句中選字、澄清資訊不足。各用一個新詞句確認，記下具體支架，不只計總分。少量書寫延伸須看官方筆順模型，不重新推測運筆。作品修正一個詞即可；不將罰寫、公開比較錯字或家長錄影作為補救。下次將錯過的一對換位置重測，再決定是否加新字。
