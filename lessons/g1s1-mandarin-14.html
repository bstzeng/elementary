握筆、坐姿與書寫習慣

先讓身體舒服、紙張穩住，再用輕鬆的手寫少量。

寫字前，先照顧身體和工具。今天不比誰寫多，練習把紙放穩、把手放輕，寫一個已學字，再看看哪裡更舒服。

建議：2次，每次20–25分鐘；握筆練習每回合2–4分鐘，中間放筆休息。孩子可由大人陪讀

出發前

準備好了嗎？

這一課，我會練習

  • 能檢查坐得穩、看得清楚、紙張不滑。
  • 能嘗試舒適、可控制且看得到筆尖的握筆方式。
  • 能在短回合書寫後放鬆與休息，不忍痛繼續。
  • 能依看範字、少量寫、對照修正的流程練習。
陪學大人：準備材料
  • 高度合適的桌椅與穩固腳踏支撐（需要時）
  • 好握的鉛筆、大格紙、橡皮擦
  • 三或十的官方範字、可選止滑墊

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

書寫小基地：先清出空間

桌上留下今天要用的東西。

  1. 把本次的紙、筆和範字放好。
  2. 把會擋住手臂的玩具移開。
  3. 坐下看看桌面是否太高或太低，請成人協助。
  4. 試著把兩腳放在地上或穩固支撐上。
  5. 肩膀放鬆，不用把身體僵住。

桌椅不是每個人坐起來都一樣。腳碰不到地時，可以請大人提供安全、穩固的支撐，不要自己站到會滑動的盒子上。

留出手臂移動空間，讓寫字和看範字都方便。

給大人的引導與觀察

本頁提供一般學習環境支持，非治療處方。以身體有支撐、肩頸舒適和操作可行為原則，不用精確角度當合格門檻。成人檢查桌椅和支撐物穩定性，不讓孩子自行疊高不穩物品。

一起學 02

紙放哪裡，才看得清楚

讓筆尖、範字都能看見。

把紙放在你舒服的位置，可以稍微轉一個角度。寫字時能看見筆尖，不需要把臉貼近紙面。

光線要讓你看得清楚，手的影子如果擋住字，請成人調整燈或紙的位置。不要直視強光，也不用勉強在暗處寫。

  1. 先看範字，再看空白格。
  2. 試著寫一小段線，觀察手有沒有擋住筆尖。
  3. 稍調紙的角度，再試一次。
  4. 請成人幫你比較哪個位置較舒服。
給大人的引導與觀察

左右慣用手的紙位和光源可不同，不用同一角度套所有孩子。若持續靠得很近或表示看不清楚，先調整環境並告知家長與教師，依需要尋求視力或其他專業評估，不在課上自行診斷。

一起學 03

拿筆要能控制，不是越緊越好

輕輕拿住，試寫一小格。

成人可以示範一種常見握法：拇指和食指幫忙拿住筆，中指提供支撐。接著讓你試試是否看得到筆尖、移得動、手不會痛。

每個人的手不同，可能需要不同粗細的筆或既有輔具。不要把手指硬扳到痛，也不用和同伴的握法長得完全一樣。

  1. 先拿起筆，不寫。
  2. 感受是不是用力捏得很緊。
  3. 稍放鬆，畫一條短線。
  4. 看線條是否清楚，手是否舒服。
  5. 需要時由成人提供另一支好握的筆比較。
給大人的引導與觀察

常見三指握法可作示範，不宣稱只有一種外觀才正常。功能目標是舒適、穩定、可控制與可見。已有專業建議的孩子依其方案，教師不自行用綁帶、橡皮筋或強迫扳指等方法矯正。

一起學 04

兩隻手可以分工

一手寫，另一手扶紙。

慣用手拿筆，另一手可輕扶紙邊，幫紙留在原位。不把手壓在正在寫的格子上，才看得清楚。

左手寫、右手寫都可以。你不需要為了和別人一樣而換手。若另一手不方便扶紙，可以請成人固定，或用合適的止滑工具。

  1. 先讓紙鬆放，試一條線，看看會不會滑。
  2. 再輕扶紙邊，試一次。
  3. 比較哪次比較容易控制。
  4. 寫完一格再調紙，不必勉強手腕彎到不舒服。
給大人的引導與觀察

雙手任務需要依能力調整，不能把兩手都能操作設為參與門檻。尊重慣用手，不因抹到字就要求換右手；可調紙位、筆材與書寫節奏。固定工具由成人確認安全，不黏貼孩子皮膚來限制活動。

一起學 05

力氣小實驗：留下清楚線條就好

寫一條，再摸摸紙的背面。

  1. 用一般舒服的力氣，在大格內畫一條短線。
  2. 放下筆，看線條是否看得清楚。
  3. 輕摸紙背，注意有沒有很深的凹痕；不必故意用力戳紙。
  4. 如果握得太緊，放鬆手，成人也可換較容易顯色的筆。
  5. 再試一條，選出自己較舒服的一次。

這是觀察，不是比誰能完全沒有壓痕。筆、紙和每個人的力量不同，清楚又舒服才是本次目標。

筆芯斷了要交給成人處理，不用手摸尖尖的斷口。

給大人的引導與觀察

避免把沒有凹痕當醫療標準，也不以字色深淺直接推論肌力。每次只調一項，如筆材或力道；若持續疼痛、疲累或明顯影響學習，先停止造成不適的練習並由照顧者尋求適當專業協助。

一起學 06

短回合習慣：看、寫、停、比

寫兩個字，也可以練得很完整。

  1. 選已學的三或十，不再增加新字。
  2. 先看官方範字和筆順。
  3. 慢慢寫一個，放下筆。
  4. 看自己寫的與模型有一處哪裡不同。
  5. 休息、放鬆手，再改寫一個。
  6. 兩個完成後收筆，不為了湊一排繼續抄。

休息時可以張開手、換個舒服姿勢，看看遠處的物品。不用用力甩手或拉手指。

覺得手痛就告訴成人，停止這個動作；不必忍到一整頁寫完。

給大人的引導與觀察

時間只是短回合建議，可依孩子需求更短。成人不以計時完成量作評分；筆順與字形可記錄，舒適度也要問孩子本人。疼痛不是努力的證據，不用練習取代必要評估。

一起學 07

我的書寫前檢查

先照顧好，再開始。

坐得穩嗎？
看得清楚嗎？
紙穩住了嗎？
手舒服嗎？

  1. 成人逐項讀，你用點頭、指卡或語言回應。
  2. 有一項不舒服，先一起調整。
  3. 完成一個短回合後再檢查。
  4. 說出今天一個有幫助的改變，例如紙不再滑動。

可把四句畫成簡單提示卡。它不是打分數的表，也不是用來糾正同伴的身體。

需要複習字形，可由成人開教育部筆順學習網，保持本次只練一個熟字。

給大人的引導與觀察

追蹤環境調整是否有效，不只說孩子不專心。成人與家庭共享可行工具或紙位即可，不需要拍孩子身體或公開書寫缺點。教學與既有職能、視覺或個別化支持方案一致。

成人協助準備穩固支撐較安全，不自行疊不穩物品。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

教學界線

連結4-Ⅰ-4的書寫姿勢與習慣方向。本頁是一般學習支持，不是醫療診斷、治療或矯正方案。課前先觀察桌椅、光線、工具、紙位與孩子主觀舒適度，再看握筆；不能只憑手指外觀或字是否漂亮推論發展問題。已有專業支持的孩子依既有建議。

兩次短課

  1. 第一次20–25分鐘：4分鐘整理桌面，5分鐘坐姿和紙位比較，5分鐘拿筆與線條試寫，中間放筆休息，5分鐘兩手分工，3分鐘說一項調整。
  2. 第二次20–25分鐘：4分鐘檢查卡，5分鐘力道觀察，5分鐘看寫停比，休息後5分鐘再試與對照，3分鐘整理工具。實際握筆分2–4分鐘小段，可更短。

具體支持

成人可示範常見三指握法，但以可控制、看得到筆尖、舒服而不痛為原則，不把單一握法當唯一定義。保留慣用手；紙張角度、筆的粗細與止滑工具按需求調整。不以硬扳手指、綁手、強制換手或整頁抄寫作矯正。腳部支撐需穩固，由成人準備，兒童不自行疊物。

差異化

起步者只畫短線或以手指書空，重點完成環境檢查；一般組寫熟字兩次並比較；熟練者獨立準備材料、發現一項不舒適並提出調整。動作需求者可由成人固定紙張、提供既有輔具，文字理解可用指卡表現；視覺需求者放大模型、提高對比與適當光線。不要同時教新字、新筆順與全套姿勢，降低任務負擔。

手痛立即停下告知成人；若不適持續或明顯影響日常書寫，由家長與教師討論並尋求專業評估，不自行診斷。台大兒童職能治療資料強調從日常活動了解能力與支持需求，本頁不宣稱練短線可治療特定問題。

觀察與家庭練習

紀錄準備工具、穩紙、看模型、短回合與休息五項，並詢問孩子哪裡舒服或不舒服。成功是能用合適支持完成學習，不是外觀像同一個模子。家庭延伸一次一字兩次，先調整桌面再寫，不因寫得少而補抄。網頁題只能檢查習慣判斷，不能評估肌力、視力或精細動作。
