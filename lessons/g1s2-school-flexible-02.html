借還書與愛惜圖書

幫《小島的雨傘》完成一次可核對的借還旅程

這是可選校訂課，接著上學期的借還流程，練習「檢查是否真的完成」。頁面借單、書名與期限全是原創模擬，不是真實館規；實際借還由成人確認當地規定。

建議：3 次，每次 30 分鐘；真實到館另依學校安排孩子可由大人陪讀

出發前

準備好了嗎？

這一課，我會練習

  • 分辨待辦、已借出、已歸還三種狀態。
  • 逐本核對書名、歸還提醒及館員確認。
  • 在借前檢查與使用後收好，遇破損不自行修補。
  • 看不完、忘帶或紀錄不清時向成人與館員詢問。
陪學大人：準備材料
  • 兩本可供練習的書或本頁虛構封面卡
  • 大張紙書籤、袋子、借書與還書服務臺紙牌
  • 本頁示範借閱卡及情境卡；不用真實證號或帳戶

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

同一本書，也有不同狀態

拿在手上，不代表已經借好了。

原創情境：阿青在教室圖書角選到《小島的雨傘》。他把書拿到服務臺，老師還在登記，他就想放進袋子。老師說：「先等等，確認借閱完成，再帶走。」阿青停下來問：「這一本辦好了嗎？」

三張狀態卡：「待辦」表示選好但還沒確認借出；「已借出」表示完成借閱；「已歸還」表示完成館方歸還程序。狀態說的是流程，不是書放在哪個袋子。

  1. 成人拿起練習書，孩子先選「待辦」。
  2. 成人扮館員說「已登記完成」，再換成「已借出」。
  3. 成人收回書並確認還書完成，才換「已歸還」。
  4. 如果成人沒有確認，先問清楚，不自行猜狀態。

這裡三張卡幫我們理解流程；真實館舍可能用櫃臺、機器、還書箱或其他方式。讀者不能只看本課紙卡，還要依館方說明核對紀錄。

一起學 02

兩張借閱卡，逐本核對

書名和歸還提醒，要配對同一本。

本課紙上借閱卡，並非真館規

卡 A：書名《小島的雨傘》；已完成借出；約定最晚本週星期四歸還；歸還處是教室模擬服務臺。

卡 B：書名《圓圓找圓形》；已完成借出；約定最晚本週星期五歸還；歸還處也是教室模擬服務臺。

練習日曆順序：星期一 → 星期二 → 星期三 → 星期四 → 星期五。今天的標記放在星期三。

成人示範：「我先讀卡 A 的書名，再指《小島的雨傘》的封面卡，最後指星期四。不能拿卡 B 的星期五替這本書延長時間。」卡 A 比卡 B 的約定歸還時間早。

  1. 由成人畫兩張封面卡，寫上頁面已有的完整書名。
  2. 把卡 A、卡 B 各放在對應封面旁。
  3. 指出今天之後先到哪個約定日。
  4. 選一個提早整理書袋的時間，不必等最後一刻。

真實借閱通常會有日期，不一定只寫星期。日期看不懂就請大人一起查，本課的「最晚」包含當天，真實歸還仍須確認館方截止時間；不能把所有書都記成同一天，也不用公開自己的真實借閱明細。

一起學 03

借走前，給書做一次溫柔檢查

看到問題就說，不先指責誰。

本課提供三張原創文字檢查卡：甲，封面平整、翻頁沒有缺角；乙，第六頁下方有一道裂口；丙，封面有一塊水漬。這是紙上描述，不要真的把書弄破或弄濕。

拿到乙卡時，阿青說：「這本書第六頁下方有裂口，請幫我確認。」他說明位置與看見的情況，沒有說「一定是前一位讀者弄壞」。館員處理前，他也沒有自己貼膠帶。

  1. 成人讀一張卡，孩子選「可以繼續核對」或「先請館員看」。
  2. 遇乙或丙卡，用一句話描述問題。
  3. 成人扮館員確認，說明能否借出或改選其他書。
  4. 換一本完好的練習書，用手輕帶翻頁，不拉扯書角。

檢查不是要找同學的錯，是讓書況記錄清楚。看不清小裂口時可由成人說明；孩子能提出求助已是參與，不必拿放大工具貼近書或爬高取書。

一起學 04

看一半先停，怎麼保護書？

留下閱讀的位置，不留下傷口。

阿青讀到小島下雨的那一頁，想暫停去喝水。他把大紙書籤平放夾好，合上書，再把書放到乾燥的位置，和水壺分開。喝水與保持衛生都重要，不需要為了保護書而不喝水。

「把頁角折起來」雖然也留下位置，卻可能傷書；「黏上很牢的貼紙」取下時也可能拉破紙。借來的書用不黏貼的合適紙書籤，或依館方方式記頁。不能用厚物把書撐開，也不把書反扣壓平。

  1. 成人翻到練習書的一頁，讓孩子指出想記住的位置。
  2. 孩子放紙書籤，或口頭指示成人操作。
  3. 合上書，再打開，看是否回到那一頁。
  4. 把書收進適合的乾燥袋子，檢查旁邊有沒有可能漏出的飲料。

若書意外碰到水或受損，先告訴大人與館員，由他們決定處理，不用熱風吹、不撕頁、不隱藏。犯錯可以補救，沒有人因為一張情境卡被嘲笑。

一起學 05

送回去之後，還有確認這一步

還書要有依據，不能只看空書袋。

原創短劇：書袋空了

星期四，阿青把《小島的雨傘》交到模擬服務臺。老師先把書放在桌上，還沒有確認。阿青說：「我的袋子空了，所以都還好了。」老師請他看看紙卡，卡 A 仍寫「已借出」。等老師完成模擬登記、將卡 A 換成「已歸還」，兩人才一起核對書名。

書袋空了，只能知道書不在袋裡；不一定代表借閱紀錄已處理。交回指定處後，依館方方式查收據、畫面或詢問館員。某些還書方式處理需要時間，遵照該館說明，不自己改期限或記錄。

  1. 重演交書、成人確認、核對書名三步。
  2. 成人故意只說「我看見你交書」，讓孩子再問是否完成。
  3. 把已歸還的卡 A 與仍借出的卡 B 分開。
  4. 說出下一本還要處理的是哪一本。

不要將已借出的書自行塞回書架以代替還書。館內看過、尚未借出的書則依館方指示放回指定處，兩種情況要分清楚。

一起學 06

看不完、忘了帶，怎麼開口？

遇到變化，早一點求助。

情境一：快到約定日，阿青還想讀《圓圓找圓形》。他不能自己把卡上的星期五擦掉，先請成人查能不能續借；續借不一定可辦，確認成功後才依新的到期日安排。

情境二：到了教室才發現書留在家裡。阿青先告訴老師：「我今天忘了帶練習書，請幫我安排下一步。」成人協助查看期限與館方處理，不讓孩子獨自返家取書。

可用句型：「我想處理這本書的……，現在遇到……，請幫我確認……。」例如「我還沒讀完，請幫我確認能不能續借。」說明需要，比改單子或不理會更能解決問題。

  1. 選一張情境卡，只練其中一個問題。
  2. 先指出要找的成人或館員。
  3. 用說、指卡或畫圖表達需要。
  4. 成人給一個可能回覆，孩子再確認下一步。

本課不教全國通用罰則，也不比誰借最多。真實逾期、遺失或修補由照顧者與館方共同處理；孩子不用在班上公開費用、證號或家庭狀況。

一起學 07

換一筆新借單，獨立走完

從選書到歸還，說得出目前在哪一步。

新的紙上任務

書名：《屋頂上的雲》；目前狀態：待辦；成人確認借出後，約定最晚星期三交回模擬服務臺。書況卡：封面完整、第三頁角落有裂口。

這次不套用卡 A、卡 B 的答案。請先處理裂口，再辦理借閱、記住這本的約定時間，最後演練歸還。成人只讀任務，不立刻說下一步；孩子可要求重讀。

做完再核對

先描述第三頁裂口請館員確認；獲准借出且辦妥後，狀態才是已借出。這本約定最晚星期三歸還，不是舊卡的星期四或五。交回後依模擬館員確認，才標已歸還。若成人判定不宜外借，可改選一本，不必硬把流程演成成功借走。

請用一句話完成反思：「我以前只注意……，現在還會核對……。」例如「我以前只看書袋，現在還會核對還書是否完成。」也可在三張狀態卡中指出最需要練的一張，下次再試。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

定位及情境準備

本課在上學期認識借還流程之上，加上狀態辨識、逐本配對、破損描述與確認閉環。它是學校可選校訂例。先核對本校或將到訪館舍的現行規則；所有頁面借期只是模擬，不要求學生自辦帳號或出示真證件。用成人預畫的裂頁卡代替真的破壞書。大紙書籤不含尖銳或易吞小零件，動作可以全部由成人代做。

第 1 次：把紀錄和書配對，30 分鐘

0–8 分演「拿到書但尚未借妥」；8–18 分讀卡 A、B，逐一配書名和期限；18–25 分把今天標在星期三，判斷先整理哪一本；25–30 分用孩子自己的話說三種狀態。若星期順序困難，保留本頁日曆條，成人指讀即可，不把日期計算變成閱讀活動的障礙。

第 2 次：檢查、收放與歸還，30 分鐘

0–8 分讀甲乙丙書況卡，練描述而非指責；8–15 分用完整書練放書籤；15–25 分重演交回卻尚未確認的情境，待孩子詢問後才給確認；25–30 分核對卡 A 已歸還、卡 B 仍借出。成人不要讓實際館藏受潮、貼膠帶或摺角來製造教具。

第 3 次：處理例外並轉用，30 分鐘

0–10 分演看不完與忘帶兩種情境；10–22 分換《屋頂上的雲》獨立完成，允許改選書的合理分支；22–27 分口頭抽問選擇題；27–30 分說下次想多核對哪一步。續借是否成功以館方確認為準，不教「想繼續就自動續借」。

差異化、迷思與評量

識字較少者用封面圖與成人朗讀；不便看圖者逐字口述卡片；手部操作困難者指示成人翻書、收書。將空書袋當還妥者，並排「書的位置」與「流程狀態」兩張卡，讓其說兩者不同；兩本期限混淆者每次只對一本。熟練者說明還書箱可能有處理時間，所以要依館方查詢。觀察能否逐本配對、描述書況、主動核對與適當求助，分別記獨立、提示後及共同完成；不以借閱量、罰款或家庭藏書評比。只使用虛構資料，不收孩子真實借閱紀錄、地址、圖書證號或照片；真實到館由學校另行安排可及動線與成人陪同。
