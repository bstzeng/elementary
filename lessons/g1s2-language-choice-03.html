一起學 01

身體部位和感覺，是不同的訊息

可以指哪裡，也可以說角色怎麼感受。

原創故事：紙偶小禾伸手拿到自己的作品，故事卡寫「小禾很高興」。這裡有兩種訊息：手是身體部位，高興是故事明確說出的感覺。看見笑臉不能永遠知道別人心情；想了解真人，應尊重地詢問，不替人下結論。

今天只選自己的語言路線，學一個部位詞和一個感覺詞。各路線部位可能不同；重點是用準確詞義說明訊息，而不是全班背同一身體表。可全程指紙偶圖，不碰自己或別人身體。

教師協助模型條件：本頁核對詞義、文字或官方詞目連結，不代表所有音訊／影片已聽看驗收。課前須由具該語能力教師確認完整可用模型、語別及版本；手語還須確認臉、雙手、起迄動作可見。沒有模型先做情境理解，不記已完成目標語聽說／手語產出；不得以華語諧音、英文讀法或單詞剪接補足。

身體與感覺詞是語言學習，不是診斷。所有小故事均虛構，不請孩子公開疾病、疼痛、藥物或私人經驗；如真有不舒服，停止角色練習，以孩子已會的方式向可信任成人求助，不要求先說對目標語才獲幫助。

一起學 02

路線A：臺灣台語，手與歡喜

一個詞指出部位，一個詞連到故事感受。

手，白讀tshiú取人體上肢義；歡喜 huann-hí取高興、愉快義。本課不選手的職業或其他引申義，也不套用手的文讀siú。成人使用這兩個詞目的完整音讀與台語教師示範。

在紙偶畫中圈出手，旁邊放一張文字情境卡「角色看到完成的拼圖，故事說他很高興」。先配詞義，再聽詞找對類別：是找部位，還是描述感受？孩子可以先不發音，用指出卡表示理解。

  1. 兩個完整詞各聽一次，建立不同意義。
  2. 打亂次序，選部位圖或情境圖。
  3. 孩子自行選想介紹的那張，跟完整詞示範後表達。
  4. 伙伴說明接收到哪種訊息，再交換角色。

不要把兩詞接成「手歡喜」這類未核句；本課用兩個獨立回合。若要說「我很高興」或「我的手」，教師另備完整核實模型。原辭典某些用例含成人情境，本課不要求照演。

一起學 03

路線B：四縣腔客語，用同一套情境辨詞

跟四縣模型，不因字相同換成國語音。

教育部臺灣客語辭典四縣欄已核手 suˋ是人體上肢；歡喜 fonˊ hiˋ是快樂、高興。只取兩個詞的相應義，不把同頁海陸、大埔或其他腔混入。

成人畫一個沒有真實姓名的紙偶，手部以箭頭標示「手」。另一張卡畫完成的大紙屋並寫「故事角色說自己很高興」。箭頭是紙圖標記，不讓孩子抓伙伴的手；感覺是故事文字給的資訊，不是從長相猜出。

  1. 完整聽手，指出箭頭部位；成人換紙偶左右位置但不變詞義。
  2. 完整聽歡喜，選故事感受卡。
  3. 孩子代角色介紹一項，伙伴選部位或感覺卡作回應。
  4. 教師只修一項影響理解的語音，完整重示後再試。

有人對同一件事不高興也可被尊重，不能用學習歡喜要求全班一直笑。若孩子不願演情緒，可做詞卡分類或觀察者，仍能展示理解。

一起學 04

路線C：馬祖閩東語，跨課連結嘴與歡喜

把來源讀清楚，不把一首歌當身體操作。

部編第1冊第5課唱小歌：跋落浦原文喙有官方中文「嘴」對照；這是上冊材料的詞義回看，不是下冊新課順序。下冊第6課大蜀歲了的短語「大儂倪囝齊歡喜」與官方中文對照支持歡喜的情境。

本課只取喙的部位義及歡喜感受，不抄完整歌詞，不演落水或動物相咬。教師先備妥相應原課的完整可用聲音；課內語流標記不直接用作獨立詞發音規則，本站不提供猜出的拼音。

  1. 以紙偶嘴部圖連到喙，和手部圖作區別。
  2. 由教師選取並示範原課歡喜語段，孩子指出是感受而非部位。
  3. 孩子選一張圖，依教師核對的完整詞或語段跟說。
  4. 把新情境「角色高興收到故事卡」連到相同感覺，保持原模型，不自造新句。

原課集體歡喜是一個教材場景，不規定新年每個人都一定快樂。不能只看嘴的圖就用華語喙字讀音代替馬祖語模型；沒有可用原音時只記圖義理解。

一起學 05

路線D：秀姑巒阿美語，kamay與lipahak

保留部位與感覺的不同用途。

官方d=2詞表已核kamay＝手與lipahak＝高興。這是秀姑巒阿美語，不用其他方言相似拼法替換，也不在前後補未核人稱或時態。

準備兩個大信封，一個標「找部位」，另一個標「故事感覺」。成人讀或播一個完整模型，孩子將相應圖放進信封。圖卡可以重複使用，主要看是否知道語義分類，不以英文字母識讀評定。

  1. 聽kamay，把手圖放到找部位。
  2. 聽lipahak，把故事明確高興的情境放到故事感覺。
  3. 抽新紙偶圖再聽，位置不固定。
  4. 孩子自主挑一項表達，伙伴取圖確認；可先跟教師，逐步減少支持。

詞彙正確不代表兩詞可任意連成完整身體感受句。若孩子想表達真實需要，先使用既有可接收方式找成人；不能把課堂語言練習設成求助門檻，也不要求把真實感覺都說成高興。

一起學 06

路線E：臺灣手語，眼睛和高興的完整模型

只指圖不等於已學到那個手語詞。

本路線採眼睛及高興官方詞目影片。13身體生病和12感覺情緒索引的逐項連結已核；不表示本頁已看驗手勢或全段播放。由具臺灣手語能力教師先確認詞義、完整動作與臉部訊號。

眼睛詞先配紙偶眼睛圖，高興詞配故事明確寫出感受的卡；不要因片名有「生病」就把眼睛當醫學症狀。只看中文標籤能配圖是詞義支持，獨立手語理解另需完整無答案提示的教師示範。

  1. 完整看一詞後休息，再選圖，不同時翻卡。
  2. 第二次觀看由教師指明一項實際觀察重點，不由本站猜手形。
  3. 教師核對後模仿，孩子可只接收或以既有輔具回應。
  4. 在新紙偶情境使用同一核實模型，伙伴確認收到部位或感覺。

面部表情可能是語言訊號的一部分，不是要求孩子一直裝出某種情緒；其具體語言功能由教師判讀。不得搬動孩子的手、要求盯人眼睛或用任何觸碰換取「正確」姿勢。

一起學 07

路線F：越南語，tay與vui vẻ

一個部位，一個故事中明說的感覺。

國教署越南語第8冊印刷21／PDF23：tay＝手；同冊印刷14／PDF16：vui vẻ＝快樂。本課跨級少量取詞，不教原冊所有情節；發音依該冊官方音訊與越南語教師所選完整模型，不聲稱代表所有地方口音。

故事卡只寫「紙偶看到作品，說自己很快樂」。孩子把tay配手圖，把vui vẻ配感覺卡。不是把tay與vui vẻ相接成一句，也不是看到笑嘴就判斷真人一定快樂。

  1. 先認兩張意思卡，再完整聽詞。
  2. 換圖位置後，孩子指出剛才收到的意思。
  3. 孩子代角色選一項，跟完整模型再嘗試表達。
  4. 伙伴用相應圖回應，教師核對詞義和形式兩欄。

保留越南語符號與分詞，不依英語字母名拆讀。若需要「我的手」「我很快樂」完整句，教師另提供核實模型；沒有模型不在自動練習裡測未教語序。能指出意思也值得記錄，口語表達可逐步練習。

一起學 08

獨立任務：誰說了感覺？我知道哪些？

觀察得到的，和需要問的，分開放。

成人做兩張新情境：甲卡寫「角色指著紙偶的手」；乙卡寫「角色說自己很高興」。孩子聽／看自己的已教模型，選符合卡，說明是部位還是感覺。馬祖用嘴圖、手語用眼睛圖，依本路線調整，不要求未教詞。

第三張只畫一個笑臉，沒有角色自述。這時可以說「圖畫的嘴往上彎」，但不能確定真人心情一定如何；若扮故事，可以由作者設定感受，再清楚寫在卡上。對真實伙伴則以其願意提供的說明為準。

  1. 先做一回成人支持的配對。
  2. 換一張紙偶圖，做一次無答案提示的完整模型配圖。
  3. 孩子選部位或感覺卡，嘗試用本路線模型介紹。
  4. 最後用既有溝通方式替紙偶提出休息，練成人先接收需要，不先考發音。

沒有身體檢查、疼痛模擬、表情模仿比賽或真人健康調查。單詞題只檢查本頁已核意思和學習策略；實際形式由教師另評，不能用選對題替代。

練習選用：共同情境與策略題可供大家練習；特定語別的詞義題只作可選查閱，僅評自己選習且已教的路線。不要求答完六語，也不以本頁總分代表語言熟練程度。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

語言目標與保護界線

本課由命名身體部位走向區別觀察、故事明說的感受及未知心理狀態。身體／情緒詞是學習語境，不是醫療、心理診斷或健康篩檢。全部用虛構紙偶，部位圖由成人簡畫標記；不強迫觸摸身體、表演情緒或分享疾病。真人不舒服時停止練習，先以任何可接收方式求助，不能要求說出目標語才提供協助。

各路線來源

台語手白讀tshiú、歡喜huann-hí；四縣手suˋ、歡喜fonˊ hiˋ，均由精確辭典詞義與音讀確認。馬祖喙來自第一冊上冊第5課中文嘴對照，歡喜來自下冊第6課語段，不把舊歌當新詞全數進度。秀姑巒d=2 kamay和lipahak由官方API字義核實。越南第8冊跨級取tay和vui vẻ。臺灣手語眼睛與高興逐項官方索引連結已核，完整影像形式仍待具能力教師確認。

第一節40分鐘

5分鐘分身體部位與感覺；10分鐘本路線一詞一圖；10分鐘完整模型與亂序配對；10分鐘代紙偶選一項表達；5分鐘核對。成人不要讓羅馬字量、國字識讀或紙偶畫工成為目標語理解的門檻。語義與形式分開回饋，先知道詞在指什麼，再一次只修一項形式。

第二節40分鐘

8分鐘換圖複習；10分鐘找出卡上誰明說感覺；10分鐘區分無自述的笑臉與已知情緒卡；7分鐘獨立新情境介紹；5分鐘練習提出休息及自評。情緒詞不應當行為要求，孩子不想演高興可任觀察者；不因不微笑判定不會。熟練者能說明哪一資訊是來源給的、哪一項需詢問，不擴張未核句型。

差異化與評量

需要支持者先兩張差異明顯的卡，成人用文字或可接收方式說明背景；有動作或視覺需求時依既有支持調整，不搬動手或強制眼神接觸。每人記一回部位理解、一回感受理解、一回詞表達和一次有需要時的求助選擇。獨立與重示後分開，字幕提示另註。部位詞正確不保證完整所有權句正確，情緒詞正確也不代表讀懂真人心理。無完整可用模型時，語言形式欄待補，不以中文分類替代。

自動題分共同概念與語別詞義：共同題可選用，路線詞義題只評所選且已教語別，其餘為可選查閱，不要求完成六語；不以混合題總分作語言熟練指標。實際聽說／視覺理解及產出另記。
