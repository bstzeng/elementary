家人、稱謂與朋友

用虛構人物關係學本路線兩至三個稱謂，練習聽／看懂、指認和友善介紹。

先用紙偶認識彼此。影音模型需成人及語言教師確認完整可用；手語影片本次未完整播放核驗。只記本路線已教詞，不把所有語別或未核實的朋友詞算成必學。

建議：選一條路線，建議2節各35–40分鐘。孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 能確認故事人物之間的關係，不只用外表或工作猜稱謂。
  • 能理解本路線已教兩至三個家人／朋友詞。
  • 能在正確模型支持下嘗試本路線稱謂詞，讓伙伴指認。
  • 能尊重家庭及腔調差異，不強迫分享真人家庭。
陪學大人：準備材料
  • 四張虛構人物關係卡
  • 紙屋、紙片和兩支彩色筆
  • 本路線指定詞目模型
  • 具該語能力的教師與可播放音訊／完整手語影片

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

只學本路線的稱謂

先用故事人物練，不需要介紹自己的家庭。

六條路線依實際選習選一：臺灣台語、四縣腔客語、馬祖閩東語、秀姑巒阿美語、臺灣手語或越南語。今天用兩個家庭稱謂作起步；有已核實朋友詞的路線再加入第三詞。詞數不同不表示語言較簡單或較重要，也不要求孩子全部學會。

先準備虛構人物米米、米米的爸爸、米米的媽媽和米米的朋友四張卡。成人可在卡背標角色，用簡單圖示或代讀說明。這是本課故事的人物關係，不是要求每個孩子家庭都有相同成員。孩子可以改演紙偶，或只配圖，不需說誰和自己住。

圖畫不以長頭髮、穿裙子、煮飯或修東西判定稱謂；關係由故事介紹。同一位成人可能在不同孩子口中有不同稱呼。每次先說清楚從哪個人物的角度來看，再選本路線詞。

模型使用提醒

語詞音讀依官方詞目或指定課文；手語依完整官方影片。成人和具該語能力的教師須課前確認完整可用模型。手語影片本次未完成全段播放核驗，不能只讀中文或猜手勢後就評已學會。

一起學 02

原創情境：誰來幫紙偶搭屋？

看人物關係，不用衣服和工作猜。

米米要搭紙屋，爸爸遞紙，媽媽扶著底板，朋友拿來兩支彩色筆。第二次，爸爸畫窗戶、媽媽遞紙，朋友扶底板。動作變了，原來的親屬和朋友關係沒有因工作改變。

  1. 成人先介紹四張卡，孩子把人物擺在米米旁邊。故事只需理解，不要求翻譯全文。
  2. 在自己的路線學第一個稱謂模型，成人播放後請孩子選對卡。
  3. 加入第二詞，先一對一練，再打亂播放與卡片位置。
  4. 完成兩詞者，按路線是否有核實朋友詞決定加第三詞；沒有就維持兩詞，不猜譯。
  5. 孩子抽一張關係卡，用已學詞指認；伙伴找到角色。交換一次。

成人故意換角色的衣服顏色，或把遞紙工作交給另一人，孩子再配一次。若他仍能找到相同關係，表示不是只記顏色或家事刻板印象。

我可以不回答什麼？

你不必回答自己的家庭有哪些人，也不用交家人照片。這些詞能透過故事學習；尊重家庭差異和學會語詞可以同時做到。

一起學 03

路線A：臺灣台語的家人與朋友

三張人物卡，各有自己的詞。

核心模型為教育部詞目：阿爸 a-pah、阿母 a-bú、朋友 pîng-iú。阿爸、阿母在本課作孩子對父母的稱謂；朋友指友人。本課選詞目主音作一致示例，家庭其他說法先辨明用法，不判成錯誤。

  1. 成人先讓米米紙偶面向爸爸卡，播阿爸；再面向媽媽卡播阿母。
  2. 只播聲音、不移動紙偶，孩子選對卡；兩詞順序改變三次。
  3. 加入朋友模型，放到共同遊戲的同伴卡；不要把所有成人都稱同一詞。
  4. 孩子拿角色卡，先聽完整詞再試說；伙伴依詞找到人物。
  5. 把人物排成新位置，撤掉先前顏色提示，再用兩個詞指認。

漢字相似不能用華語音念。字典的阿母另列地方讀法，成人選適合班級的一套，解釋家中不同讀法可能有來源。這裡只教稱謂詞，不把它們自動拼成未核實的「這是我的……」句子。熟練者請教師提供完整句模型後才擴充。

一起學 04

路線B：四縣腔客語，聽清楚人物稱謂

跟四縣腔模型，找出爸爸、媽媽和朋友。

使用教育部臺灣客語辭典四縣欄：阿爸 aˊ baˊ、阿姆 aˊ meˊ、朋友 penˇ iuˊ。成人確認欄位標為四縣；頁面同列其他腔時，不輪流混播。

詞義依序為爸爸、媽媽、友人。阿姆不是照國語字面讀成兩個國語音；本課也不拿台語相同字形當同義同音。羅馬字供教師核對，孩子先聽詞辨人。

  1. 給孩子爸爸及媽媽兩卡。成人播放一詞，孩子選卡，成人翻背確認。
  2. 第二輪加入朋友，先示範朋友卡所代表的關係，再播放詞音。
  3. 用「送邀請圖卡」遊戲：孩子說一個已學詞，伙伴把邀請圖交到對應紙偶，不交真人個資。
  4. 交換出題和接收，記是否需要模型提示。

若混淆阿爸和阿姆，先用兩卡、完整重聽，各對應一次，再混合；不要要求把聲調拆成口訣。家人使用其他客語腔調時，保留其差異，學校路線改用該腔完整示範。父母詞不應和某種固定工作綁在一起。

一起學 05

路線C：馬祖閩東語，兩個家人稱謂

先學兩個已找到正確課文的詞。

模型來自國教署部編第1冊第7課「汝厝有幾隻儂」：依爹（爸爸）、依嬭（媽媽）。互動電子書為第一級第一冊下冊印刷頁18的父母行，這是跨冊取用的入門稱謂例，不宣稱它在每所學校小一上皆為相同進度。

成人在課文選對詞與播放位置，先用原課完整語段，再依詞目聽讀。文字模型已核對，聲音由熟悉馬祖語的教師與可用官方朗讀確認；本頁不把課內連讀標記當獨立詞音教，也不造中文諧音。

  1. 兩個家人紙偶站在米米旁，教師先介紹關係。
  2. 播放依爹對應模型，指爸爸；播放依嬭對應模型，指媽媽。
  3. 把卡片換位，只聽選卡；再由孩子看關係卡試說，伙伴核對。
  4. 老師換故事中的家事，孩子仍以關係選詞。

本頁此路線只教兩個稱謂；朋友詞及其他親屬稱謂未列為已教目標。若教師有另核實朋友模型，可記下來源後擴充，不能用其他語言的朋友詞補空。故事中出現朋友角色不表示已教會其馬祖語稱呼。

一起學 06

路線D：秀姑巒阿美語，別被熟悉的字形騙了

先聽本路線的詞和意思，再選人物。

選族語E樂園千詞表d=2：爸爸 mama^、媽媽 ina^、朋友 idang。這些是秀姑巒阿美語具體模型，不是所有族語共同用詞；平台保留的符號依其原音與教師說明，不用英語讀字母。

  1. 成人只說中文角色意思作準備，再播放一個官方詞音。
  2. 孩子先配圖，不因mama看起來熟悉就套成華語「媽媽」。本路線該詞在此來源對應爸爸。
  3. 把爸爸和媽媽卡對調，再各聽一次；確定配對後加入朋友。
  4. 孩子抽角色卡，跟模型後試說，伙伴選人物；交換角色。

如果家庭或別的教材使用不同朋友詞，先核對方言與語境，不拿本頁單一詞否定其他用法。此課只使用這套詞表的三個詞，不自行改拼字或把別方言句子接上去。

特別的意思檢查

先聽已核實爸爸詞，指出爸爸，再聽媽媽詞指出媽媽。看見相似字母不代表意思相同；聲音、意思和來源要連在一起。

一起學 07

路線E：臺灣手語，完整看再指人物

用眼睛接收詞，讓伙伴知道你介紹誰。

使用臺北啟聰「15人稱代詞」連結的完整官方短片：爸爸、媽媽、朋友。本次已核對詞目與連結，未完整核驗播放；具臺灣手語能力的教師須先確認完整影像，才進行模仿與語言形式評量。

  1. 把三張角色卡放在孩子可見範圍，先確認人物關係。
  2. 每次完整看一支，看片時不拿卡、不看成人長段文字；看完再選角色。
  3. 再看同一模型，由教師提示一次只觀察一個面向，例如手部位置或非手部訊號；不自行畫手形。
  4. 看完後孩子嘗試表達，伙伴指出角色；教師核對，必要時重示完整詞。
  5. 改卡片順序與位置，再做一次，避免只記排列。

教師的獨立理解評量不能先用字幕揭露答案；帶字幕的影片選圖算支持性練習。指中人物卡不等於已正確表達詞。不能把三個詞按中文句式隨意串成家庭介紹，更不要求全班描述真人家人。

一起學 08

路線F：越南語，先學父母稱謂

同一家庭角色可能有不同說法，今天跟一套模型。

本頁越南語起步選bố（爸爸）、mẹ（媽媽），對應國教署第一冊第3課「我的家」。成人開越南語第一冊數位教材選第3課詞彙模型，並按本班越南語教師的口音示範。兩詞的中文對應已核對國教署第一冊印刷頁26（PDF第28頁）；也可參考教育部親子稱呼例。

  1. 先用故事的爸爸和媽媽兩卡，成人播放bố，孩子指爸爸；播放mẹ，孩子指媽媽。
  2. 下一輪不指圖，只播詞，孩子自己選。
  3. 各選一張角色卡，跟模型後向伙伴試說；伙伴以卡確認。
  4. 交換紙偶的工作和位置，再選詞，確定關係不是由畫中家事猜出。

其他地方或家庭也可能用別的父母稱呼；本課只是這套官方教材的例子。不要把bố和所有男性、mẹ和所有女性相連。語句中的自稱會隨對象改變，這課只教兩個稱謂詞，不臆造對長輩的長句。

收課時只做自己路線：成人抽已教角色，孩子先選意思再試表達，伙伴核對。能聽懂但還說不出，分開記錄；沒有家庭語言資源者在學校完成即可，不問國籍或移居史。

國教署原課本：爸爸、媽媽詞彙頁，本頁只取兩個詞，不重製課文或插圖。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

課前備課與教材範圍

各路線目標限已核實2–3個稱謂詞。台語、四縣客語、秀姑巒阿美語和臺灣手語含爸爸、媽媽與朋友；馬祖閩東語、越南語本頁只列兩個父母稱謂，朋友在故事中是關係對照，不是假裝已教其目標語。馬祖語取第一級第一冊下冊印刷18的第7課，是跨冊參考，不對應全國統一小一上。其餘教材同樣按孩子起點取詞，不能以資源名義推定學期進度。

先準備虛構關係圖，四卡背面標角色。成人須確認每一音檔/影片完整可用和語別正確；臺灣手語的形式及獨立理解由具該語能力者評量，影音未備妥就延後該項教學。單字標音不作變調或句音的自行拼接依據，也不要求孩子默寫。

第1節

5分鐘確認路線及隱私選擇；8分鐘搭紙屋故事，說清關係；12分鐘兩詞一次一個地建立聲/視覺形式與圖義；10分鐘亂序配圖、換位及換工作；5分鐘離堂兩次配對。初次教學不要一次放出六語詞表。先教必要詞，孩子能用兩詞理解角色已是可觀察成果。

第2節

5分鐘非固定順序複習；8分鐘有核實朋友模型的路線加入第三詞，其他路線進一步換圖和人物；12分鐘邀請卡遊戲，每人至少接收及表達各兩回；10分鐘撤掉額外顏色線索做個別理解、表達觀察；5分鐘說明還想練哪一詞。卡片只用虛構人物，不交家庭結構表、家族樹、照片或錄音。

常見誤解與回饋

  • 用衣著、性別外觀或家事猜稱謂：先重述米米與人物的關係，換工作再核對。
  • 以為語詞長得像意思就相同：秀姑巒阿美語mama^在所選詞表為爸爸，回到該語模型而非華語聯想。
  • 否定家庭不同說法：辨明語別、方言、稱謂習慣及當時對象，不要求孩子證明家人說錯。
  • 把會配圖當會說：理解與表達分開記。語音或手語形式需要合適教師核對。
  • 把一種家庭當標準：反覆說明是故事關係，允許完全不用真人家人。

差異化及評量

需要支持者用兩張大圖、較少背景、短回合及完整重示，成人代移卡片或讓孩子指認；有既有輔助溝通者照常使用。熟練者在新紙偶組合中辨相同關係，或在教師另核實的完整句中識別目標詞，不以多學其他語言當唯一進階。

評量記語別、實際教了哪2–3詞、配圖結果、表達所需支持、對伙伴的核對回應。三張卡每詞隨機呈現兩次，錯誤時先重建語義配對，再重試。不要比較家庭成員數、稱謂使用頻率或誰的家「完整」。課後可用同一套故事卡再玩三分鐘，校內完成和家庭完成同等。
