二拼音與三拼音

把兩張、三張符號卡連成一個字音，不念成分開的小聲音。

符號卡像一起工作的夥伴。今天用兩張卡拼媽，用三張卡拼家。先聽完整的字音，再看看卡片怎麼接。

建議：分3次，每次20–25分鐘；已會本課符號與基本聲調後進行。孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 能將ㄇ與ㄚ合讀為ㄇㄚ。
  • 能將ㄇ與ㄧ配三聲讀為米。
  • 能用ㄐ＋ㄧㄚ的路徑讀出家。
  • 能知道二拼、三拼都要合成一個音節，調號不算一個注音符號。
陪學大人：準備材料
  • ㄇ、ㄚ、ㄧ、ㄐ、ㄍ、ㄨ、ㄏ、ㄠ符號卡
  • 媽、米、家、瓜、花的字音卡
  • 成人正確讀音示範與官方手冊

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

完整字音先到家

聽「媽」，只拍一下。

媽　ㄇㄚ　　家　ㄐㄧㄚ

成人讀媽，輕拍一下；成人讀家，也輕拍一下。媽和家各是一個音節，不能因為符號有兩個、三個，就念成兩個、三個字。

  1. 先聽成人說「媽」。
  2. 指出完整的ㄇㄚ卡。
  3. 把ㄇ和ㄚ拆開放，看看有兩張。
  4. 成人再把它們合讀，你把兩張推近。
  5. 最後讀整個媽，輕拍一下。
給大人的引導與觀察

節拍只協助理解一個音節，不作發音時長標準。成人不要把聲符名稱拖得很長才突然接後音；先示範自然整音，分解只為觀察。若尚不認符號，保留整卡跟讀，不要求立刻獨立拼。

一起學 02

兩張卡拼出媽

ㄇ接上ㄚ，一起讀ㄇㄚ。

ㄇ＋ㄚ → ㄇㄚ（媽）
ㄅ＋ㄚ → ㄅㄚ（八）

先看第一張，再看第二張。跟著成人把聲音連起來，最後說出熟悉的字。

ㄇ換成ㄅ，後面的ㄚ不變，字音從媽變成八。只改一張卡，方便聽出差別。

  1. 成人示範ㄇㄚ，孩子跟讀或指卡。
  2. 保留ㄚ，換ㄅ，再聽ㄅㄚ。
  3. 成人說媽或八，孩子選出正確整卡。
  4. 打亂卡位，再各試一次。
給大人的引導與觀察

這裡二拼用兩個注音符號標一音節作入門。避免聲符後多加母音：不可把ㄅ先讀成ㄅㄛ再拼ㄚ。需要時由熟悉教學發音的教師示範，或用官方符號與例字音搭配，不使用英文字母B的名稱。

一起學 03

兩張卡也能拼米

ㄇ接ㄧ，再看三聲。

ㄇ＋ㄧ＋ˇ → ㄇㄧˇ（米）
ㄊ＋ㄨ＋ˋ → ㄊㄨˋ（兔）

米有ㄇ、ㄧ兩個注音符號，ˇ是聲調記號。不能因為看見三個小記號，就把米叫三個注音符號。

兔也有兩個符號，再加四聲。先聽整音，確認調號，再試著連讀。

  1. 拿出ㄇ、ㄧ兩張卡。
  2. 把ˇ小卡放到最後。
  3. 成人示範米，你指出整組卡。
  4. 把兩張大卡數一數，再把調號分開看。
給大人的引導與觀察

ㄧㄨㄩ在這類音節可充當韻母，不是一定還要接另一個符號才完整。成人可以教「兩個符號加聲調」這個可觀察描述，不為了維持簡化分類而說ㄇㄧ缺韻符。

一起學 04

三張卡：先認家後面的ㄧㄚ

ㄐ接上ㄧㄚ，一起讀家。

ㄧ＋ㄚ → ㄧㄚ
ㄐ＋ㄧㄚ → ㄐㄧㄚ（家）

先聽ㄧㄚ這一組怎麼合在一起，再讓ㄐ接到前面。三張卡一起標出家，讀完只是一個字音。

你也可以照學校正在用的拼法，由成人先示範；最後都要回到完整、自然的ㄐㄧㄚ。

  1. 把ㄧ和ㄚ放在同一張底紙上，成人示範。
  2. 把ㄐ放前面。
  3. 手指從ㄐ滑到ㄧㄚ，跟讀家。
  4. 再讀一次，不加停頓。
給大人的引導與觀察

採先熟結合韻再接聲符的路徑降低三項工作記憶負荷。某些教材採不同分合步驟，不把路徑當成唯一正確；核對的是符號順序、完整音節和聲調。不要省略ㄧ，或讀成ㄐㄚ這種錯誤標注。

一起學 05

只換前面：瓜與花

ㄨㄚ留著，換一張聲符。

ㄍ＋ㄨㄚ → ㄍㄨㄚ（瓜）
ㄏ＋ㄨㄚ → ㄏㄨㄚ（花）

先把ㄨㄚ讀熟，再加ㄍ成瓜，加ㄏ成花。兩個字都用三個注音符號。

看好中間的ㄨ，不要讀著讀著把它漏掉。說出瓜和花，可以配手繪簡圖或真物理解意思。

  1. 成人示範瓜和花各一次。
  2. 保留ㄨㄚ，只交換ㄍ、ㄏ。
  3. 成人讀一個，孩子找對第一張。
  4. 換孩子出卡，成人讀，再一起核對。
給大人的引導與觀察

只用已核對的有效組合，不把ㄨㄚ隨便接到所有聲符後。若孩子漏介符，可把ㄨㄚ兩卡放同一底紙，先確定能讀整組再加聲符；不要讓孩子反覆練習錯誤省音。

一起學 06

拼音小車站

排好卡，聽清楚，再出發。

  1. 桌上放媽、米、家、瓜四張終點卡。
  2. 成人選一個字，先讀給孩子聽。
  3. 孩子從有限卡片中排出對應注音；米另加三聲。
  4. 成人核對順序，孩子把卡推近，合讀一次。
  5. 選一張終點卡，說它有兩個還是三個注音符號。
  6. 交換任務，孩子請成人拼家，自己檢查有沒有漏ㄧ。

不會拼時先看正確整卡，遮住再試。能指出正確卡，也是一個可觀察的進步。

小車不比快，每個人可以重聽。不要用全班齊喊遮住某個孩子還沒聽清楚的地方。

給大人的引導與觀察

三層：兩選一整音配卡、依模型排卡、聽熟字獨立排卡。題目限定本課音節，避免測到新字義或新符號。成人記錄究竟是漏介符、次序錯、聲調錯，下一輪只修正其中一項。

一起學 07

拼完還要知道意思

讀出米，再找米的意思。

媽媽看花。

成人讀短句，你先找「花」。看它的注音ㄏㄨㄚ，試著合讀，然後說說花是什麼。

拼得出聲音後，還要把聲音和意思接起來。米可以煮飯，花可以觀察；不把正確拼音當成全部閱讀。

  1. 選媽、米、家、瓜、花中的一個。
  2. 先合讀，再用指物、畫圖或口頭說明意思。
  3. 把它放進一個你會說的短句。
  4. 請成人讀一次你的句子，你再找回那個字。

想查拼合範例，成人可用教育部手冊音節表，不必要求孩子閱讀整張表。

給大人的引導與觀察

語詞連結可用母語或孩子熟悉的語言說明，避免國語詞彙量遮住拼讀能力。成人代寫句子即可，本課不要求新國字書寫。最後留一個新但由已學符號構成的有效音節作教師口頭遷移，先核對再出題。

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1ㄇ與ㄚ合起來，是哪個？
給我一點提示

兩張卡都不要換。

看答案與原因

參考答案：ㄇㄚ

ㄇ加ㄚ合讀ㄇㄚ，是媽的字音，兩張卡要連起來讀。

2米ㄇㄧˇ有幾個注音符號，不把調號算進去？
給我一點提示

把小小的三聲記號先放旁邊。

看答案與原因

參考答案：2個

米有ㄇ、ㄧ兩個注音符號，ˇ是另一類的聲調記號。

3家ㄐㄧㄚ哪個順序正確？
給我一點提示

中間是ㄧ。

看答案與原因

參考答案：ㄐ、ㄧ、ㄚ

家依序是聲符ㄐ、介符ㄧ、韻符ㄚ，不可交換位置。

4先讀熟ㄧㄚ，再加哪個能拼家？
給我一點提示

看家的第一張卡。

看答案與原因

參考答案：ㄐ

ㄐ接上ㄧㄚ，合起來是ㄐㄧㄚ，也就是家。

5瓜ㄍㄨㄚ換哪一張，就成花ㄏㄨㄚ？
給我一點提示

只比較最前面。

看答案與原因

參考答案：把ㄍ換ㄏ

瓜和花共同保留ㄨㄚ，前面的聲符由ㄍ換成ㄏ。

6家有三個符號，合讀後是幾個音節？
給我一點提示

大人讀家，只輕拍一下。

看答案與原因

參考答案：1個

ㄐㄧㄚ合讀成家的一個字音，不念成三個分開的音節。

7讀家時一直漏ㄧ，可以先怎麼練？
給我一點提示

把後面兩張先放在一起。

看答案與原因

參考答案：先聽讀ㄧㄚ，再接ㄐ

先讓ㄧㄚ形成穩定的結合韻，再接ㄐ，可幫助保留中間音。

8哪張卡是三個注音符號組成？
給我一點提示

不把聲調記號算作注音符號。

看答案與原因

參考答案：花ㄏㄨㄚ

花有ㄏ、ㄨ、ㄚ三個注音符號；米與媽各有兩個。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

先備與診斷

對應Aa-I-3，並銜接Aa-I-4。先確認孩子能辨ㄇㄚㄧ與ˇ，再聽讀媽、米。會逐個念符號但不能合讀時，保留整字的意義示範，不急著塞進三拼。目標是把符號合成一音節，而非說出「二拼」「三拼」名詞。

三次教學節奏

  1. 第一次25分鐘：5分鐘完整音節聽辨，7分鐘媽與八替換，5分鐘兩符號排卡，5分鐘米加聲調，3分鐘個別合讀。
  2. 第二次25分鐘：4分鐘複習，6分鐘ㄧㄚ結合練習，7分鐘ㄐ＋ㄧㄚ讀家，5分鐘整卡遮蓋再讀，3分鐘指出中間ㄧ。
  3. 第三次25分鐘：5分鐘ㄨㄚ示範，7分鐘瓜花替換，8分鐘車站活動，5分鐘讀音與字義配對。

精準回饋

把ㄇㄧˇ數成三個注音符號時，分開大符號卡與小調號卡；把家讀漏ㄧ時，重新熟讀ㄧㄚ再連前音；能合讀卻不懂意思時，加入圖物配對；一見長組合就停頓時，先縮短練習量，只完成家一例。成人不可用「每個符號都完整念一遍再加快」取代正確拼合模型，尤其聲符不能多加另一個元音。

差異化與紀錄

起步孩子可指完整卡或將兩卡靠攏，不必同步寫；一般組依模型排、遮模型排、聽音排逐步退支架；熟練組說出同一結合韻換聲符後的差別，不要求發明未核對音節。視覺支持可放大單卡、留白，高對比文字不能只靠顏色分類；動作支持由成人移卡、孩子指方向。口語困難者仍可完成符號順序和字義配對，其發音另由教師追蹤。

離堂至少一個二符號音節、一個三符號音節，各看指認、排序、合讀、聲調與字義，不做總分貼標籤。若三拼不穩，下節保留ㄧㄚ，暫不增加ㄩㄢ。網頁的選擇題只能檢查構造和策略，成人需用實際聽讀觀察補足。家庭每次三分鐘，以學校相同拼法練兩個熟字，避免兩套口令互相競爭。
