注音語詞與句子

一個字音、一個語詞，再把意思連成短句。

注音會幫你讀出聲音。今天把聲音變成小花、小魚，再讀一個小故事。可以先聽、指、選卡，不必每個字都自己寫。

建議：分3次，每次20–25分鐘；一次讀2–3個語詞和1–2句。孩子可由大人陪讀

出發前

準備好了嗎？

這一課，我會練習

  • 能依注音拼讀小花、小魚等熟悉語詞。
  • 能把兩個字音連成有意思的詞。
  • 能讀出「小魚游。」並指出誰在做什麼。
  • 遇到不會的音節能停下看符號、請求示範，再回讀整句。
陪學大人：準備材料
  • 小花、小魚、媽媽三張詞卡
  • 本課原創短句卡、空白紙和筆
  • 成人協助讀題與教育部辭典

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

字音合起來，成為語詞

指著小花，聽兩個字連起來。

小花　ㄒㄧㄠˇ　ㄏㄨㄚ
小魚　ㄒㄧㄠˇ　ㄩˊ
媽媽　ㄇㄚ　˙ㄇㄚ

先聽成人讀小花，再用手指從小移到花。兩個字音合起來表示一朵小小的花。

「小魚」也有兩個字音；小和魚各有自己的注音與聲調，不能把ㄒㄧㄠˇㄩˊ當成一個很長的音節。

  1. 成人讀一個詞，你找卡。
  2. 選出小花和小魚都出現的「小」。
  3. 再指出不同的花和魚。
  4. 說或畫出小花、小魚的意思。
給大人的引導與觀察

先提供字義與口語詞彙，再檢查注音拼讀。兩字詞可以整體讀順，但音節界線仍要清楚。媽媽用常見輕聲模型，第二個音節的點置於前方；不同家庭讀法不拿來評斷文化或身分。

一起學 02

慢慢拼，再讀整個詞

不會的地方，停一下找線索。

ㄒㄧㄠˇ → 小
ㄏㄨㄚ → 花
小花

  1. 先看ㄒㄧㄠ三個符號，再看ˇ。
  2. 成人示範小，你跟讀或指卡。
  3. 接著看ㄏㄨㄚ，合讀花。
  4. 把小和花連起來，再讀小花。
  5. 請成人換詞卡位置，確認不是背位置。

先慢慢拼是練習的方法。讀熟後可以直接讀語詞，不必每次都把每個符號的名稱念一遍。

若卡上只有花的圖，你可以猜意思；想確認讀音，仍要回到注音核對。

給大人的引導與觀察

聽辨、符號排序和詞彙理解分開診斷。小的三聲接花的一聲時，自然口語未必完整升回，成人用自然詞讀，不逼孩子逐字誇大聲調。也不要只憑圖片判定孩子已會拼音。

一起學 03

短句告訴我們一件事

讀「小魚游」，找誰在做什麼。

小魚游。
ㄒㄧㄠˇ　ㄩˊ　ㄧㄡˊ。

這句話告訴我們：誰？小魚。做什麼？游。「游」可以用手在桌面上輕輕移動來表示，不需要真的下水。

讀到句號，這個意思說完了，稍停再讀下一句。句號沒有注音，不讀成「圈圈」。

  1. 成人先讀整句。
  2. 你指出小魚。
  3. 再指出游。
  4. 試著把三個字音連成一句。
  5. 用動作或圖卡回答：小魚在做什麼？
給大人的引導與觀察

一句可簡短但仍有可理解的完整訊息。「小魚」是詞，「小魚游。」在本情境是完整陳述。不要宣稱所有完整句都必須固定三字；先用可觀察的「誰／做什麼」架構。

一起學 04

換一個詞，意思跟著變

把小魚換成小貓，句子也要合理。

小魚游。
小貓跑。
ㄒㄧㄠˇ　ㄇㄠ　ㄆㄠˇ。

小貓的注音是ㄒㄧㄠˇ ㄇㄠ，跑是ㄆㄠˇ。成人帶你讀一次，再把「誰」和「做什麼」分成兩張卡。

卡片可以換，但要聽聽換完的意思。想說小貓跑，就不要排成小魚跑，除非你清楚在編想像故事。

  1. 先排小魚＋游。
  2. 再排小貓＋跑。
  3. 成人讀其中一句，孩子指出對應卡。
  4. 孩子選一句讀給成人聽，成人用動作回應。
給大人的引導與觀察

本課讓孩子連結字音與語意，不以現實不常見的句子一律判為語法錯誤。若孩子創作會跑的魚，先問他是否在想像，再區分本題原句的資訊。必要時先用成人示範，不測未教ㄆ的獨立拼讀。

一起學 05

原創小短文：看小魚

聽三句，找每句說的事。

媽媽看小魚。
ㄇㄚ　˙ㄇㄚ　ㄎㄢˋ　ㄒㄧㄠˇ　ㄩˊ。

小魚游。
ㄒㄧㄠˇ　ㄩˊ　ㄧㄡˊ。

小貓看小魚。
ㄒㄧㄠˇ　ㄇㄠ　ㄎㄢˋ　ㄒㄧㄠˇ　ㄩˊ。

先由成人完整讀一遍。你找找小魚一共在哪幾句出現，再選一句跟讀。

故事只說媽媽和小貓看小魚，沒有說小貓抓魚。回答時先依句子，不把自己猜的事當成已經發生。

  1. 第一句：誰看小魚？
  2. 第二句：小魚做什麼？
  3. 第三句：又是誰看小魚？
  4. 把你的答案指在文字上。
給大人的引導與觀察

全文與注音均為原創。版面以空格分隔音節方便初學者，並非中文詞間必須空格的規則。先由成人讀題降低識字負荷；延伸可比較第一、第三句只換了主語，不加情節猜測。

一起學 06

注音小編輯

把漏掉的符號找回來。

  1. 成人出示正確小花ㄒㄧㄠˇ ㄏㄨㄚ詞卡。
  2. 孩子照模型排出兩個音節。
  3. 成人暫時拿走花中的ㄨ。
  4. 孩子看正確模型，指出少了哪張，把它放回。
  5. 再排媽媽的兩個音節，檢查輕聲點是否在第二音節前面。
  6. 最後讀整詞，再說意思。

一次只改一個地方。不用一直盯著錯寫，修好就回到正確模型。

如果只看得出整個詞，也可以先做完整詞卡配對；成人幫忙拆音節，下次再試。

給大人的引導與觀察

此活動不是自由猜拼法，所有錯誤立即用正確模型核對。觀察孩子有無漏介符、跨音節搬調號或合併兩個音節。書寫量只兩個詞，可由成人代寫，孩子負責檢查與指認。

一起學 07

讀給一位聽眾聽

選一句最熟的，讓意思說清楚。

你可以選小魚游，也可以選媽媽看小魚。先悄悄練一次，再讀給成人或同伴聽。

聽眾聽完說：「我聽到＿＿。」如果他沒有聽清楚，你可以再讀一次，不用突然大喊。

  1. 選句子。
  2. 找一個還不熟的音節，請成人示範。
  3. 從句首重讀，讀到句號停一下。
  4. 讓聽眾指出誰和動作。
  5. 圈出今天讀得更順的一個詞。

課後可由成人在教育部國語小字典查本課例字，不需要錄音或上傳孩子的聲音。

給大人的引導與觀察

評量重點是注音支持下的語詞和句意，不比速度或一次不錯。較熟練者可把小貓看小魚改成自己的合理短句，成人代寫注音後孩子核對；不要求孩子自行寫所有未教國字。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1「小花」是哪組注音？
給我一點提示

先找後面的花。

看答案與原因

參考答案：ㄒㄧㄠˇ ㄏㄨㄚ

小花是ㄒㄧㄠˇ ㄏㄨㄚ；小魚的第二音節則是ㄩˊ。

2小魚的兩個字音，應如何讀？
給我一點提示

兩個國字各有自己的注音。

看答案與原因

參考答案：各自拼準，再連成小魚

小和魚各有一個字音，拼準後連成有意義的語詞。

3「小魚游。」誰在游？
給我一點提示

找動作前面的詞。

看答案與原因

參考答案：小魚

句子直接說小魚游，做游這個動作的是小魚。

4本課短文第一句，媽媽在做什麼？
給我一點提示

回到第一句找「看」。

看答案與原因

參考答案：看小魚

第一句是媽媽看小魚，所以她在看小魚，沒有提到跑步。

5短文有說小貓抓魚嗎？
給我一點提示

看和抓不是同一個動作。

看答案與原因

參考答案：沒有，只說小貓看小魚

第三句只寫看小魚，沒有說抓魚，不能把猜測當成內容。

6花的注音漏了中間符號，該補哪個？
給我一點提示

看本課正確的小花詞卡。

看答案與原因

參考答案：ㄨ

花正確是ㄏㄨㄚ，中間是ㄨ，補好再合讀。

7句號到了，讀者可以怎麼做？
給我一點提示

這是一個意思的終點。

看答案與原因

參考答案：稍停，確認一句意思說完

句號提示一個句子的結束，可以自然稍停，不讀符號名稱。

8不熟的音節使你卡住，較好的下一步是？
給我一點提示

把困難縮小，再回到全句。

看答案與原因

參考答案：請成人示範，再回讀整句

先處理不熟的音節，然後回讀整句，才能連起聲音與意思。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

教學定位

對應Aa-I-5及第一階段運用注音閱讀方向。從已學音節走向熟悉詞、短句和三句短文；不是把拼音速度當閱讀理解。開始先問孩子是否認識花、魚、游等口語詞，再聽小花、小魚配卡，確認詞彙理解與拼音起點。

三次教學流程

  1. 第一次25分鐘：5分鐘聽音選詞，7分鐘小花和小魚對比，6分鐘小花慢拼到整詞，4分鐘圖意配對，3分鐘選詞離堂。
  2. 第二次25分鐘：5分鐘複習詞卡，7分鐘誰／做什麼的卡片分組，6分鐘小魚游與小貓跑，4分鐘句末停頓，3分鐘口頭回答。
  3. 第三次25分鐘：5分鐘成人讀短文，7分鐘逐句找線索，6分鐘注音小編輯，5分鐘自選朗讀，2分鐘說明還想練的詞。

注音與聲調處理

每個音節分開標注，二三四聲跟在該音節最後，媽媽第二音節輕聲點在前。教自然詞讀，不把三聲在連讀中的半三聲表現當錯音。對不熟的字音先查辭典；正文沒有合成朗讀，成人可依官方例字音示範。不因小貓的詞義很熟，就省略檢查ㄒㄧㄠˇ ㄇㄠ是否真能解碼。

分層與補救

起步者聽成人讀、指整詞，目標兩詞辨認；一般組獨立讀詞並回答誰在做什麼；進展組比較三句中相同與不同的詞，依成人提供的新注音讀一句合理變式。若逐符號念不停，先讓成人示範完整詞，再逐步退提示；若讀得準卻不知道意思，用物品或畫圖支援；若理解正確但輸出困難，允許指圖、手勢或溝通工具，不將口語障礙與理解混計。

每次記錄一個詞的符號辨識、一句的連讀、一次文本問題回答。作答不必書寫國字，成人可代讀選項和代記孩子的說法。離堂讓孩子指出短文中的直接證據，避免把推測混成故事事實。家庭只練選中的一句，適度重讀以舒服、理解為先，不用計時、競賽或長時間抄寫。
