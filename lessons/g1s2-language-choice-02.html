一起學 01

衣物偵探：只說顏色，可能還不夠

先找物品，再找能分辨的特徵。

原創任務：紙偶的展覽桌有三張衣物圖，要請伙伴找對一張。A是紅色上衣、B是黃色上衣、C是紅色帽子。只說紅色，A和C都符合；只說上衣，A和B都符合。今天學把物品和顏色分清楚，再核對對方選擇。

這是選一語別課，不比較誰會的語言多。成人可以先用兩個分開的已核詞與指圖支架傳遞兩項資訊；未有完整句模型，不把詞拼成看似自然的新句。語言的語序和連讀不一定等同華語。

教師協助模型條件：本頁核對詞義、文字或官方詞目連結，不代表所有音訊／影片已聽看驗收。課前須由具該語能力教師確認完整可用模型、語別及版本；手語還須確認臉、雙手、起迄動作可見。沒有模型先做情境理解，不記已完成目標語聽說／手語產出；不得以華語諧音、英文讀法或單詞剪接補足。

衣物只用紙圖，不換穿或評比真人穿著、價格、性別、體型。圖卡加文字與不同邊框供核對，不以看出顏色作唯一評量途徑；有顏色辨識需要者可依文字標籤及成人描述參與。

一起學 02

三張實際圖卡：資訊如何縮小範圍

先排除不符合，再確認剩下的一張。

先用自己的溝通方式做一次：收到「紅色」資訊，留下A、C；再收到「上衣」資訊，剩A。成人展示整個判斷，不直接宣布答案。下一回由孩子選B，伙伴會發現黃色這一項在本圖就足以找到B，但增加另一張黃色帽子後，又需要物品資訊。

圖卡可列印、依文字重畫或用描述替代。這個排除活動幫你看懂訊息需要多少資訊，並不規定目標語一定先說顏色後說衣物。真正完整描述仍照該語教師確認的模型。

一起學 03

路線A與B：相似漢字，不同語言模型

同樣寫衫，也要跟自己的路線。

臺灣台語

衫 sann在本辭典表示衣服；紅色 âng-sik表示紅色。固定採詞目主音。先聽衫找衣物類，再聽紅色找對色標。活動中可用兩個獨立提示確認紅色上衣，但不能稱已核實「紅色的衫」整句；若要描述完整片語，由教師先核對。

孩子扮用品管理員，先出示「衣物」圖再表達已學詞，讓伙伴縮小候選；第二回把圖拿掉再聽完整詞，看是否仍懂。顏色詞與物品詞各記一次理解，勿只看最後是否碰巧拿A。

四縣腔客語

衫 samˊ的詞義是上衣；紅色 fungˇ sedˋ取四縣欄。與台語衫的辭典範圍不完全相同，本路線就用上衣圖，不用帽子假充衫。

先把兩件上衣歸一組，再用紅色詞找到A。教師示範兩個完整詞，孩子可以一回傳衣物、一回傳顏色；伙伴用圖確認兩項都接到。別把六腔音檔混播，也不拿同樣漢字的台語讀法替代。

一起學 04

路線C：馬祖閩東語，從課文顏色到衣物情境

已核實的顏色可練，衣物新詞先請老師核對。

來源是第1冊第8課愛食水果，第一級第一冊下冊印刷28。原短語「紅紅的蘋果」與「黃黃的黃梨」有官方中文對照，後者的黃梨是鳳梨；本課從這兩個完整模型觀察紅、黃的顏色意義。課內標音受語流影響，不把它當獨立顏色詞讀音表。

  1. 先聽教師確認的原課兩個完整短語，配紅蘋果及黃鳳梨圖。
  2. 指出顏色差異，再將紅／黃色卡移到本頁衣物圖旁，表達概念轉移。
  3. 需要說衣物名稱時，教師先提供並核對本地合適的完整衣物詞模型；本站尚未核實衫、衣裳或帽的該教材詞條，不在此編造。
  4. 衣物模型未備妥時，只記原課顏色理解與指圖選物，服飾詞表達欄標「待教師確認」。

不能把「紅紅的蘋果」刪掉蘋果，再接未核實衣物詞而宣稱句子有效。本課可比較兩個原完整短語，聽見描述對象不同；轉到衣物情境的完整說法須由合格教師確認，這個依賴是明示的教學條件。

一起學 05

路線D：秀姑巒阿美語，用兩項資訊核對

同一色也可能有不同物品。

官方詞彙d=2已核kahengangay＝紅色；fodoy / riko’＝衣服。衣服詞目列兩個形式，本課由教師在同一官方詞條內選定一個完整可用示範並記錄，不能把斜線或兩個詞連念成一個長詞。不要擴推其他阿美語方言。

先用不同形狀的紅物品建立顏色詞不是單指某件衣服；再用衣服詞找兩張上衣圖。本頁不教數量詞或所有權句，兩項訊息透過明確兩回合與圖卡核對，不按華語詞序自行拼句。

  1. 第一回合聽或跟完整衣服詞，伙伴指出衣物類。
  2. 第二回合用完整紅色詞，伙伴從衣物中選A。
  3. 表達者確認，再由伙伴選一張新目標進行交換。
  4. 若目標是黃色而尚未學到該語模型，先用黃色圖卡支援，誠實記未教的新詞，不瞎編。

評量分別看詞義、兩項資訊是否對到同一物，以及溝通確認。完整片語產出是下一個教師核實任務，不從兩個單詞答對推定自然語法已會。

一起學 06

路線E：臺灣手語，衣服和紅色分開核實

有完整詞模型，也要有清楚的所指。

官方模型為衣服與紅色，分別在03衣物及21活動美勞頁有精確標籤連結。兩支影片完整播放與手語形式尚待教師確認；不能看漢字或上衣圖自己畫手形。

教師先以完整詞示範建立衣服和顏色兩種概念，孩子看完再選，不一邊看一邊找卡。老師可用兩個明確獨立回合分辨物品與特徵；要組合為自然描述時，先由具臺灣手語能力教師提供核實完整模型，不把單詞影片直接相接。

  1. 看衣服模型，從用品圖選到衣物。
  2. 看紅色模型，從兩個標明顏色的色卡選紅。
  3. 共同確認現在談的是哪一張衣物圖，再做教師核對的完整描述或圖卡輔助選擇。
  4. 伙伴指出目標，若有兩個候選就提出需要更多資訊。

模仿時觀察起迄、位置、方向與非手部訊號的具體重點由教師指出。此頁沒有宣稱看驗手勢，也不以動作大、小或快、慢評語言好壞。字幕提示與教師指圖都要記為支持。

一起學 07

路線F：越南語，T恤和紅色兩個線索

跨冊少量取詞，不把高年級整課搬來。

使用國教署越南語第6冊印刷21／PDF23衣著詞彙：áo thun＝T恤；第2冊印刷6／PDF8詞彙表列đỏ＝紅、vàng＝黃。本課只選T恤與紅色兩個詞，完整原音由教師配數位教材核對，不要求學喜宴課全段或服飾文化概括。

將A、B兩張圖視為短袖T恤示意，先聽áo thun指到這兩張，再以已核紅色模型配A；帽子只是華語排除圖，不新教越南語帽子。孩子可先用詞加指圖完成兩項資訊確認。

  1. 對照來源字形，保留áo和đỏ的符號，不按英語讀法。
  2. 完整聽詞，換位置後再找；口語教師一次給一個發音回饋。
  3. 表達者指定一件，接收者說明得到物品還是顏色資訊。
  4. 想說完整「紅色T恤」時，先用教師核實的完整片語，不從原課紅色長衫句任意改詞。

不將教材某一角色穿長衫的場景說成所有人都必須如此穿；本課沒有真人換裝、衣物金額或性別限制。

一起學 08

獨立轉移：讓資訊真的夠用

選對後，說出你用了哪兩個線索。

成人依上圖另畫三卡：紅上衣、黃上衣、黃帽。孩子自己選目標，先決定需要提供物品、顏色或兩項資訊。只用自己路線已教模型；缺詞時可指標籤，記清支援，不由孩子現編。

伙伴第一次選錯時，先查收到哪一項：顏色對、物品錯，補物品資訊；物品對、顏色錯，補顏色資訊；兩個都不清，回到模型配圖。不是每次都加大聲量或把手勢做更快。

  1. 兩人交換四回合，至少一次有相同顏色的兩張卡。
  2. 每回合接收者展示選中的卡，表達者確認。
  3. 孩子指出一次修補前後的差別。
  4. 最後分別勾「懂物品詞」「懂顏色資訊」「能提供足夠線索」，不合併成一個全會分數。

單靠中文標籤選對是概念成果；獨立目標語理解還要有不先揭答案的完整示範。所有缺少的衣物／完整片語模型照實標待教師核實，不以本頁測驗替代。

練習選用：共同情境與策略題可供大家練習；特定語別的詞義題只作可選查閱，僅評自己選習且已教的路線。不要求答完六語，也不以本頁總分代表語言熟練程度。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

進展與學習範圍

此課將單一詞圖配對推進到兩個屬性、資訊不足與針對性修補。選一語別，不要求六路線詞表。三卡觀察用A紅上衣、B黃上衣、C紅帽，物品與顏色交叉；圖片及文字共同提供資訊，不單靠色覺。畫面與題目答案已逐一核對：紅色有A/C，上衣有A/B，同時紅色與上衣只有A。

模型差異必須保留

台語衫是衣服；四縣衫是上衣，不因字形相同就推成相同詞域。阿美語衣服詞目列fodoy/riko’，教師只選一個可用完整模型，不把斜線念入。馬祖已核的是水果課紅紅的蘋果、黃黃的黃梨，未核衣物名，故服飾產出須另備教師模型，不能把詞庫全齊當作既成。越南第6冊跨級取T恤、第2冊取紅色詞；手語分03衣物、21美勞精確詞項。所有聲音／視覺形式未全部聽看驗收，須課前實測及語言教師確認。

兩節安排

第一節40分鐘：5分鐘建立尋物任務；8分鐘三卡兩線索示範；12分鐘自己路線完整詞義；10分鐘分開兩回合傳物品和顏色；5分鐘核對。第二節40分鐘：8分鐘打亂位置；12分鐘孩子選目標及伙伴確認；10分鐘按漏掉資訊修補；5分鐘換成新三卡；5分鐘分欄自評。完整描述片語只能在教師先核實後教，不能因場景簡單而省略模型條件。

差異化與評量

需要支持者先只有兩件同類不同色，再加第三件；顏色辨識需要者可讀色標、聽成人描述或用既有輔具，不因此認定詞義不懂。熟練者增加一件同色不同物，自己判斷訊息是否足夠，但不新增陌生語法。錯誤若是物品／顏色只一項混淆，重教那一項，勿重複整段十遍。理解、表達、確認分別記獨立／重示後／需重教。

安全與誠實紀錄

所有服飾都是紙圖，不評孩子身材、性別、品牌或家庭花費，不交換穿衣、不拍攝真人。語言形式由具該語能力教師驗收，概念選對不等於學會發音或手語。沒有可靠完整模型的項目保持待補，尤其馬祖服飾詞和各語未核實組合句；未核模型不得放進自動題答案。回家可只描述虛構卡，不調查家中衣櫥或上傳照片。

自動題分共同概念與語別詞義：共同題可選用，路線詞義題只評所選且已教語別，其餘為可選查閱，不要求完成六語；不以混合題總分作語言熟練指標。實際聽說／視覺理解及產出另記。
