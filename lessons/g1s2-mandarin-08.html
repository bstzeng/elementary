童詩與短文的節奏朗讀

先讀懂畫面，再讓停頓和聲音帶出節奏。

詩裡的字會排隊，聲音也能有輕重快慢。今天讀一首小書本的詩，再讀整理書架的短文。先知道它們在說什麼，才決定哪裡停、怎麼讀。

建議：2次，每次25分鐘；可加一次10分鐘小組共讀。孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 能讀懂童詩中的主要畫面，分清想像與事實。
  • 能依詞組、標點與句意安排自然停頓。
  • 能用舒服音量嘗試不同快慢，不把朗讀當比大聲。
  • 能說出自己的朗讀選擇，並把方法帶到新短文。
陪學大人：準備材料
  • 本課原創童詩與短文
  • 可遮一行的紙條、鉛筆
  • 安靜空間；不需要錄音設備

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

先聽一遍，不急著拍節拍

耳朵找畫面，眼睛找重複的詞。

成人先讀一次下面的童詩。你先想像書本排在書架上的樣子，不用立刻一字一拍。聽完說你記得哪個畫面，再看看有沒有重複的詞。

  1. 把其他聲音先關小，選舒服的位置。
  2. 成人用自然速度完整讀，不逐字考問。
  3. 孩子指出自己聽見的書本或書籤。
  4. 第二次才跟著自己想讀的一行。

拍手不是朗讀的必要條件。你可以用手指輕點、點頭、眼神指行或安靜聽；重點是把詞語和意思連起來。

大人看：先理解再形式

先解釋書籤是夾在書中標記位置的小物。若孩子不知道它的用途，可用一小張乾淨紙示範，避免先分析節奏卻連詞義都不熟。

一起學 02

原創童詩：書架上的約定

排排站，探頭看，明天再見。

小書本，排排站，
小書籤，探頭看。
故事躲在書頁間，
明天見面慢慢談。

這首童詩由本頁原創。第一行想像書本並排站著，第二行想像露出書頁的書籤在看，後兩行把下次閱讀當成朋友約會。

先找「排排」和「慢慢」，聽重複的字帶來什麼感覺。你可以輕輕讀慢慢談，也可以用期待的語氣讀明天見面，沒有唯一像機器一樣固定的節拍。

  1. 成人讀一行，孩子回讀一行。
  2. 孩子選最有畫面的一行，說自己想像到什麼。
  3. 再讀全詩，看看四行是否接得起來。

朗讀不用先背起來；可以一直看文字。

一起學 03

詩在想像，不是物品真的會說話

書籤露一角，可以想像在探頭。

實際可能看到：書籤有一角露在書外。
詩中的想像：小書籤探頭看。

詩把物品寫得像朋友，能讓讀者想到有趣的畫面。書籤不是真的有眼睛，故事也不是有身體躲在書裡的小動物。

  1. 拿一本書，夾入紙書籤，留下能看見的一角。
  2. 先說實際看到什麼。
  3. 再讀詩中的說法，說哪一處加入想像。
  4. 想一個自己的比方，先說「我想像」。

說出自己想像的聲音或動作可以很多樣，但回答「詩中寫了什麼」時仍要回到文字。詩裡沒有說書本是紅色，不能把自己腦中的紅書當成已寫出的事實。

一起學 04

把詞抱在一起，不拆成零碎聲音

小書本是一組，排排站也是一組。

暫時的讀法提示

小書本／排排站
小書籤／探頭看
故事／躲在書頁間
明天見面／慢慢談

斜線是本次練習用的分組提示，不是原詩新增的正式標點。讀時讓一組意思自然連起來，不把小書本拆成「小書／本」，也不把慢慢談拆得讓人不知道在說什麼。

  1. 成人指一組，示範連讀。
  2. 孩子跟讀，再合回完整一行。
  3. 看原詩的逗號與句號，感受短停和一句結束。
  4. 移開提示，試讀原詩。

每一行不必停一樣久，每個字也不必一樣長；理解意思與呼吸舒適比固定數拍更重要。需要換氣時可以自然調整，不憋氣。

一起學 05

用快慢與輕重，表達你的感覺

舒服地讀，不用喊，也不用演得一樣。

「排排站」可以讀得整齊一點，像幾本書排好；「慢慢談」可以稍放慢，讓人感到不著急。這是可嘗試的表達，不是唯一正確讀法。

我把慢慢談讀慢一些，因為它讓我想到悠閒地聊天。
我把明天見面讀得有期待，因為詩中約了下次。

  1. 挑同一行，試兩種舒服讀法。
  2. 同伴說哪個地方聽得更清楚。
  3. 你選一種，說一句理由。
  4. 整行再讀一次，保留原來字詞。

不要把改音量當作改聲調，也不為了配節奏擅自換字。聲音不舒服就休息；可以改成指讀、成人代讀或既有溝通方式來表達選擇。

一起學 06

同樣是書架，短文怎麼讀

跟著事件走，不強迫每句都唱一樣。

原創短文：閱讀時間結束了。小安把書籤夾好，再把書放回書架。下一次，他可以從書籤標記的地方繼續讀。

短文直接交代整理的事件和書籤用途。先讀清「夾好書籤」和「放回書架」的先後，再讓句號提醒一段意思結束。

  1. 找出小安做的兩個主要動作。
  2. 先讀完整短語，再讀第一、第二句。
  3. 問第三句：書籤幫了什麼忙？
  4. 按句意自然讀，不要求每個字等長。

詩和短文都需要讀懂意思。詩分行、有重複詞，可以玩聲音；短文也有自然節奏，不等於只能用毫無變化的聲音念完。

一起學 07

兩人共讀：一個讀，一個聽意思

給一個具體回饋，再換人。

  1. 讀者選詩的一行或短文的一句。
  2. 聽者先說回一句意思，檢查是否聽懂。
  3. 只給一個具體建議，如「書籤兩個字可以連起來」。
  4. 讀者試一次，自己決定哪種更清楚。
  5. 交換角色，不做音量或速度排名。

有用回饋：「你在句號停一下，我知道一句說完。」
不夠清楚的回饋：「你要好聽一點。」

回饋要能讓人知道怎麼調整，而不是只說好或不好。有人用不同口音或較慢速度，只要意思清楚，就不以模仿同一種表演聲線為目標；特定讀音需要核對時，回官方辭典。

一起學 08

換一段新文字，留下自己的選擇

先懂，再分組，最後試讀。

原創新句

小書籤回到書裡，等下一次的故事。

這句也是想像式的說法。可以先把小書籤、回到書裡、等下一次的故事分成三組，讀後說「書籤夾回書中，準備下次讀」。

  1. 成人補讀孩子不認得的字。
  2. 孩子選一處自然停頓，用鉛筆作暫時記號。
  3. 說說這個停頓怎麼幫助意思。
  4. 試讀一次，再拿掉提示讀。
  5. 回到自評，選一項下次想練的能力。

延伸只需一小段，不要求背整首、錄音或上傳。你可以喜歡安靜的讀法，也可以喜歡有表情的讀法；清楚、舒服、符合自己的理解就值得繼續練。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1童詩中，什麼東西「排排站」？
給我一點提示

回到原詩的第一行。

看答案與原因

參考答案：小書本

第一行寫小書本排排站，不能把自己想像的別的物品當成原文。

2「小書籤，探頭看」主要是哪種說法？
給我一點提示

先想實際物品與詩的想像。

看答案與原因

參考答案：把書籤想像得像會看的人

詩把露出書頁的書籤寫得像在探頭，這是想像表達，並非實物有眼睛。

3練習頁的斜線「／」是什麼？
給我一點提示

它幫你找一組意思，不改原詩。

看答案與原因

參考答案：暫時幫助分組的提示

斜線只用於朗讀分組提示，熟悉後可拿掉，並不是要求修改原詩。

4哪個分組保留了完整語詞？
給我一點提示

把小書本這個詞連在一起。

看答案與原因

參考答案：小書本／排排站

小書本和排排站各是一組自然意思，不宜任意切開破壞理解。

5想把「慢慢談」讀得有感覺，哪個做法合適？
給我一點提示

快慢可以表達意思，但不必勉強聲音。

看答案與原因

參考答案：用舒服音量稍放慢，再說自己的理由

稍放慢能配合慢慢談的感覺，讀法仍可有變化，不須固定誇張時長。

6短文中，小安先做哪件事？
給我一點提示

注意再把書放回之前的動作。

看答案與原因

參考答案：把書籤夾好

短文先交代夾好書籤，再放回書架，順序清楚。

7哪個同伴回饋最容易照著調整？
給我一點提示

回饋要指出可調整的地方。

看答案與原因

參考答案：書籤兩個字可以連起來讀

指出書籤這個詞應連讀，能讓讀者具體試改；抽象要求較難採取行動。

8換新短文，最先應做什麼？
給我一點提示

節奏是為了把意思帶給聽眾。

看答案與原因

參考答案：先讀懂意思，再考慮分組和停頓

理解內容後才容易選自然詞組與停頓，速度和固定節拍不能替代理解。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

定位與前測

以Ad-I-3童詩與Ac-I-3語氣意義及第一階段朗讀方向安排，先閱讀理解，再處理聲音節奏。原創童詩與短文皆不改寫商業教材，不要求韻律術語或押韻分析。前測請孩子讀一短語並說意思，分清不認字、詞語分組不穩與理解問題。

分次流程

  1. 第一次25分鐘：4分鐘聽前詞義、5分鐘成人完整讀與跟讀、6分鐘實際畫面和想像、7分鐘詞組連讀、3分鐘自評。
  2. 第二次25分鐘：5分鐘回讀、6分鐘兩種快慢選擇、6分鐘短文事件理解、5分鐘同伴具體回饋、3分鐘新句遷移。

示範重點

斜線只是暫時分組，不改原作標點；可依孩子的呼吸調整停頓，不用一字一拍、每行同長或逗號固定秒數規定朗讀。把書籤當真有眼睛，先觀察露在書外的紙角，再說詩人想像；為求快漏字，先縮回短語再合句，不用加大音量補救。

差異化

起步組由成人補生字，只接讀排排站與慢慢談等熟詞；一般組讀全詩或短文並指出一處停頓理由；進階組比較同一句兩種讀法，說哪種與理解相符。語言、聽覺或口語需求者可指行、選分組或由成人代讀，記錄理解與朗讀輸出不同目標。保持舒適音量，嗓音不適立即休息。

評量與收尾

觀察詞組是否連貫、停頓是否破壞意思、是否理解想像、能否回應具體回饋。選擇題不能證明實際發音或韻律已熟練，須以短段個別示範或選擇讀法補足證據。接受多種自然詮釋，不以表演誇張度、同一口音或最快速度給分。離堂新句檢查能否沿用先懂再分組的策略；家庭只共讀一小段，不強制錄音、背誦或公開表演。
