三次練畫要用幾張新紙？一起看、數、試、說

這是學校可採用的校訂跨領域示例，不是額外全國共同必修。我們把生活觀察、數數、說明理由和畫提醒圖放在同一個問題裡：練畫三次，怎樣少拿一些新紙？本課資料是明示的教學例，結果要靠你自己再試。

建議：3 次，每次 30 分鐘；可用紙卡模擬，無須故意消耗新紙孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 把「節省用紙」變成一個能在課堂試的小問題。
  • 檢查紙張兩面，依是否能練畫分類並數量。
  • 讀懂三次活動的簡單用紙紀錄。
  • 試一個取紙方法，用實際結果說明是否適合。
  • 把觀察、數量與提醒圖合成有理由的小建議，承認資料範圍。
陪學大人：準備材料
  • 成人確認乾淨、無個資的單面舊紙與已用雙面紙，或本課紙卡
  • 三張標籤：還有空白面、兩面已用、請大人確認
  • 粗筆與一張紀錄紙；不必購買或列印一整本
  • 本課原創示例資料；教室重試的結果另記，不冒充全班調查

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

把大問題變成小問題

今天只研究練畫用紙，不研究所有垃圾。

故事中的小米想做環保小幫手，說：「我要讓全世界都沒有垃圾！」老師說：「想法很大，我們先挑教室裡一件能看見、能試的事。」他們發現練畫盒中有些紙只畫過一面，背面還空著。

今天的探究問題

要練畫三次，每次只要一個空白面。如果先檢查紙盒的單面舊紙，還需要拿幾張新紙？

小米猜要一張；阿禾猜不用新紙。他們還沒檢查紙盒，兩個都是猜想，先不投票決定誰對。

  1. 用自己的話說要做什麼：練畫三次。
  2. 說出需要的條件：每次有一個可以畫的空白面。
  3. 猜需要幾張新紙，可用手指表示。
  4. 說出要先查什麼：紙盒裡有幾張合適的紙。

這個問題可以用眼睛看、用手數、用畫圖試，再用一句話說結果。這就是不同學習方法一起幫忙，不是把很多科目的名稱背下來。

給陪學大人：控制研究範圍

題目聚焦新紙張數和可用性，不把這個小試驗說成完整碳排或環境效益研究。只用安全乾淨、沒有姓名、成績或家庭資訊的紙；不翻找垃圾桶、回收箱或他人文件。

一起學 02

翻看兩面，再決定放哪一區

看起來是舊紙，也可能還有好用的一面。

以下是本課準備的六張紙卡示例。大人可用已有紙張代替，不用特地弄髒或丟棄紙。

  • A、B、C、D：正面有練習圖，背面空白，共四張。
  • E、F：正反兩面都有圖，共兩張。

所以「還有空白面」放四張，「兩面已用」放兩張。四張和兩張合起來，仍是原來的六張，沒有少算或重複算。

  1. 每次只拿一張，翻看正反面。
  2. 判斷這次練畫是否能用，再放到一個區。
  3. 每一張只數一次；用手指點著數到四或二。
  4. 把分完的兩區合起來核對總數六。

有污漬、破損、尖銳附件或不確定內容的紙，放在「請大人確認」，不由孩子清理。含別人名字或私人資料的紙，也不拿來共用畫畫。用不到的紙如何處理，交由成人依實際規定決定。

給陪學大人：分類不是把所有紙都說成垃圾

本次分類標準是能否提供練畫所需的空白面，不是判斷紙的價值。雙面已用的紙可能另有用途，但不能假定適合所有活動。若孩子只看正面，成人示範翻面一次，再讓他檢查下一張。

一起學 03

讀懂三次練畫的紀錄

一格代表一次，不是三個人的比賽。

小米第一次取 A 的空白背面，第二次取 B，第三次取 C，每次都完成一個練畫圖。三次沒有取新紙，所以三次的新紙數都記 0。D 仍留在可用區，表示原本四張只取了三張，還有一張。

  1. 請大人讀第一列，你指出新紙數 0。
  2. 沿三列依序讀，核對是否每次都記錄。
  3. 把三張紙卡移到「已練畫」，看看還剩幾張。
  4. 用「這三次……」說結果，不說「以後永遠……」。

0 不是忘了寫，而是這次有查看，確認沒有取新紙。如果不知道用幾張，要標「還沒確認」，不能隨便寫 0。

一起學 04

兩種計畫，公平地比一比

要完成同樣的三次練畫，才能比較。

不用真的再拿三張新紙。我們先用紙卡表示兩種計畫，兩種都要完成三次練畫、每次需要一個空白面。

計畫甲：每次直接取一張新紙。三次會取三張新紙。

計畫乙：先查看剛才四張合適單面舊紙，三次各取一張。三次會取零張新紙。

在這個紙盒有足夠合適舊紙的示例裡，乙比甲少取三張新紙。這是兩種計畫的比較，不是某人比較乖的分數。

  1. 擺三個活動圈，每圈放一張代表新紙的卡，演計畫甲。
  2. 收起卡，再把 A、B、C 分別放入三圈，演計畫乙。
  3. 比的是「新紙」，不是把所有用過的紙都算成新紙。
  4. 說出乙能成功的條件：紙盒裡要有足夠且適合的空白面。

如果下一次只剩一張合適舊紙，還要完成三次練畫，就不能照抄「新紙 0」。先用那一張，再由成人協助準備另外兩個合適的空白面；可能要用新紙，應照實記錄。

給陪學大人：比較有條件

甲乙為桌面方案比較，不虛稱隨機對照實驗。兩個活動量相同，才可比較取新紙量。不可因此限制必要作業用紙，也不要說少三張就等於救了幾棵樹；本課沒有測量這些效果。

一起學 05

換你試一小回，留下真實結果

結果和猜的不同，也值得記下來。

請大人另準備兩張或三張可安全使用的練習紙，數量先不照故事規定。今天只實際練畫一次，畫一個自己選的簡單圖形；不要為了比較而故意浪費紙。

  1. 說出本次需要：一個清楚可畫的空白面。
  2. 和大人檢查可用紙；如有合適空白面就選它，沒有就請大人提供。
  3. 畫完後請自己檢查：圖形看得清楚嗎？紙是否適合這次用途？
  4. 在紀錄紙畫一個圈，旁邊記「新紙 0」或「新紙 1」，依實際發生寫。
  5. 用一句話說選擇理由，例如「這張背面空白，可以練畫」。

如果背面原來的深色圖透過來，看不清你的練習圖，這張紙對這次活動可能不合適。請大人一起換材料，誠實記錄調整。節省用紙仍要讓學習能完成，不用勉強畫在看不清楚的地方。

給陪學大人：支持不同操作方式

孩子可當決策者，請成人翻面、拿紙或依指示畫圖。提供大字紀錄與可辨識圖卡，不能只靠綠紅顏色分類。實作結果不用與範例一致；評量能否核對用途、選擇、記錄及解釋，而非誰取新紙最少。

一起學 06

用圖和一句話，做有用的提醒

提醒別人要清楚，不責備。

我們已用觀察找可用面，用數數讀紀錄，現在用圖畫和語句做提醒。提醒貼在練習紙盒旁就好，先經老師同意，不貼到別人的物品上。

可用的提醒

畫一張紙和翻面箭頭，配一句：「練畫前，先看看有沒有合適的空白面。」

下面加小小結果：「本課示例三次各用一張單面舊紙，新紙共用零張。」數字說清楚是哪個例子，不寫「我們全校從不浪費」。

  1. 選最想提醒的一步，不把整篇教案塞進圖裡。
  2. 讓同伴或成人看圖，請他說以為要做什麼。
  3. 若對方以為要把紙撕掉，修改箭頭或加「翻面看」的字。
  4. 把你的真實一次結果另放一格，和故事示例分開。

不寫「用新紙的人都不好」，因為有人為了清楚閱讀、特殊教材或任務要求，需要不同紙張。好的提議讓人知道可以怎麼做，也保留合理的需要。

給陪學大人：跨領域有共同目的

語文用來說明，數學用來核對數量，圖像用來傳達行動，生活探究用來試適用性。成人觀察各方法是否真的幫忙回答原問題，而非只在教案上羅列領域名稱。提醒圖不需張貼到公共網路。

一起學 07

新條件來了，辦法要跟著變

會探究，是會再問一次。

下一次任務換成寫給別人的正式感謝卡。老師說需要兩面都清楚、沒有其他文字的卡片。上次適合練畫的單面舊紙，這次不一定適合。小米先問用途，再選材料，沒有硬套舊答案。

  1. 大人給一個新條件：紙盒只有一張單面舊紙，或活動改成兩面圖卡。
  2. 你指出原來哪個條件變了。
  3. 決定要重新數量、重新分類，還是換合適材料。
  4. 說「我的辦法在……時適用」，例如有乾淨空白面、只需練畫一面時。

回想今天走過的路：問小問題、找線索、分一分和數一數、動手試、把結果說清楚。不是每次都會得到最初想要的答案；能用證據改變做法，才讓小建議變得可靠。

給陪學大人：短延伸即可

可用原有紙盒再試一次，不要求家庭做垃圾統計、拍垃圾桶或提供消費帳單。若無材料，以卡片模擬並清楚說是模擬。下堂課只檢查一項改變，例如提醒圖是否能被理解，不預先宣稱長期節省效果。

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1今天哪個問題能用課堂材料實際查一查？
給我一點提示

選範圍小、今天能動手核對的。

看答案與原因

參考答案：練畫三次，先找空白面後需拿幾張新紙

限定三次練畫的問題限定活動次數和材料，可以分類、試用並計數；另外兩個超出本課可取得資料。

2A、B、C、D 各有一個空白面，共幾張可用紙？
給我一點提示

每張紙只點一次。

看答案與原因

參考答案：4 張

四個字母各代表一張，不把同張的兩面算成兩張；可逐張指數。

3示例三次的新紙紀錄都是 0，表示什麼？
給我一點提示

看新紙欄，也讀旁邊的活動說明。

看答案與原因

參考答案：查看後確認三次都沒有拿新紙

紀錄說每次用一張單面舊紙並完成練畫，0 表示該次新紙的數量為零，不是漏記。

4原本四張可用舊紙，取走三張後剩幾張？
給我一點提示

留下的那一張字母是什麼？

看答案與原因

參考答案：1 張

四張中移走三張，還留一張 D；用紙卡移動就能核對。

5比較甲乙用紙，哪個條件應相同？
給我一點提示

要完成的工作是不是同樣多？

看答案與原因

參考答案：都完成三次、每次需要一個空白面

活動需求相同才可比較取新紙量；改變活動數或計算對象會失去原比較的意思。

6新情境只有一張合適舊紙，卻要練畫三次，應怎麼想？
給我一點提示

先用掉一張後，還有幾次要做？

看答案與原因

參考答案：重新查看還缺的兩個空白面怎麼準備

材料條件變了，需要重新準備並按實際用量記錄，不能硬套舊結果或取消必要學習。

7發現一張紙有別人的成績與名字，應怎麼做？
給我一點提示

節省材料也要保護別人的資料。

看答案與原因

參考答案：交大人確認，不當共用練畫紙

私人資料不適合作共用材料；本課使用經成人篩選、無個資的紙張。

8哪句提醒最符合這次研究？
給我一點提示

好的建議會說清楚怎麼做、何時適用。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

本課的統整主軸

以「三次練畫如何少取新紙」串連生活觀察、數量、口語說明及圖像設計，屬學校可選用的校訂探究示例。環境議題也可融入原有領域，這不是額外必修科目。範例六張紙與三次用紙紀錄為原創設定，教室另做的結果必須另記，不能偽裝成真實班級、全校或全國調查。

第 1 次：問題與分類，30 分鐘

0–6 分把大願望縮小為可操作問題，確認每次需一個空白面；6–18 分檢查六張示例卡並分類，成人先示範翻看兩面，一次只放一區；18–25 分核對四張加兩張仍為六張，加入一張不確定內容的口述情境但不改原數據；25–30 分孩子用「我猜」表達需要幾張新紙，並指出要查什麼。

第 2 次：讀資料與試做，30 分鐘

0–10 分讀三次示例紀錄，區分零張和未查；10–18 分用紙卡比較同樣三次練畫的甲乙計畫，不真的消耗三張新紙；18–27 分每人或每組實際做一次小練畫，記新紙使用數和是否清楚；27–30 分與原猜想比對。不要為了得到漂亮結果而暗示孩子記零，也不可因合理需求取新紙就責備。

第 3 次：提醒與條件改變，30 分鐘

0–12 分畫一個提醒圖及短句；12–20 分找同伴試讀並修圖；20–26 分把可用舊紙改成一張，或把用途換成兩面都需空白，檢查是否重新思考；26–30 分口述「什麼條件下這個方法可行」。圖卡、數字與口述可混用，不要求寫完整報告。

安全、隱私與材料

成人事前篩選安全無個資的乾淨紙，不使用成績單、醫療資料、姓名名冊或其他人的文件；不讓孩子翻垃圾桶或處理發霉、沾污、尖銳物。沒有合適紙時可完全使用畫出的紙卡，明示此時沒有真實用紙量測。課程不要求把家庭垃圾、收據或照片傳到網站。

誤解與差異化

只看正面就判不能用者，提供兩面對照；重複數同張者，用移動到另一區的方式一一對應；把總用紙量和新紙量混淆者，分兩欄用實物核對；認為零就是沒記者，示範先查再寫零。初學者先用三張卡和一次活動，較熟練者比較不同條件；不提前要求百分比、碳排或抽象環保標章。動作或感官需要協助者可指示成人操作、聽完整圖像描述或使用既有溝通方式，決策仍由孩子表達。

形成性評量
