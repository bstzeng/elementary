結合韻與拼讀

先讓ㄧㄚ、ㄨㄚ、ㄩㄢ成為一組，再接聲符。

把ㄧ和ㄚ靠近，聽成人讀牙；把ㄨ和ㄚ靠近，聽成人讀蛙。兩個符號一起工作，叫結合韻。今天從三組開始，不必背完整大表。

建議：分3–4次，每次20分鐘；每次2–3組結合韻即可。孩子可由大人陪讀

出發前

準備好了嗎？

這一課，我會練習

  • 能把ㄧㄚ、ㄨㄚ、ㄩㄝ各合讀為一組。
  • 知道結合韻不是把兩個字分開讀。
  • 能從家、花等字音找出後面的結合韻。
  • 能用熟字核對ㄧㄢ與ㄧㄤ，不任意亂拼。
陪學大人：準備材料
  • ㄧ、ㄨ、ㄩ與本課韻符卡
  • 牙、蛙、月、家、花、圓的字音卡
  • 三張大底紙與官方音節表

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

兩張卡，滑成一個音

聽牙ㄧㄚˊ，不分成衣和啊。

牙　ㄧㄚˊ
蛙　ㄨㄚ
月　ㄩㄝˋ

牙的ㄧㄚ、蛙的ㄨㄚ、月的ㄩㄝ，都是本課的結合韻。它們分別以ㄧ、ㄨ、ㄩ開始，和後面的韻符合在一起。

先聽完整的字，再把聲調另看。兩張卡不是兩個國字，也不是要念兩拍。

  1. 大人讀牙，孩子指ㄧㄚˊ。
  2. 大人讀蛙，孩子指ㄨㄚ。
  3. 大人讀月，孩子指ㄩㄝˋ。
  4. 先選最熟的一張跟讀，其餘可以只聽。
給大人的引導與觀察

用熟字提供整音模型，別把ㄩㄝ機械讀成獨立的ㄩ再加獨立的ㄝ。結合後的實際發音需以正確音節示範；字母加法僅表示組合，不保證逐音相加的聽感。

一起學 02

ㄧ帶來的結合韻

先練ㄧㄚ，再練ㄧㄠ。

牙　ㄧㄚˊ　　腰　ㄧㄠ
家　ㄐ＋ㄧㄚ → ㄐㄧㄚ
小　ㄒ＋ㄧㄠ＋ˇ → ㄒㄧㄠˇ

兩組都從ㄧ開始，後面的ㄚ、ㄠ不同。讀ㄧㄚ時不要自動滑成ㄧㄠ。先聽成人用牙和腰示範，再看符號。

  1. 成人讀牙或腰，孩子找卡。
  2. 只交換ㄚ、ㄠ，觀察整組改變。
  3. 把ㄐ放ㄧㄚ前，聽家。
  4. 小的讀音由成人示範，孩子找後面的ㄧㄠ。
給大人的引導與觀察

ㄧ類可逐步加入ㄧㄝ、ㄧㄡ、ㄧㄢ、ㄧㄣ、ㄧㄤ、ㄧㄥ，但這一頁不是一次精熟全部的要求。若ㄧㄚ與ㄧㄠ混淆，保留這一對，不要同時增加更多。讀音需看整體，不逐字母套英語音。

一起學 03

ㄨ帶來的結合韻

蛙和窩，後面不相同。

蛙　ㄨㄚ　　窩　ㄨㄛ
花　ㄏ＋ㄨㄚ → ㄏㄨㄚ
鍋　ㄍ＋ㄨㄛ → ㄍㄨㄛ

ㄨㄚ和ㄨㄛ都有ㄨ，最後一張不同。成人用自然字音示範，你先指出ㄚ或ㄛ，再把整組讀出來。

同一組結合韻可以和合適的聲符相拼，但不是每張聲符都能配。今天只用花、鍋這兩個已核對的例子。

  1. 蛙卡和窩卡並排，聽音選卡。
  2. 花中圈出後面的ㄨㄚ。
  3. 鍋中圈出後面的ㄨㄛ。
  4. 將聲符與結合韻兩組卡推近，各合讀一次。
給大人的引導與觀察

避免把ㄨㄛ寫成ㄨㄡ，也不以國字相似猜音。延伸可選ㄨㄞ、ㄨㄟ、ㄨㄢ、ㄨㄣ、ㄨㄤ、ㄨㄥ的有效音節，每次需先查手冊；特別是ㄨㄥ的實際讀音受聲母條件影響，不直接用英語近似音代替。

一起學 04

ㄩ帶來的結合韻

月和圓，保留前面的ㄩ。

月　ㄩㄝˋ　　圓　ㄩㄢˊ
雪　ㄒ＋ㄩㄝ＋ˇ → ㄒㄩㄝˇ
圈　ㄑ＋ㄩㄢ → ㄑㄩㄢ

先聽成人讀月、圓，找到ㄩㄝ和ㄩㄢ。再看雪和圈：前面多一個聲符，後面仍保留ㄩ。

嘴形可以觀察，但不需要用手推拉嘴巴，也不用把聲音喊大。讀不清楚可以先指卡。

  1. 從ㄨ、ㄩ中選出本組要用的ㄩ。
  2. 分別接ㄝ、ㄢ。
  3. 跟成人讀月、圓。
  4. 看圈的ㄑㄩㄢ，確認沒有漏掉ㄩ。
給大人的引導與觀察

ㄩㄢ的實際元音不能照獨立ㄢ的音色生硬相加；成人示範整音最重要。注音中ㄐㄑㄒ後仍寫ㄩ，不套用漢語拼音省略ü上兩點的規則。圈在這裡讀圓圈的ㄑㄩㄢ。

一起學 05

鼻音尾巴慢慢聽

先看煙和羊，再聽最後不同。

煙　ㄧㄢ　　羊　ㄧㄤˊ
先　ㄒㄧㄢ　　香　ㄒㄧㄤ

ㄧㄢ和ㄧㄤ只差最後一張符號。先看清ㄢ、ㄤ，再由成人說「先、香」，兩個都是一聲，較容易專心聽後面的差別。

不熟悉煙的字義時，成人簡單說明它是燃燒等情況產生的煙霧；不用接觸火或煙來做活動。

  1. 先、香兩張卡並排。
  2. 成人各讀一次，再選一個重讀。
  3. 孩子指卡，說出或指出最後的ㄢ或ㄤ。
  4. 最後回看煙、羊，找同樣的結合韻。
給大人的引導與觀察

不以兩詞聲調不同的差別取代韻尾辨別，所以另用先／香同調對比。音近辨別可分多日；家庭語音差異以尊重方式處理，不把口音評為不努力。若成人自己無法穩定區分，先使用字典或教師模型。

一起學 06

結合韻拼圖站

先放一整組，再接前面的卡。

  1. 底紙放ㄧㄚ、ㄨㄚ、ㄩㄢ三組。
  2. 成人拿家、花、圈的整卡，讀一個。
  3. 孩子先選後面的結合韻。
  4. 再選前面的ㄐ、ㄏ或ㄑ。
  5. 把卡推近，成人核對後合讀。
  6. 最後拆掉聲符，孩子仍要能指出原來的結合韻。

完成後交換角色，讓成人故意漏一張介符，孩子用正確模型指出哪裡少了。只改一個錯誤，再讀正確版本。

如果三組太多，今天只保留家和花；讀熟了再加圈。

給大人的引導與觀察

活動同時看結合韻辨認與聲符連接，但紀錄分開。能找到ㄩㄢ卻讀不出圈，不代表未懂結合韻。材料文字要清楚，每組保留空白，不把顏色當唯一提示。熟練者找書中的已學結合韻，不自己發明不存在的組合。

一起學 07

每天帶走一組

從花裡找ㄨㄚ，放回句子讀。

小花開了。

成人先讀句子，你找花的ㄨㄚ。再讀「花」或「小花」，不必整句一次讀完。

今天選一組最熟的結合韻。畫一個相關物品，旁邊由成人寫正確注音；明天蓋住畫，看看還能認得嗎？

  1. 選ㄧㄚ、ㄨㄚ或ㄩㄢ。
  2. 在本課例字中找同一組。
  3. 用手指把整組圈起來。
  4. 聽一次、讀一次、說一個意思。

由成人查教育部音節表；表中的空格不代表可以隨意補造字音。

給大人的引導與觀察

官方音節表列有國音缺音與缺字的區別，兒童不需要背，但成人備課不可把所有表格交叉組合當成有效音節。本課採常見例字；延伸查驗後才添加。以每次一組生活運用收尾，避免只記卡片位置。

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1牙ㄧㄚˊ中的結合韻是哪個？
給我一點提示

先看牙的前兩個符號。

看答案與原因

參考答案：ㄧㄚ

牙中的結合韻是ㄧㄚ，ˊ則是另外的二聲記號。

2ㄏ接上ㄨㄚ，會成哪個字音？
給我一點提示

第一個符號必須是ㄏ。

看答案與原因

參考答案：花ㄏㄨㄚ

ㄏ加ㄨㄚ合讀ㄏㄨㄚ，是花；ㄨㄚ要保留成一組。

3「月」使用哪組結合韻？
給我一點提示

月和雪有同一組結合韻。

看答案與原因

參考答案：ㄩㄝ

月標作ㄩㄝˋ，結合韻是ㄩㄝ，另有四聲。

4圈ㄑㄩㄢ中，哪個符號不能漏？
給我一點提示

看完整的正確模型。

看答案與原因

參考答案：中間的ㄩ

圓圈的圈寫ㄑㄩㄢ，中間ㄩ須保留，不套別種拼音寫法。

5先ㄒㄧㄢ與香ㄒㄧㄤ，差在哪張？
給我一點提示

從最後一張比較。

看答案與原因

參考答案：ㄢ與ㄤ

兩字的前面ㄒㄧ相同，最後的ㄢ與ㄤ不同，讀音也不同。

6讀結合韻時，較合適的做法是？
給我一點提示

牙是一個字音。

看答案與原因

參考答案：跟整音示範，合成一組

結合韻要合成一組，成人以熟字整音示範可以幫忙。

7「鍋ㄍㄨㄛ」後面是哪個？
給我一點提示

跟窩的結合韻相同。

看答案與原因

參考答案：ㄨㄛ

鍋的後面是ㄨㄛ，最後是ㄛ，不是ㄡ。

8想增加新的拼合，應怎麼做？
給我一點提示

官方表格也有空格。

看答案與原因

參考答案：請成人先核對有效音節和例字

並非每種任意組合都有國語字音，需先由成人查官方音節表。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

範圍與先備

本課對應Aa-I-4，連結Aa-I-3。先認ㄧㄨㄩ與ㄚㄛㄝㄢ等符號，再由整體熟字建立結合韻。成人需理解「介符加韻符」是書面結構，實際音色可能因結合改變，不能用每個符號的獨讀音生硬相加。目標不是一節背完所有結合韻表。

每次20分鐘的安排

  1. 第一次只教ㄧㄚ、ㄨㄚ：3分鐘聽牙蛙，5分鐘指卡，5分鐘拆合，5分鐘家花拼合，2分鐘指出共同部分。
  2. 第二次教ㄩㄝ、ㄩㄢ：5分鐘月圓整音，5分鐘符號排序，6分鐘雪圈找結合韻，4分鐘個別回應。
  3. 第三次比較ㄧㄚ與ㄧㄠ，或ㄨㄚ與ㄨㄛ，依前測二選一；保留一組熟例，逐步退除成人指卡。
  4. 第四次視需要比較先／香，完成拼圖站並回到短句。若仍混淆，只回顧，不新增結合韻。

需要明確避免的誤教

注音ㄐㄑㄒ後的ㄩ必須保留，不把漢語拼音的ü或y、w規則搬過來。ㄧㄢ、ㄩㄢ等音節的整體讀法用官方字音或教師示範；不宣稱每個符號都保持獨讀時完全相同的音值。符號兩張只代表一個結合韻，非兩個字。官方音節表有空位，不任意把聲符與韻符交叉組成練習題。

分層、回饋與評量

起步以兩張完整字音卡聽辨，不急著拆；一般組能把結合韻兩卡放一起，再接聲符；進展組在新排版的熟字中指出同一結合韻並說明哪張換了。若漏介符，將兩卡固定同底紙；若符號看對卻讀錯，回聽整個例字；若同音近音混淆，每回只比較一對、先採同調例詞。大聲齊讀不能取代個別檢查，成人應每次至少聽每名孩子讀一組。

視覺、動作與口語支持可分別使用大字、高對比、成人移卡或指認答案；音韻辨別需求者延長等待、重播一致模型，必要時與教師討論既有支持，不自行診斷。評量記「辨出ㄨㄚ」「能接ㄏ」「讀花有無漏音」三項，網頁測驗只是其中一小部分。家中從熟書找一組即可，不要求抄寫滿頁或錄音傳送。
