提問、回答與看圖說話

先說看見的，再問想知道的；猜想要說「我猜」。

小青在花圃做什麼？先慢慢看圖，找一個確定看見的東西。接著問一個想知道的問題。看不到的原因，可以猜，但要告訴聽眾那是猜想。

建議：2–3次，每次25分鐘。孩子可由大人陪讀

出發前

準備好了嗎？

這一課，我會練習

  • 能從圖中指出人物、地點線索與動作。
  • 能用誰、哪裡、什麼提出一個清楚問題。
  • 能回答與問題相關的資訊。
  • 能把圖中可見事實與自己的推測分開。
陪學大人：準備材料
  • 本頁原創花圃情境圖或對應物品卡
  • 誰、哪裡、什麼、為什麼四張問句卡
  • 三格紙與鉛筆

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

眼睛慢慢走過圖

先指小青，再找她拿的東西。

從左到右看看：長椅、紅帽子、小青、水壺、花、樹和鳥。先不用編故事，指出兩樣你確定看見的東西。

圖中沒有畫出的一面，我們還不知道。例如小青的家在哪裡，不能只憑這張圖確定。

給大人的引導與觀察

成人可讀svg圖像說明或用觸摸物品卡支援低視能孩子。圖中文字只標小青，不以衣著或外貌推論性格、家庭或身分。第一輪問可見物件，確認孩子理解圖示水壺與水滴。

一起學 02

誰、在哪裡、做什麼

把三個線索接成一句。

誰？小青。
在哪裡？花圃旁。
做什麼？用水壺澆花。
小青在花圃旁用水壺澆花。

  1. 先指出人物。
  2. 沿著她的手，找到水壺。
  3. 看水壺口旁的水滴和花。
  4. 先說「小青澆花」，再自願加地點。

可以先說短句，不必一口氣記全部。成人聽不懂時，指回圖中對應的位置，再補一點。

同一張圖可以說「椅子上有紅帽子」，不一定每句都說人物。

給大人的引導與觀察

「花圃旁」由圖中花與情境設定支持；圖中活動明確標示為澆花，不另設模稜兩可的正答。提供人物動作句與存在句，避免把誰在哪裡做什麼變成所有句子的唯一規定。

一起學 03

問得清楚，才容易回答

一次先問一件事。

「誰在澆花？」
「紅帽子在哪裡？」
「小青手上拿什麼？」

問誰，就想知道人物；問哪裡，就想知道位置；問什麼，就看後面是在問物品還是事情。

「那個呢？」常讓人不知道你想問哪一個。可以把那個換成紅帽子，變成「紅帽子在哪裡？」

  1. 選一張問句卡。
  2. 指一個圖中物品或人物。
  3. 把問題說完整或請成人代讀。
  4. 同伴回答後，一起指圖核對。
給大人的引導與觀察

起步可用句架與二選一，不一口氣問「誰在哪裡為什麼怎麼做」。疑問詞的用途由具體問題示範，避免抽象詞類解釋。孩子口語詞序不同但意思明確時，先回應再自然示範完整句。

一起學 04

回答要接住問題

問在哪裡，就回答位置。

問：「紅帽子在哪裡？」
答：「在長椅上。」
問：「誰在澆花？」
答：「小青。」

回答可以很短，只要讓意思清楚。問帽子在哪裡時，只說「紅色」雖然是真的，卻還沒有回答位置。

如果沒聽清楚對方問誰或哪裡，可以說「請再問一次」，不必急著猜。

  1. 成人問位置，孩子在圖上指位置。
  2. 成人換問人物，孩子指小青。
  3. 把紅色和長椅上兩個回答比較，找哪個切題。
  4. 孩子自己問一次，成人示範切題回答。
給大人的引導與觀察

不要把完整句當所有短答的必要條件。確定問題焦點後才練擴充；若孩子只重複問句，提供圖卡選擇與關鍵詞，而非連續催答。評量提問和回答分開。

一起學 05

看到的、猜到的，分兩邊

說原因前，看看圖真的告訴了嗎。

看得到：「小青拿水壺。」
我猜：「她可能想讓花得到水。」
不知道：「她今天幾點來的？」

圖能顯示動作，卻不一定能直接告訴心裡的想法。你可以根據澆花猜原因，但說「我猜」或「可能」。

椅子上有紅帽子，不代表一定是小青的；圖沒有說主人，可以提出問題。

  1. 把小青拿水壺放看到區。
  2. 把小青喜歡花放猜想區。
  3. 問帽子是誰的，放待確認區。
  4. 為一個猜想說出圖中線索。
給大人的引導與觀察

學習區分證據與推論，不消滅想像。只要孩子明示是創作，就可編帽子的主人；但閱讀理解問「圖中能確定什麼」時需回證據。避免用笑容推斷人物一定開心等過度確定表述。

一起學 06

你問我答小工作坊

每人問一題，再換角色。

  1. 甲選圖中一個可見物件，先不說答案。
  2. 甲用誰、哪裡或什麼問一題。
  3. 乙先聽完，再說或指答案。
  4. 兩人一起指圖核對。
  5. 交換角色，用另一個疑問詞。
  6. 最後各編一個有「我猜」的句子，說它的線索。

可以讓成人先當提問者，孩子只負責找圖。熟了再讓孩子選問句。

若兩人答法不同，先問是否指同一個位置或物件；用圖確認，不靠誰聲音大。

給大人的引導與觀察

起步：兩個問句選一；一般：自主問一題並切題答；延伸：連問兩個相關問題、分可確定與不可確定。指圖、輔具或成人代讀皆可。每回合短而明確，不要同時要求寫問句和朗讀全部。

一起學 07

我的三句看圖話

兩句看見的，再加一句清楚標示的想像。

「小青在澆花。紅帽子放在長椅上。我猜她等一下會坐下休息。」

前兩句有圖中線索；最後一句是可能發生的事，不是圖已經畫出的事。你也可以只說前兩句。

請聽眾說回哪句看得到、哪句是猜想。如果分不清，再加上「我猜」讓意思清楚。

  1. 選兩個圖中確定線索。
  2. 各說一句，成人可代記。
  3. 自願加一句想像。
  4. 回圖核對兩句事實，不把猜想改標成確定。
給大人的引導與觀察

成果保留口述、指圖或成人代寫即可；圖畫華麗程度與字寫多少不影響語言目標。家庭延伸可用自己的物品照但不必上傳，避免選含他人個資、車牌或住址的影像。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1原創圖中，小青正在做什麼？
給我一點提示

看小青手上的水壺。

看答案與原因

參考答案：澆花

水壺、水滴和花一起提供線索，圖中的小青正在澆花。

2「紅帽子在哪裡？」哪個回答切題？
給我一點提示

哪裡是在問位置。

看答案與原因

參考答案：在長椅上

問題問位置，在長椅上回答了位置，紅色只說顏色。

3想知道澆花的人，該問？
給我一點提示

要找人的問句。

看答案與原因

參考答案：誰在澆花？

誰用來詢問人物，所以誰在澆花能得到小青這個答案。

4哪句是圖中可確定的？
給我一點提示

找畫面直接顯示的內容。

看答案與原因

參考答案：長椅上有紅帽子

圖中直接畫出長椅上的紅帽，沒有提供每天或所有權的資訊。

5小青等一下會休息，應怎麼說？
給我一點提示

加上表示不確定的詞。

看答案與原因

參考答案：我猜她等一下可能休息

未來動作沒有在圖中確定提供，應把它清楚說成猜想。

6沒有看清圖，可以怎麼參與？
給我一點提示

可以換一種方式取得線索。

看答案與原因

參考答案：請成人讀圖像說明或提供物品卡

圖像說明和物品卡可提供可及的線索，仍能練提問與回答。

7「那個呢？」不清楚時，怎麼改較好？
給我一點提示

把不清楚的指稱換成物品名稱。

看答案與原因

參考答案：紅帽子在哪裡？

指出紅帽子並說明想問的位置，讓聽眾知道問題焦點。

8圖有說紅帽子的主人嗎？
給我一點提示

位置和所有者是不同資訊。

看答案與原因

參考答案：沒有，還需要確認

圖只畫帽子位置，沒有指出主人，不能憑靠近誰就下定論。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

定位與閱讀負荷

連結2-Ⅰ-2、2-Ⅰ-3及圖像支持理解的方向。原創圖提供一個穩定且可核對的情境：小青拿壺澆花、椅上紅帽、樹上鳥。成人先讀圖像說明或提供實物圖卡，避免視力、圖示辨識或識字差異遮住提問能力。

教學進程

  1. 第一次25分鐘：5分鐘找可見物，6分鐘誰與動作，6分鐘句架組句，5分鐘位置問答，3分鐘一題離堂。
  2. 第二次25分鐘：5分鐘回顧疑問詞，7分鐘切題回答，6分鐘看到／猜到／未知分類，5分鐘雙人互問，2分鐘指出證據。
  3. 第三次可選20分鐘：三句看圖話、聽眾重述、修正一個不清楚問題；保留自選是否加入想像。

提問與推論的教學

疑問詞要在具體情境中學，不要求背定義。問紅帽位置，紅色不是切題答案；問誰澆花，小青一詞就是足夠回應。教孩子由水壺與水滴推知澆花，但對動機、帽子主人與未來事件保持「我猜、可能、還不知道」等表述。創作可以超出圖片，只要不把創作當已知事實。

分層支持與錯誤對應

起步用兩個物品卡、一個問題句架，允許指認；一般組自問自答或同伴互答，再補一個地點；延伸組比較問物品與問原因，為推想提出線索。把那個說不清楚時，請他先指再命名；總答顏色時，突出「哪裡」並提供位置選項；把猜想說成事實時，回圖找證據，找不到就加我猜，不責怪想像豐富。

每次只糾正一個可改進處，避免同時改發音、語法、眼神和姿勢。聽覺、口語或動作支持需求者依既有方式回應，成人可以移動問句卡。避免用人物外觀推論情緒或私事，也不要求孩子上傳生活照片。

評量紀錄

保留一個孩子提出的問題、一個切題答案及一個證據／猜想判斷。網頁題可成人代讀，將看圖與文字解碼分開。能重述成人例句只是起點；改問紅帽、鳥等另一處，確認可遷移。若仍困難，下次保留相同圖，只換疑問詞，不急著換複雜新場景。
