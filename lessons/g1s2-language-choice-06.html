一起學 01

替換的不是任意一格，而是已核實的訊息

先知道換了什麼，再確認新的模型也成立。

本課只供口語類：臺灣台語、四縣腔客語、部編馬祖閩東語、秀姑巒阿美語、越南語。臺灣手語不做發音或拼音替換練習，請進第08–09主題。

上學期跟過一句完整模型，這次要聽出兩個已核模型差在哪裡，依新情境選對，再接合適回應。替換有兩種安全做法：同一問句換不同已學的短詞回答；或者在兩個已核完整句之間選擇。不是拿新詞隨便填空，更不是把單字音黏成新句。

教師協助模型條件：文字與意思或官方索引已核，不代表所有聲音／影片已完整聽看驗收。口語由具該語能力教師確認完整原音與自然示範；臺灣手語須確認完整起迄、臉和雙手及正確形式。沒有可用完整模型，先做情境理解，語言產出欄待補，不用諧音、合成音或單詞剪接替代。

模型白名單

每條路線只用本頁列出的完整模型及已核詞。孩子提出新說法時，先把意思畫出來，請教師另行確認；未確認的完整句不放進自動答案，也不要求猜讀。

一起學 02

先做一次：問題不變，答案跟著物品變

換的是要傳的資訊，不是圖卡座位。

成人拿兩張大卡，一張畫書，一張畫水杯。第一回合呈現書，再用臺灣台語路線的完整命名問句；接收者答已教的書詞。第二回合呈現水杯裡的水，仍用同一問題；答覆要跟著所指換成水詞。其他語別用各自後文核實模型進行，不翻譯這個台語問句當共同模板。

  1. 先展示完整範例，指出問句的功能是要知道名稱。
  2. 再讓孩子指出哪一部分保持、哪一部分改變。
  3. 把圖放到不同位置，去掉原來的空間線索。
  4. 孩子先選意思，再用核實短詞或整句回應。
  5. 伙伴用圖回指，檢查是否真的接收到新內容。

原創錯例：圖已換水，回答者還背「冊」。即使詞音正確，意思也沒有接上，需要先看所指物，不是再背問句十遍。相反地，選對水圖但發音要跟教師，表示理解有進展、口語產出仍需支持。

小一不用先背語法名詞，成人可用「不變的地方／這次改了什麼」來說明。完整句中的自然語塊由語言教師決定，不按漢字字數或羅馬字空格任意切音。

一起學 03

路線A：臺灣台語，同一問句配兩個短答

這是什麼，要看眼前共同指的物。

這詞目完整用例：這是啥物物件？，Tse sī siánn-mih mi̍h-kiānn?，中文是這是什麼東西。回答限兩個已核詞：冊 tsheh＝書與水，白讀tsuí。本課用短詞回答命名問題，不在前面自加未核整句。

  1. 先學整個問句的功能，不逐字拼音。
  2. 看書圖時問，伙伴答冊；看水圖時問，伙伴答水。
  3. 兩圖位置交換，提問者每回先確定共同所指，不用眼神暗示答案。
  4. 接收者答後，由提問者指出對應圖作確認；答不相干詞時重看所指物。
  5. 孩子自己選要問哪一張，伙伴不用背固定順序。

水採814白讀，不用815文讀suí替代。冊和水都是整詞，不加未核數量、容器或所有權。用水杯圖時成人要明確指「裡面的水」，不是把水壺和水的詞義混同。能短答不代表已會所有指示句。

一起學 04

路線B：四縣腔客語，比較兩個完整請求

先知道問的是哪件事，才選回應。

校園篇印刷8已核做得先講無？zo dedˋ xienˊ gongˋ moˇ，意思可以先說嗎；印刷11已核𠊎做得去便所無？，意思我可以去上廁所嗎。兩句都要完整學，不是從第一句自行刪接出第二句。已核回應「做得。」見印刷13。

這一回把「要先發言」和「紙偶需要如廁」兩張明確情境作比較。共同部分可以幫助注意，但不能省略完整句。前者是回合安排，後者是基本需要，成人不能用拒絕基本需求來製造問答刺激。

  1. 教師完整讀其中一句，孩子選符合情境。
  2. 指出哪個句子提到發言，哪個提到如廁。
  3. 抽一情境，孩子選用對應完整模型；伙伴以做得回應並配對下一步。
  4. 換情境但不加新動詞，再演一次。

先說話仍需確認輪流安排；如廁真需要時立即接收任何可理解表達，不考背誦。配套音只選四縣；本課不是教「所有詞都能放進做得…無」的普遍造句規則。

一起學 05

路線C：馬祖閩東語，比較兩個原課描述

整個模型換一張，不自行把詞剪貼。

第1冊第8課下冊印刷28已核兩個原短語：紅紅的蘋果／黃黃的黃梨；官方中文對照分別描述紅蘋果與黃鳳梨。這次不只是認顏色，而是注意顏色和物品都要符合整個語段。

成人準備紅蘋果、黃鳳梨、紅帽三張帶華語標籤的大圖。先完整聽兩原語段，孩子配圖；再讓伙伴用已有可接收方式詢問「是哪張」，孩子選用其中一個核實描述回應。這個支架問題不冒充本站已核馬祖語問句；需目標語全問答時，由教師先提供核實完整提問。

  1. 先聽完整模型，選符合兩項資訊的圖。
  2. 比較兩原語段，不自行把蘋果替換成黃梨外的新詞。
  3. 抽圖後用對應整段回應，伙伴展示圖確認。
  4. 遇到紅帽圖，知道不在白名單，先以圖示或既有方式回應，不編新片語。

課內拼音不是獨立詞音表，聲音未聽驗，由馬祖語教師核對原完整示範。兩個官方短語是可比較的既有模型，不據此推出所有顏色和名詞都能同樣排列，完整新組合仍需核實。

一起學 06

路線D：秀姑巒阿美語，兩個問句改了食物

兩個版本都有來源，才列入練習。

官方生活會話d=2、theme6、season2第19句Mangalay kiso to mami^ haw?意思你要吃橘子嗎；第21句Mangalay kiso to piyang haw?意思你要吃餅乾嗎。這兩個完整句各自都已核實，不是作者只會一個句框後猜第二句。

本學期第04主題練過餅乾來回，現在加入另一個已核問句，聽懂到底邀請什麼。第22句Hay, maolah kako.是餅乾問句的原相鄰回答；橘子版本不機械套同一回答，孩子可用選擇卡，或由教師核實適當完整回應。

  1. 完整聽一問，找橘子或餅乾圖。
  2. 比較兩句哪個食物訊息改了，不拆音拼接。
  3. 提問者抽圖，主動選用對應完整問句。
  4. 接收者依虛構角色意願回應，可拒選；提出者確認。
  5. 拿西瓜圖作邊界例，知道本課沒核實該新句，先請教師查核。

不吃任何食物，不解釋過敏或疾病。mami^保留這套會話舊版寫法，與另一句型教材mami’不可擅自互換；現行書寫若需更新由教師核對公告及模型，不讓小一猜符號。

一起學 07

路線F：越南語，從完整例句看活動替換

三句都核實，但新活動仍要再確認。

國教署第4冊印刷36／PDF38「換一換念一念」明列Em thích chơi đàn piano.／Em thích đá bóng.／Em thích chạy bộ.，分別是我喜歡彈鋼琴、踢球、跑步。三句都來自同一明示替換練習；本課跨冊少量取句，不要求孩子實際會這些活動。

  1. 成人畫鍵盤、球、跑步紙偶三圖並標華語活動名，先確認意思。
  2. 聽教師核對的完整句，選活動圖，換圖位置。
  3. 比較保持的喜好功能與改變的活動內容，不把chơi認成每項活動都必須有的詞。
  4. 孩子選虛構角色的喜好卡，從三個原完整句選一個回答教師的可接收提問。
  5. 伙伴選圖核對，角色可選不分享；不把固定課文偏好當孩子自己的承諾。

本頁未提供匹配這三句的完整越南語提問模型；若評目標語全問答，教師先核實合適稱呼和問句。支架提問可用已會方式，只記回答整句能力。不能直接將新活動名稱塞進句子，也不把Em的稱呼適用範圍推成所有人際場合。

一起學 08

獨立轉移：先選意思，再從模型中選句

遇到白名單外的新句，知道停下來確認。

成人先給兩張本路線熟悉圖，再給一張尚無完整模型的新圖。孩子要做的不是全部硬說，而是把「本課已有核實模型」和「想說、還要查核」分開。台語可用命名問句加已核詞回答；四縣、阿美語在指定完整問句間選；馬祖、越南語選原完整描述或喜好句。

  1. 第一輪由成人完整示範，孩子說明意思。
  2. 第二輪抽新順序圖，孩子自行選模型，伙伴配圖核對。
  3. 第三輪加白名單外圖，孩子以既有方式表達意思並提出需要老師確認。
  4. 若答了不相干內容，先重建問題功能與所指，不能只要求發音變大。
  5. 最後各選一個還需支持的模型，說明下一次要再聽哪裡。

成功是能根據意思選用、等回應及修補，不是把相同句框念最快。理解、跟說、獨立情境使用、知道模型邊界四欄可不同；不要求抄滿拼音或上傳聲音。

練習選用：共同情境與策略題可供大家練習；特定語別詞義題只作可選查閱，僅評自己選習且已教的路線，不要求完成六語，也不以混合題總分代表語言熟練。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

口語類範圍與進展

此課承接上學期完整短句及本學期需求互動，新增受控替換、語意核對和未核句辨識。臺灣手語不參加發音或拼音項目。替換並不代表一個句框可任意擴張：台語同一問句配不同已核短詞；四縣兩個完整請求；馬祖兩原描述；秀姑巒兩個官方問句；越南三個官方替換例。每個變體必須獨立有來源或教師核對。

課前核對

兩節流程

第一節40分鐘：5分鐘說明白名單；8分鐘問句不變短答改變示範；12分鐘本路線兩／三模型完整理解；10分鐘配圖比較變與不變；5分鐘記錄。第二節40分鐘：8分鐘換順序聽辨；12分鐘孩子選圖選句和伙伴核對；10分鐘白名單外新圖，練提出查核；5分鐘錯誤修補；5分鐘自評。不用空白句讓初學孩子猜語法，先完整聽懂兩句。

差異化與回饋

起步者只用兩模型及兩圖，允許跟完整示範；熟練者換伙伴和圖順序，對未核新句說明意思但不硬造。孩子答對音卻配錯圖，先補語意；配對正確但口語不自然，由語言教師示範一項重點再回整句。不要以速度、音量或字數判能力，不嘲笑家庭口音。拼音只供核對，非小一全部默寫目標。

評量及安全

各路線至少兩回完整模型選圖、一回適合情境的表達、一回伙伴確認、一項白名單外辨識。馬祖／越南沒有核實提問時，只記完整答句或描述，不記全目標語問答。全程紙圖，不跑跳、不飲食、不延遲基本需要，亦無真實姓名／家庭要求。所有學生可代虛構角色說喜好，避免強迫承諾；沒有音訊與具能力教師時，理解情境可先做，發音或整句產出待補。

共同概念題與各語詞義題分開選用，只評選習且已教路線，不要求全部語別；自動題總分不作語言熟練指標，實際理解及產出另記。
