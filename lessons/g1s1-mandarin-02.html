聲符、韻符與介符

看看每個符號在字音裡做什麼，再把聲音接起來。

符號可以一起幫國字標出聲音。今天先看「媽、家、衣」。大人讀，你指卡；先認識它們的工作，不必一次背完整張分類表。

建議：分3次，每次20–25分鐘；先熟悉本課例字所用符號。孩子可由大人陪讀

課綱主題採跨版本參考編排。教材為本站原創示例，依學生起點分次學習，不代表全國統一進度或特定教科書。

出發前

準備好了嗎？

這一課，我會練習

  • 能指出ㄇ、ㄅ、ㄐ屬於聲符。
  • 能認出ㄚ、ㄠ等韻符與ㄧ、ㄨ、ㄩ三個介符。
  • 在ㄐㄧㄚ中指出ㄧ的位置，知道不是每個字音都用三個符號。
  • 知道ㄧ、ㄨ、ㄩ也能單獨為國字標音。
陪學大人：準備材料
  • ㄇ、ㄅ、ㄐ、ㄨ、ㄧ、ㄩ、ㄚ、ㄠ的符號卡
  • 三張分類底紙與兩張空白卡
  • 教育部注音符號手冊，由成人操作

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

先聽熟悉的字

聽「媽」，再指ㄇㄚ。

媽　ㄇㄚ　　家　ㄐㄧㄚ　　衣　ㄧ

請大人慢慢讀三個字。用一根手指指向整組注音，不把「家」說成三個字。

數一數：媽有兩個符號，家有三個，衣有一個。字音可能用不同數目的符號標出，聲調記號另外看。

  1. 先聽大人讀「媽」。
  2. 在三張字卡中指出「媽」。
  3. 找出它的第一個符號ㄇ。
  4. 換到「家」，找出第一個符號ㄐ。
給大人的引導與觀察

先以熟悉口語建立整個音節，再拆符號。分類前若孩子仍不認得ㄇ或ㄚ，退回兩張卡認讀，不要求同時記住術語。數符號只用來看構造，並非讓孩子逐個斷開讀音。

一起學 02

聲符：看看音節的開頭

找ㄇ、ㄅ、ㄐ，放在同一邊。

本課先認三個聲符：ㄇ、ㄅ、ㄐ。它們出現在「媽ㄇㄚ、八ㄅㄚ、家ㄐㄧㄚ」的前面。

常用聲符共有21個；總覽用來查找，今天不必全背。

ㄅ ㄆ ㄇ ㄈ／ㄉ ㄊ ㄋ ㄌ／ㄍ ㄎ ㄏ／ㄐ ㄑ ㄒ／ㄓ ㄔ ㄕ ㄖ／ㄗ ㄘ ㄙ

  1. 把ㄇ和ㄚ並排。指出ㄇ。
  2. 把ㄅ換到前面，聽大人讀ㄅㄚ。
  3. 比較：前面的聲符換了，完整字音也變了。
給大人的引導與觀察

聲符的獨立教學音與實際拼合時的聲音要區分，不把「波ㄅㄛ」等同ㄅ。聲符能否搭配需查實際音節，不能任意排列。ㄓㄔㄕㄖㄗㄘㄙ有單符號標字音的情況，本課不宣稱聲符一律不能單獨標音。

回到本課開頭 ↑
一起學 03

韻符：接著看ㄚ和ㄠ

找出ㄇㄚ裡的ㄚ。

媽　ㄇ＋ㄚ → ㄇㄚ
貓　ㄇ＋ㄠ → ㄇㄠ

兩個字都從ㄇ開始，後面的符號不同。跟著大人把整個字音讀出來，聽「媽」和「貓」哪裡不同。

先認ㄚ、ㄠ。常見的這一組韻符還有ㄛ、ㄜ、ㄝ、ㄞ、ㄟ、ㄡ、ㄢ、ㄣ、ㄤ、ㄥ、ㄦ。

  1. 成人說「貓」，你選ㄇㄠ卡。
  2. 把ㄇ保留，只換後面的卡。
  3. 讀完配對熟悉的字義：媽媽的媽、小貓的貓。
給大人的引導與觀察

課程為教學便利分聲符、韻符、介符；教育部手冊的韻符表也收錄ㄧㄨㄩ。不要說官方只承認13個韻符，更不要把分類理解為每個符號只有一種語音功能。孩子只需先指出本組符號的位置。

一起學 04

三位介符朋友

指一指：ㄧ、ㄨ、ㄩ。

家　ㄐ＋ㄧ＋ㄚ → ㄐㄧㄚ
瓜　ㄍ＋ㄨ＋ㄚ → ㄍㄨㄚ
圈　ㄑ＋ㄩ＋ㄢ → ㄑㄩㄢ

ㄧ、ㄨ、ㄩ叫介符。在這三個例子裡，它們站在聲符和後面的韻符之間。把手指從前面滑到後面，跟著大人讀成一個字音。

今天可先只看「家」。把ㄐ放左邊、ㄧ放中間、ㄚ放右邊，再一起讀。

  1. 指第一張ㄐ。
  2. 指中間的ㄧ。
  3. 指最後的ㄚ。
  4. 把三張卡推近，聽完整的ㄐㄧㄚ。
給大人的引導與觀察

「圈」在此指定圓圈的圈，讀ㄑㄩㄢ，不涉及其他讀音。介音的語音定義見教育部辭典「介音」；此處只讓孩子建立位置感，不講發音器官術語，也不把分卡活動讀成三拍。

一起學 05

ㄧㄨㄩ不一定站中間

看「衣、屋、魚」，每個只有一張卡。

衣　ㄧ　　屋　ㄨ　　魚　ㄩˊ

這三個字不用先加一個聲符。ㄧ、ㄨ、ㄩ可以自己標出字音，再配上需要的聲調。

再看「牙ㄧㄚˊ」：有ㄧ和ㄚ，前面也沒有聲符。符號少一點，不表示少寫了東西。

  1. 拿出衣、屋、魚三張字卡。
  2. 成人讀一個，你指一個。
  3. 看ㄧ在「衣」和「家」裡的位置有什麼不同。
  4. 把魚的二聲記號另放一張小卡，知道它不是新介符。
給大人的引導與觀察

ㄧㄨㄩ可作韻母或介音，依音節而定；不要教成永遠只能夾在中間。漢語拼音y、w的拼寫規則不適用於注音。本課不在ㄧㄨㄩ前添加英文字母，也不把英文字母當注音聲符。

一起學 06

分類小工坊

先分卡，再用例字檢查。

  1. 成人只放ㄇ、ㄅ、ㄚ、ㄠ、ㄧ、ㄨ六張卡。
  2. 找出本次的聲符ㄇ、ㄅ。
  3. 找出本次的韻符ㄚ、ㄠ。
  4. 把介符ㄧ、ㄨ放在第三張底紙。
  5. 成人出示「家ㄐㄧㄚ」，請你指出介符；不必自己拼新音。
  6. 交換角色，請成人找錯放的卡。

分類時可以說名稱，也可以只指卡。若忘記，回看前面的例子，找到後再放。

只用本頁有示範的真實字音配卡。六張卡不是用來任意組出所有可能的聲音。

給大人的引導與觀察

起步者先做形配形；穩定者分類六張；熟練者從ㄐㄧㄚ、ㄍㄨㄚ兩例指出各部分。三色可以幫忙，但仍要寫上標籤，避免孩子只能靠顏色判斷。故意放錯只作一個、立即核對，不讓錯誤模式重複累積。

一起學 07

回到整個字音

分類完成，再聽一個完整的字。

今天學分類，是為了更清楚地看和讀。最後把「媽、家、衣」三張卡重新排好，大人讀一個，你找一個。

說說看：「我在家ㄐㄧㄚ裡找到ㄧ。」你也可以指中間那張，讓成人替你說。

  1. 選一個自己會的例字。
  2. 指出其中一個符號。
  3. 說或指它屬於本課哪一組。
  4. 聽完整字音，再嘗試跟讀。
  5. 明天換卡片位置，再試一次。

想再聽清楚，請成人開啟教育部手冊的讀音表。黃色格提供符號的示範音，完整詞語可再查小字典。

給大人的引導與觀察

分類題答對不代表能拼讀；離堂分記視認、分類、整體跟讀。若能跟讀但分類術語記不住，可保留例字支持，下次再回顧。不要因此限制孩子閱讀有注音的熟悉短句。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1哪一張是本課學過的聲符？
給我一點提示

想一想媽的第一個符號。

看答案與原因

參考答案：ㄇ

ㄇ是聲符，在媽ㄇㄚ中放在前面；ㄚ和ㄧ的分類不同。

2「媽ㄇㄚ」裡，哪張卡是ㄚ？
給我一點提示

從左邊慢慢指向右邊。

看答案與原因

參考答案：第二張ㄚ

ㄚ在ㄇ後面；兩個符號一起標出媽的字音。

3哪一組是三個介符？
給我一點提示

回想「衣、屋、魚」的符號。

看答案與原因

參考答案：ㄧㄨㄩ

本課另列的三個介符是ㄧ、ㄨ、ㄩ，它們也能有其他標音用途。

4家ㄐㄧㄚ中間是哪個？
給我一點提示

找第二張卡。

看答案與原因

參考答案：ㄧ

ㄧ在ㄐ與ㄚ之間，在這個音節裡擔任介音。

5「衣」的注音是哪個？
給我一點提示

衣用一個注音符號標音。

看答案與原因

參考答案：ㄧ

衣標作ㄧ就可以，不需要補聲符或英文字母。

6魚ㄩˊ右邊的ˊ是什麼？
給我一點提示

符號和聲調有不同工作。

看答案與原因

參考答案：二聲記號

ˊ是聲調記號；它不是ㄧㄨㄩ之外的新介符。

7把媽ㄇㄚ的ㄚ換成ㄠ，成為哪個字音？
給我一點提示

開頭ㄇ沒有換。

看答案與原因

參考答案：貓ㄇㄠ

保留ㄇ、換成ㄠ，完整音節為ㄇㄠ，是貓的讀音。

8看到牙ㄧㄚˊ，應該怎麼做？
給我一點提示

不同字音的符號數可以不同。

看答案與原因

參考答案：照ㄧㄚˊ讀，不亂加符號

牙的注音本來就沒有聲符，不需為了湊三張卡而補字。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

課前診斷與定位

對應Aa-I-1。本課處理分類與位置，不替代第1課的符號認讀，也不把術語背誦當作拼讀能力。先出示媽、家、衣三張卡，由成人讀，請孩子配對。再檢查ㄇ、ㄚ、ㄧ三卡是否看得出不同。若仍需支持，先縮到媽一例。

三次教學安排

  1. 第一次25分鐘：3分鐘聽熟悉字，7分鐘對比媽與貓，7分鐘分ㄇㄅㄚㄠ四卡，5分鐘回到整音，3分鐘指卡離堂。
  2. 第二次25分鐘：5分鐘回顧，8分鐘示範家、瓜的三個位置，7分鐘加入ㄧㄨㄩ分類，5分鐘由孩子找中間卡。
  3. 第三次20分鐘：5分鐘比較衣與家，5分鐘介紹屋與魚，7分鐘分類小工坊，3分鐘用一個例字說明所學。

概念界線

聲符、韻符、介符是課綱教學項目。手冊把ㄧㄨㄩ列入韻符表，而教材常另列三個介符；兩種編排用途不同。教學時明說「這三個符號會有不同工作」，不用互相矛盾的數量斷言。ㄧㄨㄩ單獨標音時不必補聲符；注音也沒有加y或w的規定。聲符ㄓ等可單符號標音，因此避免「任何聲符都不能自己讀成字音」的絕對話。

差異化、錯誤與證據

基礎組使用兩種底紙，先從ㄇ、ㄚ辨別，再加入ㄧ；進展組用六卡分類並指家中的ㄧ；延伸組比較家與牙，說明牙沒有聲符。聽覺或口語支持需求者可看成人示範、指卡或依既有溝通方式回應，不要求強制發音。若孩子把ㄧ一律放在中間，立即出示衣，再請他自己修正說法。若把調號當成第三個符號，用較小卡分開擺。每次記錄一項可觀察結果，如「能指出家中的ㄧ，衣仍想補ㄐ」，下一次先處理這個例子。

評量包括分類六張、在一個三符號音節指出中間位置，以及辨識衣不需補前音。網頁題由成人讀，僅檢查概念，不能據此判定孩子的實際發音已正確。家中只玩3分鐘找卡；不要求背完整37符號分類或搜尋未經核對的拼合。
