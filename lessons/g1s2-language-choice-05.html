一起學 01

叫名字、模仿聲音、聽到聲景，三件事不同

先問：我收到的是一個詞，還是環境的聲音？

成人說「狗」的目標語詞，是人在使用語言，不是真狗在叫。故事寫「遠處有狗吠聲」，提供的是情境設定，也不是已播放的錄音。今天一面認動物模型，一面把來源、聲音和自己的推測分開。

原創聲景記事：早上，故事教室有人翻紙；接著老師輕敲紙盒兩下；窗外傳來動物聲，但記事沒有說是哪種。你能確定前兩種來源，第三種應留「不知道」，不能因為正在學狗就猜一定是狗。

教師協助模型條件：文字與意思或官方索引已核，不代表所有聲音／影片已完整聽看驗收。口語由具該語能力教師確認完整原音與自然示範；臺灣手語須確認完整起迄、臉和雙手及正確形式。沒有可用完整模型，先做情境理解，語言產出欄待補，不用諧音、合成音或單詞剪接替代。

只用圖片、原創文字記事和低音量安全紙物。沒有帶動物到班上、追逐、誘叫、觸摸、餵食或仿真危險叫聲；不要求蒙眼、戴耳塞或突然大聲嚇人。聽覺接收不適合者可用字幕、事件卡或視覺觀察做同等來源辨識。

一起學 02

路線A：臺灣台語，動物名不等於叫聲

狗和貓換外觀，仍是同一動物類。

教育部詞目狗，白讀káu與貓 niau已核。取動物義，不學成人引申用法，不從辭典其他例句安排追捕。詞音由教師核實完整示範；本頁沒有實際狗貓聲音播放。

  1. 成人畫狗和貓兩張大型圖並加華語物名，先確認意義，不要求從抽象簡筆猜物種。
  2. 完整聽詞找動物，換位置後再試。
  3. 換成不同毛色、大小的同類圖，檢查不是只記外觀。
  4. 孩子選一個動物詞介紹紙上動物，伙伴拿對應卡。
  5. 最後把「老師說動物名」和「故事裡動物發聲」放到不同事件格。

人可以用各種聲音模仿動物，但模仿不等於官方台語詞模型，也不能拿模仿逼孩子猜測真實動物。遇到不確定的環境聲，選不知道是合理觀察，不影響已學詞義。

一起學 03

路線B：四縣腔客語，兩個名稱各自核對

同一種動物，不同語言的名稱可以不同。

教育部客語辭典四縣欄狗 gieuˋ與貓 meu，詞義各參見同辭典狗仔／貓仔項。本課採這兩個詞目主音，不加仔尾、不混海陸或其他腔，不把華語汪、喵當成客語正式詞讀音。

教師先用大圖建立狗和貓的概念，再完整示範名稱。用兩組圖：第一組坐著、第二組躺著，詞名不隨姿勢改變。孩子當紙卡導覽員，選一張給伙伴介紹，伙伴核對名稱而不是模仿叫聲。

  1. 完整模型各配圖一次。
  2. 打亂順序，指出剛才是哪個動物名。
  3. 選一張新姿勢圖，用已學詞讓伙伴找到。
  4. 另加一張獨立事件卡「老師說出動物名稱」，說明這是本次詞彙教學的紀錄，來源是老師，不是動物；此卡不屬於開頭的三項故事聲景。

不能把同一漢字看成同一發音，也不因伙伴不同家庭腔調就說其語言較差。本課為了學習一致性固定四縣兩詞；語音回饋由具該腔能力教師提供。

一起學 04

路線C：馬祖閩東語，故事青蛙不是現場聲音

認清來源，就不會把想像當成觀察。

部編第1冊第5課唱小歌：跋落浦的原文黃蜱與官方中文青蛙明確對應。這是上冊詞義回看，本課下學期換成來源辨識與圖卡導覽，不重演歌中不安全情節、不抄全歌。

教師從原課定位黃蜱完整可用詞／語段模型，核對後帶聽；沒有驗收完整音訊就不把漢字讀成華語代替。孩子先指青蛙圖，再分「課裡的角色」「故事記事中的未知聲音」兩格。

  1. 成人畫青蛙並標華語青蛙，建立意義。
  2. 聽核實模型，選青蛙圖而非紙盒圖。
  3. 孩子跟完整模型或用圖支持介紹這個故事角色。
  4. 讀聲景記事第三項：只有動物聲，沒有青蛙證據，所以保留未知。
  5. 由孩子再加一張「故事作者補充是青蛙」卡，說明是新增文字資訊，不是自己突然聽見。

歌謠和記事可提供想像與文化欣賞，不是自然調查的錄音資料。說得出黃蜱，不表示辨識所有青蛙叫聲；語詞能力和聲音來源判斷分開記錄。

一起學 05

路線D：秀姑巒阿美語，動物名和聲音名也不同

一個詞可以指動物，一個詞可以談聲音。

官方d=2詞表核實waco^＝狗、posi^＝貓；聲音類另有lifafoy＝狗吠聲。第三項是用來指狗吠聲的語詞，不能把念這個詞說成播放真狗叫。符號按該教材保留，不按英語字母名讀。

  1. 先用狗、貓圖認兩個動物模型。
  2. 成人加一張華語情境卡「故事寫狗在吠」，用教師核對的lifafoy模型連到這個意思。
  3. 孩子把兩種動物名放在「動物」，把聲音名放在「談聲音」格。
  4. 聽一個完整詞，選狗圖、貓圖或狗吠情境卡。
  5. 獨立時換卡位置，孩子自己挑一詞介紹，伙伴確認其類別。

初學者只做兩個動物詞，第三項作教師延伸，不以一次學完為門檻。不用成人自創擬聲取代來源，也不對真狗發聲測試反應。未知聲音依然可說不知道。

一起學 06

路線E：臺灣手語，用視覺辨認動物與事件

不用先聽見，才能學會描述。

官方05動物頁的精確模型為狗及貓。索引標籤與影片URL已核，但全段播放、動作與非手部訊號未驗收；必須由具臺灣手語能力教師先確認可用模型。

孩子先完整看詞，選動物圖；觀察手和臉的具體面向由教師教，不把模仿貓耳朵或狗走路當正式手語。環境聲景改用明確事件卡：人翻紙、老師敲盒、來源未知。能讀出文字事件不等於聽到聲音，也不需要如此宣稱。

  1. 看完整狗或貓模型，配圖。
  2. 換不同毛色圖再看，維持詞義。
  3. 以教師核實詞介紹紙上動物，伙伴指出接收結果。
  4. 來源記事中有未知資訊時，使用既有溝通方式表達尚不知道；不自編「狗叫」完整手語句。

臺灣手語是視覺自然語言，不是聲音辨識的替代發音課。聽力或視覺支持需要不作公開比較；中文、圖示和完整手語的評量證據分開記。

一起學 07

路線F：越南語，名字跟圖走，不跟座位走

換一張圖，仍能找到相同意思。

國教署越南語第8冊印刷21／PDF23「語文天地」直接列chó＝狗，mèo＝貓。這是少量跨冊詞彙引用，不要求小一學原冊其他題材。完整原音由成人定位該冊數位教材，越南語教師核對，不猜地域音或省略聲調符號。

  1. 先看狗和貓兩張圖，成人確認中文概念。
  2. 完整聽chó或mèo，指出圖，再換左右位置。
  3. 孩子當動物圖書管理員，用已教詞把同類圖放一堆。
  4. 伙伴任取一張，孩子以詞或支持性指圖核對類別。
  5. 最後比對「人在說動物名稱」與「記事描述動物發聲」，知道證據不同。

這個詞表不提供每種動物的真實叫聲，本課沒有捏造或合成動物錄音，也不教未核越南語擬聲詞。成人可用既有溝通方式說明聲景記事；那是概念討論，不能全部記成越南語句能力。

一起學 08

聲景小記錄：寫下證據，也留下不知道

不必猜滿每一格，記清楚更重要。

做一張三欄紙：發生順序、已知事件、還不知道。先根據開頭原創記事填：第一項有人翻紙；第二項老師敲紙盒兩下；第三項有動物聲但種類未知。這是閱讀來源記錄，不宣稱親耳聽過。

若班級願意作現場觀察，成人可先告知將用低音量翻紙及輕敲大型紙盒，不突然發聲。孩子可選聽覺、看動作或文字事件卡接收，觀察方式各自記錄；不錄下同學談話，不要求走到窗邊或靠近動物。

  1. 各自記一項確定資訊，可畫圖或口述。
  2. 再記一項不知道的資訊，不用猜填。
  3. 選自己路線一個動物模型，完成獨立詞圖配對。
  4. 向伙伴說明「這是語詞證據」或「這是事件資料」，不是混成一件事。

即使沒聽到環境聲，也能用可接收事件資料學來源判斷；語言理解以自己的完整模型另評。沒有真實動物接觸、捕捉、餵食、長時間高音量或閉眼測試。

練習選用：共同情境與策略題可供大家練習；特定語別詞義題只作可選查閱，僅評自己選習且已教的路線，不要求完成六語，也不以混合題總分代表語言熟練。

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

新增能力

本課由動物命名進到詞、聲音名、實際／文字聲景三種證據的區別。核心不是猜叫聲比賽，而是理解本路線動物模型，並能對來源不明說不知道。開頭記事為編輯虛構，第三項刻意不給物種；正確紀錄必須保留未知。本頁沒有實際動物音檔，不能把文字題說成聽音測驗。

詞項準備

台語狗4329白讀káu、貓11905 niau；四縣狗8661 gieuˋ、貓12152 meu，各見狗仔／貓仔義項；馬祖黃蜱由第一冊上冊第5課官方中文青蛙對照核；秀姑巒d=2 waco^、posi^及延伸lifafoy狗吠聲；越南第8冊印刷21 chó/mèo；臺灣手語狗kTtleCzlrpQ、貓2slSFp-u8mM。全部固定精確來源，不把動物模仿當語詞。音訊及影片形式未全部實聽看，課前由合格教師確認完整模型。

兩節教學

第一節40分鐘：8分鐘分辨人說詞和動物發聲；12分鐘自己路線模型配圖；10分鐘換外觀與位置；5分鐘孩子做圖卡導覽；5分鐘記詞義與形式。第二節40分鐘：8分鐘讀原創記事；10分鐘將已知／未知分類；10分鐘可選低音量紙物觀察或等價視覺事件卡；7分鐘獨立動物模型配圖；5分鐘說明一項證據。詞模型播放與現場紙物活動分開，不讓聲音重疊造成辨識負擔。

差異化

初學者兩張動物圖配一詞，再增加第二詞；阿美語狗吠聲名可作延伸而非必達。熟練者用三類事件卡說明為何不能從詞義推出聲景物種。圖畫不清可加中文標籤並由成人說明，正式語言理解時教師不先揭答案。使用文字、視覺或輔具接收者，記其實際方式，不把聽不到當不合作或語言能力低。

安全及評量

不帶活體、不誘叫、不靠近動物、不做動物追捕或餵食。不蒙眼、耳塞、突發大聲或接近耳邊敲擊，紙物由成人在正常距離低音量示範，任何不舒服可停止。記一回完整模型配圖、一回獨立詞介紹、一個區分語詞／事件的理由和一項未知保留。答出不知道若符合資料應給正向回饋。語言形式由具語能力教師核實；選對概念題不替代聲音或手語的實作驗收。

共同概念題與各語詞義題分開選用，只評選習且已教路線，不要求全部語別；自動題總分不作語言熟練指標，實際理解及產出另記。
