小組遊戲與成果分享

這是可選校訂合作活動，延伸先前輪流與分享，練「一起檢查、說出怎麼改」。本課不比誰最快，也不淘汰暫時需要幫忙的人。圖卡和規則都在頁面，坐著、指卡或請成人移動都能參加。

出發前

準備好了嗎？

這一課，我會練習

  • 聽懂共同目標，依兩項規則一起安排圖卡。
  • 輪流提出理由與檢查，尊重暫停和操作方式。
  • 從本頁提供的原始排法找出問題，協商一次改動再驗證。
  • 用原方案、修改和證據分享成果，並轉用到新規則。
陪學大人：準備材料
  • 本頁四張圖卡和錯排展板圖；可由成人畫成大卡
  • 一張分成二乘二格的大紙、規則卡、粗筆
  • 乾燥平坦可及桌面；不用剪刀、繩索、投擲或競速器材
  • 可選安靜分享、成人代讀或指卡的位置

用手邊安全的材料就好。孩子可以用說、指、畫或操作表示理解，不必先會讀完所有文字。

一起學 01

先知道目標，再分合作工作

完成展板，也要讓每個人有參與方式。

原創遊戲叫《四格小展板》。桌上有四張不同的圖卡，要把它們放進四格板，每格一張，全部使用一次。小組的成功有兩件事：擺法符合規則；每個人都能用自己方便的方式參與一次提議或檢查。

四張原創大圖卡

A：黃色圓形。B：藍色圓形。C：藍色正方形。D：黃色正方形。沒有更多卡，也不需分辨深淺色。

成人可以在卡上同時寫字母、顏色與形狀，讓不便辨色者靠文字或口述參與。這裡的字母只是代號，不是英文發音測驗。先摸清規則，不抓別人的手或搶走卡。

  1. 成人逐張讀卡，全組確認四張不同。
  2. 選讀規則、提出擺法、移卡、核對的工作，可合併或輪換。
  3. 需要代移者說或指位置，由同伴先確認再移。
  4. 任何人可說「請再讀」或「先停一下」。

一起學 02

兩條規則，一張卡要同時符合

看橫排，也看直欄。

第一輪完整規則

規則一：上排放圓形，下排放正方形。

規則二：左欄放黃色，右欄放藍色。

共同約定：四格各一張，A、B、C、D 各用一次；輪到的人先提議，其他人聽完再依規則核對，不同意就說哪條不合。

成人示範 A 卡：「它是圓形，所以要在上排；又是黃色，所以要在左欄。兩條一起看，A 應放左上格。」只看圓形會有兩個位置，只看黃色也有兩個位置，合起來才找到這張的位置。

  1. 用手指或成人指示上排、下排、左欄、右欄。
  2. 先把 A 放左上，說出兩個理由。
  3. 選另一張，先說形狀決定哪排，再說顏色決定哪欄。
  4. 同伴以卡片文字核對，不用「因為我說的」當理由。

如果方向容易混淆，成人在格外標「左／右、上／下」並保持整張紙同方向。輪換座位時先重新對齊，不把看向不同方向造成的誤會說成故意搗亂。

一起學 03

供應的初稿，哪裡需要修改？

不用猜別人想法，拿規則對照。

先看顏色：左邊兩張都是黃，右邊兩張都是藍，符合規則二。再看形狀：右上是正方形，右下是圓形，這兩張不符合規則一。不用全部打散，可以提出讓右上 C 與右下 B 交換的方案，交換前先說明並聽同伴核對。

請先自己指問題格，再讀下一段。不能只說「不好看」，因為漂亮與否不是這一輪檢查的規則。

一起學 04

先提議，再移卡，再驗一次

合作不是一個人把全部做完。

原創小組對話

小安說：「我看見右上 C 是正方形，和上排圓形的規則不合。」阿米說：「我提議 C 和 B 交換。」小安先問：「交換後兩張還都在藍色右欄嗎？」阿米指給他看：「會。」負責移卡的人問大家準備好了嗎，才把兩張卡交換。

修改後的可核對排法：左上 A 黃圓，右上 B 藍圓；左下 D 黃正方形，右下 C 藍正方形。上排兩圓、下排兩方；左黃右藍；四張各用一次，全部條件都符合。

  1. 每人用說、指或選卡提出一個檢查。
  2. 聽到不同意時，請對方指出哪條規則。
  3. 確認方案後只改有必要的位置。
  4. 改完再從兩條規則重查，不以大聲或多數壓過可見的錯誤。

操作較快的人可以讀規則或等候，不必替大家完成。若不小心移錯，承認並修正；不同意擺法不等於討厭同伴，也不需要抓住別人的手糾正。

一起學 05

把成果說成一段看得懂的過程

我做了什麼，改了什麼，怎麼知道合適。

成果分享不只展示最後整齊的板，也能讓別人看見合作中的思考。保留本頁初稿圖，再用你們實際排好的紙板說三句：原本哪裡不合、做了哪個改動、如何核對。

「原本右上是 C 正方形，不符合上排圓形。我們先確認顏色還在右欄，再交換 B 和 C。現在上排 A、B 都是圓，下排 D、C 都是方，兩條規則都符合。」

再補一句分工，可用角色說「有人讀規則、有人指問題、有人移卡、有人重查」，不用把同伴的姓名、照片或聲音放上網。分享前問小組是否願意展示作品；有人不願出聲，可指圖、請成人代讀或只聽。

  1. 選初稿的一個錯誤格作起點。
  2. 指出實際改動，不說沒發生過的合作。
  3. 讓聽者用兩條規則現場核對。
  4. 選一個下次想改的合作方式，例如留更長等待時間。

一起學 06

給有用的回饋，下一輪才改得動

說看到的事，再提一個具體建議。

三張回饋卡

甲：「你們很差。」沒有指出哪裡或怎麼改。

乙：「我看見你們交換前先問大家；下一輪可把規則卡放近一點，坐後面的也看得到。」有具體觀察與可試建議。

丙：「一定要讓最快的人一直移卡。」忽略其他人的參與。

請選一張較能幫小組改進的回饋，再照它的方式說一則真實發生在本次操作中的事。不確定有沒有發生，就先問或描述現在看得到的排法，不編同伴的表現。

收到乙卡的人可回：「我們願意試把卡移到中間。請你再看是不是清楚了。」回饋不是命令；不舒服或不適合的建議可以和成人討論，提出另一個方法。

  1. 說一件具體觀察，不評論人格。
  2. 提出一個小而能做到的建議。
  3. 小組選是否試用，說明理由。
  4. 真的重試一次，看看改善的是哪件事。

一起學 07

第二輪換規則，自己檢查一次

同樣四張卡，也會有新排法。

獨立轉用的完整新規則

仍用 A 黃圓、B 藍圓、C 藍正方形、D 黃正方形，各一張。

新規則一：上排放藍色，下排放黃色。新規則二：左欄放圓形，右欄放正方形。每格一張，各卡只用一次。

先不看核對答案，小組自行討論、排卡並用兩項條件檢查。這次輪換工作，讓之前沒移卡的人可以選操作或指示他人移動。不是把第一輪完成板原樣搬來。

完成後再核對

新排法是左上 B 藍圓、右上 C 藍正方形；左下 A 黃圓、右下 D 黃正方形。上藍下黃、左圓右方，每張各一次。若不合，先指出哪條，再提出最小的合理改動，不重貼人的好壞標籤。

最後說：「第二輪和第一輪的規則哪裡不同？我們怎樣確定這次也完成？」收回四張卡、整理桌面。沒有輸贏排行榜；能把規則、理由、分工與改進說清楚，就是值得保留的成果。

想一想，再試試

換我試試看

不急著猜答案。可以請大人念題目，先說出你的想法，再選一個最合適的答案。

已嘗試 0／8 題。做錯也能再試。

1第一輪 A 黃色圓形要放哪裡？
給我一點提示

同時檢查形狀和顏色。

看答案與原因

參考答案：左上格

圓形要在上排，黃色要在左欄，合起來是左上。

2初稿圖右上放的是哪張？
給我一點提示

先讀圖與等價文字，不直接猜完成答案。

看答案與原因

參考答案：C 藍正方形

實際供應的初稿右上標 C，圖形為藍色正方形。

3第一輪初稿主要是哪條規則不符合？
給我一點提示

先各檢查一次兩條規則。

看答案與原因

參考答案：上排圓形、下排正方形

顏色欄與使用次數都符合，右側上下兩格的形狀顛倒。

4哪個修改能修正第一輪初稿？
給我一點提示

想想怎樣保留已正確的顏色欄。

看答案與原因

參考答案：交換右上 C 與右下 B

B、C 交換後上圓下方，且兩張仍留在藍色右欄。

5同伴提出不同擺法，較好的回應是？
給我一點提示

合作的依據是條件，不是誰較強勢。

看答案與原因

參考答案：請他指出符合哪條規則，再一起核對

以明確規則討論才能核對方案，也尊重同伴身體與意願。

6哪張回饋卡較能讓小組改進？
給我一點提示

找看得見的事和可做的下一步。

看答案與原因

參考答案：乙：說明先詢問的行為並建議把規則移近

乙有具體觀察與可試建議，能改善可及性而不批評人格。

7第二輪上排藍色、左欄圓形，左上是哪張？
給我一點提示

這次已換規則，不能照抄第一輪。

看答案與原因

參考答案：B 藍圓

新規則左上同時要藍色和圓形，只有 B 符合。

8哪種成果分享最完整？
給我一點提示

讓聽者知道為什麼這樣改。

看答案與原因

參考答案：說原本哪格不合、改了什麼、怎麼核對

交代問題、修正及證據，聽者才能理解合作與思考過程。

陪學大人專區

給陪學大人的教學指南

先看孩子的起點，再決定今天走到哪裡。以下是可調整的原創教學示例。

展開完整教案、引導語與觀察重點

課程定位與準備

本課是可選校訂合作例，新增雙條件排卡、診斷局部錯誤、協商最小修正、過程型分享及新規則轉用。A 黃圓、B 藍圓、C 藍方、D 黃方，四張均有文字與代號；圖卡可由成人畫在大紙，沒有小零件、競速、投擲或身體接觸。桌面平坦乾燥、材料在每人可及範圍；精細動作不便者指示他人移卡，一樣能作決策。不以「移卡多」當成貢獻較大。

第 1 次：規則與初稿，30 分鐘

0–8 分認識四張卡、共同目標及可選工作；8–18 分示範 A 同時符合上排圓形、左欄黃色；18–25 分讀初稿，先核對顏色再核對形狀；25–30 分孩子各提出一個有規則依據的發現。成人先確認上／下排、左／右欄方位，不旋轉紙板造成混淆；辨色困難者直接讀卡上的色名。

第 2 次：協商、修改與分享，30 分鐘

0–10 分讀小組對話，練先提議再確認；10–18 分交換 B、C 並驗全部條件；18–26 分以初稿、修改、證據三句分享；26–30 分讀回饋卡並選一項可試建議。不要成人直接拿走卡完成答案；若意見分歧，請雙方把方案對到規則。看見快手包辦時，安排其讀規則或核對，保留他人的決定機會。

第 3 次：新規則與獨立驗證，30 分鐘

0–5 分明確收起第一輪規則，讀第二輪上藍下黃、左圓右方；5–18 分學生自行排，成人只重讀而不指答案；18–25 分各說一個位置為何符合兩條；25–30 分比較前後合作方式並整理。第二輪正確序列為上排 B、C，下排 A、D。若拿第一輪排法照抄，讓學生逐項核對新規則找差異。

差異化、迷思與評量

支持較多者一次只核對一張卡的兩個條件，成人可代移但不代決定；熟練者說明只看顏色為何仍有兩個候選格，或設計另一組可清楚核對的條件，成人先驗合理性。把漂亮當正確者回看條件；把多數同意當必然正確者用圖卡檢驗；把安靜當沒參與者觀察指卡、檢查與等待。評量分規則理解、合作溝通、修正驗證與過程分享四項，記獨立、提示後或共同完成。選擇題之外必看第二輪擺法與一個理由。分享可只對成人或用口述代讀，事前確認展示意願，不錄音拍照、不公開姓名；需要安靜或暫停者有等價參與方式，不以退場淘汰處罰。
