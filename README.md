# elementary

臺灣國小六年課綱主題地圖。延續卡片式首頁，以小一到小六、上／下學期呈現課程範圍，供先了解內容使用；不含完整教案、課文、題庫或解答。

## 資料界線

- 課程類別、學習階段、節數及領域能力架構依十二年國教官方課綱（含111學年度語文調整）。
- 十二學期的主題是跨版本參考編排，並非教育部規定的全國統一單元表。數學的年級內容與多數領域的兩年學習階段，也不能直接當作官方學期進度。
- 一、二年級以生活課程統整；三年級起分列社會、自然科學、藝術、綜合活動並有部定英語文。
- 本土語文／臺灣手語／新住民語文為依意願選一語別，各語別依課綱與程度安排；主題清單不是要求每人全部修習。
- 校訂彈性列舉可能的主題，不代表每校必開。跨領域19項議題不是額外19門部定必修。
- 本站是原創中文摘要，並未逐字重現所有「學習表現／學習內容」指標。完整官方文件與公開編排實例均可從卡片及來源目錄查看。

## 結構與維護

- `curriculum.json`：資料清單、核對日期、全站範圍說明
- `data/sources.json`：共用來源，標示官方框架或編排實例及使用範圍
- `data/framework.json`：三階段、各領域學習表現／內容摘要、核心素養及議題
- `data/semesters/grade-1.json` 至 `grade-6.json`：每年兩學期的課程卡與主題
- `scripts/build.mjs`：將全部資料預先生成為 `index.html`
- `app.js`：純原生 JavaScript，年級、學期、類型、科目及關鍵字篩選
- `tests/fixtures/approved-grade1-semester1.json`：原核定小一上內容的回歸測試基準

每張課程卡有 `sourceIds`；來源支持課綱範圍或提供編排例，不能被理解成所有主題在所有學校都於同一學期教授。更新時請核對來源並保留這個區分。

## 建置與測試

需要 Node.js 20 以上，建置與一般測試不需安裝套件。

```sh
npm run build
npm test
npm run serve
```

用瀏覽器開啟 http://localhost:8080。`index.html`、CSS、JS 與圖檔可直接部署至 GitHub Pages；不需要後端、外部字型、分析追蹤或第三方執行時依賴。

實際瀏覽器測試另外需要 Playwright 與可啟動的 Chromium：

```sh
CHROMIUM_PATH=/path/to/chromium npm run test:browser
```

若執行環境限制瀏覽器或 socket，這項測試須在支援的環境執行，不能把靜態或 DOM 模型測試視為實際畫面驗證。

## 網址與無障礙

- `#g1s1`：小一上；`#g6s2`：小六下
- `#g5s1?subject=mathematics`：小五上數學；網址亦可記錄類型與查詢字串
- 切換時使用瀏覽器 History，返回／前進能還原選取；不寫入本機儲存
- 每個學期與主題均預先存在 HTML。停用 JavaScript 時顯示全部十二學期與跳轉目錄
- 原生 button、select、details/summary、鍵盤焦點、即時結果數、減少動態效果與333px手機版面
- 列印目前篩選結果時展開可見卡片，列印後還原；每張卡保留來源

## 人工驗收清單

1. 六年上下學期各切換一次；低年級每學期6卡，中高年級10卡。
2. 切換後按返回／前進；直接開啟六下網址再重新整理。
3. 測試部定／校訂、科目與搜尋的交集；無結果後重設。
4. 以鍵盤操作年級、下拉選單及卡片；查看焦點清楚且內容對應。
5. 333px、390px、768px及桌機檢查橫向溢位、長標題、展開內容與來源連結。
6. 關閉 JavaScript，確認十二學期皆可跳轉與展開；查看列印預覽。
7. 查看三階段架構、語文選習差異及19議題說明，確認未把參考學期當成全國法定進度。
