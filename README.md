# elementary

台灣國小課程主題地圖。先從**小一上學期**開始，用課程卡片整理主題，目前不包含教學內文、練習題、解答或教材全文。

## 目前範圍

- 6 類課程、95 個整理主題；數量包含校訂示例與依語別展開的方向，不代表每位學生都需修習 95 項。
- 部定課程：國語文、數學、生活課程、健康與體育。
- 部定語文選習：本土語文／臺灣手語／新住民語文，依意願選一語別。
- 校訂彈性學習：閱讀、英語啟蒙、議題與學校特色等示例，依各校安排。
- 低年級的社會、自然科學、藝術與綜合活動由生活課程統整，未拆成四個獨立必修科目。
- 小一英語不是全國部定必修。小一下及二至六年級的入口目前停用並標示「規劃中」。

依十二年國教（108 課綱體系，含 111 學年度起的語文調整）整理。課綱多以學習階段規範，數學另有年級內容；**本網站不是全國統一的上學期章節表**。主題名稱為原創歸納，實際課名、進度與取材請以學校課程計畫及教材版本為準。公開學校計畫僅作實例。這不是教育主管機關官方網站。

## GitHub Pages

這是無套件依賴的靜態網站，不需要資料庫或建置服務。

1. 將本專案檔案（保留 assets、scripts、tests 資料夾）提交至 elementary 儲存庫的 main 分支根目錄。
2. 在 GitHub 的 Settings → Pages 選擇「Deploy from a branch」。
3. 選擇 main 與 / (root)，儲存後等待 Pages 部署完成。
4. 確認部署成功後開啟 https://bstzeng.github.io/elementary/ 。

所有本機資源都使用相對路徑，適合 GitHub Pages 的儲存庫子路徑。`.nojekyll` 停用不必要的 Jekyll 處理。不需要把 review 截圖或本機暫存檔放上網站。

## 維護資料

- `curriculum.json`：課程、主題、分組、語別選項、課綱來源、範圍註記。
- `scripts/build.mjs`：將 JSON 產生為完整、可直接閱讀的靜態 `index.html`。
- `app.js`：搜尋、部定／校訂篩選、展開清單及列印輔助。
- `styles.css`：響應式、鍵盤焦點、減少動態及列印樣式。
- `assets/`：本站原創 SVG 插圖、課程主題視覺與 favicon。

更新 JSON 後執行：

```sh
npm run build
npm test
```

並將 JSON 與重新產生的 HTML 一起提交。主題 ID 需全站唯一；每門課的 sourceIds 需對應 sources 中的 ID。不要只更動 `index.html`，下次建置會覆寫。現有建置以六類課程為範圍，擴展年級時需同時新增資料與導覽功能，不能只解除停用按鈕。

## 本機預覽與檢查

需 Node.js 20 以上執行建置／測試；靜態網站本身不依賴 Node.js。

```sh
npm run serve
# 開啟 http://localhost:8080
npm test
```

`npm test` 為無外部套件的靜態檢查及 DOM 模型互動測試，驗證主題數、ID、來源引用、本機連結、分類、文字安全、搜尋、篩選、狀態恢復與焦點行為。它不是瀏覽器視覺測試。

另提供 `tests/browser.mjs`，供已有 Playwright 與 Chromium 的環境使用：

```sh
npm run test:browser
# 若使用系統 Chromium，可設定 CHROMIUM_PATH=/path/to/chromium
```

瀏覽器測試檢查 333 / 390 / 768 / 1280px 版面溢出、搜尋與重設、篩選、鍵盤展開／收合、列印恢復、減少動態和停用 JavaScript 的備援，並將實際截圖存入 `review/`。瀏覽器需有啟動本機程序與連線的執行權限。未安裝瀏覽器或受限環境不可把測試未執行當作通過。

上線後亦應檢查：搜尋「口腔」顯示 1 個主題；「部定課程」顯示 5 類／85 個主題；「校訂彈性」顯示 1 類／10 個主題。所有 95 個主題都直接存在 HTML，停用 JavaScript 仍可用原生 details 展開閱讀。
